## Attempt 1: concrete finite-module Build/Open

Let F=F_q. Publish d-by-d *commuting idempotents* P_i, with P_i^2=P_i and P_iP_j=P_jP_i, representing the Boolean quotient F[z_1,...,z_n]/(z_i^2-z_i). Let V_x be the arithmetization of the COMPLETE original source-admission circuit (a hypothetical exact compiler, NOT implemented by this experiment), and Q=V_x(P_1,...,P_n), so Q^2=Q.

A candidate scalar toy Build_mod samples independent uniform rho in F and publishes

    C = sigma*Q + rho*(I-Q),  P_1,...,P_n, Q, x_W, public checking data.

Open_mod on witness w forms E_w=product_i(P_i if w_i=1 else (I-P_i)). If w is an *original qualifying* witness AND E_w != 0, then Q E_w=E_w and C E_w=sigma E_w. Divide any nonzero coordinate to recover exactly the same sigma. For given d,n, Build/Open algebra is classical polynomial-time. The scalar toy sigma is NOT a native PQ signature. Only *supported* witnesses can open; no actual source compiler supporting every future header/coinbase/ancillary proof is supplied.

**Unconditional spectral-support lemma:** E_w E_v=0 for w!=v, and each nonzero E_w has rank >=1. Hence at most d different Boolean witnesses have E_w !=0. Literal every-witness completeness in this family therefore requires d at least the number of distinct admissible original source witnesses. For unknown future Bitcoin parent headers/AuxPoW, no polynomial bound, representation, or ability to build that support has been established. The mere existence of a small capsule does not solve this.

**Public extraction without adversary-supplied representation:** If Q!=0, set T=Q. Iteratively choose w_i=0 and T:=T(I-P_i) whenever the latter is nonzero; otherwise choose w_i=1 and T:=TP_i. Every step retains T!=0, so the resulting public character w satisfies V_x(w)=1. If V_x were the ACTUAL original source relation, this would publicly find an actual certificate already in the matrix support, independently of an adversary's representation or quantum query log. Furthermore C Q=sigma Q, exposing sigma algebraically whenever Q!=0. When the complete Boolean relation is FALSE, Q=0 and C=rho I, independent of sigma *as a matrix*; no claim is made about correlated real VKs, sibling capsules, malicious setup or native forgery.

Consequently the family has exact supported-witness convergence and a limited FALSE-case simulation, but neither arbitrary-future-source completeness nor hidden release tied to evidence not already retrievable from the static module.

## Repair attempt 1: compact symbolic circuit, off-domain failure

To avoid one spectral dimension per supported witness, publish an ordinary arithmetic circuit C(z)=rho+(sigma-rho)V_x(z). This has no built-in constraint that raw public evaluation use Boolean coordinates. Explicit FALSE example: V(z)=z(z-1) vanishes for both Boolean values 0 and 1, but V(2)=2 over F_257. Anyone evaluates C(0)=rho, C(2)=rho+2(sigma-rho) and obtains sigma=rho+(C(2)-rho)/2, without a source witness. A Boolean guard in honest Open is irrelevant to raw public evaluation. Commuting idempotents force V(P)=0 and close *this* non-Boolean route, but reinstate the support and public extraction issue. This does not show every succinct cryptographic encoding is insecure.

## Repair attempt 2: randomized-frame linear branching programs

For a read-once *linear-output* source-verifier program T_{i,b}, privately randomize each intermediate basis R_i, publish M_{i,b}=R_{i-1}^{-1} T_{i,b} R_i, u=e_start R_0, v=R_n^{-1}(sigma e_accept). Public multiplication telescopes: u product_i M_{i,w_i} v = sigma V_x(w). Both matrices for each bit are public, however; this is not a source-secret label-delivery mechanism.

For read-once inputs, define suffix spaces S_n=span{I}, S_i=span{ M_{i,0}S,M_{i,1}S : S in S_{i+1}}. They have dimension <=d^2 and can be constructed by public Gaussian elimination in polynomial time. If there exists any input with nonzero public linear output, greedily retain a prefix whose pairing with some suffix-basis element stays nonzero. This synthesizes a matching input. If V_x is exactly the source relation, any such polynomial-size transparent read-once matrix program would publicly synthesize an original witness. The lemma does NOT apply to repeated-variable programs or arbitrary nonlinear hash-garbled output.

**False instance with repeated source bit:** A single original bit x occurs twice. The first occurrence requires x=0; the second requires x=1. There is no consistent ORIGINAL witness. Nevertheless public raw transition matrices allow independently choosing occurrence values (0,1), giving sigma, while both consistent choices (0,0) and (1,1) give zero. This is a direct FALSE-state release by a classical adversary. Random invertible intermediate bases do not change it. Requiring identical bits in honest Open is bypassable. A deterministic finite automaton that stores an arbitrary n-bit first half in order to check exact equality with the second half requires 2^n states, but this is NOT a lower bound for randomized fingerprints, cryptographic consistency checks, or other algebraic encodings. Such an alternative must enforce global consistency *inside raw release* without enabling fabricated source input choices.
