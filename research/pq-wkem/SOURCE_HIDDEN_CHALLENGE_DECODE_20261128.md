## 1. Explicit source-response availability

Let R(x,w) denote the unchanged complete finite original predicate (all three independent OR grounds, authentic relevant histories, claim binding, maturity). Reuse the prior Hamiltonian-cycle semantic reduction and its two-challenge proof only as an off-chain representation; not as a practical verifier or new source policy. For each i, Build commits to a random permutation of the public graph G_x with hash commitments. Publish the entire challenge-zero opening Z_i0 (the permutation and all edge commitment openings). Anyone with any valid original w can calculate a cycle and hence Z_i1(w), a challenge-one opening of a Hamiltonian cycle in the same committed graph. This is an explicit public algorithm. Given Z_i0, an explicit accepted Z_i1 yields the actual source certificate by the reverse reduction (or a commitment collision). It does NOT follow that an adversary producing a key must also output such a response.

Build samples c uniformly from {0,1}^t, and publishes E=sigma_cancel XOR H_mask(ctx,c) (domain-separated expanded mask as needed). To make it possible to validate a decoded c without relying on the known native message/VK, give the candidate a public domain-separated hash image Y=H_check(ctx,c). The desired additional material T must allow a receiver with all Z_i1(w) to recover c in classical PPT; the receiver with only Z_i0 must not do so in full public view. This avoids assuming an online prover or an independent native puzzle as the *solution*. Y by itself is just an independent puzzle, not a source gate.

## 2. Local response selector and adaptive attack

Attempt T as independently generated response-verification hints, one for each hidden bit c_i. Suppose public Test_i(T_i,b,z) returns accept iff b=c_i AND z is an accepted source response to b for A_i. Grant this functionality even before considering how its serialized hash-only implementation hides c_i. The public zero responses are valid for EVERY i even for false x. The straight-line attack is

    c_i = 0 if Test_i(T_i,0,Z_i0) accepts, otherwise 1.
    sigma_cancel = E XOR H_mask(ctx,c).

It needs no positive response, no source evidence, no label splice, no internal state supplied by an adversary. This also defeats a noisy test if, on the public zero response, the two c_i distributions have efficiently distinguishable outcomes and independently resampleable tests can amplify that distinction. The exact deterministic variant is already enough to reject the proposal without fixtures. Ordinary accept/reject observability is not a harmless auxiliary interface.

Try the asymmetrical repair Test_i that always gives the same output on Z_i0 regardless of c_i, and permits a receiver with Z_i1 to distinguish c_i. In an ideal black-box functionality this is correct and hides the bit from a caller restricted to zero responses. For a real serialized T_i, however, the two cases c_i=0 and c_i=1 must be computationally indistinguishable without a genuine source witness while a public operation on ANY such witness distinguishes them. This is already a one-bit source-conditioned encryption problem, with the entire original relation, not an independent hash assumption.

For an actual hash-only implementation try encrypting c_i by H_mask(ctx,i,Z_i1). Build does not know a cycle, and Z_i1 differs across valid witnesses (even with one fixed first message). Publishing a correction for each possible cycle is not PPT in general. The complete public Z_i0 contains every edge opening individually, so a key derived just from one of those openings is not private. Hashing a complete cycle is computable by the authorized receiver, but Build lacks that cycle. A public normalization of all Z_i1 to a known scalar allows direct computation of that scalar; requiring a canonical cycle instead changes every-witness completeness unless a polynomial canonicalization is actually constructed. A secret normalization rule is not an implementation. The missing operation for this repair is the public evaluation and full-view simulation of the asymmetric decoder itself. Do not implement it as a hypothetical function.

## 3. Global equality repair: an explicit decoding experiment in equations

Try hiding all local comparison outcomes, leaving a single public equality test on the whole vector. The candidate interface takes arbitrary b in {0,1}^t and matching accepted responses for all i, returning the same failure symbol unless b=c, then returning c (or the actual payload). The positive responses are globally source-authenticated; no intermediate wire labels are exposed. The candidate intended honest algorithm uses Z_i,b_i to search for the secret vector.

Even granting an ideal equality interface to the receiver with a genuine witness, the receiver's access to every response gives exactly the ability to test all candidate b, not a decoding shortcut. In the idealized experiment in which c is independent uniform, source transcripts are independent of c, and the ONLY c-dependent access is this equality oracle (no T bytes, E, or checking-key leakage in this restricted experiment), any adaptive classical q-query decoder succeeds in recovering c with probability at most (q+1)/2^t. Proof: condition on transcripts and decoder coins; along the all-negative path its q tested strings and its final unqueried guess are fixed independently of c. Only those at most q+1 strings can give success. The proof allows arbitrary dependence of the query responses on w, because all those source response computations are independent of c. This is a restricted correctness diagnosis, not a QROM or concrete SHA security theorem and not a lower bound for arbitrary public T. The actual capsule's public bytes and native verification data are additional interfaces; they cannot be assumed simulatable by equality access without a separate proof.

If t is small enough for honest exhaustive search, public Y allows the unauthorized receiver to exhaust the same challenge space independently of source responses. If t is large enough for the intended hash-only secret entropy, the equality-only honest search is not PPT. Thus this particular search algorithm cannot be the original release mechanism. Returning a masked value only upon a successful comparison does not improve it. Returning informative partial comparisons to enable decoding requires a separately implemented source-dependent asymmetric decoder; any partial comparison observable on public zero responses returns to section 2. A correlated global representation of T could in principle permit a valid-source-specific decoding shortcut, but no such representation was found. The equality test was granted only to diagnose the proposed repair, not claimed as a constructed public cryptographic gate.

## 4. Full-view simulation obligation and next selection

Source first messages and zero responses are simulatable by simply reproducing their honest sampling without a source witness. Neither that fact nor deterministic extraction from an explicit positive response simulates T correlated with c, E, Y, native VK/message, auxiliary inputs, related capsules and malicious source randomness. The local selector fails even for FALSE; the asymmetric local selector requires the desired one-bit source-conditioned encoding; the globally hidden equality repair lacks practical classical honest decoding. No arbitrary QPT key recovery/accepted native forgery reduction, including same-message changes, is obtained.

Do not repeat this variant with more repetitions, a different challenge code, an alternate proof compiler or more hash domains. A viable next candidate would need a concrete *non-equality* decoding operation where original evidence supplies a trapdoor not already computable from all public zero-response openings, and Build computes the correlated public bytes without any future evidence. Analyze arbitrary public use of those bytes and construct the simulator jointly. Source-specific fixed commitments may be examined only if the operation applies to every witness on EACH independently sufficient original ground, including future competing histories, not just a known burn path. If no such correlation is supplied, do not grant it as a primitive. No generic impossibility is asserted.
