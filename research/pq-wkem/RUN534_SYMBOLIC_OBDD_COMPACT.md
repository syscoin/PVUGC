# Run 534 — symbolic OBDD release-frontier recovery

Research-only, draft PR syscoin/PVUGC#1, branch research/pq-wkem-validation-20260918, starting SHA e93b727429f02adc6110c2ac89794629b9f1cb94. Verified predecessor Run 533 note Git blob 58b1ae695eb40e0b382aed12c49f043efc7fc933. No production change.

**Exact theorem.** Honest classical-PPT setup/evaluation, arbitrary-QPT attacker, full public checking keys/auxiliary views. A public terminal takes a freely selectable ell-bit input s (possibly including exposed random-tape bits), and produces a protected h-bit seed K for any input in a nonempty success set G; outside G its output is a *public fixed failure baseline* B. All h complete output-bit functions F_i(s) are independently accessible as actual ordinary public OBDDs of sizes S_i. Then K_i = B_i XOR Exists_s(F_i(s) XOR B_i). If K_i=B_i the opposite leaf is impossible. Otherwise nonempty G supplies an opposite leaf. Reachability in an OBDD is O(S_i), so all K is recovered in O(sum_i S_i), independent of 2^ell. If K != B, a single opposite-leaf path yields a successful public input as well. If K=B, K was public already. This is capability recovery, not just an ideal-mixer distinguisher. With explicit public terminal randomness u, include u among OBDD variables; positive correctness guarantees a success path.

**Conditional source consequence.** If every successful s publicly extracts to an ORIGINAL R(x,w)=1 witness, graph traversal also finds such a witness in polynomial time on true instances, inconsistent with independently assumed hard ORIGINAL search unless that assumption fails. If successful s falls outside the source-extraction scope, its authorization is a source bypass. Run 259 only binds actual accepted complete representations under its precise residual and SIS conditions; arbitrary terminal inputs do not automatically qualify. The theorem does not attack false-instance key hiding, native SLH signature soundness, or Bitcoin settlement logic.

**Scope/negative controls.** The fixed known failure baseline, independently inspectable *complete output* OBDDs and freely selectable raw inputs are essential. Unconstrained junk outputs can make per-bit maxima unrelated to K; 80/80 checker controls demonstrate failure of that extrapolation. EOC/RIO literature uses **per-chip** polynomial OBDDs within a correlated encoded-state composition, not necessarily a small OBDD for the final release bits. No claim breaks those compositions, arbitrary nonlinear mixers or quantum-security assumptions. A public success flag with a small OBDD independently permits a successful-input traversal. No new hardness assumption.

**Primary literature.** Chamon–Jakes-Schauer–Mucciolo–Ruckenstein, arXiv:2203.08876, Sec. 2.2, Theorem 2.2, Assumption 2. That paper explicitly cautions that whole-evaluator OBDDs may have exponential size. Its conditional per-chip security is NOT certified or refuted here. https://arxiv.org/abs/2203.08876

Both pass 80/80 junk-output controls, input lengths up to 2048 bits, maximum 4098 shared OBDD nodes, and byte-identical reruns. These toy BDD tests do not implement a general hard NP witness, LWE/SIS, native SLH or a secure KEM.
