**Narrow exact counterexample.** On three wires set `A=CNOT(0->1)`, `B=CNOT(1->2)`, `C=CNOT(0->2)`. As reversible transformations, `ABAB=C`, hence the five-gate sequence `ABABC=I`. The empty circuit and `ABABC` are both identity permutations on all 8 inputs, but have opposite gate-count parity. A local mixer whose only moves are (i) commuting adjacent commuting gates and (ii) inserting/deleting adjacent identical involution pairs `GG` preserves both functionality and gate-count parity. Thus these two implementations of the same permutation lie in different connected components of **this particular** rewrite graph.

If a proposed *representation-based* release frame encodes secret bit `k_i` by choosing empty identity for 0 and `ABABC` for 1, then applies only these local moves, an outsider reads `k_i = (#published gates mod 2)` without a witness or release call. Independent frames leak all key bits. This falsifies **this encoding and move family**, not the actual CCMR/RIO/CLZ transformations. Adding a length-5 identity rewrite destroys this specific fingerprint. The source-authentication gate and native signing endpoint are not implemented. No protected release compiler or QPT hiding is claimed.

**Known conditional complexity obstruction, precisely scoped.** If a sound, polynomially checkable reversible local rewrite system connected *every* pair of strongly equivalent arbitrary reversible circuits of polynomial input size with a polynomial-length path and polynomial intermediate descriptions, strong reversible equivalence would be in NP (guess/check the path). Jordan established coNP-completeness of strong equivalence for Toffoli/Fredkin-type universal reversible circuits; the hypothesized universal rewrite connectivity would imply `NP=coNP`. Chamon–Ruckenstein–Mucciolo–Canetti independently discuss this fragmentation principle. This is **existing** complexity literature, not a new complexity theorem. It does not rule out efficient mixing within a restricted small release-circuit family, or RIO obfuscation under additional assumptions.
