## Serialized candidate and extension

Take a deterministic bounded Boolean circuit for the unchanged complete R(x_W,w). This is a symbolic compiler for that circuit, not a new implementation of the live source verifier. Encode bounded canonical original w injectively, including lengths and domain where required. Introduce a Boolean variable for each wire, including acceptance output r. For each gate with inputs u,v and output t create a finite row variable with domain consisting of the at most four tuples (a,b,g(a,b)) in its truth table. Connect it by binary compatibility tables to u,v,t: a row is compatible with precisely its corresponding coordinate. Unary gates/constants have the analogous smaller domains. Include the unary condition r=1, with no alternate admission rule.

Build samples K uniformly in {0,1}^lambda. For each bit i append a polynomial-size deterministic circuit A_i(w) (e.g. bit i of a domain-separated hash of the complete canonical witness), with designated Boolean wire a_i. Append a two-input gate with inputs a_i,r and Boolean output b_i, whose table is b_i=a_i XOR (K_i AND r). Use the same number and types of CSP variables and same domain sizes for either bit. In particular a_i need not be constant across valid source histories. Append this gate via the same row-variable conversion.

Independently permute CSP variable IDs and row-domain labels. The two Boolean domain values can also be independently permuted on every wire except marked a_i,b_i (or publish their decoding bijections). Translate compatibility tables accordingly. Publish the complete shuffled unary and binary constraints, ordered marked pairs, a map from source input positions to wire IDs and their Boolean decoding bijections, canonical context, and E = sigma_cancel XOR KDF(ctx,K,len(sigma_cancel)). No internal circuit-to-CSP map is published, and no hidden map or secret evaluator is needed in honest Open.

Define propagation AC as the following deterministic algorithm: repeatedly delete a domain value for which some adjacent binary compatibility table has no compatible value in the adjacent variable's current domain; stop at a fixed point or an empty domain. Apply unary restrictions and optional externally supplied pins before propagation. This is classical PPT in the serialized CSP size: each nontrivial pass deletes at least one value; finite domains here have size <=4. Any full satisfying assignment consistent with the pins survives every deletion, by induction, irrespective of variable permutation or row-domain relabeling.

Open pins every source-input variable to its value from w and runs AC. For an accepted original w, its full circuit trace and gate rows give a satisfying assignment. In a topological induction, when all predecessor domains of a gate are singleton, incompatible rows are deleted and exactly the correct row remains, forcing the output wire to a singleton. The acceptance unary condition is consistent with this trace. Thus all marked colors are recovered in classical PPT, including without the hidden wire-to-gate map. Decode K_i=a_i XOR b_i and decrypt E. Every qualifying original w gives the SAME K, independent of its nonconstant a_i values. The capsule size is polynomial. This is all-witness correctness of an explicit symbolic candidate, not security. No post-recovery honest-code signature or R check is credited as enforcement.

## Complete-public attack without source input or internal map

The attacker does not supply an alleged original trace and never pins the original input positions. For each marked pair i, run AC four times, with just the two marked variables pinned respectively to (0,0),(0,1),(1,0),(1,1) in their public Boolean encoding. For any pair violating a XOR b=K_i, the gate connecting these marked variables to r has no allowed row compatible with all three singleton domains, because r is already forced to 1 by the capsule. AC necessarily detects an empty domain, regardless of secret variable IDs, hidden gate names, source validity of any partial trace, other gates, or mask complexity.

On a TRUE instance, fix any accepted original w ONLY in the analysis. Its full satisfying assignment survives the AC run with the corresponding two pins for each i. Therefore at least one of the four runs per bit has nonempty domains, and EVERY nonempty run has a XOR b=K_i. Read K_i from any surviving run, reconstruct K and recover sigma_cancel from E. The algorithm is deterministic classical PPT on the entire public capsule. It does not find the original w and does not receive any adversarial representation, proof transcript, query log or private map. The argument does not assume either possible value of a_i occurs among valid witnesses; one surviving pair suffices. On FALSE instances all four runs might fail for some bit, so no general FALSE attack is claimed from this argument.

This attack also covers the variant that replaces the two-input terminal gate by a disjoint constant-size CSP gadget in which wrong pins make the local constraints unsatisfiable when r=1, if the local gadget can be identified and exhaustively eliminated, or if the gadget's internal propagation detects the contradiction. It does NOT claim every arbitrary small gadget is arc-consistency complete. Merely using randomized labels, larger source circuits, more hash rounds before a_i, or another color alphabet does not repair the specified candidate.

## Repair attempt: diffusion between marked vectors

To remove the two-pin contradiction, try replacing the bitwise terminal with two marked vectors A,B and a public polynomial-size nonlinear circuit D, using B = D(A) XOR (K AND r), with the AND applied bitwise. A comes from the complete source trace. Keep r=1, shuffle all CSP IDs and do not publish the internal circuit map. Open still has an explicit polynomial extension algorithm by the same topological induction, and obtains K=B XOR D(A). The previous four-run argument is not immediately applicable to the two EXTERNAL marked bits: pinning two bits need not propagate through D to its other output/input positions, and a single marked vector can have exponentially many feasible values.

However, if the internal vector U=D(A) is publicly identifiable (for instance because the compiler publishes its mapping, or the terminal row tables can be identified from public structure), pin U_i and B_i instead of A_i and B_i. The exact same four-run attack works, no matter how hard D is to invert and without choosing a feasible A vector. Thus a repair cannot expose the internal decoding boundary. A caller evaluating a fully disclosed downstream gate map with independently assigned U and r would also read the local relation directly; a requirement to first verify an authentic source is not cryptographic enforcement.

A public hash of each internal wire ID with a fresh secret salt does not supply the missing protection: if the salt is published, it reconstructs the map; if withheld, the shuffled CSP itself still contains all labeled adjacency and compatibility tables and the full extension proof has not shown that locating U is hard. Using a hash of the whole witness as the salt makes Build unable to serialize one fixed graph unless it supplies the witness-blind namespace compiler already missing in the preceding note. Do not assume a secret map is hidden simply because it was not serialized explicitly. Conversely no universal polynomial graph matching attack is established for every possible globally hidden compiler.

The intended stronger repair is a genuinely global CSP compiler in which no exposed small pin set or recoverable decoding boundary reveals the marked-vector invariant. It must allow extension from every original w by public PPT with no secret map, yet make arbitrary analysis of the *full* constraint tables and E insufficient. A graph/CSP isomorphism or forced-color hardness assumption would be a new nonhash foundation, not a reduction to hash security; there is no independent hash-only argument that a shuffled encoding protects this invariant. An assumption that the resulting public CSP already hides K except with original evidence is the target itself. No globally mixed compiler with the required joint distribution was constructed. This is not an impossibility theorem for globally coupled nonlocal CSP encodings.
