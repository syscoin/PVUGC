# Run 523 — static one-reference inverse-field mask falsifier

Research-only 2026-10-15. Live PR head c3ffb74ea216e4227903d462958904168ec8f7c6. New scoped result, **not** a secure WKEM.

Run 522 (unreferenced commit afae0dbfd715d6e264859621ef3ab980ea836bff) required a dense coherent reference oracle for its Simon attack on shared nonlinear masks. Here a **single static, classically available** known-valid reference suffices for a particular structurally nonlinear permutation.

Let F=GF(2^n), with XOR addition, alpha nonzero, gamma public, and pi(u)=alpha/u+gamma (pi(0)=gamma, using inv(0)=0). Honest setup samples hidden S and independent signing seeds K_d, then publishes a_d=K_d+pi(d+S)+S and a native checking key VK_d. Claim identities d include relation, UTXO, branch and context, and are distinct. The setup may honestly erase S. We consider only this proposed shared-mask wrapper; no efficient source-gated terminal is constructed.

Take an ORIGINAL-valid reference claim r != x whose actual off-chain release reveals K_r. From its public anchor obtain delta_r=a_r+K_r. Put u=r+S and beta=delta_r+gamma+r. For u != 0, beta=u+alpha/u and hence u^2+beta*u=alpha. This is a **GF(2)-linearized equation** in u: its columns are (e_j)^2+beta*e_j. Gaussian elimination finds every root in polynomial time. If beta != 0 the kernel is {0,beta}, so the observed equation has exactly two solutions. If beta=0, the unique nonzero root sqrt(alpha) and exceptional u=0 (where inv(0)=0) produce exactly two candidates. Thus one honest reference fixes S to exactly TWO efficiently enumerable candidates S'=r+u, for every input including zero.

For false target x, publicly compute from each candidate K'_x=a_x+pi(x+S')+S'. The list has size <=2 and contains the exact protected K_x. A uniformly selected candidate wins the false-target full-seed recovery game with probability >=1/2 **even without VK_x**. If public native checking of candidate credentials is available, test both candidates; the correct one authorizes, and if both authorize that is already an unauthorized credential break. This is classical PPT, hence applies to arbitrary QPT attackers without coherent queries. It does not depend on malicious setup, an inter-claim switch, or reusing witness state.

Attack taxonomy: (1) no gate seam; (2) one-reference algebraic nonlinear synchronization; (3) inversion-specific fingerprint; (4) one reference + false target static multi-capsule; (5) no chosen oracle; (6) honest setup/erasure does not help this mask; (7) correctly separated claim labels; (8) VK optional for 1/2 full-key guessing and useful for authorization testing; (9) classical break, no distinct quantum attack. For alpha/u, the inversion map has high Boolean degree, so this is not Run 521's shared-affine-frame interpolation.

Limitations: this does NOT break an ideal random permutation, generic nonlinear PRP, AES as a block cipher, a QPRF, independent claim masks, two-round Even-Mansour, or an actual Syscoin implementation. A complete SLH-DSA secret might include several independent components; key-recovery conclusion requires that K is the actual recoverable capability or deterministically seeds it. The executed JS checker exhausts 4- and 8-bit master/reference pairs plus 16-bit fixtures. NIST FIPS 197 (2023 update) uses field inversion as a COMPONENT of AES S-box construction, not this stand-alone permutation: https://doi.org/10.6028/NIST.FIPS.197-upd1 . The ideal-permutation results of Alagic et al. arXiv:2112.07530 do not establish security of this fixed algebraic pi. No full RIO proof audit.
