An offline holder of a valid ORIGINAL witness forms z, intersects the sets of F_q-eigenvalues of C_j(z), and selects the unique candidate matching a bound public checking value H_x(K). A native signature and graph remain separate.

**Correctness.** Every satisfying z has rank M_j(z)<N for all replicas and all outer masks, so K is always a common eigenvalue. Under the explicit ideal-function event that H_x has no collision with K on F_q\{K}, every valid ORIGINAL witness recovers the identical K. This event fails with probability at most (q-1)2^-tau for tau-bit independent ideal-hash outputs. No common intermediate state is required. This event does NOT make K pseudorandom given H_x(K) or a native verification key.

**Exact soundness of the explicit field-input release API.** Fix invalid z violating f>=1 gates. With R_z=N-1+2bf, independently uniform outer masks give M_j(z)=_d U_j V_j with U_j uniform N-by-R_z, V_j uniform R_z-by-N, independent across j. Write F_q(a,n)=prod_(i=0)^(n-1)(1-q^(i-a)), zero for a<n. Then p_z=Pr[rank M_j(z)<N]=1-F_q(R_z,N)F_q(N,N). On the no-hash-collision event the public AND selector releases the true K at this invalid z iff all s independent matrices are singular, with exact probability p_z^s. If Z_x contains B invalid field inputs, the probability that ANY such input is accepted is at most sum_z p_z^s <= B pmax^s, where pmax < (1+q^(-(2b-1)))/(q-1).
