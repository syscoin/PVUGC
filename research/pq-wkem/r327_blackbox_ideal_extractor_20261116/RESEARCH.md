## Candidate and attack (full-public evaluator, not a release solution)
Let `f_j(z)=0` encode source-verifier Boolean constraints on N common gate-trace bits, including exact SHA-Ch `z + xy + xz` (degree 2). For each source constraint choose degree <= r multiplier monomials `z^a`, and set `g_(j,a)=z^a f_j`. All g have Boolean multilinear degree <= D=d_f+r, with M<=m sum_(k=0)^r binom(N,k) public functions. Build samples independent hidden coefficients b for a 256-bit uniform K, defines the PUBLICALLY EVALUATABLE function `P(z)=K XOR XOR_(j,a) b_(j,a) g_(j,a)(z)`, and publishes `D_ct=S XOR K`. Honest `Open(C,w)=D_ct XOR P(w)` yields the SAME S for every satisfying w. For the security test, the attacker receives only opaque arbitrary-input access to P, not the b coefficients, circuit internals, or any witness. This oracle is a favorable-to-candidate abstraction, **not** a classical-PPT publicly serialized Build or an ideal release authority counted as progress.

**Explicit classical black-box extraction lemma.** If a satisfying assignment exists, `1 not in V=span(g)` since evaluation at that assignment kills every g. Let `U=span(1,V)`, dimension <=M+1. Any nonzero Boolean polynomial of degree <=D is nonzero on at least fraction `2^-D` of uniform Boolean inputs. For q independent uniform z samples, union bound over U gives probability of failure of injective evaluation on U at most `2^(M+1) exp(-q/2^D)`. Thus
`q >= 2^D*((M+1)*ln(2)+ln(1/delta))`
suffices for failure <=delta. With high probability public Gaussian elimination on the evaluation rows constructs weights alpha_s with `XOR_s alpha_s=1` and `XOR_s alpha_s*g_j(z_s)=0` for ALL mask functions. Therefore `XOR_s alpha_s*P(z_s)=K` exactly, so `S=D_ct XOR K` is recovered WITHOUT producing or knowing a true witness or seeing hidden coefficients. The attack is classical PPT if D=O(log(lambda)) and M=poly(lambda); it is an unauthorized recovery for QPT adversaries as well. This applies equally to genuinely nonlinear SHA *bit constraints* in the g_j, provided their multiplier degree stays small and the raw pad evaluator is callable on invalid traces. It does not apply to genuinely source-gated evaluators that conceal all invalid-trace values or high-degree masks for which the sample bound is exponential.

## Joint-public FALSE model and attempted repair

The **function-oracle** transcript `(P(.),D_ct)` is exactly independent of any fixed S: for S' put `K'=K XOR S XOR S'`, `b_bad,empty'=b_bad,empty XOR K XOR K'`. This is a bijective tape coupling that preserves the WHOLE function and ciphertext. Even coherent QPT access to that exactly coupled ideal function cannot distinguish. It is NOT an actual public capsule simulator, does not cover general FALSE ORIGINAL relations or malicious correlated native VK/setup, and there is no instantiated program hiding the coefficients.

With public kappa, invalid-point evaluations expose P by removing the publicly computable SHA syndrome mask, and the extractor survives. With hidden kappa, there is no specified public method for evaluating E without a hidden-key program, massive syndrome table, or an independently instantiated obfuscation/functional primitive.
