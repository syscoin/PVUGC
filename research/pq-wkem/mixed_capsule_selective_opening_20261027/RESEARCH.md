## Algorithm and security games

Let lambda be the security parameter, with classical polynomial-time honest setup/evaluation and arbitrary QPT adversaries, potentially with efficiently preparable quantum advice. For each claim/path scope i fix public SOURCE statement x_i, cubic Boolean-moment source matrix M_i in F_q^(r_i x n_i), anchor vector e_i selecting the cube of its anchor variable, public relation ID, original claim/UTXO, branch, anchors/window, context and **actual native checking key** pk_i. Context/path binding in the transaction graph is an additional, unproved system obligation; adding the labels here does not automatically enforce it.

For each independently openable capsule i sample uniformly K_i,U_i,Z_i from k-bit strings, with k=256. A deterministic native SeedKeyGen(K_i) generates the genuine (sk_i,pk_i), rather than sampling pk_i separately. Publish D_i=U_i XOR Z_i and V_i=K_i XOR U_i. Represent Z_i injectively as ell_i correlated radix-m digits t_ij, where m=floor(q/g). For each column sample fresh independent u_ij uniform in F_q^r and epsilon_ij from chi^n, where chi is ternary on {-1,0,+1}. Publish p_ij=M_i^T u_ij+epsilon_ij+g*t_ij*e_i (mod q). Native signatures/authorized presignatures of independently keyed other capsules, public contexts and related capsules are included in the FULL public/adversarial view, not omitted from a marginal pad game.

Cubic SOURCE setup from the pinned predecessor compiles any 3CNF: anchor, variable one-hot groups, three weighted slack coordinates per clause, all source linear equations multiplied by homogeneous degree-two monomials, and all Boolean equations z_i²=a*z_i multiplied by degree-one monomials. A satisfying ORIGINAL Boolean witness W maps in polynomial time to its own cubic moment Y(W), satisfying M_i Y=0 and e_i^T Y=1. Distinct W may have distinct Y; all derive the identical precommitted K_i by Y^T p_ij=g*t_ij+Y^T epsilon_ij, digit decoding, and K_i=V_i XOR(D_i XOR Z_i). With h active one-hot entries including anchor, H=binom(h+2,3), and ternary noise, 2H<min(g,q-(m-1)g) suffices for all-original-witness correctness. This is source correctness, **not** source secrecy.

## Exact joint null theorem and proof

Fix one false target capsule * and any number of unopened same-key false sibling capsules, with fresh pad/source coins per sibling, for which the source compiler actually supplies a row-shift certificate c_i in F_q^r with M_i^T c_i=e_i. For each such false capsule it samples D_i,V_i independently uniform k-bit strings, samples u'_ij uniform in F_q^r and epsilon_ij from chi^n, and outputs p^0_ij=M_i^T u'_ij+epsilon_ij. It preserves pk*, all public relations/contexts and allowed native signing-oracle transcripts.

For every fixed K*, U_i,Z_i and digit t_ij, the shift u'_ij=u_ij+g*t_ij*c_i is a uniform bijection and gives the POINTWISE equality p^0_ij=p_ij with the same epsilon_ij. The translated u'_ij stay independent uniform across all columns and all unopened false siblings even when conditioned on native K*, pk*, each Z_i, and public signing transcripts, because they were fresh independent uniforms. Independently, for each fixed K* the affine map (U_i,Z_i)->(D_i=U_i XOR Z_i,V_i=K* XOR U_i) is bijective; hence D_i,V_i are independently uniform conditional on K* and native pk*. Consequently the full real and null target/sibling public transcript distributions are IDENTICAL. This exact coupling, not a marginal hiding inference, allows arbitrary coherent-QPT distinguishers.

The simulator generates every OTHER independently keyed capsule honestly, including true capsules, and retains their K_j,sk_j,U_j,Z_j. It answers any adaptive requests to reveal these non-target keys/coins and any allowed native signatures. It may verify a valid ORIGINAL witness provided by the adversary; it does not have to invent an unknown witness for an arbitrary hard-true relative. Additional auxiliary data must be publicly computable from the available transcript or reproducible by the simulator, and may include native challenge signatures on messages distinct from the fresh target path; neither hidden target pads nor target signing seed may be exposed. The exact joint identity survives arbitrary QPT postprocessing, adaptive requests to open independent relatives, and their native checking-key correlations.

## Restricted false-target native-QPT reduction and unavoidable cross-key boundary
