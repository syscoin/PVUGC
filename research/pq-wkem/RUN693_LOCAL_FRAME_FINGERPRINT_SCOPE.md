# Run 693 — identity-circuit local-frame leakage and an ideal boundary

Research-only, 2026-10-21. Started from live syscoin/PVUGC#1 head `95774b84b58f497efce5edc93f977a56a13b79dd` (open/draft/unmerged). Exact inputs read: Run 692 scope blob `bf7f24fa7fa42a2e975dc6314c1363dca37477c4` and Run 259 source-binding blob `c7f3b77f0273ca1cbe6f0b31c1a086b8eb3acbf2`. This is a **new restricted local-mixing falsifier**, not another NP-universality or canonical-witness claim.

Fix n>=3 reversible bits. Let C flip bit 2 if bit 0 is 1 (CNOT), and T flip bit 2 if bits 0 and 1 are 1 (Toffoli). Both square to identity. Circuits Q0=(C,C) and Q1=(T,T) therefore have **identical full functionality: identity**. A gate-decomposition bit b is hidden from black-box queries to the overall function.

Publish locally framed gates G1=A1 F_b A0^{-1}, G2=A0 F_b A1^{-1}. Their product is identity in both worlds.

**Theorem A, independent affine frames (classical PPT setup):** Algebraic degree is invariant under invertible affine input/output changes, so G1 has degree 1 for C and 2 for T. Moreover the four-query second derivative D_uv G1(x)=G1(x)^G1(x^u)^G1(x^v)^G1(x^u^v) is always zero for C and nonzero with exact probability 3/8 for T when u,v are uniform. Thus t independent public chosen-input tests distinguish with error at most (5/8)^t. The attacker is classical PPT, hence also QPT; it needs no frame seeds.

**Theorem B, arbitrary shared conjugation:** Taking A0=A1=P for ANY permutation P, each G is P F_b P^{-1}. Cycle structure is preserved. C fixes exactly half the inputs while T fixes three quarters. Counting/sampling public fixed points distinguishes in polynomially many evaluator calls, including for nonlinear P.

**Theorem C, ideal independent uniform permutations:** If A0,A1 are uniform and independent in the FULL symmetric group S_N, N=2^n, then G1 is uniform in S_N and G2=G1^{-1}, identically for b=0,1. The COMPLETE joint public-table distributions agree exactly (TV 0); coherent quantum evaluation of those classically sampled tables cannot distinguish them with b-independent auxiliary information. This ideal model is not practical PPT: uniformly representing one frame needs log2((2^n)!)=Theta(n 2^n) bits. Exposing A0/A1 seeds immediately reveals F_b. A compact white-box replacement would need an independently justified security theorem.

**Scope:** The two underlying whole circuits compute the SAME identity, so these are implementation fingerprints beyond public functionality. The negative attacks apply only to affine/local shared-conjugation families, NOT CCMR RIO/local thermalization; the positive statement holds only for ideal full uniformly random permutations with unrelated auxiliary inputs. No actual Syscoin RELEASE, same native key, false-instance QPT hiding, true-instance extraction, N-of-N setup security or useful 128-bit instantiation is provided. This note does not assume a WE/RIO/iO primitive.

**Taxonomy:** public chosen-input and gate-class fingerprints succeed; an internal seam cancels on composition; shared-frame cycle invariants survive arbitrary nonlinear permutations; independently uniform full frames give exact joint distribution hiding. Cross-UTXO replay, native checking-key correlation, malicious correlated coins and genuinely quantum structural attacks remain unanalysed; the ideal QPT statement is information-theoretic only.
