# Run 610 — short-source gap for a naive additive projective release

Research-only falsifier (2026-10-18). Starting PR syscoin/PVUGC#1 head 9aed4746a11a7992a68eb97a6925c64c596f6658. No production modifications.

Let q be prime, A in F_q^(n x m) public, and ORIGINAL R((A,y),w)=[Aw=y and w in W], where W restricts acceptable short witnesses. Honest classical setup samples s in F_q^n and protected K in F_q, publishes p=A^T s and c=K+<y,s>. Legitimate release computes c-<p,w>. Every valid ORIGINAL w recovers exactly K; different witnesses need not coincide.

**Theorem (ambient-language gap).** If y belongs to Im(A), ordinary public Gaussian elimination outputs an unrestricted z with Az=y. For every setup s, c-<p,z>=K. This extraction does not require z in W. Thus an ORIGINAL-false short-source statement can reveal the entire protected key whenever an unrestricted modular preimage exists. In particular if A has full row rank, every y is in Im(A), so all short-source false instances fail hiding. This is a straight-line classical public-output attack and therefore breaks the corresponding arbitrary-QPT security requirement.

Conversely, if y is NOT in Im(A), the linear map s -> (A^T s,<y,s>) has rank rank(A)+1; conditional on p the protected pad <y,s> is exactly uniform. Hence the COMPLETE public (p,c) distribution is identical for every K (and adds no leakage beyond an independent publicly correlated checking key). But deciding Im(A) membership is public polynomial time, so this is smoothness for the WRONG source language, not a generic NP witness-KEM.

**Noise boundary.** A direct graft p=A^T s+e makes raw legitimate release K-<e,w>. For accepted w,w', raw answers coincide iff <e,w-w'>=0 mod q. Uniform field noise gives probability 1/q for distinct w,w'; in the specific ternary-noise example, 21/81. Proper decoding/rounding could restore semantic equality; this toy theorem does NOT rule out noisy lattice SPH, nor show its QPT false-instance hiding.

**Exact validation.** Standard-library checker with q=17, A=[[2,3,5,7],[5,7,12,4]], W={-1,0,1}^4: 81 original witnesses produce 57 short images and 232 ORIGINAL-false y values. True y=(5,12) has two distinct valid witnesses, both recovering K under all 289 setup s choices. For each of the 232 false y, public Gaussian elimination yields a z outside W, recovering K for every one of the 289 setup values (67,048 falsifying cases). In particular false y=(0,1) has public z=(3,15,0,0). Two distinct candidate keys have disjoint full transcript supports. Extended executed checker passed 68,956 assertions; compact exact checker passed 67,915, with repeated byte-identical execution. Small-field tests are checks of algebra, NOT cryptographic security or native-signature tests.

**Run 259 interface.** Public z may violate ORIGINAL shortness/Booleanity and is NOT an accepted complete source representation. Run 259 proves only accepted complete representation -> ORIGINAL witness, potentially using its conditional SIS reduction; it does not extract z from a leaked seed or signature. The missing first arrow remains entirely unproved. Independent Run-604 native child-key derivation does not repair a single leaking capsule.

**Primary-source audit.** Katz–Vaikuntanathan, *Smooth Projective Hashing and Password-Based Authenticated Key Exchange from Lattices*, ASIACRYPT 2009, author PDF https://www.cs.toronto.edu/~vinodv/KV-PAKE.pdf: Section 2 explicitly guarantees approximate correctness on honestly generated ciphertexts Lbar subset L, smoothness only outside full decryption language L, and no property on L minus Lbar. Section 5.2 instead uses discrete Gaussian projection keys, approximate sign/threshold reconstruction and dual parameter constraints. The paper is NOT the insecure noiseless gadget above and does not give generic-NP ORIGINAL extraction or same-native-key witness-KEM. Sections 2,4,5.2,6.2 were inspected; no full errata/parameter audit.

**Security ledger.** Honest setup/evaluation classical PPT. Counterexample uses a classical straight-line attacker, hence is admissible for arbitrary QPT with all public keys, any independent auxiliary inputs, multiple capsules, coherent public-code evaluation and quantum advice. Attack already works with ONE capsule, no retained coins, no local frames/cycles, no malicious setup and no secret checking-key correlations. Independent claim/UTXO labels cannot prevent within-capsule recovery. No actual PQ signature or Bitcoin covenant graph is implemented. **Conclusion.** This rules out the direct publicly-linear projective-hash replacement for Run 609's hidden-exponent group encoding when short ORIGINAL membership is the source relation. It is not a no-go theorem for LWE SPH, all local mixing, RIO or general WE. Practical PQ WKEM stopping condition unmet.
