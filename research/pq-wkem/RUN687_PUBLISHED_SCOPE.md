## Conditional theorem

Fix a false ORIGINAL instance `x` with `R(x,w)=0` for all `w`, fully binding relation, claim/UTXO, branch, anchors/window and intended Bitcoin signature message `m_x`. Honest classical PPT setup generates native `(sk,pk)` and a **complete classical public transcript** `V_real` including all release capsules, auxiliary public values and graph/signature context. Assume a concrete PPT `Sim(pk,x,ctx)` requiring no `sk` or secret release randomness such that the complete joint distribution `(pk,V_real)` is within total variation `delta` of `(pk,Sim(pk,x,ctx))` under the *actual native signing key distribution*. The same bound must hold in trace distance if the attacker receives setup-correlated quantum advice. Ordinary setup-independent quantum advice and coherent evaluations of published classical programs are allowed.

For any arbitrary QPT attacker that outputs a **fresh**, accepted native signature on `m_x` (a legitimate EUF-CMA win; `m_x` was not signed during setup), a straight-line QPT reduction to the native signature's corresponding EUF-CMA game has success at least `Pr[real forgery] - delta`. It receives the signing challenge `pk`, samples `Sim(pk,x,ctx)`, runs the attacker **once**, and forwards the fresh forgery. Classical TV equals trace distance of the diagonal input states, which cannot increase under QPT processing. No rewinding, QROM programming or ORIGINAL extractor is used. If the real graph contains challenge-key pre-signatures or unsafe bypasses, the simulator and signature freshness/game conditions must account for them; otherwise the theorem does not apply. Exact-key recovery yields a forgery when the recovered secret can sign the previously unsigned `m_x`.

This discharges only a **false-instance signature-forgery** obligation conditional on the independently established simulator and QPT native signature security. It does NOT prove true-instance unauthorized recovery -> ORIGINAL witness, generic Syscoin source compilation, or practical release. Run 259's `accepted complete SOURCE representation -> ORIGINAL witness` theorem (blob `c7f3b77f0273ca1cbe6f0b31c1a086b8eb3acbf2`) remains downstream and has not been strengthened.

## Crucial checking-key correction

For any serialized native secret `K` and checking key `pk=PK(K)`, independent uniform masks `U_i` yield ciphertexts `C_i=K XOR U_i` that are **jointly simulable conditioned on `(K,pk)`**. This does NOT imply information-theoretic *key secrecy given `pk`*: an injective `PK` determines `K` to an unbounded adversary, and an efficiently invertible toy `PK` recovers `K` classically. Thus statistical smoothness of capsules alone is not QPT credential secrecy or native unforgeability. One needs the full-public-view simulator **plus** native QPT EUF-CMA (or another exact independent security reduction). Smoothness of individual capsules cannot replace joint simulation.
