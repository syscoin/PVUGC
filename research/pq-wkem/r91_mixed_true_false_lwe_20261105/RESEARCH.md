## Explicit classical-PPT distribution, ORIGINAL relation, and release

R90 lacked any FALSE source. Fix a polynomial-size monotone AND/OR formula f with L distinct leaf **occurrences**, and fix a REAL-key set U before sampling all key material. Each leaf i uses an independent A_i uniformly sampled in Z_q^(m by n) and B_i in Z_q^(m by ell), q prime >6. If i is REAL, independently sample S_i uniformly in Z_q^(n by ell), bounded E_i with abs entries <= beta under a declared exact distribution chi, set B_i=A_i*S_i+E_i modulo q, and retain witness (S_i,E_i). If i is uniform FALSE, choose B_i uniformly and independently of A_i and all other keys. The adversary may know the flag and **all REAL witnesses** in the FALSE-instance theorem. No honest secret/opening is known for a uniform FALSE leaf.

The ORIGINAL leaf predicate is B_i=A_i*S+E mod q AND abs(E)<=beta, checked on the actual public A_i,B_i. The ORIGINAL global predicate checks actual leaf key witnesses satisfying f and binds the relation identity, claim/UTXO, branch, anchors/window/context, frozen graph and native verification key. This is a restricted monotone formula over LWE-key witnesses, **not arbitrary NP or SYS/BTC fork evidence**. Leaf flags are not a publicly verifiable proof of falsity.

Build samples one uniform kappa-bit precommitted seed T. At an OR node it copies its parent share to both children; at an AND node it independently samples uniform kappa-bit Z and sends (Z,parent XOR Z) to its children. For each leaf share t_i, Build independently encrypts groups of ell bits under the actual leaf public key using R88's packed source: draw fresh r_{i,g} in {-3,...,3}^m, and publish C_{i,g}=(A_i^T*r_{i,g}, B_i^T*r_{i,g}+Delta*t_{i,g}) modulo q. This works identically for REAL and uniform FALSE keys. No SourceOpen oracle, witness or private encryption randomness from a challenger is needed.

A separate honestly preauthorized single native signature sigma on M=Bind(relation,x,f,claim,UTXO,branch,anchors,window,graph,vk_native) is padded using (P,Bcheck)=PRG(T), with disjoint output regions. Publish Dsig=sigma XOR P and the entire public relation/statement, leaf ciphertexts, CK=F(Bcheck,Dsig,C,context,related_roots), Aux=G(Bcheck,Dsig,CK,C,context,related_roots), and independently simulatable public preflight. F,G are fixed acyclic classical PPT and may not additionally depend on the hidden source secret, challenge encryption coins, T, P or native signing key. All public checking and auxiliary correlations must refer to **the actual ciphertext bytes** in each hybrid.

Off-chain Open takes a valid ORIGINAL witness containing independently verified secret/error pairs for an authorized leaf set. Any valid representation of a REAL public key decrypts the one deposited leaf share, provided 3*m*beta<q/4-1. ## Certified probability of FALSE, not fixed-instance false soundness

For one independently uniform FALSE RHS B, any fixed S in Z_q^(n by ell) can match B-A*S with all centered errors in [-beta,beta] with probability ((2beta+1)/q)^(m*ell). Union-bound q^(n*ell) candidates:

delta_false <= q^(n*ell) * ((2beta+1)/q)^(m*ell).

For N uniform FALSE leaves, chance that any admits *some* ORIGINAL short-error witness is at most |N| delta_false. Thus if f(U)=FALSE, the full ORIGINAL statement is FALSE with probability at least 1-|N|delta_false, even while every REAL witness is given to the adversary. If f(U)=TRUE, it is TRUE and all authorized witnesses release the same seed. This is a **sampler-distribution** result; it cannot certify every adversarially fixed FALSE statement, nor prevent a malicious builder who deliberately retained an authorized witness from opening early.

## Full joint output FALSE secrecy for the honest distribution

Fix f(U)=FALSE. Arbitrary nonuniform QPT adversaries, including coherent processing and independent quantum advice, receive the full classical relation/statement, actual A_i/B_i, all REAL S_i/E_i and opened shares, C_i, context, graph, preflight, native vk, Dsig, CK, Aux, and independent related capsules with all permitted disclosures. Key/flag sampling and public auxiliary generation are independent of root T, source ephemeral randomness and the honest native signing secret. Exclusions: target root/pre-signature disclosures, related capsules opening the same target root/secret, post-ciphertext adaptive corruption or target-key opening, malicious source key generation, source-secret-correlated auxiliary data, and arbitrary adversarial advice correlated with the honest hidden randomness.

For each uniform FALSE leaf, D_i=[A_i|B_i] is itself a uniformly random (m by (n+ell)) matrix. Because q is prime >6, distinct septenary r and r' have a nonzero difference coefficient invertible modulo q. The family H_D(r)=D^T*r is exactly two-universal for uniform D. Strong leftover hashing yields, jointly with public D, for *each* packed group:

TV((D,Enc_D(t)),(D,U_(Z_q^(n+ell)))) <= eps_LHL = 0.5*sqrt(q^(n+ell)/7^m).

The additive plaintext shift is a bijective translation for every fixed D. Independently draw a fresh r for each group. Replace each of the G_false ciphertext groups across all uniform FALSE leaves in the FULL joint public view by a **directly uniform q-vector**, at statistical cost at most G_false*eps_LHL. This one-way-to-uniform hybrid avoids the additional factor of two incurred by replacing Enc(t) with Enc(0) via a uniform intermediate. Recompute CK, Aux and independent attestations from the actual replaced ciphertexts each time. Classical statistical closeness is preserved under any quantum channel/measurement performed later by a QPT adversary. Independent related capsules must be included in G_false; arbitrary same-root or shared-key correlated opening is NOT justified.

In this hybrid, ciphertexts of FALSE leaves are independent of T. The full **joint vector** of all REAL opened shares is perfectly independent of T because f(U)=FALSE: its GF(2) coefficient span omits the root coordinate e0 (R90's exact LSSS lemma). Ciphertexts of REAL leaves are functions of those shares, independent encryption coins and known REAL public keys; hence their complete public distribution is also independent of T. The remaining target-dependent public output uses T only through PRG(T).

Apply an independently QPT-secure classical-PPT PRG to replace the **entire correlated (P,Bcheck)** output by fresh uniform independent bits, regenerating Dsig, CK, Aux and allowed preflight. Uniform P gives Dsig=sigma XOR P uniform independent of sigma. Uniform Bcheck prevents CK/Aux from recovering the pad through common seed correlations. In the resulting whole-public-view hybrid, exact recovery of T succeeds with probability 2^-kappa, even for QPT A with independent advice. To handle an accepted native signature for M, invoke a distinct independently QPT-EUF-CMA native-signature challenger; because Dsig is now uniform, the reduction never asks its signing oracle for M (unrelated legitimate messages may be queried). Accepted native signature on M is then an EUF-CMA forgery.

For this exact honest FALSE sampling distribution:

Pr[A outputs exact T] <= G_false*eps_LHL + Adv_QPT-PRG + 2^-kappa.

Pr[A outputs an accepted native signature on M] <= G_false*eps_LHL + Adv_QPT-PRG + Adv_QPT-EUF-CMA.

To additionally require a genuinely FALSE ORIGINAL instance, count at most |N|*delta_false exceptional random keys (or condition the bound by dividing by 1-|N|*delta_false). Straight-line QPT reductions, ordinary classical statistical data processing; no quantum rewinding, oracle extraction, SIS/MinRank, canonical/common source key, supplied internal representation, new witness-encryption assumption or false-source oracle.

For an **unauthorized hard-TRUE** case with a fixed disclosed REAL subset U0 satisfying f(U0)=FALSE, the identical hybrid additionally replaces ciphertexts under undisclosed independently generated REAL keys by genuine exact-distribution QPT-IND-CPA challenges, with all public CK/Aux recomputed against those challenge ciphertext bytes.
