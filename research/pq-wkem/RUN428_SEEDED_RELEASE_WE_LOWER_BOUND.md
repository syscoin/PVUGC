# Run 428: seeded common-capability release implies one-bit witness encryption

Live starting point: syscoin/PVUGC#1, draft branch research/pq-wkem-validation-20260918, SHA dcb9932270367d1caceb6db87829037c940cc064. Exact Run 427 note blob 02c930726393e2ffb48a5094d22bce51d02fd538 and provenance blob ca3aad6edaced324047573e2e32aa3f10e65a7d7 were read. This is a new scoped interface lower bound, not another reversible-gate fingerprint or a PQ construction.

THEOREM. Fix any NP relation R with L={x: exists w R(x,w)}. Suppose honest classical PPT setup can be centrally simulated to output a uniform n-bit signing seed K (n>=lambda) and the complete copyable classical public transcript Z, including native checking key vk(K), bound statement/UTXO/branch/context, and all publicly accessible correlated views. Suppose public PPT Recover(Z,w) returns that SAME K with overwhelming probability for EVERY valid ORIGINAL witness w. For each fixed x outside L, require that no arbitrary QPT given Z, coherent access to deterministic public algorithms, and polynomial K-independent quantum advice can recover K with nonnegligible probability. Alternatively, inability to forge a new signature on the witness-only challenge message under vk(K) implies this key-unpredictability because knowing K immediately yields a signature.

BUILD ONE-BIT WE: Enc(x,b) samples (K,Z) honestly, independently chooses uniform r in {0,1}^n, publishes (Z,r,c), c=b XOR <K,r> mod 2. Dec with an ORIGINAL witness recovers K from Z, then returns c XOR <K,r>. All valid witnesses return the same bit; intermediate states can be different. False-instance indistinguishability follows from the Goldreich-Levin hard-core theorem with classical side information: if a QPT predicts <K,r> from (Z,r) with inverse-polynomial advantage, classical Hadamard heavy-character list decoding with polynomial fresh runs of that QPT and the same copyable Z yields a polynomial candidate list containing K with nonnegligible probability. Picking a candidate contradicts key-unpredictability; no candidate equality test is required. An IND distinguisher for b becomes a parity predictor by choosing c uniformly and outputting c XOR its guessed b. Gap delta gives parity prediction advantage |delta|/2. No quantum rewinding or random-oracle programming is used. For nonuniform QPT, polynomial independent quantum advice copies remain polynomial-size advice. A single secret-correlated unclonable advice state and a stateful online release oracle are NOT covered.

Therefore a uniform compiler satisfying this seeded interface for all NP verifiers already supplies general-NP one-bit WE, even if all it promises for FALSE instances is complete-key nonrecovery. Merely minimizing the protected gates, avoiding witness canonicalization, or publishing a verifier does not give a strictly weaker primitive-level API. The result does NOT claim that the implementation must obfuscate the full verifier. A specific non-NP-complete Syscoin relation could be easier. The optional keyless Build that cannot centrally calculate K lies outside the premise. Simulating all honest N-of-N participants is permitted mathematically only if their collective coins/shares determine K; it does not mean any single real setup participant learns K.

CONDITIONAL REVERSE, FALSE INSTANCES ONLY: If true QPT-secure IND WE exists, encrypt a fresh native K under x and publish vk(K). For false x, replace encryption of K with encryption of zero while retaining vk(K) using IND WE; native EUF-CMA/key hardness handles the independent ciphertext world. This does NOT yield the required TRUE-instance unauthorized early recovery or signature -> ORIGINAL witness extraction; ordinary WE never promised it. Multi-bit plaintexts can use independent one-bit setups and a hybrid, not arbitrary seed-correlated multi-capsules.

EXACT CHECKS: published Node.js checker passed 274 assertions, exhaustively confirming finite posterior identities for toy Z exposing n-t bits of uniform K: full-key guess 2^-t, GL parity prediction 1/2+2^(-t-1), and masked one-bit message guessing matches GL prediction. It also confirms that complementary public views recover all eight seed bits. Extended local Python checker passed 18,910 assertions and tested 12 ordinary Ed25519 signatures after reconstructing K. Ed25519 is a NON-PQ diagnostic. These checks do not implement any source-sensitive release algorithm or establish QPT hardness.

SCOPE / PRIOR ART: Garg-Gentry-Sahai-Waters (STOC 2013) define WE. Fleischhacker-Hall-Andersen-Simkin (ASIACRYPT 2024, ePrint 2024/264) explicitly define witness KEM and a separate extractability game; their specialized pairing/KZG result is not a generic PQ solution. Goldreich-Levin and Adcock-Cleve (quant-ph/0108095) are background; the present reduction uses classical-query GL with restartable QPT subroutines. CCMR ePrint 2024/006 / quantum local-mixing followup arXiv 2609.40289 do not instantiate this interface. No complete primary-paper proof-body audit was obtained because ePrint PDF access returned HTTP 403 and a mirror 401. No claim of independent novelty of standard KEM-to-bit-OTP folklore.

HANDOFF: Run 259 applies only to accepted complete source representations, not arbitrary recovered capabilities. Still UNPROVED: any practical local mixer; all-valid-ORIGINAL SAME-K on a secure scheme; false-instance full-public-view QPT hiding; true-instance unauthorized recovery / accepted forgery -> ORIGINAL or independent QPT break; malicious N-of-N setup/erasure/abort; multi-capsule composition; 128-bit resources; conditional native Bitcoin P2MR/SLH verification.
