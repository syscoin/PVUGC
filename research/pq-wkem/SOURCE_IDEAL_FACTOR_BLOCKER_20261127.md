## 2. Precise effect on the closest recorded attack

On FALSE, P is zero in the commutative Boolean quotient. A/J is a commutative F_2 algebra generated by commuting idempotents and the identity. The polynomial map from the Boolean quotient into A/J is well-defined, so P(X) belongs to J. This is an unconditional algebraic implication, not a way to determine FALSE by checking membership (the converse need not hold for this representation).

Let v be a nonzero column used by the preceding rank-one attack, and let phi be any row with phi(v)=phi(P(X)v)=1; T=v phi is idempotent and I+T P(X) kills v. The old exact unique-singular-versus-full-rank decoder fails for every eligible phi of this fixed representation on FALSE. ## 3. Full-public simulator attempt fails by a different scalar root test

An attempted simulator for false statements would have to hide the bit even from an observer who evaluates both public pencils outside the Boolean cube. The nonadditive repair has exposed a root that cannot be removed by its random factors.

Choose an extension field F of characteristic two with size greater than a polynomial multiple of the total formula degree. Take uniformly random scalar z in F. The commutative formal P(z) is NOT the zero polynomial even on FALSE: every local factor is a nonzero formal polynomial and each separator simplifies to 1. The product is nonzero in the polynomial ring, an integral domain. Each factor in D is nonzero as a formal polynomial (it equals 1 on Boolean points). Thus, for a single bit, the product P(z)*D_(j,0)(z)*D_(j,1)(z) is nonzero formally and has polynomial degree. By the finite-field polynomial root bound, with probability at least 1 minus degree/|F| it is nonzero at the chosen z. This uses no knowledge of Q or K. Set t=1/P(z), computable from the public original formula at the random scalar point. Every g_l vanishes at commuting scalar values; hence F=1. The selected p is exactly zero and the other equals its nonzero D. The public affine pencil can be evaluated over this extension field using its unchanged published coefficients; ABP Schur elimination and invertible constant equivalences preserve singularity. Read the bit from the unique singular matrix. Choose |F| large enough for the union bound over all lambda bits, or repeat probes; extension degree and rank computation are polynomial.

This is not the previous constant-polynomial fingerprint (both determinants now generally vary), nor the noncommuting idempotent rank probe (blocked above on FALSE). It exploits a common publicly computable root factor that survives the multiplication. ## 4. Exact bounded local checker

CPython standard library only; executed once. Synthetic FALSE formula x*(1+x) with separator B=1+uv+vu, W=xuvx. This checks only the section 2 effect in one explicit representation; section 3 is a static proof, not measured cryptographic security. Exact executed code:

```python
# GF(2) matrices as tuples of row bitmasks; synthetic FALSE f1=x,f2=1+x.
from itertools import product
W='xuvx'; d=len(W)+1
I=tuple(1<<i for i in range(d)); Z=(0,)*d

def add(a,b): return tuple(x^y for x,y in zip(a,b))
def mul(a,b):
    out=[]
    for row in a:
        r=0
        for i in range(d):
            if row>>i&1:r^=b[i]
        out.append(r)
    return tuple(out)
def flat(a):return sum(r<<(d*i) for i,r in enumerate(a))
def rank(a):
    basis={}
    for x in a:
        while x:
            k=x.bit_length()-1
            if k in basis:x^=basis[k]
            else:basis[k]=x;break
    return len(basis)
def gen(h):
    return tuple(1<<(i+1) if i<len(W) and W[i]==h else 1<<i if i and W[i-1]==h else 0 for i in range(d))
X={h:gen(h) for h in 'xuv'}
for a in X.values():assert mul(a,a)==a
P=mul(mul(X['x'],add(I,add(mul(X['u'],X['v']),mul(X['v'],X['u'])))),add(I,X['x']))
assert P[0]>>(d-1)&1
# Build an ideal basis, recording each basis member as prefix [a,b] suffix.
basis={}; members=[]
def insert(a,pre,h,k,post):
    v=flat(a)
    while v:
        i=v.bit_length()-1
        if i in basis:v^=basis[i]
        else:
            basis[i]=v;members.append((a,pre,h,k,post));return
for h,k in product(X,repeat=2):insert(add(mul(X[h],X[k]),mul(X[k],X[h])),'',h,k,'')
i=0
while i<len(members):
    a,pre,h,k,post=members[i];i+=1
    for s,b in X.items():
        insert(mul(b,a),s+pre,h,k,post)
        insert(mul(a,b),pre,h,k,post+s)
v=flat(P)
while v:
    k=v.bit_length()-1
    assert k in basis
    v^=basis[k]
# All allowed phi, not only one chosen by the original attack.
phis=0; min_blockers=d*d
for phi in range(1<<d):
    T=(0,)*(d-1)+(phi,)
    if mul(T,T)!=T or not (phi>>(d-1)&1):continue
    if not (mul(T,P)[d-1]>>(d-1)&1):continue
    phis+=1
    assert rank(add(I,mul(T,P)))<d
    blocked=sum(rank(add(I,mul(T,a)))<d for a,*_ in members)
    assert blocked
    min_blockers=min(min_blockers,blocked)
    M=I
    for a,*_ in members:M=mul(M,add(I,mul(T,a)))
    assert rank(M)<d and rank(mul(add(I,mul(T,P)),M))<d
print('synthetic W=',W,'dimension=',d,'ideal_basis=',len(members),'eligible_phi=',phis,'minimum_singular_factors=',min_blockers)
print('all eligible rank-one probes blocked for both selectors; no real source or security test')
```
