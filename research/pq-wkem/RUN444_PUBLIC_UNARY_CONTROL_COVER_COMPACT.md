## Restricted public-unary release game

Honest `Setup(1^lambda,x)` is classical PPT, does NOT know a later ORIGINAL witness, and publicly outputs copyable `P_x,c_0,vk`, native branch message `m_x`, and a classical PPT fixed unary evaluator `F_x`. All checking-key, setup, UTXO, branch, related-capsule, and auxiliary public data are in `P_x`. `Out_x(c)` publicly returns either a signing-sufficient capability or an accepted native signature, possibly using fresh public coins. A watcher with valid witness `w` may choose a witness-dependent stopping time `t(w)` from a PUBLICLY ENUMERABLE set `S_x`, of size `B(lambda)=poly(lambda)`, and run `Out_x(F_x^t(c_0))`. **The only witness-dependent input to this release interface is the choice of t**; there is no witness-bearing ciphertext, source-bound authenticator, secret keyed transition, online authority, or noncopyable device. Different valid witnesses may choose different t/states; every valid witness must obtain the SAME protected capability K_x (or a valid branch signature). Completeness is at least `1-epsilon`.

## Exact classical attack and true-instance extraction separation

Enumerate every public action t in S_x. Execute the corresponding public unary orbit from c_0, invoke Out_x with fresh coins, sign if needed, and check Verify(vk,m_x,sigma). Return the first accepted native signature. Cost is O(B) terminal tests and, for literal t=0..T with T polynomial, O(T) public unary transitions. **For every true x and valid w**, couple Out_x at t(w) with one honest release run. If honest release succeeds, some enumerated public action succeeds. Therefore witness-free forging probability is >= honest completeness `1-epsilon`. The argument does not enumerate ciphertext states and holds even when the hidden-state space is exponentially large and individually mixed ciphertexts are opaque. Honest setup/erasure is not attacked: public repeatability alone suffices.

For the hard-true relation `R(x,w)=[f(w)=x]` with quantum-secure one-way f and x=f(w) for uniform w, suppose Setup and all public auxiliary values are simulatable from x alone. This witness-free forger is efficiently simulatable from x. Any QPT straight-line extractor which, from its code/public transcript/accepted signature and no witness-bearing advice, outputs an ORIGINAL preimage with nonnegligible probability gives a QPT inverter of f. There is no rewinding or QROM step. Thus this interface supplies neither true-instance knowledge security nor Run259's missing `signature -> accepted complete source representation` arrow. This theorem says NOTHING about false-instance hiding of a general scheme, and does not assume witness privacy.
