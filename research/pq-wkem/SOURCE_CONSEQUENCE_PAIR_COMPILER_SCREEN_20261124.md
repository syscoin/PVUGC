## Candidate distribution and public algorithms

Represent the canonical complete source verifier by a bounded Boolean circuit. Let F_x(z) be its usual CNF encoding with explicit input, gate-consistency, and acceptance constraints; every qualifying original witness w deterministically computes a satisfying trace z of length n. Conversely a satisfying z must include an original w and certify the complete typed relation. This is a symbolic compilation, not a newly implemented real consensus verifier. Let k>=1 be a clause width, with clauses having k distinct variables and one sign per variable (no tautologies). Let G_x be a public classical PPT sampler that returns a width-k consequence C of F_x, without needing a satisfying assignment. Examples: randomly resolve known clauses and forget the derivation, or weaken a smaller consequence using extra literals. Conditional sampling or hidden provenance will matter below.

Sample uniform lambda-bit K. For every bit i and repetition j independently:
1. Draw C from G_x. Record its variable set I, size k.
2. Draw D on EXACTLY I with independent uniform signs.
3. Publish ordered pair (C,D) when K_i=0, else (D,C), without provenance.
Publish E = sigma_cancel XOR KDF(ctx,K,len(sigma_cancel)), canonical ctx, and the pairs. This entire candidate is classical PPT with polynomial repetitions, assuming G_x is. No secret or online evaluator survives setup. A fixed output order is used in the actual canonical bytes; no hidden map.

Open computes z from w; for each bit look for an evaluated false clause in the pairs. If the second is false and the first true, vote 0; reverse votes 1. A valid z cannot falsify C, so all non-abstaining votes agree with the same K_i. If no vote exists, fail. Recover K and decrypt E. A post-recovery signature or R check is not credited as a security boundary.

For every fixed satisfying z, conditional on any genuine sampled C/I, exactly one of the 2^k possible sign strings gives a false D. Hence q=2^(-k) is independent of which consequence G_x returned and of z. For N repetitions per key bit, failure is (1-q)^N <= exp(-qN). The union bound over lambda bits and at most 2^n satisfying traces gives failure probability <= lambda * 2^n * exp(-qN) over honest Build, EVEN when the challenger chooses its qualifying w after seeing the capsule. Set N >= ceil(2^k * (n ln 2 + ln(lambda/delta))) for simultaneous correctness at least 1-delta. Thus k=O(log n + log lambda) is a plausible polynomial regime. No dependence on a common canonical original witness. This correctness is exact for the specified distribution and bounded relation, but not security. It does not instantiate G_x with the required hiding property.

## Full-public attack: learn the genuine support, rather than solve F_x

For constant k, the public domain of possible clauses has size Dmax=2^k * binom(n,k), polynomial. The attacker does not see the private sampler tapes, and does not need to reconstruct them. Independently run the known G_x M times and store the set S of returned clauses. For a fresh genuine draw C, write p_c=Pr[G_x=c]. The probability it is absent from S is sum_c p_c(1-p_c)^M <= Dmax/(M+1), because p(1-p)^M <= 1/(M+1) for 0<=p<=1 (its maximum is at p=1/(M+1)). Choose M >= Dmax*lambda*N/epsilon. By union bound, all genuine clauses in the capsule are in S except probability epsilon. This is polynomial for constant k, even if G_x used a long, nonlocal resolution derivation or nonuniform output probabilities.

Now mark a pair's absent clause as the random D whenever exactly one lies outside S. For any TRUE instance, fix any satisfying trace z only in the analysis; the attacker is never given it and never evaluates it. All members of S are consequences and satisfied by z. A random D is false on z with probability q, so on those events it cannot belong to S. With the same all-witness correctness N (or just N>=q^-1 ln(lambda/epsilon)), at least one such marked pair exists per bit except epsilon. Under the good event all genuine clauses are in S; every marked pair gives its true key-bit order. The attacker recovers K and the exact native capability with probability >=1-2epsilon. This is a straight classical PPT full-capsule recovery on every TRUE instance, whether or not the attacker knows an original certificate. The observation does not prove such instances are hard or give a reduction extracting an original certificate; it explicitly shows recovery can be performed using only the public sampler and clause membership. Any claimed hard-TRUE security of this candidate would need original witnesses to be easy on these instances or independent evidence of a hash/native break, neither established here. No SHA break is used. On FALSE instances this particular proof cannot use a satisfying z to bound decoy absence; no unconditional FALSE attack claimed from it.

No larger constant-width fixture, shuffled derivation, randomized clause basis, or hash placement is justified after this attack.

## Repair attempt: logarithmic-width clauses and joint variable/sign sampling

The global support count becomes superpolynomial at k~log n, so the preceding unconditional PPT bound does not automatically cover it. To avoid the obvious marginal fingerprint of independently generated random variable sets, the candidate already couples I exactly. Try a public global resolution sampler which starts from F_x, executes polynomially many randomized resolution/weakening steps, discards provenance and emits an entailed width-k C, with a deterministic width-k consequence fallback if a step cannot emit one. One can define a fallback by padding any known clause of width <=k with distinct variables (assuming n>=k). Consequence correctness is unconditional. Matching I with random signs preserves the above all-witness correctness.

However, if a repair generates I first, then computes genuine signs from it with a public PPT conditional sampler G_x(.|I), the global domain size is irrelevant: for each public pair, there are only 2^k possible signs. Generate M' independent conditional genuine samples for THAT I, mark the absent clause as random. Conditional on I, the missed genuine mass is at most 2^k/(M'+1), by the same finite-support calculation. Choose M'>=2^k*lambda*N/epsilon, per pair, and use the same union and valid-z decoy argument. For k=O(log(n+lambda)), this remains a PPT attack. The conditioning assumption is exact; a sampler for the joint distribution need not admit efficient sampling conditioned on I. Approximate conditional sampling would need an additional quantified total variation bound across all calls; not assumed.

Likewise the explicit easy construction that takes a publicly known original clause and weakens it to width k is broken even without conditional sampling: test whether each serialized clause contains any of the known source clauses with matching signs. Every genuine weakened clause does; any decoy false under a satisfying trace cannot. Recover order using exactly the previous argument. If a global sampler has some nontrivial probability of this easy provenance, that alone is not a universal attack; the difference between genuine and decoy classifier rates must be quantified.

Therefore a surviving repair must simultaneously generate variable support AND entailed sign pattern in a way that is hard to condition or recognize, even given the support. Simply using a hash/PRG for sampling randomness does not establish this: the adversary also has the public sampler, and no secret is required to evaluate it. A random hash mapping seed to a support does not generate an entailed sign pattern for that support. Public per-pair variable renaming cannot conceal the relation if its mapping is supplied to Open. A secret map unavailable to Open leaves the source operation unimplemented. No concrete global resolution sampler with independently justified hash-based conditional hardness and full-public security was found. The bounded resolution algorithm is a correctness-only candidate, not a claimed new independent hardness assumption. No test count would resolve this gap.

## Arbitrary invalid-trace attack obligation even if support learning is avoided

Fix any publicly computable z (not necessarily canonical or satisfying) and define p_z=Pr_C[C(z)=false]. For each paired sample use score S=1[first clause false]-1[second clause false], in [-1,1]. The mean is p_z-q when K_i=0 and q-p_z when K_i=1. The attacker can estimate p_z by sampling G_x; q is known. If |p_z-q|=a>0 and its sign is known, Hoeffding gives per-bit wrong sign probability <= exp(-N a^2/2). For inverse polynomial a and a sufficiently long capsule this is a polynomial-time order decoder, with no original witness and no secret label. A wrong source trace with p_z>q is NOT necessarily harmless: the attacker can invert its score. Estimating the sign to error <a/2 takes O(a^-2 log(1/epsilon)) independent sampler calls for inverse-polynomial a. This attack does not assume trace consistency, an honest-code validity check, or a volunteered representation by the attacker. It is one explicit arbitrary public attack family; it is not a proof that every global sampler has an exploitable z at the actual N or that all QPT attacks can be reduced to a trace. In particular, proving only PCP-style soundness (some constraints reject) does not establish a statistically neutral score for invalid traces. Security would require the bias at the actual N to be unexploitable for all PPT-computable z without original evidence, then a much stronger full-public reduction for arbitrary QPT adversaries. Honest verification of R after key decoding cannot repair leakage.

This separates the new exact missing equation: a PPT witness-blind source consequence sampler with both hard conditional provenance and a computationally protected evaluation gap between valid ORIGINAL traces and ALL unauthorized inputs. No independent hash assumption supplying that joint property has been derived. The original KEM reduction still needs more than this necessary condition; it would be wrong to assume a consequence sampler whose security already states the desired release.
