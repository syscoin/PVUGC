## Candidate screened
R328's globally consistent full-witness hash rows required enumerating unknown future ORIGINAL certificates. Attempt a compact **prefix-bound** release instead. For canonical certificate bits b_1...b_L, let
 s_0 = SHA256("path-start" || x_W || seed)
 s_{i+1} = SHA256("path-edge" || x_W || i || s_i || b_{i+1}).
The intended Build would release the SAME frozen safe cancellation capability on all fully authenticated ORIGINAL accepting paths and no inconsistent concatenation of source fragments. Every certificate remains bound to the original claim/outpoint/burn/recipient, exact native message and VK, source anchors/window, actual semantic ancestors, contextual modern chain ID, exact canonical SYS tag, depth/deadline/reset and capsule identity. The three independently sufficient ORIGINAL challenge branches remain unchanged.

Compared to local-gate label joining (R289), this changes the state to depend on the ENTIRE source-certificate prefix, so an apparent suffix cannot silently switch predecessor identity. But it does NOT instantiate a public Build/Open. If seed is public, every synthetic prefix's path state is publicly derivable; path hashing alone does not authenticate the source or restrict secret release. If seed is private, Open lacks a publicly implemented means to derive the first secret state from arbitrary future ORIGINAL evidence. Per-full-path release rows reproduce R328's exponential list. Declaring a compact secret-dependent verifier/release program merely renames the missing WE mechanism. No ideal source-label oracle can count as a repair.

## Restricted exact state-count observation, NOT a WE lower bound
For a deterministic explicit-state hash path graph that reads u then v and should accept iff EQ_n(u,v)=[u=v], the residual suffix language following prefix u is {v=u}. Every one of the 2^n prefixes has a distinct residual language. Merging two distinct prefix states incorrectly accepts a suffix on at least one of them, unless the machine retains further information. Therefore, a label-per-residual-class graph needs at least 2^n distinct states at the half-way boundary. This is ONLY for this explicit-state path-graph representation. Public polynomial circuits can store u in n bits and test equality efficiently; no general circuit/obfuscation/ORIGINAL-source-WE lower bound is claimed.
