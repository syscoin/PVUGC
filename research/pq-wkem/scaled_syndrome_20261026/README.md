## Constructive change and exact honest release
The prior vector LWE reference source used primitive b and published per-column residue helpers h_j=P_j mod Delta. Instead put the public rounding lattice directly in a deliberately **nonprimitive public syndrome b**; no helper needs publication or cryptographic simulation.

Fix q=2^a, g=2^nu with 1<=nu<a, m>=2, n>=1, a PUBLIC b in Z_q^m with gcd(q,b_1,...,b_m)=g, and an error distribution chi supported on integer [-beta,beta] satisfying **g>2n beta**. Write b=g b' with b' having an odd coordinate. b is fixed before A and independent of it (or deterministically derived from permitted public context in the same order). Choose A uniform in Z_q^(m x n). Reference ORIGINAL relation is R_(A,b)(w): w is binary and Aw=b (mod q). This is an average-random-linear language, NOT a compiler for generic NP/PoW.

Independently sample k-bit native signing seed K and native public pk(K), and choose ell>=ceil(k/(a-nu)). For j=1,...,ell, sample s_j uniform in Z_q^m and e_j independently from chi^n. Privately compute
    p_j=A^T s_j+e_j;    P_j=b^T s_j = g t_j (mod q);
    z_j=canonical(P_j)/g in {0,...,q/g-1}.
Concatenate exactly r=a-nu bits per z_j as Z and take pad=L_k(Z) for a public fixed full-row-rank k-bit linear map (truncation suffices). Publish V=(x,A,b,{p_j},D=K XOR pad,pk(K),bound context,simulatable aux). **No h_j or secret-derived tag is published.** All setup s_j,e_j,P_j,z_j,K and unauthorized signing material must be protected/erased; malicious N-of-N ceremony not proved.

For ANY valid ORIGINAL binary witness w, y_j=w^T p_j=P_j+w^T e_j (mod q), with |w^T e_j|<=n beta<g/2. Since the P_j lie on the public multiples-of-g lattice in Z_q, nearest cyclic-lattice rounding uniquely returns every P_j and hence each z_j. Open obtains exactly K=D XOR L_k(Z), simultaneously for **every** valid w, including adaptively selected w. Distinct witnesses need not share internal states. This is an explicit classical release, not a SourceOpen oracle. Checking pk(Khat) is optional honest hygiene and not assumed to constrain attackers.

## Exact standard-QPT-LWE full-public challenge
Choose v,N with b'^T v=1, b'^T N=0 and T=[v N] invertible over Z_q. One explicit choice for odd b'_1: v=(b'_1)^(-1)e_1; for i>=2, N_(i-1)=e_i-b'_i(b'_1)^(-1)e_1. Every uniform s_j decomposes uniquely as s_j=v t_j+N u_j, where t_j uniform in Z_q and u_j uniform in Z_q^(m-1), independent. Put alpha=A^T v, B=N^T A. The invertible map A <-> (alpha,B) makes alpha and B **independent uniform**, since A was sampled uniform independently of b. Therefore
    p_j=alpha*t_j+B^T u_j+e_j;    z_j=t_j mod (q/g).
Given a standard LWE challenge (B,c), c either B^T u+e or uniform Z_q^n, the simulator samples independent uniform alpha,t_j and publishes p_j=alpha*t_j+c, z_j=t_j mod(q/g), with all real K,pk(K),D and other columns generated consistently. It reconstructs A=T^(-T)[alpha^T;B], so the **actual public matrix** is correctly distributed. This is the source opening and LWE simulator **together**. No challenge secret u or fixed digest opening oracle is assumed.

Hybrid H_j makes first j p-columns uniform and preserves the real common A, the real K/pk, all private t_i used to form D, and all simulatable context. Each adjacent change has at most one decisional-LWE_QPT advantage at the same exact (m-1,n,q,chi) parameters, including relevant resource overhead. In H_ell the columns p_j are independent uniform and the z_j are independent uniform r-bit strings, so a rank-k L_k produces an EXACT uniform pad independent of all published material, K and real pk(K). Null simulator given a native pk challenge samples A and independent uniform {p_j}, uniform D, and prescribed context without K. Thus for any arbitrary QPT key-recovery attacker on this complete classical public view:
    Pr[recover exact K] <= eps_native_seed(B*) + ell*Adv_QPT_decisional_LWE(B*).
Likewise fresh-message intended-path native forgery admits eps_native_EUF-CMA+ell*Adv_LWE when genuine signing queries and legitimate presignatures are **explicitly simulatable**. Already-authorized signatures and graph bypasses are not new-message forgeries. This is a straight-line reduction (no quantum rewinding, inverses, RO programming or copy of quantum advice). It covers coherent joint attacks across columns. Native checking materials, auxiliary state and independent related-capsule openings are permitted only when their challenge-level generation is simulatable without unknown K/t_j/e_j; nonuniform QPT advice is handled only under matching LWE/native advice assumptions.

## False and hard-true scope (not generic NP)
For a FIXED A,b whose transverse B=N^T A has full **column** rank modulo 2 (requires m-1>=n), B^T u is exactly uniform over Z_q^n, so p_j is independent uniform even conditional on t_j and all key/public-binding information. D is then independent uniform conditional on real pk. This is an exact complete-public-output simulator against any quantum postprocessing with suitably independent auxiliary state. The instance must be false: B w=N^T b=0 would force w=0, contradicting Aw=b!=0. Do NOT infer all false circuits have this rank certificate.

For fixed nonzero b and unplanted UNIFORM A, each nonzero binary w satisfies Aw=b with probability q^-m. Distinct binary w,v have a unit 2x2 minor, so their acceptance events are pairwise independent. Number N_A of witnesses has E N_A=(2^n-1)/q^m, Var N_A=mu(1-q^-m), and Pr[N_A=0]<=min(1,q^m/(2^n-1)). Thus n>=ma+lambda+1 gives a predominantly TRUE reference distribution; the unconditioned QPT-LWE key bound transfers when conditioning on true by dividing by Pr[true]. This does NOT prove hardness for a fixed adversarial NP statement or quantify Bitcoin economics. No practical 128-bit parameter choice has been established.

A QPT algorithm that finds a valid binary w from public uniform A,b (not target LWE c) breaks ordinary decisional LWE: embed B into A, sample alpha, run finder, check Bw=0 and test cyclic |w^T c|<=n beta. Real c=B^T u+e always passes for a valid w; uniform c makes w^T c uniform since w nonzero has a unit coordinate. With tau=(2n beta+1)/q<1, Pr[find ORIGINAL reference witness] <= Adv_QPT_LWE/(1-tau). A finder depending on the target c requires a different reduction, not this argument. Arbitrary final-key recovery is already covered by the full-view LWE hybrid, without requiring adversarial internal representation.

## Cost, exact exclusions and next unsolved equation
Compared with the earlier primitive-b helper scheme at effective rounding gap Delta=g, this different random source distribution has the SAME q, error tolerance, per-column entropy a-nu, ell and exact ordinary QPT-LWE bound, but drops ell*nu PUBLIC helper bits and their helper-correlation simulation. Payload excluding A itself: ell*n*a + k + |pk|+|context| bits. A from scratch adds mn*a bits. E.g. a=16,nu=9,n=128,beta=1,k=256 means g=512>256, ell=37, 333 helper bits removed; this is arithmetic, not validated PQ hardness or a material change in TB-scale generic-source storage.

The reference R_(A,b) is NOT the user's ORIGINAL burn/light-client/PoW circuit. Randomizing an existing structured A_x with row bases does not remove easy nonbinary short openings or make its transverse matrix B_x uniform. Fixed-source false security is proved only on the full-rank subclass; the uniform-matrix game does not become selected-instance security by conditioning on FALSE. There is no generic-NP compiler, no arbitrary hard-true PoW economic work reduction, no malicious setup/abort/retained-coins proof, no keyless builder, no Bitcoin P2MR/native SLH deployment, no cross-source same-key selective-opening proof and no validated 128-bit parameters.

The exact remaining equation is to produce a polynomial-size **witness-preserving ORIGINAL source compiler** for (relation, actual burn/authorization/output, anchors/work, claim/UTXO/branch, native checking key) AND a joint simulator matching its actual (x,A_x,b_x,{p_j},D,pk,aux,related capsules) under an independently justified QPT challenge, WITHOUT the challenge secret and without accepting short non-ORIGINAL pseudowitnesses. Uniform-A ordinary-LWE is not proof for structured A_x. This iteration advances the helper-free exact reference release but does NOT solve generic NP or the bridge.
