## 1. Candidate interface and concrete first construction

Let lambda be the security parameter, H_proj an ideal lambda-bit random oracle with injectively encoded, domain-separated inputs, and H_row, H_root, H_final distinct domains (equivalently independent ideal oracles). These are explicit ROM idealizations, not claims about concrete SHA. For each wire v and bit b, Build samples independent lambda-bit labels L_(v,b), rejecting duplicates across the polynomially many labels. These are stable hidden labels, not invented original source credentials. For a gate g on wires x,y,z, b=f_g(a,d), define

    A=L_(x,a), B=L_(y,d), D=L_(z,b)
    C_(g,a,d)=D XOR H_row(ctx,g,A,B).

The ordinary table is built once. A full original trace w and a fresh independent lambda-bit salt rho define root q=H_root(ctx,w,rho). Project each label using

    J_q(L)=H_proj(ctx,q,L).

The new mechanism would make a public translator T_g(C_g,aux_g,q,J_q(A),J_q(B)) return J_q(D), for every local row of every gate and arbitrary fresh root. Any public row-selection information and row checks may be supplied in aux_g; grant the evaluator the correct row for this preflight. A false local row or malformed projected input is not required to produce any specific value. Honest local evaluation must be possible with only the projected input labels and public hints, otherwise this is not a replacement for reusable public garbling. Build can produce polynomially many arbitrary extra hash-derived corrections before q exists. Open would propagate these projected labels along the actual V trace. One proposed terminal capsule is E=S XOR H_final(ctx,L_(out,1)); a terminal translator would reveal that stable accepting label (or the final mask) from its projected form. Terminal recovery is allowed only for a qualifying original witness.

First concrete translation tried on paper is a hash of the table row plus a new hash of the projected inputs:

    T_g^0 = H_proj(ctx,q,C_(g,a,d)) XOR
            H_row(ctx,g,q,J_q(A),J_q(B)).

The input encodings of H_row for this attempted correction and the base row are distinct. With distinct random labels and fresh q, J_q(D) is independent uniform conditional on the inputs to T_g^0, except on the event C_(g,a,d)=D (probability 2^-lambda), and accidental target prequeries. T_g^0 therefore does not achieve completeness. More importantly, replacing T_g^0 by arbitrary polynomial public code and hints cannot achieve the intended *one-way isolation* in this ideal-hash model, as follows. This is the selection's substantive obstruction, not a claim about all hash-only schemes.

## 2. Fresh-projection extraction from honest public evaluation

Fix any classical PPT Build algorithm allowed Q_B total classical oracle queries. It may compute arbitrary correlated public hints using all base labels, the complete original V and context, and public native key/message. Let the row input labels A,B and output D be distinct. Consider an evaluation root chosen uniformly after Build independently of its full state; equivalently use the salted H_root above on a selected w with independent fresh salt, up to the negligible event of setup having already queried that root input. The root oracle domain is independent of the projection domain. Let F be the event that no setup projection query has root q. For an independent uniform q, Pr[not F] <= Q_B/2^lambda. In the salted case an additional at most Q_B/2^lambda bounds a setup hit on the salt for any fixed w, even if w was known to setup; otherwise its root output is fresh. The same calculation applies to prior evaluations whose queried roots are added to the excluded set. We do not claim this freshness when roots are adversarially fixed in advance or chosen from setup outputs.

Condition on the setup tape/state, q, F and the input projections J_q(A), J_q(B). Neither is at the target address (ctx,q,D). In a lazy sampled oracle, Y=H_proj(ctx,q,D) is still an independent uniform lambda-bit value. All future non-target oracle replies are sampled independently of Y. Let an arbitrary public classical evaluator T make at most Q_T oracle queries, with local independent randomness. Include any public hints produced during setup, not just the base C above. If it never queries the target address, its output is independent of Y. The joint event of correctness without a target query therefore has probability at most 2^-lambda. Formally run a modified evaluation where the target address is never answered with Y, but with an independent placeholder if reached; until reaching that address the two executions are identical, and the no-hit event and output are independent of Y. Thus

    Pr[correct and no target query | F] <= 2^-lambda.
    Pr[target query | F] >= Pr[correct | F] - 2^-lambda.

No computational hardness assumption is needed for this inequality. The target input includes the entire stable label D, not just its projected value. A classical attacker executing the actual public translator can record the hash query inputs and outputs, including those of all public subroutines; no private honest tape, volunteered adversary representation, classical rewinding of a quantum adversary or QROM extraction is assumed. This is an explicit classical algorithm running public code in the ROM. It knows q, ctx, and the translator's claimed output. Among H_proj queries at this root, it selects the query whose answer equals that output. On a correct fresh evaluation, the target query appears with the probability above. Distinct fresh queried addresses have independent random outputs; the probability that a second distinct address at this root has the same output is bounded by Q_T*(Q_T+1)/2^(lambda+1), plus any supplied distinct projected input addresses counted in the same birthday bound. Duplicated queries to the same address are irrelevant. Alternatively, if public label commitments exist, candidates can be tested against the appropriate commitment. Therefore with overwhelming probability for a correct translator, its public evaluation yields the stable label D itself.

This is not inversion of J_q. It is extraction from the required *forward generation* of a fresh random-oracle projection. More public polynomial hints, nonlinearity of the translator, and hidden base-row randomness do not alter the argument, unless the hints already contain the fresh target value or the caller provides it. Precomputing target values for polynomially many roots has negligible coverage of a fresh uniform root. Sending the fresh output as an extra input is circular. A quantum honest translator would require a different argument; the original requires classical honest algorithms, which is the case proved here.

## 3. Consequence for the intended source compiler and joint view

Suppose the reusable-row design supplies projected input labels for arbitrary candidate traces (rather than already implementing the missing original-source gate), and every locally consistent row can be evaluated at a fresh root. This is the particular class the repair targets. The proof in section 2 converts any correct local translation into a stable-label export operation. An adversary can recover an intermediate stable label from one local evaluation, compute its projection at any other root by a single ordinary hash call, and supply it to later local rows under that root. The exported value is the same L_(v,b) used in setup, not a root-specific credential.

In the usual public-input garbling version, where both base labels on each witness-input wire are obtainable, an even simpler explicit attack maintains the set of known base labels at each wire. It processes gates in topological order, enumerates at most four pairs of available input labels, samples a fresh root per translation, projects those labels, runs the correct public local translator, and extracts the output label by the procedure above. It reaches all syntactically reachable output labels under independent local row choices. The number of calls is at most four times the gate count (binary gates), with a polynomial union bound on fresh-root hits, correctness errors, and oracle-output collisions. Constant inputs only supply their fixed labels. If independent local choices reach the accepting output despite no globally consistent original witness, it exports L_(out,1) and decrypts E exactly. The same scope applies to cross-witness partial labels exposed in the split-mask construction: no need to invert any hash or create a new source history to rescope a recovered stable label. This is conditional on local accessibility and a spurious accepting local combination, not an assertion that every original FALSE statement has that combination. R289 is the recorded regression to retain, not rerun here.

Binding q to the full witness commitment only at honest Open does not stop the attack on public reusable translators. The attacker can execute row code directly and make projections under a common q. A cryptographically enforced obligation that the caller already possess an entire qualifying ORIGINAL proof before any local translator exports an accepting path is not part of this construction and would be the missing release mechanism, not a repair supplied by the root projection. Likewise an input mechanism that only yields stable labels to already-qualified full original witnesses is not instantiated. No ideal SourceOpen or label issuer is accepted as a solution.

A simulator that independently samples root-specific hidden labels but does not expose their stable preimages is inconsistent with the real public forward-evaluation transcript. In a real correct translator a fresh projected output was queried at its stable preimage; the public execution and repeated roots reveal the same stable label. Thus a root-isolation simulator based only on noninvertibility of H_proj is invalid for this class. This is a local-to-joint obstruction, not a full impossibility proof of hash-only public release or a concrete SHA theorem. The classical attack suffices to refute security where its assumptions hold even against a QPT adversary class. It does not claim arbitrary quantum query extraction.

## 4. Handoff

Reject the static projected-label compiler before implementing larger fixtures. Do not substitute H(q,L) with nested hashes, publicly rekeyable masks, additional root commitments or more independent label salts while requiring the honest public translator to generate a fresh projection of a stable hidden label: the same forward-query argument applies to the last stable hidden preimage of the fresh output. If a fresh output is not a random-oracle projection of a reusable hidden token, this particular argument does not apply, but its joint simulation and same-capability convergence must be derived, not presumed.

The next useful mathematical target is a genuinely **non-exportable path-dependent** local transition: labels generated from the entire original witness need not be projections of stable wire tokens at all; however all valid paths must converge to one native capability with a witness-independent Build. In particular, propose a serialized mechanism for convergence without (a) raw fixed accept labels available by independent row choices, (b) a setup table enumerating all future roots, (c) hidden-program execution or a release oracle. Prove the joint distribution with actual source-dependent inputs, not just fresh ideal marginals. The result here eliminates one proposed route to that target; it does not supply it.
