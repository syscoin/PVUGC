## New release algorithm and the previously missing composition

R56 shared a single secret tuple (r,s,e,Kbind) across all authorized ORIGINAL branches of one OR manifest. A valid witness for one TRUE branch then revealed ALL other branches' opening/checking secrets. R59 instead proved that *separate claims* with distinct messages could use independently sampled LWE secrets under the same public matrix, but did not produce a single authorized same-capability OR manifest. This version combines one fixed N-of-N preauthorized native signature sigma_* on ONE specific challenge message m_* with independently sampled source/LWE/checking secrets for EACH authorized ORIGINAL branch. A valid witness in any authorized branch yields the SAME sigma_*, without sharing witness states or branch keys. A TRUE branch legitimately reveals sigma_*, so the scheme makes NO assertion of continued signature secrecy afterward.

Let x bind the exact ORIGINAL relation identity, statement, fixed claim and UTXO, authorized OR branches, anchors, ancestor/fork conditions, relevant interval tags, observation window, actual burn/authorization/output, native verification key and challenge capability. The authenticated manifest and N-of-N one-honest preauthorization fix m_*=DomainHash(version, x, manifest, branch policy, vk) and obtain one sigma_*=Sign(sk,m_*) **before irreversible funding**. Non-bypass transaction graph, actual signature preavailability, malicious abort resistance and honest erasure are separate premises, NOT proved here. The related, independently openable external claims have distinct native messages and independent secrets.

Classical BuildORisolated samples ONE honest uniform public A in Z_(2^t)^(m×n). For each branch j=0,...,B-1 independently sample s_j uniform in Z_(2^t)^n, e_j from the declared small-error law chi^m, and Kbind_j uniform k bits. Compute Y_j=A s_j+e_j mod 2^t and D_j=sigma_* XOR Encode(Y_j), where Encode is an exact bijection to the fixed native signature length; no truncation or invented KDF expansion. For every canonical source word mu_(j,u) of s_j,e_j,Kbind_j, publish Z_(j,u)=P_j(Delta mu_(j,u) 1+eta_(j,u)), with P_j and canonical source section built from the ORIGINAL R_j (the exact R59 Boolean-clause source), and bounded errors with specified joint sampling law. Source construction must be polynomial-time in any proposed practical regime; R59's current dense 2^n coefficient model is NOT polynomial in a generic NP witness length.

Compute Base=H(canonical(manifest, context, native m_*, vk, A, full relation/branch identifiers, all (D_j,Z_j), permitted independent related capsules)), explicitly EXCLUDING CK/Aux to avoid cycles. For each branch independently set CK_j=F_(Kbind_j)("CK",Base,j) and Aux_j=F_(Kbind_j)("AUX",CK_j,Base,j). This defines the WHOLE public transcript, not only a marginal LWE pad. H and F are concrete deterministic transcript functions: QPT collision resistance/PRF security of any chosen implementation is a separate assumption for rebinding/credential authenticity, not a consequence of the following distribution proof.

OpenORisolated(j,w) FIRST verifies actual R_original,j(x_j,w)=1 OFF CHAIN, authentic relation/manifest/scope and authorization. It evaluates all sections S_j(Z_(j,u)) on w, decodes s_j,e_j,Kbind_j under the stated cyclic error condition, checks CK/Aux, then returns sigma_j=D_j XOR Encode(A s_j+e_j) only if Verify(vk,m_*,sigma_j)=1. For EVERY valid ORIGINAL witness of ANY authorized branch, Ev_w(S_j(Z))=Delta mu+Ev_w(eta), so the same precommitted sigma_* is returned. No canonical witness or common intermediate witness state is needed. Exact R59 256-bit source-word correctness requires 2×2^(n_j)×B_noise < 65299 at q_source=2^272-237, Delta=65536.

**Credential isolation is limited and exact:** opening a TRUE branch reveals sigma_* and hence all public Y_i=D_i XOR sigma_*, but does NOT itself reveal independent Kbind_i, s_i, e_i. The latter secrets need independently justified post-release security; R60 does NOT prove them hidden in a hard-TRUE source. A valid TRUE branch authorizes the whole single OR path; do not claim security of a FALSE sibling's signature after release.

## Full-public-view restricted QPT theorem

Predesignate one target OR with B polynomially many certified-FALSE branches, each with a PUBLIC, efficiently checkable certificate P_j(1)=0 invariant under challenges. No branch has a valid ORIGINAL witness. Independently sample (s_j,e_j,Kbind_j) across branches, even though all share A and sigma_*. Source noise tapes and auxiliary/related opening laws must be jointly samplable *without the challenged target secrets*, including any allowed cross-branch noise correlation. Allow polynomially many independently seeded related TRUE claims under the same A or vk, with genuine classical adaptive openings and their own native signatures on messages distinct from m_*. The adversary is arbitrary QPT with polynomial quantum advice independent of the target signing key, target branch secrets, target pads and sigma_* conditional on the public authenticated scope; it may process classical transcripts coherently. No target opening, coherent opening-oracle access, shared-secret TRUE sibling, malicious correlated advice, unauthorized signature oracle for m_*, or dynamic context rebinding is permitted. If rebinding is allowed, add an independently established QPT binding term.

For each FALSE target source capsule, the **pointwise identity**
Z_(j,u)=P_j(Delta mu_(j,u) 1+eta_(j,u))=P_j(eta_(j,u))
makes the target SOURCE independent of target s_j,e_j,Kbind_j, even conditional on a permissible jointly sampled noise tape. In hybrid j, a straight-line simulator given ONE actual ordinary decisional-LWE challenge (A,Y) generates all other branches with its own independent LWE secrets under SAME A, has sigma_* from its own signing key for the LWE hybrids, and sets D_j=sigma_* XOR Encode(Y). It generates j's source P_j(eta) without challenged s_j/e_j, chooses Kbind_j, and then computes every CK, Aux and full-base dependency after all D/Z. It independently generates/open-answer all related TRUE claims, including their disclosed s/e/Kbind/witnesses, never requiring a SourceOpen oracle, a representation volunteered by the adversary, quantum rewinding or random-oracle programming. Thus when Y is an LWE sample the WHOLE joint public transcript is exactly honest, and when Y is uniform it is exactly the next hybrid.

Replace B independent target LWE samples in turn. In the final all-uniform hybrid, (D_0,...,D_(B-1)) are independent uniform even given the common sigma_*, since XOR by fixed sigma_* is a bijection on each coordinate. A straight-line native EUF-CMA reduction can therefore receive vk, sample all D_j uniformly WITHOUT knowing sigma_* and never ask its signing oracle for m_*, while using oracle signatures only on distinct related messages. An arbitrary QPT output of any accepted native signature for m_* is a fresh-message forgery. Conditional bound, fixed authenticated scope:

Pr[QPT recovery of an accepted fixed-path sigma] <= B Adv_QPT-DLWE + Adv_QPT-native-EUF-CMA (+ independently proved QPT context-binding/rebind term, when applicable).

This is **only** the complete specified certified-FALSE OR experiment. It neither proves arbitrary-FALSE nor hard-TRUE security, nor does it establish numerical QPT-128 parameters. It assumes honest classical setup and branch-independent target LWE secrets. A TRUE sibling cannot be treated as an unopened FALSE target once sigma_* has been legitimately released. HMAC/tag authenticity, malicious N-of-N setup and auxiliary correlations outside the declared law remain additional obligations.
