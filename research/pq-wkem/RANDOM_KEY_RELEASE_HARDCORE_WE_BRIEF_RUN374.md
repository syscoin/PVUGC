THEOREM (scope). Suppose for every NP relation R and every x, classical witness-independent PPT Setup(x) outputs public P and an ell-bit secret capability K, for both true and false x. P includes vk=PK(K), every public capsule/transcript, and the bound claim/branch context. Classical PPT Recover(P,w) returns precisely this SAME K for EVERY valid ORIGINAL witness, with negligible all-witness correctness error. For every false x fixed before setup, arbitrary uniform QPT algorithms with reproducible auxiliary input cannot recover exact K from complete P (false-instance full-key one-wayness). Then the following public classical algorithms implement NP *single-bit witness encryption* against that QPT model:

Enc(x,b): sample (P,K)=Setup(x), random r in {0,1}^ell; return (P,r,d=b XOR parity(r AND K)).
Dec((P,r,d),w): obtain K'=Recover(P,w), return d XOR parity(r AND K').

CORRECTNESS: Every valid ORIGINAL witness reconstructs the same exact K, so Dec returns b. Witness-dependent intermediate states may differ; no canonical witness/preimage is required.

SECURITY: If a QPT distinguisher differentiates b=0 and b=1 by advantage delta on a false x, a simulator given ONLY P samples random (r,d), runs a fresh distinguisher and outputs d XOR its plaintext-bit guess. After orienting the guess, this predicts parity(r AND K) with advantage delta/2. A Goldreich-Levin parity list decoder using polynomially many independently rerunnable classical-input/classical-output predictor invocations outputs a polynomial-size list containing exact K with inverse-polynomial probability. Choosing a uniform list element contradicts false-instance exact-K one-wayness. The whole correlated native verification key vk and any other simulatable public output already belong to P. No pseudorandomness of K conditioned on vk, QROM programming, or quantum rewinding is assumed. The classical decoder with freshly initialized QPT predictor circuits is QPT. This is a functionality implication, NOT a proof of the required OW premise.

QUANTUM LIMIT: The decoder needs repeatable predictor invocations. A single unknown, unreplicable quantum advice state correlated with K cannot be copied for those calls; no theorem for that stronger auxiliary model is claimed. Adcock–Cleve's quantum Goldreich-Levin theorem explicitly analyzes quantum one-way permutations, not arbitrary correlated WKEM capsules; the present argument instead uses classical list decoding with a repeatable QPT subroutine. The complete arbitrary-quantum-auxiliary security game remains UNPROVED.

MINIMALITY CONSEQUENCE: Run 373 required chosen-message IND hiding to get WE syntax. Here random-key false-instance one-wayness plus a public hardcore pad already suffices for bit WE. Thus for generic NP, merely sampling a native signing seed does NOT establish a functionality fundamentally below witness encryption. This does NOT prove that weaker mathematical assumptions are impossible, does NOT construct a local mixer, and does NOT rule out a restricted Syscoin relation-specific primitive. Multi-bit encryption and correlated multiple capsules need separate composition proofs. The stronger target true-instance key/signature recovery -> accepted Run-259 source representation -> ORIGINAL witness is entirely UNPROVED.

ATTACK LEDGER: Native checking-key correlations are in P; chosen/coherent evaluator use is allowed for QPT distinguishers described by the public classical code. Seam, gauge, gate fingerprints, multi-capsule correlations, malicious setup/retained seeds, cross-UTXO reuse and arbitrary one-copy quantum side information are NOT solved. A sibling true-instance capsule sharing K would violate the needed JOINT false-key one-wayness. The theorem does not permit replacing a protected release with a public trusted signer or Bitcoin-side NP verifier.
