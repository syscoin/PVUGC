## 1. Candidate using cycle-normalized whole transcripts

Let R_x(w) be the full original bounded relation, unchanged three OR grounds, actual source admission, relevance and maturity. For a setup with a known accepting input, consider Q(w,u)=R_x(w) OR [H_trap(u)=h], h=H_trap(t) for fresh random t known to setup only. This auxiliary witness is solely an attempted setup device; it is not an allowed substitute for original evidence and no independent puzzle is claimed as the release mechanism. Use a deterministic witness-preserving reduction of Q to an undirected Hamiltonian-cycle instance G, with a cycle from either accepting input and extraction of an accepting input from any cycle. This is a formal generic NP reduction requirement, not a compiled actual Core/LC circuit or a claim that a standard reduction has the special orbit property investigated below.

For any Hamiltonian cycle c of G on n vertices, let P(c) consist of its 2n ordered listings (all rotations and both directions). For each listing p, relabel G by sending its successive vertices to 0,...,n-1. Let A(p) be the canonical upper-triangle adjacency bit string of this relabeled graph. Define the normalized orbit O(c) as the *sorted multiset* of 2n strings A(p), retaining multiplicity. All of these graphs have the same standard cycle edges C0={01,12,...,(n-1)0}.

Explicit trial (polynomial in n, lambda and source-circuit size, assuming a polynomial witness reduction):
* Build derives c_t from the setup-only auxiliary witness. Choose public rank j uniform from 0,...,2n-1 and fresh seed r; define A*=O(c_t)[j]. For all graph coordinates e (unordered vertex pairs) let salt_e=H_salt(ctx,r,e). Form the canonical whole transcript T(A*) consisting of H_com(ctx,e,salt_e,A*_e) for every e and the fixed openings (1,salt_e) for e in C0. The latter are always valid because the cycle has been normalized. The graph and ctx, not c_t, A*, or T(A*), are published. Include the full binding context (source, claim, capsule ID, native VK/message etc.), h, j, r and S XOR XOF(ctx,T(A*),|S|), S being the frozen safe cancellation capability. Erase the auxiliary witness and setup's computed private strings.
* Open derives c_w from the actual original witness, computes O(c_w)[j], uses the same salts to regenerate T, and XORs the corresponding XOF pad. There is no honest-code acceptance bit guarding a raw public key; recovering the correct pad requires the normalized transcript to match or an accidental XOF equality.

This is a concrete serialized algorithmic trial. It has the intended *same* capability for all witnesses only if their normalized whole-transcript outputs agree for all possible setup ranks (or their distinct outputs have equal XOF, which is not a correctness mechanism). In contrast to a fixed committed-view extension, Open does not open any commitment generated by Build; it samples its own complete transcript using the shared rank. Its correctness problem is alignment of the sampled orbit, not checking a commitment opening against a prior commitment.

## 2. Exact orbit criterion, and counterexample to the proposed generic compiler

O(c)=O(c') iff an automorphism of G maps the undirected cycle edge set c to c'. Proof: if a relabeled adjacency string appears in both multisets, the two vertex bijections to standard labels compose to a graph automorphism, and both send their respective cycle to C0. Conversely a cycle-mapping automorphism bijects the ordered listings, preserving every adjacency string including multiplicity. Thus if equality fails, the two multisets are not just unequal: they have disjoint support. Sorting and choosing a common rank cannot align them at even one rank.

Concrete hand-checked example, no test execution: G has vertices 0,...,5 and edges
01,12,23,34,45,50,02,13,03,14.
It has cycles c=(5,0,1,2,3,4) and c'=(5,0,2,1,3,4). Every listed cycle edge exists. Degrees of vertices 0 through 5 are (4,4,3,4,3,2). The unique degree-two vertex is 5. The degree sequences starting at 5 in both orientations of c are (2,4,4,3,4,3) and (2,3,4,3,4,4). Those for c' are (2,4,3,4,4,3) and (2,3,4,4,3,4). No equality; graph automorphisms preserve degrees. Therefore no shared adjacency string between the normalized orbits. This illustrates a failure of the proposed generic normalization on an explicitly specified Hamiltonian-cycle instance, not a claim that a particular actual source certificate maps to this graph.

For any different adjacency strings at the same rank, at least one commitment coordinate e is computed from distinct domain-separated inputs sharing the same salt. Identical complete T would imply a hash collision at that coordinate. In the random-oracle idealization for fresh XOF domain inputs, distinct T yield independently uniform output pads, so for fixed honest choices the probability of equal pads is 2^(-|S|). This is a correctness failure, not a QPT security theorem. The actual Q reduction would require an additional orbit-transitivity property (at least across the auxiliary and every original witness), not supplied by ordinary witness preservation. Do not assume it from witness indistinguishability or randomness of graph relabeling.

## 3. Repair: use the accepting-challenge simulator rather than graph-specific off-cycle entries

The challenge that requests only the normalized cycle opens only C0. A simulated transcript can choose off-cycle bits arbitrarily and compute all commitments with the same public salts. In particular set all non-cycle bits to zero. This transcript is independent of the source, valid for that fixed cycle challenge under the local commitment-opening test, and every evaluator can reconstruct it exactly. If both Build and Open use it as the common pad input, a classical public algorithm on a FALSE original instance recovers S directly. This repair does not instantiate a Fiat-Shamir proof; enforcing the other challenge would require demonstrating that the committed graph is a relabeling of the actual G. That reintroduces the original differing orbit issue if whole transcripts are to align. Merely deriving a public challenge from ctx or hashing the opened cycle also does not enforce it. No claim is made that a standard multi-challenge ZK proof itself is unsound.

More generally, suppose the intended repair aligns complete transcript distributions by public rank J in a canonical sorted support. In an exact finite uniform-support version, if the source-free simulator has the same support AND admits an efficient canonical unranking algorithm UnrankSim(ctx,J), then an adversary runs that algorithm to reconstruct the exact secret pad input. In the nonuniform case the analogous sufficient attack condition is efficient common cumulative-mass quantile evaluation with the same public rational coin. Equal distributions alone do *not* imply such efficient unranking. Ordinary HVZK sampling or computational indistinguishability in particular does not supply exact coupling under a fixed rank. If the simulator has no efficient unranking, the remaining constructive task is to give a source-witness-dependent unranking algorithm that produces the same exact hidden transcript, along with a full-public simulator that never exposes that map. The cycle trial explicitly supplies efficient unranking only for each witness's own orbit, not one common orbit; its proposed simulator repair makes unranking public and loses FALSE security.

An alternate repair could try to build a special witness reduction into one cycle orbit without publishing a canonical graph. Even granting that property, deriving the pad from that relabeled graph leaves a separate arbitrary-recovery question: a party who computes the canonical adjacency string has not necessarily supplied an isomorphism back to G, much less an original source certificate. One cannot infer the mapping from its existence or count on graph-isomorphism hardness as an independently justified hash-only foundation. Publishing a mapping or accepting auxiliary trapdoor recovery as a substitute for original evidence does not meet the goal. No such reduction, extractor or security proof is supplied.
