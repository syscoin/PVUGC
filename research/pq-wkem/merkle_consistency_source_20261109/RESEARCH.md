## 1. Actual polynomial-time hash-only component

Take any deterministic classical polynomial-time ORIGINAL verifier V(x,w), with fixed polynomial-length n-bit random-access witness tape. Holder of a complete ORIGINAL evidence w builds a domain-separated collision-resistant binary Merkle tree and obtains root rho. The tree binds ctx (original relation identity, claim/UTXO, branch/path, anchor/window, intended native VK and message, source commitments), n, index i, and bit b in each leaf. All missing padding and node orientations are canonical.

Instrumented off-chain execution asks for each witness bit read i. The holder supplies (i,b,pi_i), where pi_i is a Merkle path to the SAME rho. The verifier checks exact path length, direction, index, bit and root; supplies b to its original computation. Repeated reads do not require an explicit stored copy of every earlier bit. Thus public *consistency* verification needs O(lambda + log n) extra workspace and O(log n) hash evaluations/read instead of the R167 candidate's enumeration of secret states for all assignments.

**Exact lemma, including QPT adversary:** If an arbitrary QPT A outputs a **classical accepted transcript** (rho,trace), a deterministic classical polynomial E produces either (a) an actual ORIGINAL satisfying w, or (b) two different concrete underlying hash inputs m != m' with H(m)=H(m'). This is a strict *accepted-transcript-output-to-ORIGINAL-witness* reduction, not an arbitrary final-signature/key recovery reduction.

**Proof:** Replay V deterministically and collect each requested (i,b,path). Reject missing/extra malformed reads. On a second accepted read of an index i that returns opposite b, there are two accepted paths for distinct canonical leaf inputs under the same rho. Trace both hash trajectories upward. Either the two distinct leaf encodings themselves collide, or at the first parent level where distinct inputs give the same digest, output that exact collision. If no contradictory read occurs, extend the partial bit assignment with arbitrary values for unqueried indexes. Replay original V on that completed w; induction over every adaptive read proves identical values, instructions and final acceptance. Runtime O(n+T log n+time(V)). No rewinding, quantum query-log access or claim that a QPT adversary volunteers a key-recovery representation.

An accepted trace might have artificial sibling hashes that cannot extend to an honest Merkle tree of a full w. That does not invalidate witness extraction: the actual ORIGINAL verifier only queries recorded indexes, and the reconstructed full w reproduces the computation. The extractor does NOT promise that w opens its entire tape under the particular rho, only V(x,w)=1. The lemma assumes the ORIGINAL relation is fixed and deterministic; time-varying canonicality/consensus oracles must be made explicit authenticated snapshot inputs or separately modelled.

## 2. Honest release correctness is STILL MISSING

Build knows R,x and a **frozen ordinary native signature sigma** before any future source witness or its Merkle root rho exists. A naive public ciphertext D=sigma XOR H_mask(ctx,rho_*) decrypts only with that one root. Different valid ORIGINAL witnesses generally have different roots; no hash property forces their masks to agree. Publishing rho_* to all holders exposes its pad to attackers who can ignore post-hoc verification. Replacing the mask with a public program "if Merkle/ORIGINAL verifies, return sigma" literally embeds sigma. No protected source-dependent correlation has been instantiated.

A simple root-polynomial correction is also precisely constrained. Suppose P(z) is a *public univariate field polynomial* degree <=d and the accepted witnesses have m>=d+1 distinct field encodings z_w, all with P(z_w)=K. Then Q=P-K has >d roots, so Q identically zero; P(z)=K publicly exposes K. To discriminate one false root with a different output, deg(P)>=m is required. This is ONLY a lower bound for this explicit low-degree public-polynomial class; it does not rule out high-degree succinct circuits, nonpublic protected evaluators or hash-only WE in general, and is NOT a security theorem about SHA.
