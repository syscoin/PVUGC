## Precise theorem

Take an arbitrary NP language L and security parameter lambda=n=statement length. Classical PPT witness-independent Setup(x) generates, for BOTH true and false x, the entire public capsule P_x, bound target challenge message m_x and native verification key vk_x. The public target signature is not already legitimately disclosed. A separately callable classical PPT Open(P_x,z) accepts ALL raw d(n)-bit inputs z and returns either a candidate signing credential, a target signature, or rejection. The public native verification key allows anybody to check whether an output authorizes the designated branch/message. All graph pre-signatures, branches and other public auxiliary information belong to P_x.

Assume every valid ORIGINAL witness w for true x yields SOME witness-dependent raw state s_w of length d that makes Open authorize the SAME exact branch capability with error at most epsilon_c. No canonical witness/state is required. Assume for every false x, ALL classical PPT / QPT outsiders given the entire public capsule have unauthorized pre-release target-signature success at most epsilon_s; exact-key hiding by itself is insufficient (Run 369).

If d(n) <= c log2(n) for constant c, and epsilon_c,epsilon_s are eventually each below 1/6, then L is in BPP. Consequently a generic-NP compiler satisfying these premises implies NP subseteq BPP.

Proof: on x generate Setup(x) without a witness, enumerate all at most n^c raw states z, run Open(P_x,z), sign m_x if given a candidate key, and check the resulting signature under the REAL public vk_x. Accept if any test succeeds. This is classical randomized polynomial time. On a true x, a valid witness exists and its successful state occurs in the enumeration, giving acceptance at least 1-epsilon_c. On a false x, this enumerator is itself a PPT unauthorized target-signature adversary, hence acceptance at most epsilon_s. Standard amplification completes BPP. The theorem requires no inverse circuit, pseudorandom-mixer assumption, quantum rewinding, QROM, statement-adaptive CRS, or nonuniform setup advice. QED.

This is NOT an unconditional impossibility theorem: NP subseteq BPP is not known to be false. The theorem only applies where the short raw suffix is independently callable. A single cryptographically non-bypassable program accepting an ORIGINAL witness rather than a freely supplied raw z is OUTSIDE its scope; merely placing a PUBLIC source verifier before a separately callable suffix does not enforce that boundary. Minimal gate COUNT is not minimal input BIT WIDTH. A cryptographic-width frontier can avoid polynomial enumeration without proving security; coherent attacks for larger widths remain separate (Run 367). No concrete 128-bit claim follows.

The true-instance extraction corollary is conditional: on any planted hard-ORIGINAL-search distribution, the same raw enumerator recovers the capability. A universal QPT recovery-to-ORIGINAL extractor would then solve the assumed-hard original search or another explicitly assumed-hard problem. Run 259 supplies only accepted COMPLETE representation -> ORIGINAL witness / stated SIS break. A guessed raw state or native signature has not automatically satisfied Run 259 acceptance.

Attack taxonomy: local callable seam and adaptive public evaluation break; native checking-key correlation supplies the success test. Fresh claims, honest seeds, frame independence and UTXO binding do not repair one short callable frontier. Gauge alignment, statistical fingerprint, multiple-capsule combination and quantum-only attack are unnecessary. This classical attack already lies within QPT. Malicious setup and sealed-entrypoint security are not evaluated.

Exact compact checker: frontier_width_compact_run371_check.py, standard library. It exhausts all Boolean acceptance functions on raw widths 1..4 (4,16,256,65536 functions) and checks exhaustive recovery iff some accepted raw state exists. Additional finite true/false fixtures use a toy hash-based native-like checking key at widths 6,10,14. Python syntax passed; two executions were byte-identical; 149101 assertions passed. The extended local-only checker passed 197584 assertions. Neither checker proves NP hardness, native SLH-DSA, post-quantum security or an implementable sealed gate.
