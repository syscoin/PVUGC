SPHFwGZ has disjoint language L, smooth set Lprime, and grey set G=X minus (L union Lprime). Correctness is only required on L; smoothness is only required on Lprime, NOT on every false ORIGINAL instance outside L. The LWE construction defines L as honestly encryptable zero words c=As+e with bounded error B; Lprime consists of words where Dec(T,c) is not zero. A gap can arise when Dec(T,c)=0 for error beyond B but inside its larger decryption acceptance radius. OT security and ECC amplification do not automatically repair this missing worst-case false-instance WKEM guarantee.

CONDITIONAL THEOREM. Let Q be any NP language. Suppose classical PPT Gen produces (pub,T), with exactly the public setup distribution a proposed witness-independent compiler uses; Map(pub,x) is classical PPT; and Test_T(c) is polynomial time. If for EVERY x in Q, Test_T(Map(pub,x)) accepts with probability at least 1-epsilon_plus, while for EVERY x outside Q it accepts with probability at most epsilon_minus, both errors below 1/3 by constant margin, then Q is in BPP. Proof: a BPP decider itself executes Gen, retaining T, executes Map and Test_T, and amplifies. In the cited LWE language take Test_T(c)=[Dec(T,c)=0]. Hence a generic gap-free classical reduction from arbitrary NP into this trapdoor-decidable L/Lprime split would imply NP subseteq BPP. Honest ceremony erasure does not alter the simulated decision procedure. This is not an unconditional impossibility; other public-parameter distributions without an efficient sampling trapdoor and specialized relations are outside scope.

EXACT TOY GAP. For odd q in {17,19,23,29}, take A=(1,0)^T and c=(c0,v) over Zq squared. Honest zero encryption accepts centered second-coordinate error magnitude at most B=1, while toy zero decryption accepts at most Bdec=3. Consequently L has 3q words, G has 4q words, and Lprime has q(q-7) words. For every q, c=(0,2) is false for the ORIGINAL honest-opening relation, yet Dec(c)=0. Every L word has THREE different honest openings, illustrating that the source witness need not be canonical. A separate synthetic projection logical countermodel can leak the entire key on G while retaining correctness on L and smoothness on Lprime; it is explicitly NOT the complete cryptographic SPHFwGZ, nor an attack on the cited LWE scheme.

SECURITY GAP. A purported release compiler needs a separate proof that every false ORIGINAL statement maps to Lprime, except negligible worst-case/adaptive probability, or independent hiding on G. If Gen exposes a private membership-testing T to its own generator, the theorem constrains generic NP maps. Source equality Dec(T,c)=0 is not a Syscoin ORIGINAL witness.
