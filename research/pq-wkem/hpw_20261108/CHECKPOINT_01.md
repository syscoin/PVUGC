## Concrete hash-only release layer being investigated

Let F be a field of size 2^lambda. Let n distinct nonzero x_i be public. Sample a uniformly random polynomial f of degree <t, including its constant coefficient K=f(0). Sample independent r_i in F. A finite set of public symbols A embeds injectively into F. Define a hidden cell token

    Z[i,a] = r_i + a*f(x_i).

Publish domain-separated hash commitments

    C[i,a] = H(Encode("HPW/token", context, capsule_id, i, a, Z[i,a])).

For a fixed baseline codeword a0, release only Z[i,a0_i]. For a second codeword b, an actual token Z[i,b_i] with b_i != a0_i gives

    f(x_i) = (Z[i,b_i] - Z[i,a0_i]) / (b_i-a0_i).

Any t distinct such rows interpolate K. A code of distance at least t makes every pair of distinct codewords reconstruct the SAME K; they need not use the same differing rows or internal state. A frozen native signature sigma can be masked by an independently domain-separated hash of K. The signature itself is not generated by the token layer.

This is an actual finite classical algorithm on supplied token preimages, but it is NOT yet a SOURCE compiler. Tokens are not merely their public hashes. Supplying a string containing a PoW header does not by itself produce Z[i,a]. A verifier which rejects fake evidence is not cryptographic protection against raw token recovery.

## Joint-public proof opportunity (to be checked)

A proof must include every C[i,a], the baseline tokens, masked sigma, checking/audit fields, the complete source statement and context, sibling capsules and disclosures. For a fixed set D of fewer than t revealed row shares, the polynomial is uniformly distributed subject to f(x_i) for i in D. Consequently K and each remaining f(x_i) individually remain uniform over F. Each unrevealed cell token remains uniform when a != a0_i. This is stronger than claiming the pad marginal is random, but is not itself a cryptographic proof.

Investigate a quantum-random-oracle hybrid: sample all public commitment values and the mask value independently; leave their hidden inputs unprogrammed in a reference oracle. Program the actual hidden cell points and mask point only in the real experiment. Domain separation makes a query address a particular capsule/row/symbol, rather than any of many unlabeled targets. A telescoping unitary argument, if all reference states are independent of the remaining hidden polynomial, should bound distinguishing norm by 2Q/sqrt(|F|) for Q total oracle queries. The exact distribution/access conditions, selected-output recovery, native forgery and selective-opening limits must be written explicitly; no classical extraction argument is automatically quantum-safe. This is an investigation in the quantum random-oracle model, not a standard-model claim for SHA-256.

## Syscoin-specific source-binding experiment

Keep TWO distinct identities:

1. A semantic outcome identity: original claim scope, selected source height, its parent/ancestor slot, and the pure child-header hash. It defines which source outcomes genuinely conflict.
2. A work-certificate identity: the complete canonical child/header/coinbase/Merkle/AuxPoW/Bitcoin-parent/anchor evidence for that outcome.

Do not substitute the second identity for the first. Two different parent PoW solutions can certify the same child; their distinct parent hashes must not automatically count as contradictory source outcomes. Conversely, the work authentication still must bind the actual parent, tags, interval, linkage and context. This pass treats that behavior as a source model to be checked, not as a new deployment claim.

The proposed source-seal is to commit the capsule table root and claim context in the source's authenticated coinbase/AuxPoW path. Test BOTH obligations separately:

    SourceAuthentic(x,w,root)=1
    PublicDerive(x,capsule,w) = the actual hidden Z tokens.

A commitment can address the first; it does not automatically implement the second. Neither an online token issuer nor source-selected retained token secrets is allowed as a replacement. Native Bitcoin still receives an ordinary signature, not the NP verifier or a fraud-proof dispute.
