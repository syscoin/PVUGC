## The short-inverse problem
Run 638's conditional proof simulator requires an *integer* J (t by m) for public D (m by t) such that D J = I_m (mod q) and alpha=(sigma_G/s_F)^2 ||J||_op^2<1. Set B=s_F/sigma_G.

**Straight-line ISIS reduction.** Let q be prime and D be *uniform* over F_q^(m by t), with no correlated trapdoor or auxiliary advice. Suppose a classical PPT algorithm finds such a J with probability p. Given independent uniform A in F_q^(m by t) and y in F_q^m, abort only if y=0 (probability q^(-m)). Complete y to an invertible matrix T with T e_1=y; set D=T^(-1) A, run the inverter, and output z=J e_1. For every T, D is exactly uniform and independent of T. Thus A z=y mod q, ||z||_2<B, with success at least (1-q^(-m))p. This is a classical straight-line ISIS solver, no rewinding; it also accommodates a classical-I/O QPT inverter with instance-independent quantum advice. It does NOT lift to advice correlated with the source matrix or prove a full SOURCE reduction.

**Unconditional uniform counting bound.** Put N_t(B)=number of nonzero integer vectors z of Euclidean norm <B. For uniform D, Pr[exists right inverse J with ||J||_op<B] <= min(1,N_t(B)/q^m). Proof: the first column z must solve D z=e_1; every fixed z nonzero mod q reaches e_1 with probability q^(-m), and a vector zero mod q never does. For B=2, N_t(2)=2t+4 C(t,2)+8 C(t,3). Hypothetical (NOT Syscoin parameters) q=3329,m=256,t=512,B=2: N=178434048 and success <=2^(-2968.0). Where this bound is negligible, the required J is absent with overwhelming probability even for an unbounded solver.

**Distribution-free arithmetic obstruction.** Let R=max_i ||D_i||_2 for an integer lift D. If D has no integer right inverse over Z, then any modular right inverse obeys ||J||_op >= (q-1)/R: D J-I=qH with some nonzero integer entry; Cauchy-Schwarz applies to that entry. Therefore alpha<1 is impossible when (q-1)*sigma_G >= R*s_F. For full-row-rank integer D an integer right inverse exists iff the gcd of all maximal minors is 1. In the square case det(D) must be +/-1. Example D=diag(2,2),q=17: D is invertible mod 17 but every modular right inverse has operator norm at least 8; J=diag(-8,-8) attains 8. The bounds concern the actual small integer lift, not an arbitrary modular representative.
