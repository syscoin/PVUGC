# Run 582: degree/support obstruction for an acceptance-only local release frontier

**Date:** 2026-10-17. **Live branch starting SHA:** `08f8af4bff5fceca42b7fd5537f10f3106df78d5`. Draft syscoin/PVUGC#1, `research/pq-wkem-validation-20260918`. Exact dependency: published Run 580 note blob `fba4dadaad8b942d3c6887f449081d0b52367e6b`; exact unreferenced Run 581 note at `5f2145bce5adf57aee65d957bd7c74c47ae7e7e7`. Not a WKEM, QPT hardness proof or production change.

**Restricted interface.** Classical PPT setup publishes a Boolean local authorization predicate `Q_x:{0,1}^n->{0,1}` accepting at least one hidden state even on an ORIGINAL-false x. Public computation is coherent-reversible to a QPT adversary. The *strong* model-specific premise is: **every** `z` satisfying `Q_x(z)=1` suffices, using public `Finalize(P_x,z)`, to recover an accepted credential under the branch's public verification key. If accepted states instead undergo any further protected filtering (hash, native signature, SOURCE representation), THIS RESULT DOES NOT BREAK THAT CONSTRUCTION. A Boolean comparator alone, as in Run 581, is not itself a signing credential.

**Theorem 1 (Reed–Muller minimum weight).** For nonzero Boolean multilinear ANF `Q` of algebraic degree `d<=n`, the number `M` of accepted states satisfies `M>=2^(n-d)`. Proof: decompose `Q(u,b)=Q0(u)+b Q1(u)`. If Q1=0, both halves are the same and induction doubles weight(Q0). Otherwise at every u with Q1(u)=1 exactly one of Q(u,0),Q(u,1) is one; induction on Q1 of degree <=d-1 supplies >=2^(n-d) points. Equality is reached by products of d independent affine forms.

**Theorem 2 (QPT forgery in the restricted interface).** Random classical chosen inputs find an accepted z after expected <=2^d trials. Coherent multiple-marked-point Grover/BBHT finds one in `O(sqrt(2^n/M))<=O(2^(d/2))` public predicate evaluations, even when x is ORIGINAL-false. Under the acceptance-sufficient premise this yields an accepted challenge credential without any ORIGINAL witness. For n>=256, d<=128 gives an `O(2^64)` generic quantum *query* attack, not a concrete gate cost.

**Gate-depth corollary.** A circuit over XOR/NOT/constant/input and 2-input AND gates with total acceptance-predicate AND-depth t has `d<=min(n,2^t)`. With t<=7 and n>=256, the same `O(2^64)` quantum-query attack follows. Eight AND layers are at best a weak necessary condition for a 128-bit black-box search margin, never sufficient. A native key checker or hash in the *actual complete* acceptance path changes the bound; do not count only a low-depth prefix.

**Theorem 3 (affine gauge invariance).** For invertible affine coordinate substitution g(z)=Az+b, `deg(Q∘g)=deg(Q)`, by substituting and applying the inverse, and `weight(Q∘g)=weight(Q)` by bijectivity. Independently randomized affine input frames cannot lower the acceptance fraction. Nonlinear reversible local mixing is out of scope.

**Scope and attacks.** Seam spoofing: attackers call the public finalizer on found z, not through the original source verifier. Gauge: affine mixing preserves ANF degree and support. Fingerprints: density >=2^-d survives relabeling. Public chosen-input attacks: direct classical and coherent QPT search. Multicapsule, malicious setup/retained seeds, erasure/abort, replay, native public checking-key correlations, arbitrary auxiliary-input attacks, and the conditional P2MR/SLH graph are NOT established positively; attack already applies with one honestly sampled capsule and needs no advice. For Q-positive states that do NOT yield credentials, this proof makes no forgery claim, and the extra filter needs independent QPT analysis. Run 259 supplies ORIGINAL extraction only for accepted complete source representations, not arbitrary Q-positive states.

**Relation to Run 581.** A unique accepted hash point `Q_h(z)=[H(ctx||z)=H(ctx||h)]`, when collision-free, has full ANF degree n, agreeing with the theorem; nonetheless its Boolean answer cannot by itself reveal h. There is no late ORIGINAL-witness release construction here. The local degree bound is a falsifier against acceptance-only gadgets, not an obfuscation/WE construction or a reintroduction of discarded linear rank candidates.
