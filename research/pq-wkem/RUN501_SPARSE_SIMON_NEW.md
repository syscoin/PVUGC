# Run 501 — sparse exceptions do not repair a release-critical Simon seam

Draft syscoin/PVUGC#1, branch research/pq-wkem-validation-20260918, starting SHA ad2a67989a69b3fef6dc81db3b68239799bc7d73. This is one bounded *falsification* extending Run 493's exact Simon-period attack; it is not a practical PQ WKEM, new WE assumption, or refutation of CCMR's published RIO construction.

**Candidate.** A minimal protected release region attempts to conceal a release-critical nonzero XOR offset Delta by publishing a classical-PPT evaluator f which equals a perfect two-to-one Simon oracle g except on a sparse set of inputs. g(x)=g(y) iff x=y or x XOR y=Delta. A proposed capability wrap is C=K_x XOR H(context,Delta), with context binding the relation ID, claim/UTXO, branch, anchors/window, and native checking key. This is an offset-hiding subcomponent, not a demonstrated all-ORIGINAL-witness opener. The PPT implementation of the promised evaluator is conditional: a finite oracle table is not a scalable hidden-offset construction.

**Theorem A (arbitrary t-input perturbation).** Let N=2^n and delta=t/N be the fraction on which f and g differ. Define |psi_h>=N^(-1/2) sum_x |x>|h(x)>. Their inner product is 1-delta and their pure-state trace distance is sqrt(2delta-delta^2). Hadamard/Fourier measurement is a channel and cannot increase distance; m independently prepared output samples have joint statistical distance at most m sqrt(2delta-delta^2) by a product hybrid. Under g, outcomes are uniform in the hyperplane orthogonal to Delta; for m=n+c samples, binary rank failure is <2^(-c-1). Consequently a uniform QPT adversary using the public evaluator coherently and ordinary GF(2) elimination recovers Delta with probability >=1-2^(-c-1)-m sqrt(2delta-delta^2), when positive. No quantum advice, QROM programming, or rewinding is assumed.

**Theorem B (exact fresh-label law).** Suppose each modified input receives a new distinct output label, absent from the image of g. Let j be the number of Delta-pairs with at least one modified member. There are N/2-j intact 2-element output classes and 2j singleton classes. The exact probability of each Fourier outcome y is (2N-2j)/N^2 if <y,Delta>=0, and 2j/N^2 otherwise. Proof: each intact pair contributes squared Fourier amplitude 4 on the even hyperplane and 0 on the odd coset; each singleton contributes 1 everywhere. Therefore Pr[odd parity]=TV(p_f,p_g)=j/N<=delta; conditioned on even parity, y is still *uniform* in Delta-perp.

For m=n+c samples, the adversary returns the unique nonzero vector of the GF(2) measurement kernel, if one exists. The probability it returns the *actual* Delta is exactly ((N-j)/N)^m times product_{i=0}^{n-2}(1-2^(i-m)). Any odd sample excludes Delta; conditioned on all-even samples, exact uniform-hyperplane rank gives that product. A single changed input (j=1) destroys the exact Simon promise yet leaves success >=1-m/2^n-2^(-c-1). Knowledge of Delta releases K_x in the example XOR-key-wrap even for an ORIGINAL-false instance, without an accepted COMPLETE-source representation. This does *not* attack constructions for which Delta is irrelevant to protected release.

**Attack taxonomy and QPT scope.** (1) sparse changes leave the XOR seam; (2) Fourier constraints recover the global gauge; (3) exception labels themselves can fingerprint branches; (4) related capsules can be attacked individually, requiring no shared key; (5) reversible coherent access to public evaluation is essential; (6) fully honest, even setup-ZK-certified, generation does not help; (7) context-specific wrapping prevents only replay, not fresh same-claim recovery; (8) the native verification key and all public auxiliary information are included and ignored by the quantum period attack; (9) the attack exploits actual coherent Hadamard interference, not classical acceleration. An explicit small truth table is classically inspectable; no claim of a cryptographically hidden period implementation.
