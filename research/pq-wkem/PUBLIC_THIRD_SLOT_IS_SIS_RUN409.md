# Run 409 — literal public Enc3 would solve short SIS

Source: Agrawal–Yadav–Yamada, *Multi-Input Attribute Based Encryption and Predicate Encryption*, CRYPTO 2022, Section 6, PDF pages 615–617: https://crypto.iacr.org/2022/papers/530630_1_En_21_Chapter_OnlinePDF.pdf .

Starting head syscoin/PVUGC#1: 77bbbc5333c61eb0cce2ae6260f4bf293295090c, branch research/pq-wkem-validation-20260918, draft/unmerged. Run 408 note blob: 00be403b1d6e0ff8e8e0ae5bb6712b26c53b1220. This is a **format-specific conditional impossibility**, not a WE/local-mixing impossibility.

For slot-three attribute x3 in {0,1}^ell, the public C matrix contains paired k-by-n blocks plus two tail blocks. Selecting one per attribute and both tails gives M_x3 in Z_q^(k x r), r=(ell+2)n. The paper's literal Enc3 uses a **secret trapdoor** to sample a short vector t_x3 satisfying M_x3^T*t_x3 = 0 (mod q). Its ciphertext output is the unencrypted integer vector t_x3. The relation cancels lattice masks during Dec.

**Straight-line reduction.** Suppose a freely publicly callable classical PPT PublicEnc3(pp,x3) outputs nonzero t of norm at most beta<q satisfying this exact equation with probability p for some fixed public selector x3. Suppose the C matrix generated by TrapGen is within statistical distance delta of a uniform C. On a uniform SIS challenge A in Z_q^(r x k), embed its r rows as the selected columns of C and sample remaining columns independently uniformly. Simulate the remaining independent public parameters. The resulting pp is delta-close to honest pp. Run PublicEnc3 once. Whenever it succeeds, A*t=0 mod q and 0<||t||_2<=beta. Thus it directly solves ordinary average-case SIS_(r,k,q,beta) with probability at least p-delta. The same straight-line reduction applies to a QPT candidate with classical vector output under an explicitly QPT-hard SIS assumption; no quantum rewinding or QROM programming is used.

The conclusion is limited to a public replacement retaining the **bare nonzero short-kernel-vector third-slot format**. Zero output makes the SIS reduction vacuous and does not give general correct ABE decryption. beta>=q admits trivial vectors q*e_i. A restricted sampler available only on hard-to-find valid ORIGINAL evidence falls outside the all-x3 theorem; for a universal compiler supporting easy known-valid input too, this obstruction reappears. Hardness is NOT established from the name SIS: actual (r,k,q,beta), TrapGen marginal and quantum assumptions must be audited. The cited source itself uses pairing groups and is not PQ.

Run 408's second-slot chosen-coin normalization did not recover the message. Here the distinct **third-slot** obstruction follows without an Enc2 attack. This does not rule out a redesigned publicly encryptable third slot or a different local mixer, and does not prove arbitrary key recovery, source extraction, or native Bitcoin signing.
