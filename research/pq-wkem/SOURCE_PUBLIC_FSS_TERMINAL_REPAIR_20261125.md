## Candidate A: use both FSS keys as a publicly executable point function

Consider the elementary two-key binary seed-tree construction with each share state (s_b,t_b) at every prefix, b=0,1, t_b a control bit. A public hash/PRG expands a state to two children, and public correction words are applied depending on the control bit. The standard invariant for encoding the point a is that the two *complete* states coincide off the prefix path to a and have differing control bits along that path. An XOR-output terminal correction masks the payload. This requires neither LWE nor group hardness; conventional single-key privacy is not joint-key privacy.

Publishing both keys makes a directly recoverable. At any prefix on its path, expand both keys to both children and select the unique child with unequal states (or differing control bits). Induction recovers a in n steps and uses only public expansion. Even if Build had a known source point, this is not a hard-TRUE release; and Build does not generally know any point at all. Single-key hybrids cannot simulate both keys. Using a known public point R_x(w)=1 in place of a bypasses ORIGINAL evidence, because the adversary evaluates the point directly on input 1. No implementation or point-function size sweep is justified.

## Candidate B: retain decoy divergent paths, correct only at the leaves

Try dropping unique divergent-prefix control. Allow arbitrary many distinct pairs of states throughout the tree, including on invalid full inputs; only at the terminal layer use a shared m-bit correction B. For a prefix expansion circuit F built from public hash expansion/correction words, both keys are now public and any w produces

    (s_0(w), t_0(w)), (s_1(w), t_1(w)) = F(C_tree, w)
    p(w) = t_0(w) xor t_1(w)
    d(w) = h_0(s_0(w)) xor h_1(s_1(w))
    T(w) = d(w) xor p(w) B.

Here h_b are domain-separated m-bit hash-derived potentials, with an optional public terminal dictionary replacing them in the attempted repair below. Want T(w)=K for every R_x(w)=1 and T(w)=0 otherwise. Open would compute D xor T(w) on the full original certificate. This construction attempt does not posit an ideal gate, secret evaluator, or local label release.

Exact simultaneous conditions for the trial are

    h_0(s_0(w)) xor h_1(s_1(w)) = R_x(w) K xor p(w) B.

The decoys can make the simple Candidate A path traversal ambiguous. However, the terminal equation has to hold *on all full inputs*, including multiple complete genuine witnesses. In particular all valid leaves with the same p must have exactly equal d. Random independent terminal hash outputs do not supply this invariant. For any two leaves with the same p and distinct pairs of side-typed seed inputs, if the involved terminal hash values are still fresh independent uniform values conditional on the tree/setup transcript and selection of the pairs, equality of d occurs with probability 2^-m (the XOR of the symmetric difference contains at least one fresh independent term). This is a conditional classical random-function calculation, NOT a QROM adaptive-query theorem: a Build that deliberately correlates states using those hash queries is outside this calculation. Merely using a longer PRG or larger tree does not implement that deliberate correlation.

Try deriving the terminal correlations as exact potentials rather than random independent hashes. This is a genuine repair of the independent-output correctness failure. Form the bipartite multigraph with vertices (0,s_0) and (1,s_1), one edge for each full w, labelled (R_x(w),p(w)). Write the equations for vertex potentials H_v. For every even closed walk L, telescoping forces

    (xor_{e in L} R_e) K xor (xor_{e in L} p_e) B = 0.

Conversely, for a fixed K and B this cycle condition is sufficient for freely chosen potentials on an explicitly given finite graph: choose one m-bit potential per connected component, propagate along a spanning tree with edge difference R_e K xor p_e B, and use the cycle identities to verify every remaining edge, including parallel edges. Thus avoiding odd source-parity cycles with zero control-parity is necessary for nonzero K. If two different cycle parity vectors impose B=0 and B=K, then K=0 as well. Choosing an acyclic leaf-pair graph avoids all cycle constraints, but does not provide an efficient way to construct the potentials from the original implicit source predicate. This is a correctness characterization, not a security reduction or a proposal to enumerate the exponential witness graph.

## Attempted concrete serialization and joint-public countercheck

For an explicit polynomial-size terminal seed dictionary, Build could sample root potentials, compute the other potentials by the spanning-tree equations, and serialize them with the two tree keys and B. This is a candidate hash-only public representation, avoiding hidden evaluators and secret hash programming. Its exact security fails even if the graph is acyclic and the correctness equations are magically supplied without solving the source problem.

An attacker lists all left and right public dictionary potentials, enumerates each pair (u,v) and each p in {0,1}, computes k'=H_u xor H_v xor p B and S'=D xor k', and tests N_x(S'). If a qualifying original certificate exists then the pair and control of its leaf occur in this enumeration, so at least the correct S is a candidate. Complexity is at most 2 |V_0| |V_1| native verifications, polynomial for the proposed explicit dictionary. No witness, accepting edge, or source transcript is required. A different accepted S' is already an accepted native cancellation, whether or not it is the exact precommitted S. This uses the public VK and exact native message, not an assumption that every native signature is unique. A native-key-free indistinguishability analysis of one FSS share would miss this dictionary attack entirely. The attack also applies if the polynomial sets of terminal seeds are publicly listed and their potentials are obtained by hashing rather than stored. It is a deterministic classical attack against the joint view; it needs neither QPT rewinding nor an adversarial representation.

The attack does NOT apply solely from a bound on the number of distinct seeds if their values are not efficiently enumerable from the capsule. In that case the tree keys must implement a nonlinear correlation over implicit, hard-to-find terminal states, with all valid edges satisfying the exact equation and without a public list of those candidate masks. Nor does it apply to arbitrary FSS constructions outside the terminal representation above. Adding an honest-code check R_x(w) before output is insufficient: the polynomial dictionary enumeration does not call Open. Including source proof bytes, capsule IDs or domain separation in the hashes does not hide the public dictionary values.
