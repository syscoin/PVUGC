**Exact conditional lemma:** If a public classical-PPT frontier evaluator `E_P:{0,1}^n->{0,1}^m` satisfies `E_P(u)=E_P(v) iff v=u or v=u XOR delta` for hidden nonzero `delta`, then a uniform QPT adversary can recover `delta` with `n+c` coherent evaluations, failure `<2^(-c-1)`. Public classical code can be reversibly run on a quantum computer; hiding the source code's masks does not prevent coherent evaluation.

**Proof:** Query the uniform superposition into an output register and measure that register. Input collapses to `(|a>+|a XOR delta>)/sqrt(2)`. Apply `H^n`. The amplitude on `y` is `((-1)^(a.y)+(-1)^((a XOR delta).y))/sqrt(2*2^n)`. Consequently observed `y` are uniform among vectors orthogonal to `delta`. With `q=n+c` samples, a union bound over nonzero missing linear functionals gives failure `<2^(n-1-q)=2^(-c-1)`. Classical GF(2) elimination recovers `delta`. This is genuine quantum interference, not merely Grover acceleration. If a capability is `K=C XOR H(ctx,delta)`, extracting the offset also extracts `K`. This says nothing by itself about all-witness ORIGINAL completeness or native-signature-to-ORIGINAL extraction.

**Scope:** This rules out concealing a release-critical XOR offset behind an exact Simon-periodic *public* evaluator. It is NOT a general RIO/local-mixing impossibility result.
