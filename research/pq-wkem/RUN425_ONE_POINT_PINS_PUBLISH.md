# Run 425 — one encoded label per boundary leaks a source predicate

Actual starting PR head: ee3e74a87d6f7420cf55d39759baf88c6d3e3e5d; branch: research/pq-wkem-validation-20260918. Dependencies read at exact SHA: Run 424 full-frame boundary theorem (blob 7c8bbbd205dadc3431044588daebdf13ed20b811) and Run 423 holonomy theorem (blob 08f5576bf3595bd53f1b98b5a7b974d581ceafea). This iteration strengthens the Run 424 counterexample: no complete endpoint frame is required.

MODEL. For d>=2, honest classical PPT setup independently samples M0,M1,M2 uniformly from S_d. Fixed source permutations F0,F1 are transformed into public forward-evaluable tables G0=M1 F0 M0^-1 and G1=M2 F1 M1^-1. The public sees only one encoded endpoint point each: L=M0(a) and T=M2(b), for public a,b. It does not see either full endpoint frame or the intermediate frame.

EXACT THEOREM. Set e=[(F1 F0)(a)=b] and H=G1 G0. The public tuple (G0,G1,L) is uniform on S_d x S_d x [d] and independent of the source assignment. Conditioned on this tuple, if e=1 then T=H(L) with certainty; if e=0 then T is uniformly distributed among the d-1 OTHER labels. Hence the laws of the COMPLETE public transcripts for different source assignments are identical exactly when they have the same e, and disjoint otherwise. One public forward evaluation computes e=[G1(G0(L))=T], without any frame recovery, inverse gate evaluation or quantum subroutine. The theorem extends verbatim to longer paths.

PROOF. Fix G0=g0,G1=g1. Every M0 determines exactly M1=g0 M0 F0^-1 and M2=g1 g0 M0 (F1 F0)^-1. Therefore g0,g1 are uniform and independent of M0; L=M0(a) is uniform. Let c=(F1 F0)^-1(b). Then T=g1 g0 M0(c). If c=a, T=H(L); otherwise a uniformly random permutation conditioned on its image of a maps c uniformly over the other d-1 points. This proves the exact two-class law.

CROSS-CAPSULE ATTACK. Capsule A exposes only (G0,L), and capsule B only (G1,T), reusing hidden intermediate frame M1. Each isolated capsule has a perfectly uniform S_d x [d] marginal for EVERY source assignment, while together they disclose e with probability 1. The attack requires only publicly callable forward transformations, not even complete public tables. This is a stricter negative control than Run 424's complete pinned frames; it does not attack any published CCMR/RIO construction.

KEY-RECOVERY NEGATIVE CONTROL. For d=2, F1=identity; choose F0=identity for one secret bit and swap for the other. The public equality reveals each of 256 signing-seed bits. The extended Python checker recovered 3,072 bits across 12 fixtures and generated 12 accepted non-PQ Ed25519 signatures even for an identically false ORIGINAL relation. A distinct-branch signature was rejected. This deliberately broken toy is NOT an all-witness SAME-K construction, so it only demonstrates false-instance failure of this mixer class.

VALIDATION. Executed exact compact JavaScript checker: 8,052 assertions, exhaustive S2/S3 source assignments and all mask triples; it verifies uniform individual capsule marginals and the two distinct joint laws. For S3, the e=1 law has 108 equally likely transcripts, e=0 has 216, and each isolated capsule has 18. Extended Python: 12,724 assertions, byte-identical rerun; independent JavaScript: 7,970 assertions. No quantum hardware or positive cryptographic assumption was tested.

SECURITY LEDGER. Classical PPT setup and attack, thus applies to arbitrary QPT with complete public outputs and coherent evaluation. Tested: (1) intermediate seam cancellation, (2) partial gauge invariant with no frame synchronization, (3) exact fingerprint, (4) multi-view composition, (5) chosen forward evaluation, (6) honest independent masks (malicious setup remains unproved), (7) leak within a context even without cross-UTXO reuse, (8) correlated native checking key in signing fixture, (9) classical QPT-applicable attack, not a uniquely quantum attack. No QROM programming, rewinding or SIS reduction. Run 259 only extracts ORIGINAL evidence from an accepted complete representation, which this attack bypasses.

BOUNDARY. The test fails to apply if the second encoded point or forward evaluation cannot be obtained independently of an authenticated ORIGINAL witness. Nor does it prove security for schemes lacking this leak. CCMR, TCC 2024 DOI 10.1007/978-3-031-78023-3_2, and Gheorghiu et al., arXiv 2609.40289, are architectural context only; their full proofs were not audited this run. No generic iO/RIO or WE implementation or new release assumption is claimed.

HANDOFF. The minimal local release frontier must authenticate the source-dependent input/output seam. SAME-K correctness for all valid ORIGINAL witnesses, false-instance full-public QPT hiding, unauthorized true-instance release/forgery to ORIGINAL or independent QPT break, malicious N-of-N setup/erasure/abort, multiple capsules, practical 128-bit parameters and conditional P2MR/native-SLH endpoint remain UNPROVED. No practical PQ witness-KEM has been constructed.
