## Theorem and exact game

Fix x including relation identity, claim/UTXO, branch, anchors, window and context; honest classical-PPT setup transcript P_x; all public checking keys, auxiliaries, related capsules and legitimately opened references; and one valid ORIGINAL witness w. Honest classical-PPT front-end outputs token s according to Q=Law(S_w | P_x,aux). Independently callable public classical-PPT terminal T(P_x,s;u) uses *fresh independent* coins and outputs a candidate capability. Public native checking defines p(s)=Pr[usable bound authorization]. Honest correctness: C=E_Q p(s).

Suppose a witnessless classical-PPT sampler, using only this complete public view, outputs s~D such that for a set B with Q(B)<=eta, Q(s)<=2^d D(s) for all s outside B. (This distributional domination is an **attack premise**, not an assumed secure primitive.) Then A=E_D p(s) >= 2^(-d)(C-eta). Proof: restrict E_D to not-B, substitute D>=2^-d Q, and use p<=1 to discard at most eta correct mass. m independent samples and terminal evaluations recover an unauthorized usable credential with probability 1-(1-A)^m >= 1-exp(-m*2^-d*(C-eta)). With C>eta, m=ceil(2^d/(C-eta)) gives >=1-e^-1. If d=O(log lambda) and C-eta is inverse-polynomial, this is a classical-PPT unauthorized recovery without ORIGINAL w or a Run-259 representation.

For public classical code with explicit sampler coins z and terminal/signing coins u, G(z,u)=NativeCheck(T(P_x,Sampler(z);u)) can be reversibly evaluated by QPT. Coherent quantum search uses O(1/sqrt A) such public predicates, hence O(sqrt(2^d/(C-eta))) queries when the premise holds. No quantum access to an online secret service is assumed. This is a query upper bound, NOT a gate-count estimate, nor 128-bit-security proof. The theorem addresses **true-instance premature authority**; it does not itself prove false-instance key-hiding failure.

## Tight falsifier: longer random tokens do not supply authentication

For honest tokens (a(w),r) with an ell-bit source-dependent public-synthesizable prefix and independent uniform b-bit salt, sample a' uniformly from ell bits and r' uniformly from b bits. If the terminal's success depends only on matching a(w) (randomized success alpha), then Q/D=2^ell on the honest support, C=alpha and A=alpha/2^ell. The bound is tight **independently of b**, even if b=1024. Thus ell=128 still has a generic O(2^64) coherent query *upper bound* in this model; ell=256 yields O(2^128), not a security proof. If the token fields have a public relation, the adversary can sample correlated fields rather than waste effort sampling them independently. Very high Shannon entropy of honest randomized tokens does not imply low public-sampler overlap.

Countercondition: a genuinely authenticated state whose honest Q has negligible overlap with all efficient witnessless D may escape this theorem. This does NOT construct that authentication. A public terminal that internally checks R or hides K by assuming WE/iO/RIO has not thereby acquired a noncircular construction. Run 259 cannot turn direct unauthorized authority into ORIGINAL extraction unless an accepted complete representation satisfying its precise theorem is actually obtained.
