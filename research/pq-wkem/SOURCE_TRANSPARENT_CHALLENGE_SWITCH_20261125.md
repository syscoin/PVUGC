Missing original-source operation: derive the same frozen cancellation capability from either the setup's native signature witness or ANY later qualifying original witness, using a public capsule. The preceding bucket trial could not produce a new accepting transcript in a fixed high-entropy challenge bucket; the earlier fixed-MPC-view trial could not replace a binding first message without recovering withheld view randomness. The mathematical change here is to choose a proof whose first message has a transparent full opening independent of either witness. ## Explicit transcript construction

Let x include the frozen context, claim and endpoint bindings. R_x(w) is the unchanged OR of all three original source grounds, including authentication, exact relevant work, ancestry and maturity, finite burn refutation and tag-fault typing. Let V_x(s) be the fixed native message/key signature predicate. Define the tagged relation F_x(b,z) = (b=0 AND R_x(z)) OR (b=1 AND V_x(z)). In the trial take a standard classical polynomial-time witness-preserving reduction of this bounded verifier to directed Hamiltonian cycle: G_x, Encode(b,z), Decode(cycle). Require Decode(Encode(b,z))=(b,z), or at least recovery of the branch bit and an accepting witness on that branch. This is a proof-compiler requirement, not an implemented source verifier or reduction in this note. The graph is built only from x, not from the particular native signature S. It is Hamiltonian even if the original source relation is FALSE. This latter distinction is essential.

1. Public first message: sample a uniform permutation pi of the graph vertices and independent lambda-bit salts r_ij. Let A_ij be adjacency of pi(G_x). Form a_ij = H("adj",ctx,i,j,A_ij,r_ij) with unambiguous encodings and independent domain separation. Publish a=(a_ij) and the transparent challenge-0 response T0=(pi,(r_ij)); the graph determines A. Anyone checks the commitments, all entries, and the permutation.
2. For any satisfying tagged witness (b,z), take L=pi(Encode(b,z)). The challenge-1 response T1 consists of the ordered Hamiltonian cycle L and the r_ij of its directed edges. Check that it visits each vertex once and that all edge commitments open to one. The fixed first message is identical for setup and all source openers. A qualifying original witness needs neither a private setup secret nor any new first-message hash search to produce T1. Classical time and communication are polynomial in the graph size. No actual graph reduction or source circuit was executed.
3. Setup can compute T1_S with (1,S); Open can compute T1_w with (0,w). Both are valid for exactly the same a and T0. Under branch-preserving Decode their cycles differ: a common cycle would deterministically decode to both tag values.

This is an explicit same-first-message proof response conversion (conditional on the ordinary witness-preserving compiler above), not a conditional secret evaluator. It does not establish ANY new hidden correlation. The entire distribution (a,T0) can be sampled exactly given x without either witness. Unlike the previous proof-bucket construction, completeness of this response conversion costs no search.

## Attempt to transport a native witness via challenge switching

For a conventional two-challenge special-soundness proof, applying the extractor to (a,T0,T1_w) yields the inverse-permuted cycle, hence a witness for F_x. It does not yield the setup's particular native S. Indeed that extractor gives branch 0 on honestly encoded source responses. The setup's knowledge of S need not enter this extraction at all. This is why replacing a proof-of-source with a proof-of-OR does not make special soundness a native capability extractor.

Consider adding the concrete trial ciphertext E = S XOR KDF(ctx,a,T0,T1_S), with fixed length pad, and decoding E XOR KDF(ctx,a,T0,T1_w). Use canonical response encodings, including ordered vertex list normalized for cycle rotation. The branch-preserving reduction still makes setup and source cycles different. With an independent ideal random function for KDF, on distinct input strings the two pads are independent uniform; probability of exact S is 2^(-|S|). This is the previously known distinct-transcript hash collapse, now applies even though the new proof response succeeds at the SAME first message. Accordingly no more fixtures or parameter variants of this pad were implemented. This is not a theorem about concrete SHA and not a new general barrier.

Consider projecting to a transcript feature P(a,T0,T1) to remove cycle dependence. The required equation is
  KDF(ctx,P(a,T0,T1_S)) = KDF(ctx,P(a,T0,T1_w))
for every qualifying w, except negligible failure in the honest Build distribution. In the independent ideal KDF model, if the projections are unequal and the choice is independent of that KDF, accidental equality has probability 2^(-|S|). If P is computable from (x,a,T0) alone, the entire capsule including E discloses S by a straight-line classical algorithm. This does not show that all computationally hard witness-dependent invariants are impossible; it specifies the exact missing operation for a nontrivial projection. A public proof acceptance bit is not such a feature. A fixed digest of the full graph is not such a feature. No assumed common-value map is counted as an implementation.

## Second repair: instance-dependent commitment mode as a bit carrier

To avoid the independent KDF mismatch, try to transport bits of S through the choice of which challenge the first message was built to answer. For bit zero, use the above permuted graph. For bit one, instead sample a graph A' containing a known Hamiltonian cycle independent of G_x. A hash-commitment matrix for A' allows a challenge-1 cycle opening even when the *original* relation is FALSE. This is the usual two-transcript-mode idea, not a release. An opener knowing an original witness could potentially distinguish the two modes by checking whether its own mapped cycle opens.

Test the actual public information necessary for that check:

- Publish pi and the salts of every matrix entry, for both modes. Anyone can verify each bit by evaluating the hash twice; except for collisions, the complete committed matrix is recovered. A distinguisher checks whether it equals pi(G_x). If the one mode was independently sampled, it differs except for the actual graph-sampling collision probability. One can choose the one mode explicitly different when such a Hamiltonian graph exists, which makes distinction immediate. Thus the intended bit-hiding fails before any source evidence appears.
- Withhold independent salts for entries to hide the matrix, retaining only public hashes and pi. A source witness specifies the cycle positions and that their bits are 1; it does not specify any salt. For a withheld entry with uniform lambda-bit salt independent of the source, use a separate ideal hash domain with output at least lambda bits and distinct position tags. A classical q-query opener finds the actual salt with probability at most approximately (q+1)/2^lambda (including a final guess), by symmetry until it hits the planted input. It may find a different salt opening to the same hash with probability at most q/2^lambda plus a final guess. For the intended procedure opening such an edge with polynomial q, merely knowing the source cycle does not solve this independent hash task. The bound is a screening argument in a restricted ideal model and not a full public QPT theorem.
- Publish only the salts of actual edges in the zero mode, or a recognizable subset sufficient for ALL source cycles. Where the membership list itself distinguishes the matrices, the bit is exposed. Hiding the list while allowing only a qualifying full cycle to obtain all relevant salts requires a new explicit source-dependent retrieval mechanism. This third case is not asserted impossible; it has not been built. Publishing separate edge labels with local access restrictions would return to the R289 consistency problem unless the new algorithm actually enforces full original witness dependence. No tests or code for such a variant.

The mode trial cannot change the endpoint to accept a challenge-1 proof instead of the frozen native signature. That would put the original verification on Bitcoin, contrary to the target. It also cannot rely on a source witness containing the independent salt or a newly issued OTS label. Future original evidence need not be constructed by a cooperative miner or signer.

## Handoff

The genuine change from the preceding note is the transparent same-first-message conversion, which removes the independent bucket search and fixed hidden-view substitution from the *proof-response* step. This is not the missing release. The new failure occurs after the proof response, at native-branch-specific extraction or secret transport. A candidate that uses this conversion must construct, rather than assume, a non-public common native pad or a two-mode commitment decoder in which original source evidence unlocks hidden information without being a preimage of an unrelated setup hash. It must preserve the tagged branch distinction and every-witness correctness; setup's signature branch must not become an alternative source challenge. Do not implement further variants just changing hash domains, transcript feature choices that are public, independent salts, or graph size.
