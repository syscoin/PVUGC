# Run 437 — finite gauge-holonomy barrier for locally framed reversible gates

Verified base: syscoin/PVUGC#1 draft branch research/pq-wkem-validation-20260918, starting SHA e2012029b3bd356cf2cabc53afa0ae2987e4f9ea. Scope: a restricted information-theoretic negative theorem, NOT a witness-KEM construction or an attack on CCMR/RIO.

Model: let a connected directed multigraph have reversible gates T_e in a finite group H=S_d. Classical honest setup samples an independent uniform vertex frame U_v for every vertex and publishes all gate tables G_(u->v)=U_v T_e U_u^-1, but not the frames. The adversary receives the full public graph/tables and any public checking key/auxiliary inputs.

Forest lemma: for a forest, the entire vector of published edge tables is independent uniform in H^E, irrespective of the source gates. Root each component; every desired edge vector and fixed choice of root frames determine all remaining frames uniquely. Each transcript has |H|^components preimages out of |H|^vertices uniformly likely frame assignments. This proves privacy ONLY for bare tables without public input/output/release interfaces.

Cycle theorem: root a spanning tree, and let P_T(v) and P_G(v) be its root-to-v path products. Then P_G(v)=U_v P_T(v) U_root^-1. For each non-tree edge e:u->v, publicly derive h_e(G)=P_G(v)^-1 G_e P_G(u). This equals U_root h_e(T) U_root^-1. The simultaneous conjugacy class of the complete fundamental-cycle tuple is a COMPLETE invariant: two source gate systems induce identical public transcript distributions exactly when their fundamental-cycle tuples are simultaneously conjugate, and otherwise their supports are disjoint. Sufficiency follows by choosing the root conjugator and propagating gauges along the tree. This is elementary finite gauge-orbit algebra, not a new hardness assumption.

Concrete S3 failure: in a triangle 0->1,1->2,0->2 with identity tree source gates and a chord S, H=(G12 G01)^-1 G02 is conjugate to S. Its cycle type perfectly exposes whether S is identity, a transposition, or a 3-cycle even though every vertex frame is hidden. Enumeration over all 216 choices of frames produces three disjoint transcript supports of sizes 36,108,72. With TWO parallel chords, each a transposition, the individual holonomy cycle types agree, but the joint invariant h1^-1 h2 distinguishes equal from distinct transpositions; support sizes 108 and 216 are disjoint. The extended local checker also recovers an entire diagnostic 256-bit seed encoded by 256 such public triangle classes without any ORIGINAL witness. This intentionally insecure negative control does not implement native signing.

Validation: exact Node.js checker passed 1533 assertions in two byte-identical executions; independent local Python checker passed 2446. No cryptographic security is inferred from finite tests.
