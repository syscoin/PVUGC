**Narrow negative theorem.** For fixed bound `x=(relation,UTXO,branch,anchors,window,context)` suppose classical PPT honest setup publishes initial `C0`, deterministic public `Step`, public off-chain `Release` and native `vk_x`. The **only** witness-dependent admission parameter is an integer `t(x,w) in {0,...,T}`, where `T=poly(lambda,|x|)`. A watcher computes `C_t=Step^t(C0)`; `Release(C_t)` returns a usable bearer native signing capability, or failure/decoy, without receiving any additional witness, proof, or authenticated source representation.

If every valid ORIGINAL witness `w` can choose such a `t` and produce an accepted native signature for the precisely bound branch message `m_x` with probability at least `1-epsilon`, then **anyone** enumerates `C0,...,C_T`, runs `Release`, signs and tests each result against `vk_x`. The attack takes at most `T` forward steps and `T+1` terminal/sign/verify calls and succeeds on every honest deterministic setup for which a valid witness can sign. It never computes an ORIGINAL witness. This is a classical PPT attack and hence works for arbitrary QPT; no quantum advice, oracle programming, inverses or special mask algebra are needed.

The argument generalizes to any public polynomial-size enumerable control set `A_x` and public `Apply(C0,a)`. It is **not** a generic WE impossibility theorem: if the release evaluator also authenticates the supplied ORIGINAL witness/complete representation, or uses a witness-dependent public control space not polynomially enumerable, these hypotheses fail. If a fixed unary orbit needs exponentially many steps to reach release, honest polynomial-time recovery is lost in this exact iteration-only interface unless an additional witness-controlled fast-forward/admission operation is supplied.

**Minimal constructive handoff:** two controlled updates `Step_0/Step_1` can admit `n` bits in `n` updates with up to `2^n` reachable states. This defeats only the counting/enumeration attack; their integrity, source binding and native authorization hiding are UNPROVED. Never call an assumed secret-gated terminal a secure primitive. The advertised CLZ fixed-unary homomorphism is not alleged vulnerable: this falsifies one proposed *application* of it to late witness admission, not the paper's actual FE/CCA scheme. Run 259 gives only accepted COMPLETE representation -> ORIGINAL witness under its stated residual/SIS assumptions, and does not bridge native signature -> representation.
