Model each protected capsule as an *ideal* source-gated oracle: c0 returns the same root S for every valid witness, and c1 always returns bottom. After an authorized c0 release, a classical attacker computes `sk_1=F_S(Enc(c1))` and signs the native c1 challenge message. **Capability-closure lemma.** In the public deterministic derivation DAG of private capabilities, revealing any node from which an unauthorized other context's native signing seed is efficiently derivable violates the full-view release game. Absence of such a path is necessary, **not sufficient**. This is not Run 441/442 frame reuse or Run 449/450 fold forgery: no source validation or mixing is broken. The attack targets multi-capsule/branch replay and correlated checking keys (taxonomy 4,5,7,8), while malicious setup (6), seams/gauges/fingerprints (1–3), and quantum-only attacks (9) remain unproved/unexamined for any real mixer.

**Narrow conditional leaf-only repair.** Release `sk_i` and never a shared root/ancestor. For *only* the restricted distribution of polynomially many classical contexts, public `vk_i`, and selectively revealed leaf seeds, replacing `F_S(Enc(c_i))` by independent uniform seeds follows by a straight-line hybrid from a QPT-secure PRF with chosen **classical** queries and simulatable auxiliary information. Public keys are deterministic postprocessing. With no target seed or pre-authorized target signature, native QPT EUF-CMA then bounds cross-leaf native forgery (plus polynomial multi-target loss). If a public release program exposes coherent F evaluations, instead require and prove the stronger quantum-query PRF game.
