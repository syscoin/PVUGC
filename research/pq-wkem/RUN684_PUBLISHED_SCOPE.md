# Run 684 — lawful selective opening pivots across distinct HPS capabilities

**Scope:** research only, \`syscoin/PVUGC#1\` draft branch at initial SHA \`046d38b90859150ccdefd22ba36eeca222863c98\`. Extends the exact Run 683 independently keyed restricted-group SPHF checkpoint, not generic witness encryption.

Let a single restricted-DH projective hashing key \`(alpha,beta)\` define the homomorphism \`T(u,v)=u^alpha v^beta\` into an odd-prime-order group \`G\`. Distinct ciphertext slots carry distinct group-valued protected capabilities \`M_j\` using \`C_j=M_j*T(W_j)\`.

**New selective-opening attack:** If a target false-word slot at \`W_*\` reuses the hashing key with slots whose \`M_j\` values are legitimately disclosed, and \`W_*=product_j W_j^{a_j}\`, the attacker computes

\`M_* = C_* / product_j (C_j/M_j)^{a_j}\`.

Crucially **the protected capabilities need not be the same**. In a two-statement OR example, statement A has only a false clause at \`W\`. Statement B has a valid clause with a public witness that releases \`M_B\` plus a false clause at the same \`W\`; hashing-key reuse makes \`M_A=C_A*M_B/C_Bfalse\` publicly recoverable although A is false. The variant \`W_B=W_A^2\` also works via inversion of 2 modulo group order. Thus domain-separating native seeds per UTXO/branch does not rescue hashing-key reuse. A source relation must allow the relevant B false clause; no universal source-language attack is claimed. This generalizes Run 683's two-view inverse-word cancellation, which assumed the **same** protected capability.

**Independent-slot positive lemma:** For a false DH word \`(g^r,h^t)\` with \`h=g^a\`, \`a!=0\`, \`t!=r\`, condition on public projection exponent \`theta=alpha+a beta\`. Then \`log_g T = r theta + a(t-r) beta\` is exactly uniform as beta varies. With fresh independent secret hashing-key fibers for each public slot, target false-slot ciphertexts remain jointly uniform conditional on all public projections, capabilities, correlated native-checking outputs, and lawful openings of **other** slots, provided that auxiliary data do not depend on those target secret fibers. This is statistical and survives arbitrary QPT postprocessing of the classical public outputs. It does not include a secret-key superposition oracle, quantum advice correlated with the target fibers, malicious correlated setup, or word choice after the target ciphertext.

**Executed evidence:** \`run684_selective_opening_hps_check.py\` is the exact deterministic standard-library checker, compiled and executed twice with byte-identical captured output. In the order-11 subgroup of F_23*, it validates 14,641 same-false-word distinct-credential attacks, 14,641 power-related-word attacks, and 14,641 exactly uniform conditional distribution cells across 161,051 fresh-key pair instances; 60,282 assertions. Tiny finite tests validate the algebra, not cryptographic security.

**QPT/security scope:** The attack is classical PPT and therefore defeats QPT secrecy in this particular reused-key group construction. The positive claim is information-theoretic only under the explicitly independent target-fiber model. The DH language itself is not post-quantum because Shor computes true discrete-log witnesses. Benhamouda–Blazy–Ducas–Quach, *Hash Proof Systems over Lattices Revisited* (PKC 2018, ePrint 2017/997) treats restricted lattice ciphertext languages and relaxed WE; it does not provide an arbitrary Syscoin ORIGINAL witness compiler.
