## Concrete attempted repair and complete distribution
Given a Boolean ORIGINAL circuit, BLSC publicly builds integer rows `A_x` with complementary coordinates `(u,1-u)`. An AND gate `t=a AND b` has slack rows `a-t-s1=0`, `b-t-s2=0`, `1+t-a-b-s3=0`, with binary slack bits for legitimate witnesses; XOR and NOT are similarly compiled. For any original witness W, the resulting integer vector `v_W` satisfies `v0=1`, `A_x v_W=0`, `||v_W||_1=M`. The minimum-norm lemma says that any *supplied* normalized integer kernel vector of norm at most M yields a genuine ORIGINAL Boolean witness. It does NOT extract a witness from arbitrary key recovery.

The failed public bit carrier is `c=A_x^T s+e+g*m*e0 mod q`; `s` is uniform over `F_q^rows`, `e_j` are independent uniform integers in `[-B,B]`, `g=(q-1)/2`, q an odd prime. Build is classical PPT, no ORIGINAL witness or SourceOpen oracle. Deterministic completeness for all valid ORIGINAL witnesses and error samples follows from `q>4BM+2`, because `v_W^T c=gm+v_W^T e` and `|v_W^T e|<=BM`. **This fixed source-dependent sparse A is not a standard QPT-LWE challenge distribution.** The attempted repair is to shrink q toward its lower permitted bound, or post-hash the scalar output, instead of changing the readout itself.

## Exact FALSE pseudo-witness and parameter-independent boundary
Take the FALSE original predicate `t=x AND NOT(x)`, accept t=1, and add d arbitrary dummy Boolean input bits. The public matrix has M=7+d. The normalized non-Boolean integer assignment `(x,not_x,t,s1,s2,s3)=(0,1,1,-1,0,1)`, with dummy bits 1 and complements `1-u`, satisfies **every integer source row exactly**, but is no ORIGINAL witness. Its vector `v*` has `||v*||_1=M+2`, `||v*||_2^2=M+4`. Consequently, for every generated public ciphertext, `v*^T c = gm + X (mod q)`, where `X=Σ_j v*_j e_j`. All terms `A_x^T s` vanish. This is a classical PPT public recovery channel, without adversary-volunteered representations or cryptographic assumptions. Genuine native checking keys, context, auth, auxiliary data or related capsules cannot re-hide the key.

For **independent mean-zero bounded errors** `e_j in [-B,B]`, Hoeffding gives
```
Pr[|X| >= MB] <= 2 exp(-M^2/[2(M+4)]).
```
With q>4BM+2, the scalar nearest-center decoder is correct on `|X|<MB`. Thus even at the smallest permissible prime, the FALSE pseudo-vector decrypts a bit with probability at least `1-2 exp(-M^2/[2(M+4)])`, tending to one exponentially with M. A union bound handles any polynomial number T of independent ciphertexts: all decrypt with probability at least `1-2T exp(-M^2/[2(M+4)])`. This is an **attack success** statement, not an encryption guarantee.

There is a stronger **q-independent** comparison for uniform bounded errors. An honest binary normalized vector has exactly M coefficient-ones, so its noise law is `X_h=S_(M-1)+V`; the FALSE pseudo-vector replaces one 0/1 coordinate pair by -1/2, so `X_f=S_(M-1)-U+2V`, where U,V and each summand of S are independent uniform [-B,B]. Coupling on identical S,U,V gives `X_f-X_h=V-U`. Convolution of integer-uniform laws is symmetric unimodal. A translation of an integer unimodal probability mass function by t has TV distance at most `|t|*max_z Pr[S=z]`; triangle inequality and coupling therefore establish
```
TV(Law(X_f), Law(X_h))
 <= [4 B(B+1)/(3(2B+1))] * max_z Pr[S_(M-1)=z].
```
This is preserved under reduction modulo **any** q and any public fixed scalar decoder. The Boolean comparison vector is NOT a valid witness for this false source, but its scalar error law equals that of an honest binary kernel vector in a TRUE source of the same dimension. Thus relaxing deterministic completeness and retuning q alone does not make the two laws meaningfully distinct. In the exact uniform-noise census, TV falls from 0.113978 (M=7) to 0.007534 (M=127).
