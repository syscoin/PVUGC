## Fixed logical safety model

Fix ctx=(ORIGINAL relation, exact claim/UTXO, challenge branch, anchors/window, public context). Define Bad(ctx) := exists ORIGINAL w such that R(ctx,w)=1. The relation must independently certify a *real, admissible* SYS/BTC safety violation. An arbitrary syntactically plausible fork or mathematically constructible future header is NOT automatically authenticated observed BTC history. NP cannot certify absence of unseen forks. The bridge's source semantics, actual anchors, best-chain assumptions and windows require separate proof.

Assume the entire presigned covenant-emulation graph is correct and a challenge signature can ONLY send the locked claim to a predetermined safe/quarantine sink, permanently preventing unsafe payout. ## QPT hybrid composition (assuming WE, not constructing it)

Assume classical PPT witness encryption Enc,Dec for the exact ORIGINAL relation R, with full-public-output false-instance IND against arbitrary QPT; a classical PPT native signing scheme Gen,Sign,Verify with QPT EUF-CMA under the actual output-bound challenge sighash; and a classical PPT SimAux(ctx,vk) that reproduces every adversary-visible setup/graph artifact permitted in this theorem from only public ctx and vk. Quantum advice may be arbitrary if independent of secret setup coins given public inputs, or efficiently generated by SimAux. Non-simulatable retained setup randomness/key shares are **outside** this theorem. Preissued signing transcripts may be provided only in the appropriate EUF-CMA fresh-message game; the actual veto signature must not already be public. No other capsule may release the same sk without a joint security theorem.

Honest setup: (sk,vk) <- Gen; C <- Enc(ctx,sk); publish P=(ctx,vk,C,SimAux(ctx,vk)). Every valid ORIGINAL witness decrypts the SAME sk (not necessarily the same intermediate state), then signs the preauthorized challenge transaction OFF CHAIN. On Bitcoin the presumed native verifier sees only an ordinary signature with fixed graph constraints. P2MR/native SLH remain CONDITIONAL, not activated.

**Lemma.** Fix a false context Bad(ctx)=false, independent of Gen coins (or with vk appended solely as an inert binding field not affecting truth). For any arbitrary QPT A outputting a fresh native signature accepted for the challenge message,

Pr[false challenge] <= Adv_WE-IND^QPT(B) + Adv_SIG-EUF-CMA^QPT(F)

for straight-line quantum polynomial-time reductions B,F, plus routine encoding/correctness terms.

**Proof:** Game 0 exposes (vk,Enc(ctx,sk),SimAux(ctx,vk)). Game 1 swaps only the ciphertext message for zero: (vk,Enc(ctx,0^|sk|),SimAux(ctx,vk)). A false-instance WE-IND reduction generates its own (sk,vk), submits challenge messages sk and zero, and simulates all other public fields. This explicitly RETAINS correlation between the signing secret and its public checking key vk, rather than asking WE to hide vk. In Game 1 an EUF reduction obtains vk from the signature challenger, builds Enc(ctx,zero) and SimAux(ctx,vk) without knowing sk, and forwards any fresh signed challenge as its forgery. Both reductions are straight-line QPT, no classical rewinding, oracle programming or QROM extraction. WE indistinguishability requires the actual false ORIGINAL language; merely computationally sound proof-acceptance languages can have extra mathematically existing witnesses (Run 402 boundary).

## Falsification / attack taxonomy

(1) local seams, (2) frame/gauge and (3) program fingerprints are not proved for any mixer; the WE hypothesis encompasses false-output indistinguishability only. (4) Reusing sk across related capsules allows another legitimate witness to defeat the false-capsule guarantee. (5) Chosen-input evaluation is addressed only by the WE QPT IND hypothesis. (6) Malicious setup or auxiliary shares unsimulatable from vk defeat the second hybrid. (7) Reused branch key and noncommitting sighash permit replay; require strict context isolation and output binding. (8) Public vk correlation is handled by the displayed hybrid. (9) Coherent quantum adversaries are covered only conditionally by **QPT** WE and **QPT** signature security; finite tests do not validate either.

If the challenge edge permits bearer-selected payments or an unrestricted slashing bounty, a true-instance attacker recovering sk without actually discovering a witness may create economic harm. The logical safe-sink monotonicity premise then DOES NOT justify the broader protocol. This is not license to relax the mandatory true-instance property.
