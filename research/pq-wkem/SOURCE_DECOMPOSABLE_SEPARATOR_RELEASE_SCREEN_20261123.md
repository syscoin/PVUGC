## Exact conditional transport equations

Take the actual bounded classical verifier R(x_W,w), including all three branches, compile into Boolean constraints with full witness/trace variables v. Every accepting assignment must decode to the ORIGINAL w, not merely a claimed digest or valid-looking execution fragment. For this construction screen a finite circuit representation is mathematical input, not a claim that a source compiler has been implemented. Represent fixed statement bits as constants. Let (T,B_t) be a rooted tree decomposition of the constraint primal graph: every constraint's entire scope is contained in some bag, every variable occurs in a connected subtree, and every constraint is assigned exactly once to a containing bag. Write S_t=B_t intersect B_parent(t); root separator is empty. For a bag assignment a, L_t(a) means all constraints assigned to t hold.

For a child u of t, b_u=a restricted to S_u. For each separator assignment s independently sample a secret lambda-bit token k[t,s]. A root token k[root,empty] is the payload mask key. For each locally valid bag assignment a publish a single row (t,a,D[t,a]):

    D[t,a] = k[t,a|S_t] XOR H_row(ctx,t,a,
                          (k[u,a|S_u])_{u in children(t)}).

Use injective encodings with child order, role/domain and capsule identity. A leaf has an empty child list, so its row mask is publicly computable. Publish E=sigma_cancel XOR KDF(ctx,k[root,empty],len(sigma_cancel)). Distinct capsules use independent keys. All row indices and constraints are public; no hidden selective execution is assumed.

Honest Open computes the actual accepting assignment v from ORIGINAL w, then evaluates bags in postorder, applying the row for v|B_t using already recovered child tokens. Induction proves every such v obtains the same k[root,empty], hence exactly sigma_cancel. No new signature generation, source signer, canonical witness or online evaluator appears in this *explicit-table* equation. The OR root can be represented by normal Boolean selector constraints; each of the original alternatives is independently sufficient when the original verifier says so.

Unlike unconstrained reusable local garbling, the *structurally reachable* token rule has a strong exact consistency property. Define Reach(t,s) to hold iff there exists a locally valid a with a|S_t=s and Reach(u,a|S_u) for every child u. A leaf requires only its local constraints. Then Reach(t,s) iff the subtree constraints have a simultaneous satisfying assignment extending s. Proof by induction: the forward direction chooses each child's satisfying assignment. If a variable occurs in two child subtrees, running intersection places it in B_t and both corresponding separators; both assignments therefore agree with a. If it occurs in the child subtree and the bag, it lies in that child's separator. Their union is a well-defined assignment satisfying all constraints. Conversely a simultaneous assignment restricts to such a and child solutions. At root, Reach is equivalent to R(x_W,w) for some ORIGINAL w, under the full witness-preserving circuit compilation assumption. This is a structural fact, not an arbitrary-QPT recovery theorem for the encrypted rows.

The useful distinction is that *all* alternative a extending the same s are allowed to recover the same token. Mixing those alternatives with other subtrees cannot invent a globally inconsistent source certificate: their shared variables are exactly constrained by the separator. This does not yet address arbitrary key guesses, hash attacks, auxiliary dependence, malicious setup or native forgery. In particular it does not justify demanding that an adversary return its row traversal.

## Full-public preflight: the source-hardness problem is now explicit

With explicit tables, let M=sum_t 2^|B_t|. The public algorithm Solver visits bags bottom-up, enumerates locally valid assignments, marks each reachable separator entry, and stores a pointer to one witnessing bag assignment per reachable entry. Each child test is a direct lookup. On TRUE, follow pointers from the empty root entry and unite the assignments by the running-intersection proof, then decode the ORIGINAL witness. On FALSE, root is unreachable. Runtime is polynomial in M and the circuit description, including the total child lookups.

Thus if Build emits polynomially many explicitly enumerable bag rows and the decomposition is public, this class admits a polynomial public original-witness solver (and the same public token traversal). It cannot establish a nonvacuous hard-TRUE release for an original source regime in which finding the qualifying evidence is independently hard. This conclusion is conditional on the explicit decomposition/table representation, not an assertion of any general complexity separation or a measured treewidth of SHA or the source circuit. It also is not an unauthorized-recovery attack if the solver actually outputs qualifying evidence. Rather, the explicit representation loses precisely the source-hard instances that the proposed capsule was meant to protect. An enormous table is not practical PPT Build. No bounded fixture or empirical success changes that.

The FALSE game does not rescue this proposal. The builder itself can run Solver if the explicit table is polynomial and decide whether to emit a dummy E on FALSE. That yields a trivial FALSE simulator for such a modified construction but does not preserve a hard-TRUE domain. For the original row equations, key hiding would additionally require a joint QROM proof; no such proof is made here. Source-hardness is already lost before spending time on independent-label hybrids.

## Attempted implicit repair, and exact next missing equation

The potentially useful repair is to make bags or separators large, yet serialize an implicit table whose entries can be opened at the actual assignments furnished by an original w. Let f_t(seed_t,s) be a private keyed hash/PRF generating k[t,s] rather than storing exponentially many independent tokens. Then Build would need a public row generator G_t for the original source circuit, satisfying:

    G_t(C,a) = f_t(seed_t,a|S_t) XOR
               H_row(ctx,t,a,
                 (f_u(seed_u,a|S_u))_{u in children(t)})

for each locally valid a, while no public access to G_t allows recovery of a protected separator token except through a qualifying child certificate or an independent justified break. Open could evaluate only one row per bag using w; it would never enumerate all rows. Joint simulation must cover all G_t, not one isolated row oracle, and arbitrary raw root/payload recovery must yield ORIGINAL evidence without requiring a reported traversal.

Three concrete checks on this equation:
1. Publishing the seeds so G_t can evaluate its hashes also gives f_root(seed_root,empty), a direct raw payload bypass. Publishing all per-separator keys instead has the same problem. Suppressing those fields in an API does not suppress access to serialized public data.
2. Generate a state token by hashing the child tokens and full a, with no correction row. This is executable on an honest accepting assignment but produces an assignment-specific token. Two distinct extensions of the same s have different domain-separated hash inputs; equality of their outputs is not enforced. In an independent ideal hash model the fixed distinct-input pair agrees with probability 2^-lambda. A fixed root ciphertext cannot decode to the same capability under those unrelated keys. Using only s as the input makes the separator token publicly computable. Neither is the intended common-value release.
3. Treat G_t as a circuit with hidden seeds and public output access. A public ordinary circuit includes its constants/seed material, giving the first bypass. A private execution service or an assumed function-hiding evaluator is outside the permitted offline model. A hash commitment to that circuit or a proof of correct execution does not compute G_t from public bytes. This is exactly where a new non-black-box hash-only construction would have to intervene; a commitment to the full assignment or a larger bag is not such a construction.

An alternative partition into source-atomic leaves (e.g. complete original authenticated header/carrier/ancestry checks rather than freely chosen Boolean literals) might avoid the public SAT solver because leaf satisfiability could itself be hard. But for each such leaf Build must then generate a token accessible from EVERY admissible original local certificate while hidden otherwise. That is the source-release problem at a new boundary; one cannot assume that primitive or use unauthenticated digest tokens. Furthermore cross-leaf relevance and consistency must still pass through actual separator assignments, and the OR branches include finite burn refutations and full malformed-carrier authentication. This is not an independent solution.

## Disposition

Global consistency via running intersection does remove the *structural* split-mask splice for reachable table paths. The actual serialized table with polynomial row count, however, makes a public original witness solver available; the implicit repair lacks its public hidden-seed row compiler and joint arbitrary-recovery reduction. Reject before coding a toy or tuning width, rank, basis, hashes, compression or parameters. No source compiler, actual chain proof, native signature, test run, full-public simulator or QPT theorem is claimed. This is a resource-bounded analytic construction attempt and preflight, not a missing-advance result. Keep the automation active, no ordinary PR comment or user notification.
