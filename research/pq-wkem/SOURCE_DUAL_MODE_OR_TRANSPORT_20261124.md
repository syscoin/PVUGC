## 1. Compatibility check: a public inverse of the common object is not the right extractor

The previous graph proposal uses Q_(x,h)(u) = R_x(w) OR [H_trap(t')=h] where R_x is the unchanged original verifier, setup samples uniform t and h=H_trap(t), and setup and original witness maps F(x,h,t) and J(x,h,w) would give the same ordered graph matrix A. The public capsule's mask is derived from A. A public inversion algorithm from A to an anchored graph isomorphism, followed by the ordinary graph compiler's witness extractor, would give a Q witness. Even granting the missing compiler and exact orbit property, that proposed repair must pass the following two-experiment check.

Work in a conditional hard-TRUE distribution: (x,w,z) sampled independently of t, with R_x(w)=1; x,z alone computationally hide every ORIGINAL certificate from QPT algorithms. The sampler including w must be efficiently executable by a reduction (or w may be fixed independent nonuniform advice in a fixed-instance preimage reduction; then original hardness with that advice is NOT assumed). Assume independent-target H_trap preimage resistance for uniform t, against QPT. These are abstract screening premises; no assertion that actual future PoW witnesses have this particular sampling/hardness distribution. Any auxiliary public data needed by the algorithms must be sampleable in the respective experiment. Let Pr[F=J] >= 1-eps. Let E be a public QPT extractor from (x,h,A) returning a typed ORIGINAL witness or a preimage of h. Denote the respective disjoint success probabilities on A=F by p_R and p_H (if both are available choose one deterministically).

* ORIGINAL-hardness experiment: given x,z without w, generate t,h, compute F, call E, return its ORIGINAL output. Success p_R. Giving this algorithm t does not affect the premise, because t is independent and can be sampled by that algorithm.
* Preimage experiment: given h distributed as H_trap(t) without t, independently sample x,w,z; compute J and call E. On F=J the complete input to E is identical to the previous experiment, so preimage success is >= p_H-eps. E need not be deterministic: couple its output distribution on identical inputs. No rewinding, quantum query observation, or representation from an adversary is used.

Thus p_R+p_H <= Adv_original + Adv_preimage + eps in these experiments. This includes an E that first solves the public graph isomorphism problem and then extracts a Q witness. For the particular graph mask format, E may also receive the public capsule if all other randomness and S are independent of t conditional on x,h,A: the preimage reduction samples the native signature/context according to the same distribution and builds the capsule with J, using the equality event. It does NOT cover arbitrary t-dependent additional setup material; that material must have its own simulator. It is not a theorem against arbitrary-recovery reductions, only against a public inverse in this particular two-witness common-object arrangement. In particular, no contradiction follows from a simulator-private extraction key not available to the real setup, or an extractor that uses the attack algorithm/oracle interaction rather than A alone. Do not assert that all WE is impossible. The previous graph note did not establish such an inverse or claim security.

The useful design consequence is that an efficient public inverse of the common object is not sufficient progress toward this particular release approach. The inverse must be replaced by a mode-dependent reduction, with a real source evaluation that does not need the simulator's extraction key. A public hash of the common object does not cure this: the setup itself computed the hash input.

## 2. Concrete dual-mode candidate and its source opening

Take a deterministic QPT-secure hash-derived PRG G:{0,1}^lambda -> {0,1}^m, m=3 lambda, as a conditional independent primitive. Distinguish PRG security from merely collision resistance of concrete SHA; no concrete hash security theorem is claimed. The following public commitment format provides an exact mode-switch calculation:

    real-binding: sample s0 and r independently uniform; c=G(s0)
    alternate-mode: sample s0,s1 independently uniform; c=G(s0)
                    r=G(s0) XOR G(s1)
    CheckOpen(b,s): G(s) XOR (b*r) == c

In binding mode the probability over r that *any* commitment can have both openings is <= 2^(2lambda-m) by the union bound over pairs of seeds. In alternate mode the known openings are (0,s0),(1,s1). The pair (c,r) in alternate mode is computationally indistinguishable from binding mode under the PRG assumption: given challenge y, independently generate s0 and output (G(s0),G(s0) XOR y). This also works with independently sampleable context/auxiliary input and s0; it does not establish simulation of arbitrary source-dependent related capsules. The two-opening mode is not a general trapdoor for equivocation of arbitrary commitments: the two seeds were chosen for this one c.

Try using the two modes to switch the graph compiler's setup branch to a source branch, without needing a public inverse of its common ordered object. The actual trial release equations are:

    Build_inc(x,S):
        sample s0,s1; c=G(s0); r=c XOR G(s1)
        K=H_key(ctx,c,r,s1)
        return (ctx,c,r,S XOR XOF(ctx,K,|S|))
    Open_inc(C,w):
        s <- D(x,c,r,w)
        return B XOR XOF(ctx,H_key(ctx,c,r,s),|S|)

where the intended source-dependent operation D must find a 1-opening. This notation is the *missing operation*, not an assumed subroutine or a completed algorithm. The proposal changes the proof distribution by a PRG indistinguishability hybrid rather than requiring a public inverse; it would require the original source witness to provide the alternate-mode seed without setup knowing that witness. The exact opening target is c XOR r. The extra binding/opening check is not a cryptographic release mechanism; it cannot replace D. For every original certificate to open the same mask, the actual input s must equal s1 (or lead to the same key; merely being another valid PRG preimage is not sufficient). This construction does not implement D.

Check whether the independent dual-mode generation can make D feasible, even allowing *any* opening seed rather than requiring the exact one. In the same independent-source sampling experiment, give a reduction y, either G(s1) or uniform m bits. It samples x,w,z,s0, sets c=G(s0), r=c XOR y, runs D, and accepts iff G(D(...))=y. In the PRG-output case this is the actual proposed D experiment. In the uniform case success is <= 2^(lambda-m), since at most 2^lambda output strings have any seed, regardless of D's power. Hence any nonnegligible honest probability of obtaining even an alternate opening would distinguish the PRG from uniform. This is an actual obstruction at the source opening equation, before asking for FALSE or hard-TRUE full-view simulation. It applies to the stated D interface, which does not receive the mask B; it is not a general theorem for a redesigned capsule whose mask supplies additional correlated data. Supplying s1 directly, or a publicly recoverable encoding of it, would trivially expose the release key. Supplying the known setup seed s0 does not help this reduction: it can sample s0 too.

Candidate repair: choose the alternate-mode output y from source evidence instead of from an independent seed. But at setup y is not known for future original witnesses. Requiring y=G(T(w)) for every original witness makes the missing correlation explicit: Build must choose y from x alone, and T must derive an opening from each actual original certificate; independent fresh s1 does not realize it. Hashing source bits individually or publishing per-bit opening seeds would return to label switching/public enumeration and is rejected without implementation. Likewise, a programmable oracle assigning common pads to all future valid witnesses is not a classical-PPT Build with concrete hash. The mode switch by itself is only a useful distributional device, not an original-source encryption primitive. In particular one cannot replace the original evidence by the independent s1 puzzle. Do not increase stretch, change PRG seed length, or add more dual-mode commitments under these unchanged independence premises.
