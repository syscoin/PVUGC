# Run 443 — Native signature forgery hiding implies a one-bit WE wrapper

Research-only checkpoint, syscoin/PVUGC#1, starting head 435a871fb8d53e6f065037890f3e430c94997501. This is a scoped lower-bound theorem, NOT a construction of a practical local mixer, PQ WKEM or Bitcoin consensus change.

## Theorem and game
Assume classical PPT Setup(x) creates public P, native verification key vk and a signing-sufficient ell-bit string K. Classical Recover(P,w) gives the SAME K to every valid ORIGINAL w for the fixed bound x. Intermediate states may differ. Sign(K,m) generates a fresh accepted signature for the exact bound challenge branch message m. Public P includes all public checking-key correlations, related capsules, setup-visible information, branches, contexts and public evaluation circuits.

False-instance native-forgery game: for every x outside L_R, every arbitrary QPT attacker with allowed public/auxiliary views, but no retained authorized signing secret or previously authorized signature on m, has negligible probability of producing an accepted fresh signature for m. This is a HYPOTHESIS about the missing secure release; it is not justified by this theorem. Its setup/malicious-party scope must be explicitly specified.

Construct one-bit encryption: sample r uniformly from {0,1}^ell and publish (P,vk,m,r,c=b XOR <r,K>). Any valid ORIGINAL w recovers K, then c XOR <r,K>=b. This uses neither a canonical witness nor a common intermediate state.

For a quantum distinguisher D with classical inputs (P,r,c), write d_c(r)=Pr[D(P,r,c)=1]. The signed distinguishing gap is Delta=E_r[d_<r,K>(r)-d_(1 XOR <r,K>)(r)]. Construct randomized predictor B(r)=1 XOR u XOR D(P,r,u) with uniform u. Exact conditioning proves E[(-1)^B |r]=d_0(r)-d_1(r), hence E[(-1)^(B XOR <r,K>)]=Delta. After sign correction, a standard classical noisy Hadamard/Goldreich-Levin decoder recovers K with polynomially many fresh calls to D whenever |Delta| is nonnegligible. Sign recovered K on m and verify with public vk. Thus a successful false-instance bit distinguisher gives a false-instance native signature forger. This refines the Run 428 reduction by requiring actual forgery hiding rather than insufficient full-original-serialized-key hiding (Run 433).

## Quantum and extraction scope
D may use coherent quantum evaluation and arbitrary QPT computation internally. The reduction invokes D at independently chosen classical inputs; it assumes polynomially many independently reinitializable copies of any quantum advice used by D. An unrepeatable key-correlated single-copy advice state is NOT covered. No QROM programming or quantum rewinding is used. On true instances, upgrading a successful distinguisher to an ORIGINAL witness requires a separate native-signature-to-ORIGINAL extraction theorem; ordinary signature EUF-CMA does not supply it. Run 259 only handles already accepted complete source representations or an SIS break; it cannot derive a representation from an arbitrary signature.

Attacks on seams, gauge cycles, fingerprints, malicious seed reuse, multi-capsule correlations, adaptive public evaluation, branch replay and checking-key correlations are NOT defeated by this wrapper; they must be excluded by the native-forgery hypothesis itself. The theorem does not prove malicious N-of-N ceremony security or practical 128-bit parameters. It shows that any successful generic-NP native-release compiler meeting these conditions already has at least one-bit WE power, regardless of a compact witness-sensitive frontier.
