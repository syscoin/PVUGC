THEOREM (unconditional, supplied-admission-object scope). Let q>=3, Delta != 0 modulo q. Run 372 publishes a base vector C0 of ciphertext key slots and initially-zero witness slots (u_j,v_j). Inject(C0,w) leaves all key ciphertext slots and every witness u_j unchanged and adds Delta*w_j modulo q to each witness v_j. Define OrbitCheck(C0,C) by exact equality on all key slots, unchanged witness u_j, and difference (v'_j-v_j) in {0,Delta} mod q. Extract(C0,C) maps each such difference to its unique bit w_j. For ANY public C0, even adversarially generated, Extract(Inject(C0,w))=w, and every orbit-accepted C equals exactly one Inject(C0,w). Adding public R(x,Extract(C0,C)) gives perfect ORIGINAL-witness extraction from any qualified supplied admission object. Proof: all fixed coordinates are checked, and the residues 0 and Delta uniquely encode each bit. No cryptographic assumption, random oracle, rewinding, QPT extraction algorithm or SIS assumption is needed for THIS scope. Base correctness and native-vk/key consistency are not proved.

QPT INTERFACE CONSEQUENCE. For any hypothetical public protected Open(P,C) rejecting off-orbit inputs, define OpenWitness(P,w)=Open(P,Inject(C0,w)) on R(x,w)=1; it rejects otherwise. On qualified orbit inputs these functions are exactly equivalent under public Extract and Inject. Their publicly known classical polynomial-time mappings can be computed reversibly with polynomial overhead even for coherent quantum input queries. This shows the Regev witness offset wrapper has not narrowed the cryptographic release problem: w is publicly reconstructible from offsets, and a watcher could supply w directly. This is NOT a proof of the existence or QPT security of Open. Re-randomized ciphertexts lie outside this exact-byte orbit and require an additional sound admission proof.
