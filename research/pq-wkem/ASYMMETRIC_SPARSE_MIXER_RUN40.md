# Run 40 — asymmetric sparse mixer: exact subset likelihood DP and a symmetry-breaking false-instance attack

## Status and scope

Starting verified draft head: `abae29c57f94db1b5bba0c6636ee3629e00c0c29` (Run 39).
The latest PR conversation at the start of this run ended with the Run-39 result;
no later research checkpoint was present.

This run uses only the repository research record, original derivation, and local
standard-library computation.  No external literature or web search was used.
It does **not** complete a generic PQ witness KEM.

Run 39 rejected the logarithmic notched walk on a direct-sum false family by a
histogram likelihood DP.  An obvious attempted repair is to destroy every gadget
permutation symmetry: give every gadget a distinct public selection weight, make
weights slot-dependent, or apply a dense public scramble to the quotient.

The constructive attempt here does exactly that.  The result is negative, but it
closes a materially broader class than the Run-39 histogram argument:

1. for any public channel generated by only `H` sparse hit opportunities, where
   each opportunity assigns itself to at most one direct-sum gadget (or idles),
   **arbitrary labelled/asymmetric public weights and arbitrary public local
   stochastic kernels still admit an exact likelihood DP in `O(m 3^H)` up to
   polynomial local-state factors**;
2. for `H=O(log lambda)` that is polynomial time, even if the raw support is
   quasi-polynomial and there is no useful histogram symmetry;
3. there is an explicit all-distinct-weight perturbation of the Run-39 false
   family whose complete-view distinguishing advantage remains inverse
   polynomial, so the new DP gives a concrete PPT false-key attack rather than
   merely a likelihood algorithm with unknown advantage; and
4. any public efficiently invertible dense scramble is information-theoretically
   and algorithmically vacuous: the attacker inverts it before running the DP.

This is not an impossibility theorem for dense non-factorizing channels,
noninvertible statement-aware sketches, or witness encryption in general.

## 1. General asymmetric sparse-hit model

Take a direct-sum public quotient with `m` labelled gadgets.  Gadget `g` has a
constant- or polynomial-size public local state space `S_g`; a distinguished bit
of the local state contributes to a single global key-sensitive parity.
The public endpoint therefore has the form

```
y = (s_1, ..., s_m, p),
```

where `p` is the XOR of the local parity contributions.  The key shift toggles
only `p`.  The Run-39 canonical quotient is the special case with four local
syndrome states and one global parity bit.

There are `H` public hit opportunities.  For each slot `t`:

- it publicly chooses exactly one owner from `{idle,1,...,m}` according to an
  arbitrary rational distribution `pi_t`;
- if the owner is gadget `g`, it applies an arbitrary public local stochastic
  kernel `K_(t,g)` to that gadget only;
- the weights and kernels may depend on both `t` and `g`; no exchangeability,
  identical-gadget assumption, or commuting-kernel assumption is needed.

The only structural condition is **sparsity across the direct sum**: one slot
acts on at most one gadget.

The raw owner support is `(m+1)^H`.  For `m=poly(lambda)` and
`H=Theta(log lambda)`, enumerating that support is generally
`2^{Theta((log lambda)^2)}`.  Run 39's histogram DP also no longer applies once
all labelled weights differ.

## 2. Exact subset-partition likelihood DP

Fix an observed endpoint `y=(s_1,...,s_m,p)`.
Let the slot set be `[H]`.  For a gadget `g` and subset `A subseteq [H]`, define

```
L_g(A,q)
```

to be the exact probability contribution that

1. precisely the slots in `A` choose owner `g`;
2. their local kernels, applied in chronological order, end gadget `g` at the
   observed local state `s_g`; and
3. the local parity contribution is `q`.

The owner factor is simply

```
prod_(t in A) pi_t(g),
```

and the endpoint factor is obtained by multiplying the public local kernels for
those slots.  All `L_g(A,q)` can be computed in
`O(2^H poly(H,|S_g|))` arithmetic work per gadget.

Now partition the slots among gadgets.  Define

```
D_g(U,q)
```

as the total probability contribution after processing the first `g` gadgets,
where exactly the slot subset `U` has been assigned to them and their accumulated
parity is `q`.  The update is

```
D_(g+1)(U union A, q xor r)
  += D_g(U,q) L_(g+1)(A,r)
```

for every `A subseteq [H]\U` and `r in {0,1}`.

After all real gadgets are processed, every unassigned slot must be idle, adding

```
prod_(t notin U) pi_t(idle).
```

The desired likelihood is the sum of the states whose parity equals the observed
`p`.

### Complexity

For one gadget update, the number of ordered pairs `(U,A)` with `U cap A=empty`
is exactly `3^H`: each slot is in `U`, in `A`, or in neither.  Therefore the
exact endpoint likelihood is computable in

```
O(m 3^H poly(H,S,L))                              (1)
```

bit operations up to the usual polynomial factor for local-state dimension `S`
and `L`-bit rational arithmetic.  There is no permutation or histogram
assumption in (1).

The two key-conditioned likelihoods are obtained by evaluating the observed
parity `p` and `p xor 1`.  Thus exact public MAP decoding has the same asymptotic
cost.

When

```
H = c log_2(lambda),
```

we have

```
3^H = lambda^(c log_2 3),
```

so (1) is polynomial for any fixed `c` and polynomial `m,S,L`.

This is the central proved claim of the run.

## 3. Why the resource-feasible Run-38/39 notch regime is inside the theorem

One Run-38 notch cycle consists of two sparse opportunities, so

```
H = 2C.
```

Its honest fixed-mode bias is

```
beta_H = (3/10)^C.                               (2)
```

If honest recovery is to retain inverse-polynomial signal

```
beta_H >= lambda^(-a)
```

for a fixed constant `a`, then

```
C <= [a / log_2(10/3)] log_2(lambda),
H <= [2a / log_2(10/3)] log_2(lambda).            (3)
```

Substituting (3) into the subset DP gives

```
3^H <= lambda^(1.8249785787863964 a).             (4)
```

Thus every notch parameter choice with polynomially amplifiable honest bias is
inside the polynomial exact-likelihood regime.  Taking `C=omega(log lambda)` can
make the subset DP superpolynomial, but (2) then makes the honest signal
superpolynomially small, so the recorded independent amplification layer would
require superpolynomial resources.

This closes the apparent `support-size versus honest-bias` escape for the sparse
notch family.  It does not say a dense correlated channel must have the same
tradeoff.

## 4. Explicit symmetry-breaking perturbation that remains false-insecure

The DP theorem alone computes MAP; a false-statement break also needs
non-negligible key-conditioned distance.  Run 39 supplied that distance for the
uniform-gadget walk.  Here it survives an explicit perturbation that destroys
all nontrivial gadget-permutation symmetry.

Let

```
A_C = (3/10)^C.
```

Use the same explicit false direct sum and choose `m` as in Run 39:

```
m >= 4 binom(2C,2) / A_C.                        (5)
```

Then the uniform construction has

```
TV_uniform >= A_C/2.                              (6)
```

For every hit slot replace the uniform gadget distribution by a labelled
all-distinct rational distribution `p=(p_1,...,p_m)` at total-variation distance

```
delta = A_C/(100 C)                              (7)
```

from uniform.  One explicit choice is

```
b_g = 2g-(m+1),
S   = sum_g |b_g|,
eta = 2 delta / S,
p_g = 1/m + eta b_g.                             (8)
```

The `b_g` are distinct and sum to zero, so the probabilities are distinct and
sum to one.  Because `delta <= 0.003` for `C>=1`, (8) is positive.  Equations
(5)--(8) have only polynomially many bits when `C=O(log lambda)` and
`m=poly(lambda)`.

For a mandatory slot the owner-distribution perturbation is exactly `delta`.
For the Run-38 optional slot it is `(4/5)delta`, since the idle mass `1/5` is
unchanged.  Coupling the `2C` public owner choices gives, for either key bit,

```
TV(P'_K,P_K)
 <= C delta + (4/5) C delta
 = (9/5) C delta.                                 (9)
```

Data processing through all local transition kernels cannot increase this
coupling error.  Therefore the difference between the two key-conditioned TVs
obeys

```
| TV(P'_0,P'_1) - TV(P_0,P_1) |
 <= 2 (9/5) C delta
 = 9 A_C / 250.                                  (10)
```

Combining (6) and (10),

```
TV_asymmetric
 >= A_C/2 - 9A_C/250
 = 116 A_C/250
 > 2 A_C/5.                                      (11)
```

For `C=Theta(log lambda)`, (11) is inverse polynomial.  The exact subset DP is
polynomial by Section 3 and gives a public MAP key distinguisher with advantage
at least

```
TV_asymmetric/2 > A_C/5.                         (12)
```

This is a direct false-statement confidentiality failure.  There is no source
witness on the Run-39 direct-sum family.  The attack is classical PPT, hence is
also a QPT attack.

Crucially, every gadget has a distinct public selection weight.  The Run-39
histogram sufficient statistic is gone; the attack now uses labelled subset
partitioning.

## 5. Public dense invertible scrambling is vacuous

Another natural repair is to apply a dense public invertible map to the quotient
before publication.  This cannot change security.

For any public efficiently invertible bijection `F`, define

```
Q_K = F_* P_K.
```

Then

```
TV(Q_0,Q_1) = TV(P_0,P_1),                        (13)
```

and for every observed `y`,

```
Q_K(y) = P_K(F^(-1)(y)).                          (14)
```

So a public MAP attacker first computes `F^(-1)(y)` and runs the same likelihood
algorithm.  A dense invertible binary matrix is only a change of coordinates.

A **noninvertible** statement-aware public sketch could discard the attacking
statistic and is not ruled out by (13)--(14), but it must simultaneously preserve
decapsulation for every valid witness.  A **secret** erased scramble also is not
ruled out, but then a witness holder needs a public way to transport its witness
decoder through the unknown scramble.  Supplying that witness-only transport is
again a form of the missing witness-restricted public encoding, so it cannot be
assumed for free.

## 6. Source-witness transfer consequence

The exact-DP result also sharpens the Run-38 distinction between native weak
encryption and source-witness transfer.  On every statement family whose public
quotient has the sparse direct-sum form above, exact key likelihood is public in
polynomial time for `H=O(log lambda)`.  Therefore the public MAP raw-bit decoder
is Bayes-optimal and performs at least as well as any prescribed witness raw-bit
decoder on the same distribution.

Consequently the already-recorded independent bounded-distance
reconciliation/privacy-amplification wrapper cannot convert such a publicly
MAP-decodable raw channel into witness-only source transfer: replacing witness
raw estimates with Bayes-optimal public estimates cannot reduce the outer
success probability.

This is a composition statement for the sparse direct-sum channel class.  It is
not a proof that every generic-NP statement has such a factorized quotient.

## 7. Implemented validation actually executed

The attached standard-library checker was executed twice; the captured JSON was
byte-identical.

It deliberately uses **nonexchangeable** public channels:

- slot/gadget owner probabilities are independently generated asymmetric
  rationals;
- every `(slot,gadget)` has its own dense random `8 x 8` rational stochastic
  kernel, so local kernels need not commute;
- the public endpoint keeps two syndrome bits per gadget and only the XOR of the
  local parity bits.

The checker compares the subset-partition DP against an independently written
full labelled-state Markov enumerator.  Across 20 deterministic fixtures with
`m=1..4` and `H=1..4`, it checked

```
1,742 exact endpoint likelihood equalities.
```

It also checked 30 independent exact owner-partition mass identities.

For five explicit Run-39 transition fixtures, it replaced uniform gadget
selection by all-distinct labelled probabilities at base TV `1/1000`; the exact
complete key-conditioned TV changed by less than the proved coupling bound in
every case, and sampled endpoint likelihoods matched the subset DP exactly.
These finite fixtures validate the coupling/DP implementation; the asymptotic
attack is proved by (5)--(12), not inferred from them.

Finally, on all 20 random asymmetric fixtures the checker generated a fresh
public dense invertible binary quotient matrix and verified exact equality of
pre/post-scramble key-conditioned TV.

Local SHA-256 values of the final executed files are recorded in the provenance
file.  The second checker execution reproduced the captured JSON byte for byte.

## 8. Claims classified

### Proved in this run

- Exact subset-partition likelihood formula and `O(m 3^H)` DP for arbitrary
  public labelled slot/gadget weights and arbitrary public local stochastic
  kernels in the one-gadget-per-slot direct-sum model.
- Polynomial exact MAP for `H=O(log lambda)`.
- Resource implication (3)--(4) for the Run-38/39 notch honest bias.
- Explicit all-distinct-weight perturbation (8) with inverse-polynomial false
  complete-view TV, equations (5)--(12).
- Invariance and attack transport through every public efficiently invertible
  quotient scramble, equations (13)--(14).

### Implemented and actually executed

- Independent full-state enumerator versus subset DP on 20 asymmetric fixtures.
- 1,742 exact endpoint likelihood comparisons.
- 30 exact owner-partition controls.
- Five exact all-distinct-weight Run-39 transition controls.
- 20 exact dense invertible-scramble TV controls.
- Two final checker runs with byte-identical captured JSON.

### Not proved

- Security or insecurity of a dense error event that touches many gadgets in one
  genuinely non-factorizing step.
- Security or insecurity of a noninvertible statement-aware public sketch that
  somehow preserves all valid witness decoders.
- A reduction from any surviving channel to LWE/LPN/SIS or another independently
  justified PQ assumption.
- Arbitrary-QPT early-key-recovery to source-witness extraction.
- A completed generic-NP public offline PQ witness KEM.
- Final malicious-secure ceremony composition or end-to-end practical
  parameters.

## 9. Handoff

Breaking gadget symmetry is not enough.  The stronger invariant exposed here is
**sparse factorization across a polynomial direct sum**: with only
`O(log lambda)` one-gadget hit opportunities, exact likelihood can be summed by
a subset-partition DP even when every label and local kernel is different.
Public invertible mixing cannot hide that structure because it can simply be
undone.

The next constructive attempt should therefore use a high-entropy **dense,
non-factorizing** correlated event whose complete quotient likelihood is not a
small-subset partition function, while retaining a public witness-only observable
with inverse-polynomial-or-better completeness.  A public linear subspace
sampler is unlikely to suffice by itself because its distribution is exposed by
linear algebra; a computational dense generator would need an actual reduction
to an independently justified PQ assumption and must not smuggle in the missing
witness-restricted evaluator as an assumption.
