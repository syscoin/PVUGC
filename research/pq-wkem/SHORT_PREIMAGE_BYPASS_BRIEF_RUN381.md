**Candidate.** For public `A in F_q^{m x n}`, source word `x`, and bounded ORIGINAL witness set `W_B`, define `R_A(x,w)=[A w=x AND w in W_B]`. Honest classical setup samples uniform `h in F_q^m` and scalar signing-capability proxy `K in F_q`, publishes `p=A^T h` and `C=K+<h,x>` along with the checking key and claim context. Every valid ORIGINAL w recovers SAME K by `C-<p,w>`; distinct valid w may differ.

**THEOREM — exact unauthorized recovery.** For ANY `x in Im(A)`, Gaussian elimination publicly computes an UNRESTRICTED field solution `z` to `Az=x`. Then `C-<p,z>=K` identically, whether or not `z in W_B`. In particular, if x admits no bounded ORIGINAL witness, false-instance hiding fails with probability one; on a hard true instance, key recovery also bypasses the need to find an ORIGINAL witness. For full-row-rank A, p additionally reveals h itself, because `A^T` is injective. For rank-deficient A, the public image-membership test is already polynomial; outside-image hiding does not enforce NP-hard bounded-preimage membership.

**Explicit false ORIGINAL witness counterexample.** Over F11, `A=(1,1)`, `W_B={-1,0,1}^2`, `x=4`. The possible bounded sums are -2 through 2, so there is NO ORIGINAL witness, but `z=(4,0)` solves `Az=x`. The capsule has `p=(h,h), C=K+4h`, so anyone outputs `K=C-4*p[0]`. For true x=0, witnesses `(0,0),(1,-1),(-1,1)` all correctly output the SAME K. A public norm checker before the exposed projection is bypassable by evaluating the projection algebra directly.

**Rank-deficient counterexample.** With `A=[[1,1,0],[2,2,0]]` over F11, x=(4,8) lies in the image but has no short `{−1,0,1}^3` preimage; `z=(4,0,0)` still releases K. In contrast x=(4,7) is outside the image and this distinction is publicly decidable.

**Run 259 interface.** Its theorem accepts a complete, source-admissible representation and returns an ORIGINAL witness or specified SIS break. Independent fresh masks across capsules do not fix this single-capsule attack as long as each p has the bare `A^T h` form.
