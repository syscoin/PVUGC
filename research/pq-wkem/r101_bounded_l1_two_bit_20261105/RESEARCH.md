## New release algorithm, precise applicability

R100's honestly sampled restricted LWE-key witness leaves used one truly uniform shared matrix A and independently honest secrets/errors for each leaf, encrypting *one bit* in each of ell=16 public (u,v) coordinates. R101 makes a practical ciphertext-bandwidth change: encrypt TWO bits per v coordinate with deterministic correctness for EVERY valid bounded-error ORIGINAL source-key representation and EVERY accepted encryption tape, **at the same modulus q=65521, same dimension d=256, same error bound beta=3 and same ordinary decision-LWE assumption family**. Seven added LWE rows and an explicit bounded-L1 sampling rule make this possible. It does NOT compile generic ORIGINAL NP relations and does NOT resolve generic true-instance capability extraction.

Parameters: q=65521 (prime, locally confirmed), d=256, ell=16, m=1656, beta=3, chi independent mean-zero error entries supported in [-3,3], with a polynomially bounded number of honestly generated leaf source keys. Sample A uniformly from F_q^(m x d), independently S_i uniformly from F_q^(d x ell), E_i from chi^(m x ell), B_i=A S_i+E_i mod q. Valid restricted ORIGINAL leaf witnesses are ANY (S_i,E_i) that satisfy the published equality and ||E_i||_infinity<=3, not just the originally sampled one. A threshold ORIGINAL witness holds k distinct genuine leaf witnesses. The public statement includes relation identity, claim/UTXO, challenge branch, anchors/window, context, frozen transaction graph, intended native verification key and claim-scoped challenge message; these remain unchanged from R92/R95/R100.

Let D_m={r in {-3,-2,-1,0,1,2,3}^m: sum_j |r_j| <= 2729}. For each packed group sample r UNIFORMLY from D_m, independently across leaves, groups and related capsules. One exact classical-PPT sampler repeatedly samples the full septenary cube and rejects outside D_m; the acceptance probability is 0.004601156368426031, meaning approximately 217.34 full vectors per accepted r. An exact DP sampler avoiding rejection can use F(0,b)=1 and F(t,b)=sum_{a=-3}^{3} F(t-1,b-|a|), with F(t,b)=0 when b<0; select each next a with conditional probability F(t-1,b-|a|)/F(t,b). The recurrence identifies a classical polynomial-time exact sampler, although this run did NOT benchmark its full-size memory/time.

Each GF(256) Shamir share byte becomes four 2-bit symbols. Let Delta=floor(q/4)=16380. For ell packed two-bit symbols mu_j in {0,1,2,3}, publish

u=A^T r mod q,
v=B_i^T r+Delta*mu mod q.

Off-chain opening of any actual ORIGINAL pair (S_i,E_i) computes z=v-S_i^T u=E_i^T r+Delta*mu mod q, decodes each coordinate to the nearest cyclic codepoint among 0, 16380, 32760, 49140, and rebuilds the Shamir share. ANY k distinct valid threshold leaves reconstruct the SAME precommitted root T, which rederives the check secret, signature mask, native preauthorized sigma and the same bound challenge-path signature. No canonical witness, common preimage, local label switching, shared intermediate state or Bitcoin NP verifier is introduced.

**Deterministic all-valid-ORIGINAL-witness correctness theorem.** For every valid source pair (S_i,E_i), including alternate secret representations, and every r in D_m,

|E_i^T r| <= ||E_i||_infinity ||r||_1 <= 3*2729 = 8187.

The minimum cyclic distance between the four codepoints is 16380. Unique nearest-neighbor decoding works for all |noise|<8190. Since 8187<8190, decryption is correct simultaneously for all valid source-key representations and all accepted coins. In particular the capability cannot depend on which source secret happens to be supplied, and all k-leaf ORIGINAL witnesses recover precisely the same T, not a merely collision-resistant digest.

## Strong leftover-hash bound and full-public simulator

For a uniform FALSE leaf B_i independent of the shared uniform A, the map h_(A,B_i): r -> (A^T r,B_i^T r) in F_q^(d+ell) is pairwise universal: for any distinct r,r' in D_m, r-r' is nonzero over F_q because q>6 is prime. Therefore strong leftover hashing with uniform restricted r gives

epsilon_D <= (1/2) sqrt(q^(d+ell) / |D_m|).

There is NO appeal to small-coefficient LWE pseudorandomness for the encryption randomness; this statistical fact holds for the exact stated uniform source-key distribution. |D_m| is computed by summing coefficients up to degree 2729 of (1+2z+2z^2+2z^3)^m. The exact-integer DP gives log2 |D_1656|=4641.215963129408..., while the FULL 16-leaf x 16-related-capsule worst-case group budget for a 11008-bit T is G=16*16*ceil(11008/(2*16))=88064. Thus log2(G*epsilon_D) <= -129.22663005990486. This is a rigorous 128-bit-or-better STATISTICAL ciphertext-extractor budget for that specified group count, NOT a measured 128-bit QPT cryptanalytic strength. At m=1655 the analogous log2 bound is -127.90657695128762 and does NOT meet the chosen 2^-128 budget.

## Exact resource calculation and runtime tradeoff

R100 with m=1649 and a shared honest A: public source PK=1649*(256+16*16)*2=1,688,576 bytes; each leaf's ciphertext for a 11008-bit root=ceil(11008/16)*(256+16)*2=374,272 bytes. R101 uses m=1656, PK=1,695,744 bytes (increase 7,168 bytes), while the ciphertext per leaf per capsule is ceil(11008/32)*(256+16)*2=187,136 bytes: EXACT 50% reduction. For one capsule and 16 source keys the net source-public-plus-ciphertext saving is 16*(374272-187136)-7168=2,987,008 bytes. This omits unchanged signatures and constant metadata. The tradeoff is potentially major off-chain CPU cost for uniform bounded-L1 coin sampling; deployment practicality is NOT proven.
