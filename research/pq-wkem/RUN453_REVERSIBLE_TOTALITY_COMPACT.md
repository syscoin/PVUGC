# Run 453 — White-box release-totality audit is coNP-complete, even with reversible gates

Date: 2026-10-12 UTC. Live draft `syscoin/PVUGC#1`, branch `research/pq-wkem-validation-20260918`, starting SHA `bf186f014a82fb8faf0bba56fb52b1142c29b4d3`. Latest ordinary PR comment `6067040320`. Distinct from Run 452's **black-box** audit lower bound (unreferenced Run 452 commit was read, not republished).

**Theorem (unconditional classical complexity).** Fix ORIGINAL relation `R(x,w)=1` for all n-bit w and a *known* common capability K. Given a public candidate circuit G returning K or bottom, deciding `TOTAL(G): for all w, G(w)=K` is coNP-complete. Membership: a bad w is an NP certificate. Hardness: from arbitrary CNF phi compile a polynomial-size reversible X/CNOT/Toffoli circuit with zero-initialized scratch, `U_phi(w,0^a,b)=(w,0^a,b XOR phi(w))`. Define G_phi(w)=K when final b=0 from initial b=0, bottom otherwise. Then `TOTAL(G_phi)` iff phi is UNSAT. Construct U via reversible NOT/AND/OR gate templates, copy the formula result to b, then uncompute. Every local gate is bijective; local reversibility does not certify totality. This proves **weak initialized-ancilla** equivalence, not strong identity of the entire reversible permutation.

**Certification consequence.** A deterministic P checker with polynomial NP-style certificates, sound and complete for *every* arbitrary correct candidate G, would put CNF-UNSAT in NP, implying NP=coNP. A polynomial QPT white-box solver would imply coNP contained in BQP; that inclusion is not known to be impossible. This is not a QPT lower bound and says nothing about correlated quantum advice. Restricted syntactically authenticated compilation escapes the generic-candidate quantifier.

**Narrow constructive invariant.** A typed authenticated release frontier with only one `Emit(K)` output and bottom can enforce `successful release -> SAME K` by syntax, without testing exponentially many witnesses. It still must prove `every valid ORIGINAL w -> successful release`, faithful malicious-setup compilation, false-instance QPT hiding and `arbitrary native signature -> ORIGINAL witness or independent QPT break`. A public verifier's bare accept bit cannot be trusted across an unauthenticated protected seam. Run 259 covers only an accepted COMPLETE representation -> ORIGINAL, not signature -> representation.

**Primary-literature audit.** Stephen P. Jordan, arXiv:1307.0836, full five-page PDF proof read. Definitions 1/2 separate weak/strong reversible equivalence. Its Barrington-width-five/Fredkin proof establishes the *stronger* coNP-complete strong-equivalence problem; Corollary 1 transfers to Toffoli. Our direct reduction above is narrower. Source: https://arxiv.org/pdf/1307.0836 .

Does not resolve local mask seams/gauges/fingerprints (1-3), cross-capsule reuse/replay (4,7), or coherent cryptanalysis of a concrete mixer (9). Classical honest synthesis/test and classical malicious candidate; no hidden code or key. No assumed iO, WE, RIO, LWE, SIS or KDF. No actual local-mixing confidentiality proven.
