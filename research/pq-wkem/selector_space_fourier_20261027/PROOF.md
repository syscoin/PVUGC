## Concrete construction

The prior optimal Fourier star sampler groups gates with ONE common quadratic factor. We extend it to a batch of h gates whose different quadratic factors all lie in a common rank-r public affine selector space. There is no SOURCE-opening oracle or witness enumeration and no requirement that valid witnesses have a common internal state.

Let the ORIGINAL gate equations over GF(2) be c_i = u_i*v_i + nu_i, where nu_i marks NAND. Retain the original four physical assignment labels in the homogeneous SOURCE and all exact affine rows. After removing XOR/NOT affine gates, write Pi_i = span(U_i,V_i) for the quadratic factor plane generated by linear parts of inputs u_i,v_i. For each batched gate select nonzero A_i in Pi_i intersect the rank-r selector span, and independent B_i in Pi_i, with affine lifts A_i(z),B_i. The Boolean polynomial ell_i = u_i*v_i + A_i(z)*B_i is affine, because both products have the same degree-two part over the Boolean ring (squares reduce to linear terms). Thus C'_i = c_i + nu_i + ell_i equals A_i(z)*B_i exactly when the ORIGINAL gate is satisfied. All lifts and affine corrections are verified symbolically and using four original label assignments.

For each column draw eta uniform GF(2)^r and lambda uniform GF(2)^h, REJECT exactly lambda=0 AND eta!=0, then beta uniform GF(2)^r. Define a physical SOURCE mask E whose pairing with normalized SOURCE v is

  <E,v> = eta·(z(v)+beta) + SUM_i lambda_i*(C'_i(v)+A_i(beta)*B_i(v)).            (1)

For fixed sampled eta,lambda,beta this is a LINEAR vector of original SOURCE coordinates. Put eta·z on existing selector wire/affine labels, eta·beta on the distinguished constant e0 label, and put lambda_i*(C'_i(label)+A_i(beta)*B_i(label)) on every ORIGINAL gate assignment-label position. It is polynomial-time classical sampling, does not evaluate the ORIGINAL circuit on a hidden witness, introduces no nonlinear checks and publishes no sampling coins.

Before conditioning on rejection, for fixed beta, averaging over eta,lambda gives the indicator that z(v)=beta and all C'_i(v)=A_i(beta)*B_i(v). Averaging beta produces exactly 2^-r on every valid normalized gate state and zero on every invalid normalized state. The rejected event has probability a=(1-2^-r)*2^-h, and its Fourier contribution averages to zero for EVERY normalized state (lambda=0, eta!=0, the eta·beta character cancels). Thus the conditioned, admitted law has exact local character:

  rho_(r,h) = 2^-r / (1-(1-2^-r)*2^-h)
            = 2^h / (2^(r+h)-2^r+1),                                         (2)

on every valid normalized SOURCE state and zero on every invalid one. At r=1 this exactly recovers the former single-factor star 2^h/(2^(h+1)-1). The physical SOURCE has odd parity in each four-label block, so a three-hot assignment's effective inputs match its missing label while its output is complemented. Consequently it cannot satisfy the original nonlinear equation; affine normalization preserves the discrepancy. Independent disjoint batches multiply their signals. The sampler is not claimed to be globally Fourier-optimal.

Worst-case polynomial Build caps rejection attempts at T per batch and aborts BEFORE irreversible funding if unsuccessful. Conditional on admission the distribution is exact. Across N columns the honest abort upper bound is N*SUM_batches a_batch^T_batch; expected attempts per batch are <=2. Abort and setup disclosures require separate lifecycle modeling, not automatic malicious setup security.

A deterministic polynomial heuristic starts from the prior star grouping. Consider merging batches, compute rank r of the selected factors by GF(2) elimination, verify original quadratic corrections, and merge ONLY IF the exact rational new rho_(r,h) is strictly greater than the product of the former batch coefficients. This avoids regression of the Fourier signal, not necessarily regression in all finite package metrics. No claim of globally optimal partition.

## Non-common-factor example

Let x,y be two independent selector variables. Twelve AND gates use mutually independent other inputs t_i. Four gates have left quadratic factor x, four y, and four x+y. ## Exact limits and next obligation

If ALL nonlinear gates are covered by r selector bits, trying every one of the 2^r selector assignments reduces the remainder to affine equations. Thus r=O(log circuit size) gives easy SOURCE search, not meaningful hard-true security. This result improves release rate for such a gate SUBCOMPONENT inside a potentially hard general circuit.
