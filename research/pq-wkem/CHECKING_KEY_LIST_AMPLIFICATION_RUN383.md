## Unconditional candidate-list authorization lemma

Let a classical PPT setup publish a capsule `P`, a native verification key `vk`, and hide a full signing seed `K`. Suppose a *public* PPT algorithm lists at most `B(lambda)` candidate signing seeds, containing `K` with probability `eps`. If a public deterministic test `Test(vk,k)` accepts `K` and every accepted candidate can produce a native signature accepted under `vk` for the exact target path/message, enumerating the list gives a signature forgery with probability at least `eps` and at most `B` tests. If the checking key uniquely identifies `K` on this list, the same attack recovers the exact key. A collision does not restore authorization security when both matching candidates sign. This argument uses no rewinding, obfuscation, SIS/LWE assumption, or oracle programming; a classical PPT attack is also a QPT attack. The endpoint's actual seed-to-public-key and seed-to-signature compatibility is an explicit assumption, not implied by a mere hash coincidence.

When the list is efficiently indexable and the public test admits reversible coherent evaluation, amplitude amplification can find a marked candidate in `O(sqrt(B))` checks, rather than `B`, assuming an applicable marked-item promise. This *coherent checking-key* attack is not a quantum cryptanalysis of standard LWE. Residual `t` checkable bits must not be reported as 128-bit post-quantum protection: generic search uses `O(2^(t/2))` quantum checks.

## Source-gapped noisy projection falsifier

Use a **toy**, nonstandard error distribution. Set `q=257`, `Delta=128`, `A=(1,1)`, and ORIGINAL `R(x,(w1,w2))=[w1+w2=x and w1,w2 in {-1,0,1}]` (integer equality). Choose an `n`-bit hidden capability `K`, independent `h_j uniform F_257`, and independent errors `e_j=0` with probability `1-1/n`, `e_j=+25` or `-25` each with probability `1/(2n)`. Publish `p_j=(h_j+e_j,h_j)` and `C_j=128*K_j+h_j*x (mod 257)`, alongside the checking key `vk=PK(K)`. The public projection on `z=(z1,z2)` is `D_j(z)=C_j-p_{j1}z1-p_{j2}z2`.

For **every** valid ORIGINAL witness, `D_j(w)=128*K_j-e_j*w1`, whose error has absolute value at most 25, inside the nearest-codeword radius 64. Thus all valid ORIGINAL witnesses recover the SAME `K`, without identifying their intermediate states.

But `x=3` has no valid ORIGINAL witness. The public unauthorized `z=(3,0)` nevertheless yields `D_j(z)=128*K_j-3e_j`. If `e_j=0`, the true bit is uniquely within cyclic distance 75 of a codeword. If `e_j=+/-25`, **both** bits are within distance 75, while direct nearest rounding chooses the *wrong* bit. Compute public sets `S_j={b in {0,1}: dist_257(D_j(z),128*b)<=75}`. Exactly `T` positions are ambiguous, where `T~Bin(n,1/n)`. Enumerate the `2^T` full seeds and test `PK(candidate)==vk`. The test identifies an authorized signing seed (and the exact toy `K` in the checker). This works despite *incorrect naive rounding* and with independent honest noise, without an ORIGINAL witness.

For `t=ceil(2 log_2 n)`, `Pr[T>=t] <= choose(n,t)/n^t <= (e/t)^t=n^{-Omega(log log n)}`. Outside the negligible tail, at most `2^t<=2n^2` candidates suffice. Thus this false-instance authorization attack is **classical PPT with overwhelming probability** in the declared toy family, not merely a quantum speedup.

## Scope and attack surface

This is a general **checking-key/list-recovery criterion**, illustrated on the already-rejected Run-382 projection family; it is **not** a proposed linear fix or an attack on real LWE parameters. The sparse noise is artificial, the toy checking key is `SHA256(domain||bits)` (not an actual SLH-DSA public key or Bitcoin signature verifier), and the toy relation lies in P. We neither claim full false-instance QPT hiding nor true-instance arbitrary-QPT ORIGINAL extraction. The false `z` is **not** an accepted complete Run-259 representation, so no Run-259 source-binding theorem applies to its recovered key or signature.

Attack taxonomy: **(1)** local source seam bypass via `z`; **(2)** global gauge unnecessary; **(3)** exceptional slots have distinguishable two-candidate fingerprints; **(4)** 16–256 independent bit capsules jointly constrain a short list; **(5)** all queries are public/offline; **(6)** no malicious setup or retained secrets required; **(7)** the attack applies to the correctly bound *same* false statement and is not a replay claim; **(8)** `vk` is the decisive candidate-selector; **(9)** a separate finite reversible Grover-oracle simulation checks the coherent search calculation.
