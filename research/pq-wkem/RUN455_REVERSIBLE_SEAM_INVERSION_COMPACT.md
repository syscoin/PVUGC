# Run 455 — Public reversible mixer inverse defeats even a sparse release frontier

Date: 2026-10-12 UTC. Repo syscoin/PVUGC PR #1; verified starting head f07a33bbdaa38225cf442a4cb4f3a28f2d70669f, draft research/pq-wkem-validation-20260918. Production unchanged. One bounded falsification, NOT a completed PQ WKEM.

**Candidate interface.** Honest classical PPT setup publishes a gate-by-gate invertible permutation P_x on b input bits, an ell-bit terminal tag tau_x, a context-bound native public checking key, and a release capsule. An *ideal opaque* terminal, with a secret leaf signing capability K_x, returns K_x iff prefix_ell(P_x(s))=tau_x. Its s input is freely writable. A public honest source encoder E_x(w) checks ORIGINAL R(x,w) first. On true instances it may output s_w=P_x^{-1}(tau_x||h(w)) with different suffixes h(w); all valid witnesses obtain the SAME K_x. On a false instance the honest encoder never outputs a state.

**Reverse-reachability theorem.** The false-instance release is nevertheless defeated in O(size(P_x)+native signing cost), with one terminal call: choose any suffix u, compute s=P_x^{-1}(tau_x||u) by reversing the PUBLIC gate list, ask the terminal for K_x, then sign the intended native branch message. This is classical PPT and therefore works against an arbitrary-QPT target. It needs no malicious setup, quantum oracle, leaked source witness, replay, or signature forgery. Since the terminal accepts all preimages of tau_x||{0,1}^r, r=b-ell, its density is 2^-ell. For b=320, ell=312, r=8, generic Grover search would take about 2^156 predicate queries, but structured inversion still needs one terminal query. This is compatible with Run 454: density bounds give generic ATTACK UPPER BOUNDS, not security LOWER BOUNDS.

**Necessary seam condition.** A public verifier before a separately callable release terminal is not provenance enforcement. The protected boundary must authenticate the state as coming from an accepted COMPLETE ORIGINAL representation, or prove independent protection for arbitrary frontier inputs. A properly protected source-image check, internal clean-ancilla initializer, or an obfuscated construction whose security is actually proved may block this exact attack. This does NOT refute RIO/iO/CCMR/CLZ or their assumptions. The inverse theorem assumes publicly invertible P, publicly selectable accepted *terminal output* and externally writable s. It does NOT assume a common intermediate state, witness privacy, or native computation on Bitcoin.

(4) distinct capsules and (7) branch/UTXO binding do not fix this same-context attack; (6) honest setup suffices. (3) fingerprints and (9) coherent attacks are unnecessary.
