## Candidate: hash-sealed full-verifier-state graph
Build assigns random secret labels L_s to the complete states of an ORIGINAL witness verifier. Public rows for transitions s -(i,b)-> s' contain tag H_tag(ctx,L_s,i,b) and ciphertext E=L_s' XOR H_pad(ctx,L_s,i,b), with a publicly known root label. All accepting terminal states lead to the SAME precommitted capability K. If source verifier states are enumerated, any complete valid witness traverses a path and obtains K. The state must retain every reused constraint bit plus actual Syscoin child, full AuxPoW parent certificate, coinbase, ancestor, claim/UTXO and window; an outcome-only label is not source-complete.

**Theorem A (public BFS):** Suppose the full sealed graph has N vertices, E publicly retrievable/decryptable outgoing edges once a vertex label is known, a public root label, and a terminal acceptance path reveals K. Public BFS traverses each reachable vertex/edge in O(N+E) lookups and exposes K without a qualifying source witness supplied by an honest prover. If N,E are polynomial and accepting paths correspond to ORIGINAL valid witnesses, the traversal also constructs such a witness; the graph cannot protect K on hard-TRUE source instances. A hidden source-dependent edge enabling value can evade this argument, but that is precisely the missing independent cryptographic gate, not implemented by a post-hoc verifier or ordinary hash of the public label.

**Theorem B (repeated witness values):** A left-to-right deterministic state machine recognizing L_n={a||b:a,b in {0,1}^n, a=b} needs at least 2^n different states after the first n bits. For distinct a and a', suffix b=a accepts after a and rejects after a'. The 2^n distinguishable-prefix lower bound applies to explicitly sealed deterministic path states in this read order, NOT arbitrary circuits or generic WE. A polynomial bit-length exact fingerprint f(a,b)=sum 2^i(a_i-b_i) still has 2^n intermediate values. A public accept mask H(ctx,"accept",0) leaks K from a published K XOR mask directly; a private-keyed accept mask cannot be computed by an unprivileged witness holder without a new source gate.

**Theorem C (fixed native-preimage target; narrow structural consequence):** Fix one deterministic native function F:{0,1}*->{0,1}^k with k a fixed constant independent of ORIGINAL NP input length. Assume polynomial classical Build(x)->(y,Aux) with no original witness, and classical polynomial Extract(x,Aux,u), such that for every satisfiable x Build succeeds with probability >=2/3, y lies in im(F), and from **EVERY** u with F(u)=y, Extract returns a verified ORIGINAL witness with probability >=2/3. Hardwire one finite preimage u_y for each of the at most 2^k possible outputs y in im(F). Given any x, sample Build, look up u_y, call Extract, check R_original(x,w), and repeat a constant number of times. This is one-sided randomized polynomial-time SAT search/decision; hence the hypothesis for generic NP implies NP subset RP. With deterministic fully correct Build+Extract, P=NP. This is an **existential** proof with an astronomically large constant advice table, not a practical method for making SHA preimages. The strict premise "EVERY native preimage yields an ORIGINAL witness" is stronger than computational QPT source soundness. It does NOT apply when the native hash family varies with x via public seeds/addresses (or security parameter scales with input length), and does not rule out general hash-only WE. For a *fixed* SHA256d target y the all-preimage-to-ORIGINAL-witness target from R171 must not be assumed for unbounded generic NP without this complexity consequence.

## Specific repair directions that remain uninstantiated
(A) An x/context-dependent native tweakable hash F_{x,ctx} evades the fixed-image finite-table proof, but ordinary public salts do NOT force work certificates to be ORIGINAL witnesses. (B) A compact label compiler with source-dependent hidden transition edges evades public BFS but must actually provide honest Open a hidden edge preimage from complete authenticated source while remaining unavailable on false or forged source; the earlier arbitrary hash puzzle does not. (C) Nonblackbox SHA bit-circuit correlations could be studied, but cannot be renamed public oracle gates, randomized fingerprints, NP proof verifiers, obfuscation, or a hash-only native signature wrapper and counted as a construction.
