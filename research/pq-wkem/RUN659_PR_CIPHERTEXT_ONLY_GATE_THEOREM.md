Let classical PPT setup produce `(pk,evk,C_K,VK,P,aux)`, where `C_K=Enc_pk(K)`, `VK` checks native branch authorization by `K`, and all public auxiliary output is efficiently simulatable independently of which witness a later IND-CPA challenger encrypts. In particular, `P` contains no secret-key-correlated obfuscated decryptor or decryption key. Fix equal-length `w+`,`w-` with `R(x,w+)=1`, `R(x,w-)=0`. Public `Rel(P,Enc_pk(w))` receives **only** a ciphertext of the late witness, never plaintext, coins, witness proof or a private functional key. Let `Check(VK,Rel-output)` publicly test the intended branch signature/credential.

**Theorem:** For the actual above simulatable public view and QPT IND-CPA security of the FHE, the difference between native-check acceptance probabilities on `Enc(w+)` and `Enc(w-)` is bounded by the QPT IND-CPA advantage. **Proof:** the straight-line IND-CPA adversary generates `P,C_K,VK`, submits `(w+,w-)`, passes its challenge ciphertext to public `Rel`, and outputs public `Check`. It uses no rewinding/QROM programming and preserves checking-key correlation. If all valid original witnesses produce accepted native authorization with probability `>=1-eps`, then running the public release on the known invalid `w-` succeeds with probability `>=1-eps-Adv_INDCPA`. Thus ciphertext-only late admission cannot implement selective public release from ordinary FHE IND-CPA alone.

The uniform reduction requires efficiently samplable `(x,w+,w-)`; fixed hard witnesses require an explicitly nonuniform assumption/advice. The invalid-input attacker needs only `w-`, not `w+`. The result does not cover secret-key-dependent public decoders, quantum advice correlated with challenge bit, malicious N-of-N setup, cleartext witness/proof side inputs, or setup distributions that cannot be simulated in the IND-CPA game. Such escape interfaces require a new security analysis; publishing `sk` directly trivially leaks `K`. A publicly verifiable admission proof alone still cannot decrypt the protected `C_K`. For universal NP, simply assuming a witness-selective public decoder with common-K release and false-instance hiding is WE-like and not independent justification.
