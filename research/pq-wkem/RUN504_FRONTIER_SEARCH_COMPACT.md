# Run 504 — chosen-state Grover search at a short public release frontier

**Draft syscoin/PVUGC#1**, 2026-10-14 UTC; starting PR head `17fb1f7ef66cd7cd9d7dacd7e418bc81ac007b3b`. Scoped QPT falsifier/parameter upper bound, **not** a witness-KEM or RIO break.

Run 503 established exact hiding of local reversible gate tables on a forest when no two endpoint frames are fixed, but left the release-boundary admission problem unresolved. This pass shows that a **public native checking key supplies a Grover marking predicate** for any proposed public release function whose *entire input state* is short and freely enumerable. No path reconvergence, gauge reconstruction or publicly exposed output frame is needed.

**Model.** Honest classical PPT setup outputs a public claim-bound capsule `P_x` and native verification key `VK_x`; a classical PPT total, public evaluator `M(P_x,s)` accepts any `b`-bit candidate state and outputs `⊥` or a candidate signing credential. The adversary sees all public setup proofs, auxiliary inputs, keys, context, and other capsules and can run the public algorithms coherently. Fix the intended challenge-path sighash `m_x` and deterministic signing randomness `r0`; let `T_x(s)=1` exactly when `M(P_x,s)!=⊥` and `VerifyNative(VK_x,m_x,Sign(M(P_x,s),m_x;r0))=1`. A deterministic public-key consistency test is an equivalent checker. All valid ORIGINAL witnesses must lead to some accepted `s_w`, and honest witnesses must release the SAME native capability; the `s_w` need not agree. Let `N=2^b` and `t` be the number of accepting states.

**Theorem.** For `t>=1`, coherent evaluation of the entirely public classical `M`, `Sign`, and `VerifyNative` gives a phase oracle `|s> -> (-1)^T_x(s)|s>`. Grover search then obtains an accepted state and valid native authorization in `O(sqrt(N/t))` predicate calls when `t` is known, with exact success probability `sin^2((2q+1) asin sqrt(t/N))` after `q` iterations. Boyer–Brassard–Høyer–Tapp search handles unknown `t>=1` in expected `O(sqrt(N))` calls. Classical exhaustive search takes at most `2^b` calls and is PPT if `b=O(log lambda)`. The attack is **genuinely coherent QPT** and uses no quantum setup, QROM programming, or rewinding. The public `VK_x` identifies a successful candidate without revealing any ORIGINAL evidence.

For `t=1`, unit-cost query upper bounds are `2^64` at `b=128`, `2^96` at `b=192`, and `2^128` at `b=256`. These are **search-query counts, not real quantum work factors**: reversible signature-check circuit cost and depth may be substantial; 256 frontier bits are not sufficient evidence of 128-bit security. **Count all freely chosen admission bits, including proof bytes, not merely local gate width.** A separately secured non-public decoder or inability to evaluate `M` on arbitrary candidate states falls outside this theorem.

**Soundness boundary.** For an ORIGINAL-false statement, any state passing `T_x` is an acceptance bypass; the attack finds one at the stated cost. For a true but hard-witness statement, it recovers a valid signing credential without *initially* finding an ORIGINAL witness. Whether this violates `authorization -> ORIGINAL witness or QPT break` depends on whether the found state can be lifted to a **complete accepted representation** with source extraction. The exact Run 259 note (`c7f3b77f0273ca1cbe6f0b31c1a086b8eb3acbf2`) proves source binding only for such complete `z`, with a global residual and optional SIS reduction. It does NOT extract from a short `s` or native signature. This run asserts no impossibility against a mixer in which every accepted `s` is extractable.

**Attack audit.** (1) seam and (2) gauge attacks unnecessary; (3) checking-key fingerprint recognizes an accepted candidate; (4) multiple views may help but no composition theorem claimed; (5) arbitrary chosen-state evaluation is essential; (6) honest setup already suffices; (7) claim-specific replay protection does not prevent a fresh authorized challenge; (8) correlated native checking key is the marking oracle; (9) phase-oracle amplitude amplification is a coherent quantum attack. No WE-like assumption is introduced or claimed secure.

**Exact checks.** The committed `run504_compact_check.js` executed twice with byte-identical stdout `run504_compact_validation.json`: 403 assertions, 201 finite Grover fixtures, maximum simulation/closed-form error `1.12e-13`. An independent, locally preserved Python checker executed 486 assertions and 12 toy Ed25519 contexts, each with two eligible states returning the same capability. Neither checker implements actual quantum hardware, a secure mixer, SLH-DSA, ZK or practical WE.

**Literature:** Boyer, Brassard, Høyer, Tapp, *Tight Bounds on Quantum Searching* (1998), https://arxiv.org/abs/quant-ph/9605034 ; Zalka, *Grover's quantum searching algorithm is optimal* (1999), https://doi.org/10.1103/PhysRevA.60.2746 . This pass applies standard quantum search, not a new cryptographic assumption; a full RIO proof audit was not performed.
