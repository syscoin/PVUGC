**Candidate:** keep ORIGINAL NP witness computation public/off-chain, generate a succinct proof pi, and protect only a small verifier-conditioned SAME native capability K_x. This is an architectural idea, not an implemented release primitive. Neither proof-verification nor local mixing alone hides K_x.

**Theorem (semantic counterexample):** Given any complete QPT-computationally-sound proof verifier V(crs,x,pi) for ORIGINAL R, sample t uniformly at honest classical PPT setup and publish h=f_ctx(t), where f_ctx satisfies QPT planted-preimage hardness on the complete public context. Erase t. Define V'(x,(0,pi))=V(crs,x,pi) and V'(x,(1,tau))=[f_ctx(tau)=h]. Source completeness is preserved. For each fixed source-false x, any QPT adversary producing an accepting proof either breaks base QPT soundness (tag 0) or inverts f_ctx (tag 1); hence Adv_sound(V') <= Adv_sound(V)+Adv_preimage(f_ctx). Extraction of a classical proof is straight-line, with no rewinding or QROM programming. Auxiliary inputs revealing t are excluded unless the preimage game explicitly supports them.

Yet for EVERY source-false x there EXISTS the accepting proof (1,t), even when no ORIGINAL witness exists. Thus the proof-existence language L'={(crs,h,x):exists pi' V'(crs,h,x,pi')=1} is TRUE on all honestly generated such instances. Ordinary WE false-instance hiding for L' therefore provides NO hiding guarantee for ORIGINAL-false x. This is a definitional gap, NOT an efficient attacker recovering t or K_x at cryptographic parameters and NOT a break of any deployed SNARK.

**Necessary alignment condition:** a sufficient setup-wide mathematical condition is that except with negligible setup probability, for every admissible adaptively chosen x, acceptance of any pi implies existence of an ORIGINAL witness for x. Per-fixed-x statistical soundness, ordinary computational SNARG soundness, and computational knowledge soundness are not interchangeable with this condition. Alternatively one needs an independently justified release game that hides K_x for source-false x even when L' is mathematically true; merely renaming it witness encryption is circular.
