## Exact honest distribution

Security parameter lambda; odd prime q; dimensions d,n; independent bounded error distribution chi on [-B,B]; choose bit gap g satisfying g>2B(n+1) and 2(g+B(n+1))<q. Honest classical PPT setup samples A uniformly from F_q^(d x n) and t uniformly from F_q^d. The SOURCE ORIGINAL relation is

R((A,t),w) = (w in {0,1}^n) AND (A w = t mod q).

For every scope i in {1,...,N}, independently sample a native signing key pair (sk_i,vk_i) using a classical-PPT native KeyGen. All native seeds are *independent*, not generated by a common secret KDF. The canonical signing secret sk_i has ell_i bits k_i[j]. For every occurrence j across its polynomially many related same-key capsules, sample independently s_ij uniform from F_q^d, e_ij from chi^n and e*_ij from chi. Publish

beta_ij = A^T s_ij + e_ij (mod q)
tau_ij = t^T s_ij + e*_ij + g k_i[j] (mod q).

For each scope, bind the relation identity, claim/UTXO, branch, source anchors/window, intended vk, designated-owner/bearer credential policy, and message domain by an injective canonical context encoding. Full public view includes (R,A,t), all real SOURCE-dependent ciphertexts and related capsules, all actual native verification keys, context, publicly computable auxiliary fields and genuine native setup-time preauthorization signatures. Honest signing policy is classical PPT and may choose messages adaptively based on the entire public history and earlier valid signatures or sibling disclosures; it may not read the target secret key directly, target encryption coins, an ORIGINAL witness or hidden secret-dependent data except through an actual Sign(sk_i,message) callback. All native signing queries are classical. Preauthorization messages have exact P-domain bytes; intended challenge messages have disjoint C-domain bytes. Actual Bitcoin sighash, UTXO graph, flags and timelock coverage are a separate assumption and are not supplied by a mock byte prefix.

An arbitrary nonuniform-QPT adversary, including coherent quantum processing and independent auxiliary quantum advice, observes this full *classical* public distribution. It adaptively makes polynomially many classical full-opening requests for sibling scopes, receiving their canonical sk and every (s,e,e*) encryption coin, and sees authentic public native preauthorization transcripts. It finally chooses some scope i* it NEVER opened and attempts a fresh native signature in the C challenge domain under vk_i*, or returns the actual canonical signing key from which such a signature can be produced. Selecting a previously opened target is invalid. No target same-key capsule, target coin or sk may be disclosed. Auxiliary inputs may depend on the public view and disclosed siblings; external information correlated with target sk independently of these sanctioned channels is excluded. Signing-oracle superposition access is excluded.

## Every valid ORIGINAL witness releases the same precommitted key

For every binary ORIGINAL witness w with A w = t,

tau_ij - w^T beta_ij = g k_i[j] + e*_ij - w^T e_ij (mod q).

The absolute error is at most B(n+1). The gap/modulus inequalities give unambiguous nearest-center decoding of each bit. Thus all valid ORIGINAL witnesses w, even when distinct and with distinct intermediate state, reconstruct exactly the same precommitted native secret key sk_i for a particular scope and can publicly sign the intended challenge path off chain. Public decoding correctness is NOT a security argument against arbitrary other recovery algorithms.

## Restricted theorem and independently instantiated full-joint QPT simulator

Set p=Pr_uniform A,t[exists binary w:Aw=t], delta=2^n/q^d. By union bound p<=delta. Let F denote uniform A,t *conditioned on FALSE* (not efficiently sampled by the reduction). Let T_i count all target scope i bit ciphertexts, including related capsules. Assume standard ordinary nonuniform-QPT decisional LWE for uniform M=[A^T;t^T] of dimension (n+1) x d, one uniform secret vector s and independent errors chi^(n+1), versus a uniform ciphertext vector, and native nonuniform-QPT EUF-CMA with classical signing-oracle queries. Honest native keygen/sign are classical PPT. All counts and adversaries are polynomial in lambda. For any admissible nonuniform-QPT adversary A:

Pr_F[unopened, adaptively selected target fresh native challenge forgery or forgeable canonical key recovery]
<= p + SUM_i( SUM_{j=1}^{T_i} Adv_QPT_DLWE(B_ij) + Adv_QPT_native_EUF-CMA(C_i) )
<= delta + (SUM_i T_i) epsilon_LWE + N epsilon_native.

This relies on standard *single-vector* ordinary QPT DLWE in each hybrid: no unproved multi-secret matrix-LWE assumption, no SOURCE-opening oracle, no representation volunteered by the adversary and no automatic PPT-to-QPT lifting. A coherent QPT adversary can carry quantum memory through the full classical disclosure sequence; all reductions are straight line.

Proof:

1. Fix any binary w. Since t is independent uniform in F_q^d, Pr[Aw=t]=q^-d. The union bound across 2^n w gives p<=delta. The exact total variation distance of uniform (A,t) and uniform conditioned FALSE is p. Apply the same efficient randomized source-dependent capsule generator, keygen, signing policy, adaptive sibling openings and quantum adversary stochastic kernel to both source distributions; total variation cannot increase. This costs p ONCE, not once per target or ciphertext, and does not require a FALSE oracle.

2. Under unconditioned uniform source, define disjoint winning events E_i: adversary finally chooses target i, has never opened scope i, and produces a fresh accepted native challenge signature (or recoverable sk). Analyze each i fixed in the reduction code. An attempted opening of i disqualifies E_i. In the final signature challenger simulation, the reduction aborts and scores zero if i is opened; this changes nothing about E_i. This handles adaptive target selection without quantum rewinding or post-hoc witness extraction.

3. For fixed i, perform T_i hybrids, replacing exactly ONE target ciphertext vector at a time. A usual nonuniform-QPT DLWE challenger provides uniform M and y either M s + eta or independent uniform. Interpret the first n rows of M as A^T and last row as t^T. Generate actual sk_i,vk_i, shift only y's final coordinate by g k_i[j], and place it as the selected target ciphertext. Generate all other target vectors according to their fixed hybrid positions, and *genuinely* generate EVERY independent sibling sk,vk, real source-dependent ciphertext and all unrevealed coins using M. The reduction can disclose complete sibling sk and coins whenever the QPT adversary adaptively requests them. It constructs the actual checking-key correlations, policy-defined auxiliary data and complete adaptive native preauthorization signatures using known target sk_i and known sibling signing keys. Thus the DLWE challenger distribution and random-vector distribution are exactly adjacent whole-public-view hybrids, not merely equal marginal ciphertext pads. Reusing one shared random M across all columns introduces no new assumption because the reduction samples all nonchallenge columns from M itself.

4. After all T_i target vector replacements, uniform target ciphertexts are independent of target sk_i. Native QPT-EUF challenger supplies the REAL target vk_i and only its classical Sign oracle. This reduction samples target ciphertexts uniformly, independently samples every sibling key and its actual source-dependent ciphertexts/coins, honestly answers all adaptive sibling openings and signs sibling setup messages, and relays every adaptive target policy signing query to the native oracle. Since the target ciphertexts are independent of sk_i, this simulates *the entire final-game correlated public view* without knowing sk_i. It forwards any fresh C-domain accepted target signature; if canonical sk_i was recovered, it calls Sign with that sk to produce a fresh C-domain signature. Signing policy must never pre-sign that challenge. This is a normal native EUF-CMA attack, with no hidden signing-key bypass.

5. Triangle inequality across all ordinary LWE hops, union over disjoint target E_i and final p conditioning gives the bound. No quantum rewinding, QROM proof, generic-group reduction, SIS extraction or unproved structured SOURCE hardness was assumed. QPT-independent advice is allowed; arbitrary advice already containing the target sk is not a meaningful secure game.

This is a **genuinely instantiated but narrowly distributional composition**. It proves nothing for an adversarially chosen FALSE statement and nothing about unauthorized recovery on an arbitrary hard TRUE statement, so cannot fulfill the generic-NP WKEM obligation.
