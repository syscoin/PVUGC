# Run 439 — semantic-output orbit and terminal-injection barrier

Live base: syscoin/PVUGC#1, draft, research/pq-wkem-validation-20260918, verified starting SHA d45c05bafd1ffe8d0d4088c7026edf5d028473a5. Continuation of exact Run 438 endpoint-pin orbit theorem. This is a restricted mathematical falsification, NOT a practical PQ WKEM or a CCMR/RIO refutation.

## Exact colored-orbit theorem

Take d-point reversible permutations T_1,...,T_h and independent classical uniform U_0,...,U_h in S_d. Publish G_i=U_i T_i U_(i-1)^(-1), distinct named source pins A_j=U_0(a_j), and a public semantic decoder D_pub(y)=D(U_h^(-1)(y)), where D:[d]->Q colors source terminal states. Write T=T_h...T_1 and f=D o T. The full transcript distribution depends **only** on the color histogram N_c=|f^(-1)(c)| and the ordered pinned colors f(a_j); equal invariants give identical distributions, different invariants give disjoint supports. Let n_c count pinned colors c. Each transcript has precisely prod_c (N_c-n_c)! compatible vertex-frame assignments and the support is (d!)^(h+1)/prod_c (N_c-n_c)!.

Proof: (U_0,...,U_h) <-> (U_0,G_1,...,G_h) is bijective. Conditioned on G edges, U_0 is uniform. Publicly pull the decoder back via G=G_h...G_1: D_pub(G(z))=f(U_0^(-1)(z)). Thus the observer sees the uniformly relabeled finite colored and marked source set. Orbit-stabilizer yields the stated complete distribution and exact count. Crucially, even when there are **no output endpoint pins**, a many-to-one public semantic decoder exposes its color histogram. Native checking keys are not assumed to encode output labels; correlated auxiliary information must be audited separately.

## Restricted source-bypass theorem

Consider a publicly executable deterministic terminal decoder Dec_x:Y_x->signing capability/accepted native signature, with a polynomially enumerable terminal set Y_x. Suppose each valid ORIGINAL witness w reaches some y_w in Y_x yielding an accepted intended challenge signature with correctness 1-epsilon, but Dec_x needs no nonforgeable ORIGINAL-source authenticator beyond its terminal input y. An adversary simply enumerates all y, calls Dec_x, and uses the actual public native verifier. On any correctly generated true instance it succeeds with probability at least 1-epsilon without w, even if valid witnesses retain different complete terminal states and only semantic capability agrees. Signing-equivalent material suffices; exact serialized original signing-secret recovery is not required (Run 433).

For hard true instances x=f(u) of an arbitrary-QPT-secure one-way family, where classical honest Setup receives x but not u, an extractor converting this attack into an ORIGINAL preimage with nonnegligible probability would yield a straight-line QPT inversion algorithm, under advice simulatable from x and setup coins (or covered by the OWF auxiliary-input game). It does NOT imply arbitrary extraction impossibility for unrestricted correlated advice. Coherent checking gives an O(sqrt(|Y_x|/t)) upper-bound search when t>0 accepted terminal values exist, not a positive QPT claim. A 128-bit *generic* quantum-search work factor would demand |Y_x|/t>=2^256, but other structural attacks can be faster. The barrier does not apply if an independently source-bound, nonforgeable admission token is required, or if terminal states are not feasibly enumerable. It is not a new assumption and does not solve the admission token.
