## 1. Actual compiler trial and release equation

Let R_x(w) be the unchanged original bounded verifier, with the three independently sufficient grounds and complete source authenticity, claim relevance and LC maturity. Sample uniform lambda-bit t, publish h=H_trap(t), and define Q(w,u)=R_x(w) OR [H_trap(u)=h]. The latter branch is setup-only. All encodings and hashes are domain separated; ctx binds the full claim, native verification key/message and capsule ID, not just h.

Use a public deterministic Tseitin CNF for Q with its acceptance output asserted. Its satisfying extension from any Q witness is polynomial by circuit evaluation. Convert shorter non-tautological clauses to width three with fresh variables: (a OR b) becomes the two clauses with third literal p and not p; a unit a becomes four clauses a OR (+/-p) OR (+/-q), all sign choices. Remove tautologies and repeated literals first. This ensures distinct variables per resulting clause. Fresh padding variables can be zero in an honest extension. Introduce a reference variable z. Replace each clause a OR b OR c by NAE(a,b,c,z), where NAE means not all equal; setting z=0 gives exactly the original clause. Replace this four-literal relation by NAE(a,b,v) AND NAE(not v,c,z), with fresh v. Proof: when a=b, v must be their complement; when c=z, v must equal c. The two requirements conflict exactly when all four original values agree. In all remaining cases choose any consistent v. Thus with z=0 every Q witness gives an explicit satisfying assignment; conversely every satisfying assignment, after complementing every variable if necessary to make z=0, yields a Q witness by the CNF projection. The NAE formula F has a global complement symmetry. Its clauses each use three distinct variables.

For a concrete gauge-key trial, designate a sequence of acceptance-output variables y_1,...,y_lambda forced to fixed public relative bits b_i=y_i XOR z on all satisfying assignments. ## 2. Hidden correspondence does not hide the gauge

First, if each triple of variable IDs occurs only once, comparing its original and transformed NAE relation reveals m_i XOR m_j and m_i XOR m_k directly. The forbidden local assignments are a pair of complementary triples; their difference from the original forbidden pair determines the gauge up to simultaneous complement. In a connected component of the variable interaction graph these relative masks propagate. This does not require finding a satisfying global assignment. A forced relation y_i XOR z cannot span disconnected components: flipping all variables of the component containing y_i alone would preserve satisfiability while changing that relation. Thus in this simple case the attack already recovers all k_i.

Repair attempt: add multiple different clauses with the same variable support, randomly permute clauses and their literal order, and retain only the unordered multiset of relations. This genuinely removes the unique local correspondence used in the simple attack. For arbitrary multiplicities it still permits a polynomial reconstruction, as follows.

For a triple T=(i,j,k) of variable IDs sorted canonically, represent a clause by its sign vector s in F2^3, modulo (1,1,1) (the two choices yield identical NAE relations). Identify its class with q(s)=(s_i XOR s_j, s_i XOR s_k) in F2^2. Record the multiplicity function A_T on the four possible classes in F and B_T in G. Literal ordering and global complement of any one clause disappear under this normalization. The mask translates all classes on this support by the same d_T=(m_i XOR m_j,m_i XOR m_k). Enumerate the four elements of F2^2 and define

    D_T = {d : B_T(r) = A_T(r XOR d) for every r in F2^2}.

Because the actual mask works, D_T is nonempty. Pick any d_0 in D_T. Define the translation stabilizer H_T={e : A_T(r)=A_T(r XOR e) for every r}. H_T is a linear subspace: it contains zero, and successive preserving translations preserve the multiplicity function, hence it is closed under XOR. Exactly D_T=d_0+H_T by subtracting the two valid translations. Compute the affine linear constraints defining this coset in dimension two (zero, one or two independent equations) by enumerating its four elements. Substitute the two relative-mask expressions above. For every support T, accumulate these equations in the global mask variables. Supports present only in one formula or an empty D_T would reject malformed input; honest setup never does so. Solve the entire binary linear system by Gaussian elimination. Every solution n satisfies F^n=G as multisets of NAE relations, and the actual m is a solution. This is a polynomial algorithm in the public formula size, with no knowledge of any source bits, setup trapdoor or original witness.

Now prove that ambiguity of n cannot protect the key. For any compatible n, let delta=m XOR n. Since F^m=F^n, applying n gives F^delta=F. Translation by delta is a bijection of the satisfying assignments of F. Let a be any satisfying assignment, which exists by setup. Both a and a XOR delta satisfy F. The public forced-bit condition therefore implies

    (a_(y_i) XOR a_z) = ((a_(y_i) XOR delta_(y_i)) XOR (a_z XOR delta_z)) = b_i,

hence delta_(y_i) XOR delta_z=0, or n_(y_i) XOR n_z=m_(y_i) XOR m_z, for every i. This is true even for supports with full translation symmetry and under arbitrary duplicate-clause multiplicities. Consequently all compatible gauges produce exactly the same k, which the attacker reads as (n_(y_i) XOR n_z XOR b_i)_i. The source witness, if present, is not used.

Attack on the serialized public capsule: reconstruct public F; compute n using the above finite translation system; compute k and XOR the public mask with XOF(ctx,k,|S|). This returns the exact native capability with probability one under honest setup, independent of the hash assumption and number/entropy of original certificates. It is classical PPT and thus also QPT. In particular this attack succeeds for FALSE source statements: the internal setup trapdoor makes F satisfiable and supplies the required forced-bit property. No extraction of even that trapdoor is needed. The claim is a deterministic algebraic attack on the trial's public representation, not a theorem about all NAE formulas or hash-based WE.
