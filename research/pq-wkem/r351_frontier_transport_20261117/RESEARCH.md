## Constructed restricted compiler and proof

Fix a finite Boolean relation R(x,w)=AND_{j=1}^m C_j(w|S_j,x), where each C_j only reads bits in an explicit scope S_j and x is public. Let Seen_j=UNION_{i<=j}S_i and Future_j=UNION_{i>j}S_i. The live frontier is F_j=Seen_j INTERSECT Future_j; F_0=F_m=empty.

Public directed graph nodes at level j are (j,b) for b in {0,1}^{F_j}. Given node (j-1,b), choose values a for the variables newly required by S_j, consistent with b; add a unique-ID edge to (j,(b UNION a)|F_j) exactly when C_j holds. Label the edge with consumed local values to permit witness replay. This graph compiler is classical and explicit. Distinct original witnesses need not use the same path.

Completeness: any globally satisfying assignment w selects an edge at each level. Soundness: for any directed start-to-terminal path, a variable still used later remains in the frontier and cannot silently change between its first and last occurrences. Every C_j is checked, so replaying the local edge values reconstructs ONE consistent satisfying w. The bound is |V| <= SUM_j 2^{|F_j|}, |E| <= SUM_j 2^{|F_{j-1} UNION S_j|}. Thus polynomial construction is conditional on bounded local scope and maximum bag width O(log lambda); it is NOT polynomial for arbitrary SHA/AuxPoW verifier structure.

Apply the actual R350 finite-graph transport to this graph with independent secret K_v per explicit vertex, public K_s, and ciphertext C_e=K_v XOR H_edge(x,e,u,v,K_u) for edge e:u->v. Set C0=S XOR H_out(x,K_t) with a separately domain-separated FULL L-bit ideal output for L-bit frozen S (not a 256-bit PRG expansion silently identified with uniform L-bit pads). Every path opens the SAME S by induction. For a FALSE relation the graph has no s->t path; R350's restricted independent-hidden-key joint-public QROM simulation applies under its stated auxiliary, native, and sibling-independence assumptions. This is not concrete-SHA or ORIGINAL-source security.

## Adversarial decision and why this is NOT the missing release

**Public BFS barrier.** The entire explicit graph is public. Ordinary BFS finds an accepting path in O(|V|+|E|). The path labels then reconstruct a satisfying witness. Consequently, any polynomial-size PUBLIC path-sound source graph with completeness for a TRUE source instance also makes a source certificate polynomial-time discoverable; it cannot preserve the intended hard-TRUE evidence-search property. If instead a spurious path is permitted, that path directly opens S, even on a FALSE ORIGINAL instance, without authenticated evidence. This is a sharp barrier to using a publicly explicit graph as the needed hard-TRUE source compiler, not a general impossibility theorem for WE or for implicit source-dependent transport. A true source certificate existing and publicly discoverable in an already-observed source window may make BFS unproblematic there; the intended hard-TRUE and *unknown future source* case is the decisive scope.

A straightforward compressed streaming verifier retains a k-bit fingerprint of an unknown prior hash. In a fixed input order where an entire lambda-bit first word precedes the second word, deterministic equality checking requires 2^lambda distinguishable intermediate states: each distinct prefix u is distinguished by suffix u. Hash truncation to k bits creates merged prefixes/candidate collisions; for k=O(log lambda) they are brute-force enumerable, whereas explicitly representing 2^k keyed states for k=Omega(lambda) costs exponential space. If the words are interleaved bit-by-bit, the equality check alone needs only constant live state; the ordered-word bound is NOT a universal lower bound on arbitrary SHA-circuit pathwidth. Exploitation of a truncated-key collision as a fully authenticated actual AuxPoW original witness was NOT shown.

A lost-frontier synthetic attack is explicit: the two constraints x=0 AND x=1 yield no path with persistent x, but if the x state is forgotten and independently chosen per occurrence, the graph accepts the impossible mixed sequence [0,1]. This is precisely the earlier splicing defect, not a hash collision.
