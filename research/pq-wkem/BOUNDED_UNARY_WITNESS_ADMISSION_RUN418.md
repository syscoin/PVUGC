## Exact restricted model

Honest classical PPT `Gen(x)` receives a public external NP statement but **no ORIGINAL witness**, and produces a public capability-bearing state, native verification key, release program, and any setup-public auxiliary data. Every valid ORIGINAL witness must recover the SAME claim/branch-bound signing capability (possibly through distinct intermediate states). The late witness affects protected evaluation **only by selecting a control u** from a public enumerable set `U_x` with size `B=poly(lambda,|x|)`. The public release evaluator can be obfuscated or even supplied as an ideal opaque black box, and it may have secret K encoded internally; anyone can evaluate it on chosen controls and publicly verify the resulting native credential. The witness contributes no additional private/authenticated data or encrypted witness-bearing state.

This includes a fixed deterministic unary transition `T(C)` on an initial capability-bearing state when the *only* witness-dependent operation is choosing an iteration count `0 <= t <= B`. A fixed output functional key distributed publicly to all watchers is part of the public interface.

## Theorem — witness-free exhaustive release

Suppose for every valid `R(x,w)=1`, the public evaluator on control `u_x(w)` yields a native accepted credential with probability at least `1-delta`. Then for every *true* x a classical PPT attacker with **no ORIGINAL witness** enumerates the B controls, invokes the public evaluator, and verifies candidates against the actual native verification key. Because the correct control is among them, it succeeds with probability at least `1-delta`. For unary iteration, scan the orbit with B applications of T and at most B+1 output checks. No key extraction from code, rewinding, quantum queries, or cryptographic hardness assumption is needed. Different valid witnesses may select different controls and intermediate states.

**Extraction contradiction on hard true instances.** Let f be a QPT-secure one-way *function*, sample z uniformly, and take the true statement x=(1,f(z)) with ORIGINAL relation `R((b,y),(z',a))=[b=1 AND f(z')=y AND a in {0,1}]`. Two witnesses (z,0),(z,1) exist. Since honest Gen(x) never receives z, an arbitrary QPT extractor that turns the public enumerator's accepted credential into a valid ORIGINAL preimage would invert f: an inverter given y runs Gen((1,y)), simulates the enumerator and extractor, and returns z'. This is straight-line and requires no QROM/rewinding; the result is conditional on QPT OWF hardness and the extractor's stipulated interface. This is **unauthorized true-instance pre-release recovery**, not false-instance confidentiality and not legitimate downstream key delegation.

## Scope and attacks

A one-bit Boolean verdict forwarded from a public verifier to a separately invocable release gate is the |U|=2 special case: the attacker forces the accepting input. Merely running a correct public verifier does not authenticate the gate's input. A **superpolynomial** control family or a source-authenticated witness-bearing ciphertext avoids the *specific polynomial enumeration theorem* but is not thereby secure; old common-hash/preimage failures still apply. This does **not** refute the real Canetti–Luo–Zhang scheme: its fixed unary controlled homomorphism acts on encrypted plaintexts; a public way to inject a later witness into an encrypted state carrying K is exactly the missing application interface, not ruled out by this theorem. Private per-witness functional keys would fail our public permissionless-watcher goal without separate setup.

Relevant attack taxonomy: (1) source/release seam is unauthenticated, (2) no gauge synchronization needed, (3) native checking key recognizes outputs, (4) one capsule suffices, (5) exhaustive public chosen-controls is the attack, (6) honest setup and public coins already fail, (7) replay or other UTXOs not required, (8) all checking-key correlations remain public, (9) the classical attack is automatically a QPT attack; no new quantum-specific speedup is claimed. Run 259 only states accepted **complete source representation -> ORIGINAL witness**; here the recovered credential need not supply a representation.
