# Macaulay rank-pad: a restricted fixed-FALSE SOURCE release construction

**Status: concrete restricted release repair, NOT generic-NP witness-KEM.** This record gives a witness-free compiler, an actual ciphertext release equation, same-precommitted-K correctness for every valid ORIGINAL witness, and an information-theoretic full-ciphertext hiding theorem for fixed FALSE instances with a degree-D Boolean refutation. Its security condition is independently decidable by matrix rank for constant D. It does not provide arbitrary fixed-FALSE security, hard-TRUE witness extraction, or a general witness-KEM. This is not a repaired tensor/Frobenius/Schur construction or a generic WE/iO assumption.

## Construction and exact distributions

For public ORIGINAL R,x (including claim/UTXO, branch, anchor/window, context, intended native pk/capability binding) express R(x,W) as a polynomial-size 3CNF F_x with standard deterministic gate-extension witnesses. Let v be the number of Boolean variables, c clauses. Fix a constant degree D>=3, odd prime q and Boolean quotient B=F_q[z_1,...,z_v]/(z_i^2-z_i). Define each clause's violation polynomial p_j(z)=product over its literal occurrences of (1-literal), reduced multilinearly.

Let M_D consist of every square-free monomial of degree <=D; m=sum_{k=0}^D binom(v,k). For each p_j add public coefficient rows for the Boolean-reduced products u*p_j over square-free multiplier monomials u with deg(u)<=D-deg(p_j). Append a normalization row for constant monomial 1. Set A_x to these n by m rows and U_x=(0,...,0,1)^T in F_q^n. These public matrices are generated CLASSICALLY without knowing or planting an ORIGINAL witness, in polynomial time for constant D. Given every valid ORIGINAL W, compute a satisfying gate extension z and Phi_D(W)=(product_{i in S} z_i) over M_D. This vector is Boolean, satisfies A_x Phi=U_x and has integer L1 norm <=h=m. Distinct valid W may have distinct Phi, but all must recover the same precommitted K. Accepted arbitrary short vectors do NOT automatically extract ORIGINAL witnesses.

Build independently samples native key K using the native seed distribution and publishes its genuine intended verification key pk(K). For a fixed byte-aligned encoding, sample t independent uniformly random same-length XOR shares Z_i and publish mask M=K xor Z_1 xor ... xor Z_t; use independently randomized native KeyGen if its secret format requires it. Set h=m, g=2h+3, radix T=floor(q/g)>=2. Independently encrypt each base-T digit a of every Z_i with fresh s uniform F_q^n, e uniform {-1,0,1}^m, eps uniform {-1,0,1}, publishing FULL ciphertext c=A_x^T s+e, d=U_x^T s+eps+g*a (mod q). All honest algorithms are classical PPT, with no SOURCE-opening oracle.

Public off-chain Release computes Phi_D(W), then nearest cyclic digit center of d-Phi^T c=g*a+eps-Phi^T e (mod q). Since |eps-Phi^T e|<=h+1<g/2 and the cyclic centers have gaps at least g, **every valid ORIGINAL W**, including distinct ones, deterministically recovers ALL Z_i and the ONE precommitted native signing capability K. No original NP verifier, VM, PCP, or proof trace is run by Bitcoin.

## A genuinely instantiated restricted false-instance theorem

For any specific fixed FALSE F_x whose public constraints possess a degree-D Boolean identity 1=sum_j f_j p_j, where every f_j p_j expands as a linear combination of the compiler's permitted product rows, a public vector z exists such that A_x^T z=0 and U_x^T z=1 (mod q). Equivalently U_x is not in the column span of A_x. This condition is independently checkable in PPT from exact public matrices, not assumed as an ideal security oracle. It is NOT true for all FALSE x.

Fix A_x,U_x meeting this condition, any fixed protected digit a, and even the specific e,eps. Condition on public c. Uniform s may be shifted along every s+lambda*z for lambda uniform F_q. Such a shift leaves c exactly invariant and increments d by lambda. Thus d is **exactly uniform over F_q, conditional on c, e, eps and a**. Independent per-digit coins make the complete protected ciphertext collection perfectly independent of the protected XOR shares and of native K. The proof is algebraic and information-theoretic, so subsequent coherent processing by an arbitrary QPT adversary does not regain information.

The joint-public view includes relation/statement, claim/path/anchors/window/context, A,U, all ciphertexts, mask M, genuine pk(K), independent auxiliary input, and related capsules that are generated with their own independent native keys and coins. The allowed adaptive Open oracle discloses at most t-1 distinct whole target shares, including ALL their plaintext digits and s,e,eps coins; the protected remaining share and its coins are not disclosed. Permitted related-capsule replies and signing queries are classical, fresh target-path forgeries are checked exactly, and independent nonuniform quantum advice is allowed. Arbitrary hidden-key-correlated advice, malicious setup/retention of the builder's K or hidden s, target-secret reuse in related capsules, and coherent quantum opening queries are NOT covered.

A straight-line QPT native EUF-CMA reduction can receive the genuine target pk from its native challenger. It guesses an unopened whole-share index J, generates the other shares and their complete encryptions with known coins, sets M uniformly, and publishes uniform J ciphertexts. These are EXACTLY the real rank-separated FALSE distribution, even though the implied J share depends on the unavailable native secret K. It answers all non-J opening requests and aborts if J is opened; given at most t-1 openings, its guess succeeds with probability >=1/t. Any recovered K can sign a fresh intended-path message, and any fresh native signature is directly a native forgery. Therefore the false-instance bound is at most t*Adv_QPT-native-EUF-CMA, using the native scheme's exact key-generation distribution and signing-oracle model, with no decisional-LWE hybrid, SourceOpen oracle, quantum rewinding, or volunteered representation. The ciphertext secrecy claim itself is UNCONDITIONAL; the final-key/forgery conclusion is conditional on INDEPENDENT native QPT EUF-CMA. This is restricted to honestly generated source/capsules and independent admissible auxiliary input.

## Exact finite tests

At q=257, v=3, D=3, m=8, h=8, g=19, T=13, TRUE F=(x OR y OR z) has 7 distinct satisfying witnesses. The actual checker recovers an identical precommitted 256-bit three-share K from ALL 7 ORIGINAL witnesses in four independent trials. Here A has 2 rows and 8 columns.

The fixed FALSE example (NOT x) AND (x OR NOT y) AND y, with one unused third variable, has the explicit Boolean degree-2 refutation 1=y*x+(1-x)*y+(1-y). Its D=3 public A has 19 rows and 8 columns; the exact checker exhibits z with A^T z=0, U^T z=1. It exhaustively runs four complete 257-element affine orbits, showing the public ciphertext c never changes but the protected d visits every residue exactly once. A separate independent extended Python checker includes the same-capability and degree-1/2/3 rank tests. In the earlier paired-binary compiler this same fixed FALSE family was vulnerable to a short public noisy pseudo-decryptor. **This repair is only for rank-refutable FALSE sources.**

The exact published Python checker, executed twice with byte-identical JSON output, passes **7,938 assertions**, including four 256-bit COMPLETE-key recoveries for each of seven valid witnesses, four exact q-element false-source uniform orbits, and source/certificate checks. An independent extended LOCAL-only checker passed **12,009 assertions twice identically**, including six whole-key trials. SHA-256 or integer key equality in these checkers is a mock capability check, NOT native SLH-like signature implementation, concrete PQ security benchmarking, or a Bitcoin deployment.

## Limits and precise handoff

If a FALSE instance lacks the allowed low-degree refutation, U may lie in Im(A), leaving publicly computable fractional/pseudomoment pseudo-openings that cancel the LWE term and leak K. Hard-TRUE instances may likewise have public low-norm non-ORIGINAL pseudo-openings, so **arbitrary final-key recovery/native forgery -> ORIGINAL witness or independent PQ break remains UNPROVED**. Raising D to the degree needed for all false formulas may require exponentially many monomials; fixed-D rank-refutability itself is polynomial-time recognizable, and therefore is not an NP-hardness solution. No claimed QPT LWE security for arbitrary deterministic source matrices.
