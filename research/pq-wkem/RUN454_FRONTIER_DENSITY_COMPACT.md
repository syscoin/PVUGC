# Run 454 — Public frontier acceptance density permits witness-free native signing

Date 2026-10-12 UTC. New research on the draft syscoin/PVUGC#1 branch research/pq-wkem-validation-20260918, starting SHA d5109ceece36cd170e88a23eead82e3170f43a7d. Production unchanged. Not a practical PQ witness-KEM.

RESTRICTED INTERFACE: Honest Setup(1^lambda,x) is classical PPT and does not know a later ORIGINAL witness. It publishes a copyable classical release program D_x, native checking key vk_x, fixed branch message m_x, and arbitrary public auxiliary data. A freely writable protected-frontier input s has b bits. The terminal D_x(s;r) is classical PPT, stateless, publicly reinitializable, and may consume a public random tape r, including native signing coins. Its output is either a branch-native signature or a signing-sufficient capability, turned into a signature by a public signing procedure. The test A_x(s,r) is native Verify(vk_x,m_x,sigma). No uncopyable device, online release authority, or private admission oracle is part of this interface. An arbitrary QPT attacker can coherently simulate the publicly known classical algorithms, with polynomial reversible overhead.

Let S_x={E_x(w):R(x,w)=1} be the set of DISTINCT frontier inputs of valid ORIGINAL witnesses, M=|S_x|, with witness-dependent states allowed and all valid witnesses recovering the SAME protected leaf key K_x. Suppose every s in S_x releases a native-valid capability/signature with probability at least 1-epsilon over r. Then
 p=Pr_{uniform s,r}[A_x(s,r)=1] >= M(1-epsilon)/2^b.
PROOF: the M disjoint fibers at good s each contribute at least 1-epsilon of their random tapes. Other accepting states only increase the density.

ATTACK: Uniform independent public queries recover an accepted native signature in expected at most 2^b/[M(1-epsilon)] evaluations. A coherent phase marker implementing A_x(s,r) from the copyable public program and Verify gives quantum multiple-solution search in O(sqrt(2^b/[M(1-epsilon)])) public evaluations, even when r is long. For unknown marked count use Boyer–Brassard–Høyer–Tapp search. This is an explicit quantum attack on a TRUE-instance signing interface, not a false-instance hash-fold search. With b=O(log lambda), the classical attack is PPT. Run 444 enumerated a polynomial ACTION set along an opaque unary orbit; this theorem instead enumerates/searches ALL freely chosen frontier states, with no restriction on the number of actions.

PARAMETER CAUTION: For b=256 and M=2^64, the generic coherent attack costs about 2^96 oracle evaluations, not 2^128. Avoiding this specific 128-bit quantum-query attack requires approximately b-log2(M)>=256 for high correctness (e.g. b=320 when M=2^64). This is a necessary anti-search budget only, NOT a proof of PQ security. An encoder whose larger number of states also increases b may leave density unchanged. M counts distinct successful states, not the number of ORIGINAL witnesses.

ORIGINAL-EXTRACTION SEPARATION: For R(x,w)=[f(w)=x] with QPT-one-way permutation f and x=f(random w), assume honest setup and all public outputs are simulatable from x without w. If b=O(log lambda) and M>=1, the public enumerator creates an accepted signature without w. Any claimed straight-line polynomial/QPT extractor that obtains ORIGINAL w from this forger and only simulatable setup information would invert f. The attack does not provide an accepted complete Run-259 representation; Run 259's supplied-representation theorem does not apply. This is restricted to the stated interface, not a general WE/iO impossibility.

Context and branch replay checks (7) do not block attack on the legitimate target context. Malicious setup (6), multi-capsule collisions (4), and seams/gauges/fingerprints (1–3) are not required or established. No actual CCMR local mixer, CLZ functional scheme, iO, lattice or SLH signer is broken.
