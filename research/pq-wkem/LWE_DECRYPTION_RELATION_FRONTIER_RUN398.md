For odd q, define ORIGINAL R_dec((A,b),(s,e)) iff b=A s+e mod q with s in Z_q^n and ||e||_infty<=B. Setup samples independent native (vk,K) and publicly encrypts each bit K_j using Regev-style subset-sum PKE: sample independent binary r_j of length m, publish (u_j=A^T r_j, v_j=b^T r_j+floor(q/2)K_j) mod q. A valid witness recovers bit j by subtracting s^T u_j from v_j and rounding to the closer message center. For every valid witness, the noise is e^T r_j, bounded in absolute value by mB. If mB<q/4 with rounding slack, **all** valid ORIGINAL witnesses recover the SAME K. Distinct s, e and intermediate states are allowed. The witness then produces an ordinary native branch signature off chain.

For an honestly generated LWE pk and independently generated native vk=PK(K), a QPT accepted fresh-signature adversary without a source witness is bounded by an ell-bit multi-message PKE IND-CPA hybrid plus native EUF-CMA forgery. The hybrid changes encryption of K to encryption of zero while **retaining the same correlated vk**. Its simulator knows K and can choose both PKE challenge messages, so does not assert K is indistinguishable from an independent key given vk. In the zero world native forgery applies. This is conditional on exact QPT IND-CPA security (itself conditional on a specified QPT decisional-LWE distribution and PKE correctness), native QPT forgery hardness, classical PPT setup/evaluation, and efficiently simulatable independent auxiliary inputs. QPT adversaries can process public ciphertexts and run all public code coherently; there is no secret decryption oracle. No concrete 128-bit security is established.

This provides **distributional** false-instance hiding (also with independently correlated native vk), NOT hiding for every attacker-chosen false x.
