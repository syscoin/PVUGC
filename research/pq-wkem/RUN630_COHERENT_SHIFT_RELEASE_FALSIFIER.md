## Candidate and exact all-pair semantics
Choose a hidden K in F_2^n and a uniform random permutation P of F_2^n. Expose forward oracles O0(z)=P(z), O1(z)=P(z xor K). A publicly verified matching pair (z0,z1) with O0(z0)=O1(z1) yields K=z0 xor z1 exactly, for EVERY such pair. Witness-specific pairs remain different; only their recovered key agrees. The matching-pair relation is NOT the ORIGINAL SOURCE relation. No way of deriving a matching pair from each arbitrary future original SOURCE witness is constructed, so original all-witness correctness is UNPROVED. Adding a public SOURCE accept-bit check does not control adversaries inspecting the raw evaluation oracles.

## Quantum attack: an exact Simon promise
Construct public oracle F(b,z)=O_b(z) on n+1 input bits. Set h=(1,K). Then F(x xor h)=F(x), and because P is injective these are the only equal-output input pairs. This is the exact 2-to-1 Simon period promise for EVERY P,K, including K=0. A quantum attacker queries the coherent reversible oracle |x,y>->|x,y xor F(x)> in superposition, measures the output and Hadamards the input. Each measurement is independently uniform over h-perpendicular (dimension n). After n+t samples, the failure probability of full rank is at most 2^(-t); linear algebra with h's first coordinate fixed to 1 recovers K. This is O(n+t) coherent public queries, with no SOURCE witness, trusted checker, setup randomness, quantum rewinding or native signature computation. An actual SLH-like signature under K remains conditional on the native endpoint/key mapping and is NOT implemented here.

## Why classical tests would miss it
With forward-only random-permutation queries, a classical test querying q0 first-view inputs and q1 second-view inputs encounters a cross-output match only for one of at most q0*q1 XOR differences. For fixed queries the probability over uniform K is exactly |difference set|/2^n; no-match transcripts exclude only these differences in the usual lazy-sampling model. Thus classical matching is birthday-scale whereas coherent evaluation gives polynomial-query key recovery. If the inverse of P is publicly efficient, K=z xor P^{-1}(O1(z)) is available after ONE classical query. If a compact classical O1 circuit embeds K transparently, unrestricted white-box inspection may reveal it immediately. These caveats prohibit treating the oracle separation as a secure compact cipher or a QPT result for an existing RIO construction.
