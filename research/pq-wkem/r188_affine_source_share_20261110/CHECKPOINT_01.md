# R188 — Affine source-share fork release: candidate checkpoint before testing

**Hypothesis, not a security result:** For a claim-prefix-scoped Syscoin challenge, normalize every qualified semantic source observation to the child-header identity `z` at the exact claim-relevant height `h_rel`. Distinct parent Bitcoin work certificates for that same child yield the same `z`. Valid histories that share the claim-relevant prefix yield `z=z0`; a relevant fork diverging at `d<=h_rel` yields `z!=z0` absent a child-identity hash collision. Actual qualification must authenticate full Syscoin/AuxPoW/BTC evidence, source window, lag/tags, height and descendants. This is the semantic projection, **not** a cryptographic source-authentication gate.

Choose field F_p with p>2^256; encode header hash z=1+uint256(H_child) so z!=0 and is injective on 256-bit digests. Setup picks K,a uniformly from F_p, constructs p(z)=K+a*z, publishes baseline share u0=p(z0), and keeps K,a protected. A future authenticated source observation at z supplies u=p(z). If z!=z0 then recover K=(z*u0 - z0*u)/(z-z0) in F_p. For any distinct authentic alternative z the result is SAME precommitted K, regardless of work-certificate changes. At z=z0 no inversion / no release. A fixed native cancellation signature can be sealed under domain-separated H_pad(context,K), with native VK checking. Do not confuse K with the field polynomial p.

A random slope makes u0 uniformly distributed independently of K when z0!=0. This is a genuine unconditional masking property of ONE baseline share, including joint baseline shares if their slopes are independently sampled per branch. No secret is released on a baseline observation alone.

**Critical missing function:** Classical-PPT `BuildSourceShare(x,K,a)` must produce a public object which, for every *future* qualified ORIGINAL source certificate `w` with semantic value z(w), evaluates u=K+a*z(w), without revealing K or a from public capsule / retained source coins, and without allowing fabricated strings or unauthenticated headers to obtain nonbaseline shares. This source-conditioned *oblivious polynomial evaluation* is not constructed here and might be at least as hard as the requested WKEM. Publishing K,a plainly or a public polynomial evaluation formula plainly reveals the cancel key. The source party cannot know a; if it retains a, it extracts K from the public u0 before any fork. A source-selected different `z` is insufficient unless admitted by the ORIGINAL relation. A fake source helper or programmable oracle is not an implementation.
