# A boundary for predicate-oracle witness-transfer compilers

**This is not a completed generic post-quantum WKEM or its missing public prover.**

This continuation starts from `ae5042e87fd74d2200979168825f064cd85d480c` and `PUBLIC_PROVER_TRANSFER.md`. Only the supplied record and requested GitHub operations were used. No outside literature, priority claim, secure parameter recommendation, or production-code change is involved.

## 1. Restricted model

Let U be a witness domain of size M. A public setup/encapsulation algorithm E and public decoder D receive the relation only through a Boolean predicate oracle O:U->{0,1}. All other input and advice is independent of which predicate is selected. Setup returns a public classical header C and an internal comparison key K. A valid witness u has O(u)=1.

Let O0 be identically zero, and Ou accept precisely u. The compiler is not given u, a u-dependent circuit description, or additional relation-specific algebra. This oracle-only restriction is essential. The results below do not rule out non-black-box use of an actual NP verifier's code or public lattice/group/commitment structure.

A secret hardware oracle releasing K is outside the model: O here returns only one bit. A public rejection check is not a restriction on adversarial computation.

## 2. Classical setup theorem

Suppose E makes at most Q classical predicate queries, possibly adaptive and randomized. Define average true correctness

    c = Pr[D^Ou(C,u)=K : u uniform in U, (C,K)<-E^Ou].

There exists a false-instance adversary with key-recovery probability at least

    c - Q/M.

The adversary chooses u uniformly, runs the public decoder on (C,u), and implements every predicate call using its own equality test Ou. No witness exists for the actual predicate O0.

Proof. Fix E's randomness in the O0 execution, and let T be the set of its distinct queries. Couple E^Ou using the same randomness. Until query u occurs, both executions get exactly the same answers and follow the same adaptive path. They have identical outputs, including K, whenever u is not in T. This fails with probability |T|/M<=Q/M. Apply the same decoder with locally simulated Ou to both outputs. Its success probability changes by at most Q/M. On the point-oracle setup its average success is c; on the zero-oracle setup it is the specified attack. QED.

If false-instance key hiding bounds every efficient adversary by p, then

    Q >= M*(c-p).

For n-bit witnesses M=2^n. Near-perfect correctness and negligible recovery on false instances force essentially exhaustive classical setup in this oracle-only model. The theorem also counts the total Boolean calls of an MPC implementing this same classical computation. It does not constrain an MPC realizing a different, non-black-box cryptographic construction.

## 3. Quantum setup variant

For setup with Q coherent Boolean predicate queries, the corresponding recovery lower bound is

    p_attack >= c - 2Q/sqrt(M).

Consequently false-instance recovery bounded by p requires

    Q >= (c-p)*sqrt(M)/2.

Proof. Purify setup randomness and defer measurements. Before query j in the O0 execution let p_j(u) be the squared query-address amplitude at u. Its sum over u is at most one. Telescope the point-oracle and zero-oracle circuit products with an O0 prefix and an Ou suffix in each term. The query unitaries differ only at address u, so the j-th term has norm at most 2 sqrt(p_j(u)). Final state distance is at most 2 sum_j sqrt(p_j(u)). Averaging u and applying Cauchy bounds it by 2Q/sqrt(M). Trace distance of the measured (C,K) output is no larger. For each u, apply the same decoder with simulated Ou to both outputs, and use data processing. QED.

This argument allows a QPT decoder, but needs the public decoder's executable circuit and the stated oracle-only input model. Unknown unpreparable advice and inaccessible hardware are not covered. No quantum hardware was run in the validation.

## 4. Exact boundary control

A full table with one entry per u can be generated by testing every u, writing K at accepting positions and independent fillers elsewhere. Every valid witness then reads the common K. On O0 all table entries are independent of K. This costs M tests and M entries, and is not an efficient generic compiler.

If only Q distinct addresses are tested, with uniform k-bit fillers, average correctness for a uniformly hidden single accepting point is exactly

    Q/M + (1-Q/M)*2^-k.

The zero-world simulated decoder recovers K with probability exactly 2^-k. The two joint distributions, including the point and key, have variation distance

    (Q/M)*(1-2^-k).

The finite tests verify these equalities. They are an exponential-domain control, not a claimed cryptographic instantiation.

## 5. Scope and consequence for the missing prover

Giving setup the hidden point in an additional descriptor permits one query to find it, violating the independent-input premise. The tests include this negative control. An actual verifier's representation can similarly contain structure that the oracle model omits. Thus these bounds do NOT prove that general computational witness encryption is impossible.

The planted matrix sampler already has mathematical structure beyond a bare relation oracle, but it still does not implement Prove(P,x,w). A wrapper that merely checks R(x,w), a proof, or a root opening and then branches to an unspecified secret-release operation is not a completion of that missing algorithm.

The attempted globally bound commitment approach did not yield such a construction in this pass. Binding local openings to one witness and transferring a hidden seed are distinct obligations. No theorem excluding every commitment-based construction is asserted here.

## 6. Validation record

Eight local test groups passed. They cover 16 exact table distributions (1852 finite executions), 400 adaptive query trees (2640 point-transcript comparisons), 450 small quantum statevector comparisons in 60 averaged cases, and explicit-description, full-table, false-header-independence, and rejection-gate controls. Counts overlap and replays are not additive coverage.

Finite probabilities are checked with rational arithmetic. Statevector checks use NumPy and the stated numerical tolerances; the proofs above establish the general bounds. Fixed seeds provide reproducibility, not cryptographic randomness. The source, longer note, counts and source hashes are saved in the conversation artifact `wkem_oracle_transfer_audit.zip`. This documentation commit does not claim those test sources have been committed.
