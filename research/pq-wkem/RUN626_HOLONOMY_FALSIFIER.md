# Run 626: a two-path holonomy falsifier for transparent local-frame mixing

Research-only checkpoint, 2026-10-18 Vancouver. Source: live draft `syscoin/PVUGC#1`, branch `research/pq-wkem-validation-20260918`, starting SHA `6d55f1b7d2f2b56aa775d5ac9ea8183d74b90094` (Run 625). This is not a PQ WKEM, a practical key-release primitive, or an attack on CCMR/RIO.

Consider a finite efficiently computable group G, with two labeled alternative paths and hidden gate words whose products are U_0,U_1. Classical setup samples independent uniform common endpoint frames P,Q and independent uniform interior frames F_b,i on each path. Publish every dressed edge E_b,i=F_b,i-1 g_b,i F_b,i^-1, with F_b,0=P and F_b,end=Q. The adversary sees the entire gate table and arbitrary independent auxiliary public information; its allowed class is arbitrary QPT, but the attack is deterministic PPT.

**Exact theorem.** Multiplying each public path cancels all interior seams: M_b=product E_b,i=P U_b Q^-1. The joint public value M_0 M_1^-1=P(U_0 U_1^-1)P^-1. Thus any efficiently computable conjugacy-class invariant of U_0 U_1^-1 is exposed. If two candidate secret/release-bit worlds use disjoint relative conjugacy classes, their full public distributions have disjoint supports, giving distinguishing advantage one. Yet each M_b individually is uniform in G in both worlds (Q->P U_b Q^-1 is bijective). Every individual dressed edge is also marginally uniform. Thus marginal gate/path security is insufficient for joint masked release.

**Explicit counterexample.** In S4 set U_0=identity; world 0 uses U_1=(0 1)(2 3) and world 1 uses U_1=(0 1 2). Both are even nonidentity permutations. Their publicly exposed relative cycle types are (2,2) versus (3). Exhaustively over 576 (P,Q) pairs in each world, joint supports have sizes 72 and 192, with zero intersection and total variation one; each individual path product is exactly uniform over all 24 permutations. The local hidden workspace may be discarded by a semantic output projection, so visible outputs can coincide while a hidden local gate-class choice leaks. This is a falsifier of this particular transparent-frame mixing distribution, not of all semantic-only release.

**Exact interface restriction.** If the paths use independent endpoint frames, the *two completed path products alone* are independent uniform: the specific holonomy test no longer applies. However, publicly supplied exact adapters L=P_0 P_1^-1 and R=Q_1 Q_0^-1 align M_1 as L M_1 R=P_0 U_1 Q_0^-1 and restore the same leak. This does not prove that an unaligned or cryptographically reconciled implementation is correct or QPT secure.

The reproducible checker `run626_publish_check.py` exhaustively verifies the S4 joint laws, cycle types, disjoint support and a public-alignment negative control. It uses Python 3 standard library and tests finite algebra, not post-quantum hardness. The expanded local proof and larger checker additionally cover arbitrary interior gate counts and the nine-class attack taxonomy.
