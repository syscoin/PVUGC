# Run 420: public functional-decryption keys are not protected by ordinary FE message privacy

Source: syscoin/PVUGC#1, draft branch research/pq-wkem-validation-20260918, read-first head bd0bc87f5b79c9a3d143802d3cecf653a37a4d9c. Latest ordinary substantive comment 6067040320. Candidate: public FE encryption of later witness w, with an offline preissued and publicly distributed functional key for F_{x,K}(w)=K if ORIGINAL R(x,w)=1, otherwise bottom. It has late-witness input and every valid witness can get the same K if the functional key is secure. But ordinary functional-encryption IND-message privacy does not protect hidden constants in a PUBLIC functional key.

Theorem (exact reduction). Take any FE with ordinary chosen-function IND message privacy. Define FE' with identical Setup/Enc/Dec but KeyGen'(msk,f)=(KeyGen(msk,f), description(f)). The querying adversary already supplied description(f) in the IND-message-privacy game, so the reduction appends exactly those known descriptions to every returned key. Adaptive classical key requests, ordinary public classical encryption, and arbitrary QPT adversaries are supported conditional on the same restrictions and QPT security of the underlying FE game. Every simulated transcript is identical and the distinguishing advantage is unchanged. The reduction is straight-line; no rewinding or QROM programming. No FE implementation or security assumption is constructed here.

Counterexample for release: the description of F_{x,K} contains K. Publishing its FE' key reveals K directly to an attacker with no ORIGINAL witness. For false x, every F_{x,K} is extensionally the same constant-bottom function, despite different syntactic descriptions containing different K. Hence FE message IND security alone cannot imply false-instance capability secrecy or unauthorized true-instance extraction. The attacker is classical, so it is also QPT. Independent signing keys and honest N-of-N erasure do not repair this syntax leak.

Conditional false-instance hybrid (not supplied by ordinary FE). Assume a stronger equivalence-key-hiding theorem in the full correlated view, comparing public functional keys for F_{x,K} versus constant bottom when x is false, while keeping the SAME native verification key vk(K), all capsules, auxiliaries and chosen-input/coherent public evaluation. Also assume the constant-bottom reference can be simulated given vk without K, with the relevant graph pre-signatures, and a QPT-EUF-CMA native signature scheme. Then a straight-line hybrid gives Pr[false-instance fresh native-signature forgery] <= Adv_equivalence_key_hiding + Adv_native_QPT_EUF-CMA. This is a conditional game decomposition, NOT an independently justified local-mixing assumption or practical construction. For true x the functions are unequal, so the hybrid proves no unauthorized true-instance extraction. Native signatures do not supply Run 259 accepted complete representations.
