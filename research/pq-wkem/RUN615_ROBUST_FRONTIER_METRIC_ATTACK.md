# Run 615 — Robust frontier metric inflation and branch collision

2026-10-18. Research-only checkpoint on syscoin/PVUGC#1, branch research/pq-wkem-validation-20260918, starting commit e5d7d21e235b3827fe0dce9d1efd8b56bfadd2ea. No production modifications. Builds on Run 614's independently callable state search; does not claim a new witness-KEM.

**Model.** Every valid ORIGINAL witness w yields an arbitrary d-bit state s_w. The protected public suffix G(P_x,s) returns a candidate native signing capability, recognized by a polynomial-time deterministic checker against the real public native checking key pk_x. The candidate-specific ROBUSTNESS assumption is that G returns the SAME K_x for EVERY state in the Hamming radius-t neighborhood of s_w. This extra condition models error-tolerant local sketch release, and does not follow from general all-witness correctness. Analyze even an ideal black-box suffix; actual public code cannot hide more than the oracle.

**Theorem 1 (metric amplification).** Let C={s_w:R(x,w)=1}, T={s:the public native key check accepts G(P_x,s)}, B_t(c) the Hamming ball, V(d,t)=sum_{j=0}^t binomial(d,j), and P_t(C) the maximum number of distinct C states pairwise farther than 2t. Then T contains the union of B_t(c), and |T| >= P_t(C)*V(d,t). Proof: every required ball accepts; balls centered more than 2t apart are disjoint by the triangle inequality. Uniform classical chosen-state search succeeds with probability |T|/2^d per trial; coherent QPT BBHT/Grover search takes O(sqrt(2^d/|T|)) public evaluations, hence at most O(sqrt(2^d/(P_t(C)*V(d,t)))) in query scale when a true instance has a center. The public checker is part of the adversarial view. An accepted arbitrary state is NOT necessarily an ORIGINAL witness or a Run-259 accepted complete representation.

**128-bit query condition for this specific oracle attack.** A necessary, not sufficient, condition for approximately 2^128 quantum queries is d - log2(P_t(C)) - log2(V(d,t)) >= 256. Example: for d=256,t=25, log2(V)=114.734734 and the exponent is at most 70.632633 for only one center; for d=384,t=38 it is at most 104.444028; for d=512,t=51 and packing size 2^16 it is at most 130.214624. All are mathematical query counts, not concrete 128-bit SLH-DSA resources. The ball asymptotic uses binary entropy H_2(t/d), with O(log d) lower-order uncertainty.

**Theorem 2 (cross-branch incompatibility).** If ONE deterministic state-only suffix is supposed to output different native keys K_A != K_B on B_t(s_A) and B_t(s_B), but does NOT cryptographically bind branch/UTXO/relation context, and dist(s_A,s_B)<=2t, the balls intersect; its output on the intersection would have to equal both keys, a contradiction. Domain separation enforced INSIDE the protected suffix avoids this particular contradiction. Domain separation merely added to a public wrapper is not proven sufficient.

**Checker.** run615_publish_check.py exhaustively tests disjoint/overlapping metric balls, source-state same-key acceptance, a toy SHA-256 public checker, exact small-state Grover amplitudes, and Hamming-overlap geometry. The extended independently executed checker run615_robust_frontier_check.py is preserved in the local research archive. Results are algebraic/finite diagnostics, not a QPT security theorem or a native-signing implementation.

**Attack ledger.** (1) seam and (2) gauge attacks unnecessary; (3) statistical fingerprints unnecessary; (4) neighborhood overlap and separate branches analyzed, general multi-capsules unproved; (5) adaptive/chosen-state public evaluation decisive; (6) malicious setup/retained coins unproved; (7) replay/branch separation requires inside-suffix domain binding; (8) checking-key correlation explicitly used to recognize success; (9) actual coherent Grover attack has a square-root advantage (finite state-vector simulation is not quantum hardware). Classical honest algorithms, arbitrary QPT attacker with public keys/auxiliary data/quantum advice (ignored), and coherent access to public deterministic evaluation are the model. No quantum rewinding, oracle reprogramming or new cryptographic hardness assumption.

**Scope.** This is a TRUE-instance unknown-witness attack surface. False-instance hiding is NOT disproved: there may be no marked states when R(x,w) is false. Without independently callable error-tolerant suffix semantics, the result does not apply. Even a successful native signature is not automatically an ORIGINAL witness: Run 259 gives only accepted complete representation -> ORIGINAL witness under its actual conditions. Malicious N-of-N setup, full QPT hiding and arbitrary recovery extraction, multi-capsule correlations, concrete native PQ signature and conditional P2MR graph remain UNPROVED. Bitcoin does not verify NP here. No complete practical PQ WKEM; stopping condition unmet.
