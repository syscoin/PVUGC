**Named candidate:** first-divergence source-root token. From two qualified, differently tagged Syscoin histories E_A,E_B, compare tagged ancestors at min(t_A,t_B), authenticate predecessor paths from higher reference to that point, and if incompatible locate minimal child height d for which H_A(d) != H_B(d). Required before promoting: all accepted witnesses produce the same setup-chosen K, no manufactured conflict or private source coin can yield it, and QPT recoverer yields the complete original witness or independent hash break in full public view.

**Positive component to test:** deterministic extractor for an *already supplied actual pair* of linked, source-qualified branches. Under domain-separated collision-resistant child-header identities, a same-reference-height ancestor hash contradiction implies a real child-header fork at d<=t, and the earliest divergence and k_LC depth can be checked in polynomial time in supplied history. It must not mistake multiple BTC parent work certificates of one Syscoin child for a fork. The chosen starting anchor and each history's complete intermediate links must be authenticated; a pair of arbitrary hashes does not qualify. The toy checker will model only linked SHA histories, not live BTC canonical inclusion, AuxPoW or coinbase rules.

**Source-binding repair trial:** mask K by a deterministic hash of earliest-divergence information; if that information is publicly selectable without a valid source certificate, an attacker can compute the pad from a fictional divergence. Instead include the full authenticated source witness in the pad; then distinct valid witnesses obtain independent pads and fail common-K correctness unless Build anticipates their hashes or supplies hidden cross-witness correlation. Explore actual equations, not just an honest verifier wrapper.

**Security boundary:** The earliest-divergence extractor is not a release gate. Distinct native signatures under the same public key do not authorize treating a proof-derived hash as the one frozen signature. QROM SHA claims, malice from source-selected mining nonces, and related capsules are unresolved. No claim that synthetic histories are actual Syscoin or that an offline verifier can enforce public real-time inclusion.
