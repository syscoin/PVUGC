# Run 647 — Coherent Simon falsifier for an XOR-period local release frontier
Date: 2026-10-19. Research-only. Exact live PR head before work: 93937ee77f20540fbd23c2ce851cc99c8e016f5e, branch research/pq-wkem-validation-20260918, open/draft/unmerged.

## Narrow candidate and outcome
Let K be a uniform nonzero b-bit branch credential seed. Choose a full-rank binary linear map Q_K with kernel span(K), and a reversible (possibly nonlinear) output permutation P generated by O(b^2) classical NOT/CNOT/Toffoli gates. Publish a deterministic evaluator F(s)=P(Q_K s), hypothetically protected by a local mixer concealing the representation of Q_K. For any s!=t with F(s)=F(t), s XOR t=K: all valid frontier collision witnesses recover the SAME credential despite different states. This is a toy frontier relation, NOT a completed transformation of every original Syscoin witness. A raw public Q_K reveals K even classically; to make the falsifier stronger, grant the candidate an opaque public coherent oracle for F.

## Complete coherent attack
For all s,t, F(s)=F(t) iff t=s or t=s XOR K. A QPT attacker queries the public F coherently, measures the output to prepare (|s>+|s XOR K>)/sqrt(2), then applies Hadamards to the input register. The observed y is exactly uniform in the b-1-dimensional subspace K-perp. With n independent measurements, failure to span that hyperplane is at most (2^(b-1)-1)*2^(-n). For n=b+128, this is <2^-129. Classical Gaussian elimination recovers the unique nonzero K perpendicular to the samples. Query and computation cost are polynomial. Any bijective nonlinear output relabeling P leaves this hidden-period promise intact. This is Simon's known quantum algorithm, here used as a local-release counterexample, not a novel cryptographic primitive.

If the native branch signing credential is determined by K and the public VK_x binds that credential to one UTXO/branch, an attacker can sign without original evidence. On a false source instance no ORIGINAL witness exists, but the same public F leaks K: false-instance QPT hiding fails even with honest erasure, one capsule and no auxiliary input. For true instances recovery of K produces no accepted complete source representation by itself; Run 259's supplied-z theorem cannot fill that missing arrow.

## Exact limits and attack ledger
This does not break arbitrary nonlinear INPUT mixing, generic RIO, CLZ, Gaussian SOURCE, or a hidden-period-free release gadget. Honest setup and evaluator are classical PPT; the adversary is arbitrary QPT able to coherently execute public classical software. The attack needs no quantum advice or QROM programming and survives even an ideal opaque oracle. Relevant families: exact output-seam/collision invariant (1), global period surviving unknown frames (2), output label fingerprints irrelevant (3), single capsule already enough (4), chosen-input coherent evaluation (5), honest setup already attacked (6), branch binding does not stop local recovery (7), VK checking cannot hide K (8), Simon interference not merely classical exhaustive-search speedup (9). Source-binding Run 259 remains downstream only.

Supplementary state-budget check: for a standalone b-bit public release input with M distinct inputs that yield an accepted credential, multi-target Grover costs O(sqrt(2^b/M)), so an idealized 128-bit query-work target needs b-log2(M) >= 256. This necessary work-budget inequality does not prove security when met; Simon's attack on the stated candidate is polynomial regardless.

## Reproducibility and literature
The exact executed standard-library Python checker tests 246 (b,K) fixtures at b=2..7, 54,472 reversible gate operations, exact two-to-one fibers and rational Hadamard probabilities, plus 1,476 simulated independent quantum-sample recovery trials. Compilation and two repeated runs passed with byte-identical output: 46,629 assertions. It is a classical simulation of proved quantum measurement probabilities, not quantum hardware or a signing implementation.
