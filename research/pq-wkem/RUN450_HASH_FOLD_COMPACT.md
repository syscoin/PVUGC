# Run 450 — Per-representation hash folding does not restore all-input equivalence

Live draft PR #1: `syscoin/PVUGC`, branch `research/pq-wkem-validation-20260918`, starting SHA `944be053d576d0b8aee845db1a5290b01635d10b`. **New question** (distinct from Runs 448–449): for ONE fixed ORIGINAL-false statement x, does a different hash-derived folding matrix per candidate complete representation z repair Run 449's linear-system attack *and* supply the all-input zero-release equivalence assumed in Run 447?

**Exact ideal-oracle model.** Set `z in F_2^d`, full residual `rho(z)=(1,z)` (never zero). Let injective `Enc(z)` domain-separate x and representation. Sample independent uniform t-by-(d+1) binary matrices `S_z=H(x,Enc(z))`, including coherent QROM access. Public source predicate `Acc(z)=[S_z rho(z)=0]` is classical PPT. Each fixed z passes with probability `2^-t`; events for distinct z are independent. Therefore the number of accepted invalid representations is `M~Binomial(2^d,2^-t)` and

`Pr[M>0] = 1-(1-2^-t)^(2^d)`; `E[M]=2^(d-t)`.

At `d=t`, the existence probability tends to `1-e^-1` (~0.632); at `d>=t+16`, it is overwhelmingly near one. A classical attacker testing Q distinct candidates succeeds with probability `1-(1-2^-t)^Q` for `Q<=2^d`. Hashing each candidate removes Run 449's *single fixed matrix* Gaussian solver in this ideal model, but not the existence of false accepted candidates.

**Actual coherent attack.** A QPT adversary can compute H in superposition, phase-flip when `S_z rho(z)=0`, uncompute H, and Grover search. With `2^d` sufficiently larger than `2^t`, high-probability search takes `O(2^(t/2))` coherent H queries. For `t=O(log lambda)` this is polynomial-time QPT. The compact checker simulates Grover's marked-phase and diffusion steps on 8 amplitudes, checking the `sin^2((2j+1)theta)` identity. At cryptographic t this is **not** a demonstrated polynomial-time break or an independent PQ guarantee.

**iO boundary.** For a false x, a hypothetical release program `G_K(z)` giving K exactly when `Acc(z)=1` is *not* extensionally equal to an always-bottom program whenever M>0. Standard exact-functional-equivalence iO does not justify the Run 447 zero-program hybrid using only pointwise `2^-t` soundness. Computational differing-input protection would need a separate exact QPT game and independently justified assumption. This analysis does not itself build such a program, local mixer, or witness-KEM.

**Source/extraction boundary.** Run 259 still proves *accepted COMPLETE representation -> ORIGINAL witness* in its exact sufficiently-folded statistical or QPT-SIS models. It does not prove *arbitrary native signature -> complete accepted representation*. Public residual-only witness evaluation is constant on valid witnesses and cannot hide K. A release gadget trusting ONLY the forged `Acc(z)` is broken; independently authenticating ORIGINAL representations could evade this attack.

**Attack scope:** covers (1) folded-source seam substitution, (5) adaptive public candidate evaluation, (9) coherent quantum search. (4)/(7): injective representation encodings and proper relation/UTXO/branch/anchor/window domain separation are assumed; shared capsules remain unproved. (6) malicious setup/bias/retained coins unproved. (8) public native checking-key correlations do not validate the source check. No global mask/gauge or distribution-fingerprint cryptanalysis is claimed. Setup/evaluation are classical PPT; attacker may be arbitrary QPT with coherent ideal-oracle access and public auxiliary inputs. No assumption is introduced.

**Literature scope:** Don–Fehr–Majenz–Schaffner, CRYPTO 2019/arXiv:1902.07556, proves QROM Fiat–Shamir results under properties of the underlying sigma protocol; it does not automatically secure this ad hoc fold. Unruh, ASIACRYPT 2017, likewise requires specific hypotheses. Primary abstracts/landing pages only checked; full proofs not audited.

**Handoff:** fixed-x per-representation hashing can replace an immediate linear-algebra solver with an exponential search requirement, but does not ensure that NO false accepting representation exists. Neither source-folding nor a QROM citation supplies the common native signing capability or unauthorized-true-instance signature-to-ORIGINAL extraction. All-witness SAME-K release, false-instance full-public-output QPT hiding, N-of-N malicious setup, multi-capsule security and conditional Bitcoin PQ endpoint remain UNPROVED.
