**Specific proposed gadget.** Honest classical PPT setup encrypts `(K,alpha,ctx,a=0,u,tag)`, where `K` is the intended native signing capability and `alpha` an encrypted MAC/signing secret. A fixed public functional release key outputs **unchanged K** iff `a=1` and `tag=Auth_alpha(ctx,a,u)` verifies. Honest late input `w` uses unrestricted public homomorphic evaluation of `F_w` to set `u=w, a=R(x,w)` and recompute `tag`. All valid ORIGINAL witnesses get SAME K; states can remain different.

**New falsifier:** Unrestricted public FHE evaluation also permits the polynomial-size circuit
`B(K,alpha,ctx,a,u,tag)=(K,alpha,ctx,1,u_star,Auth_alpha(ctx,1,u_star))`.
The adversary **does not know** `alpha` or `K`: it homomorphically uses their encrypted input wires. Functional release on `Eval(C0,B)` returns original `K`, including when `R(x,w)=0` for every ORIGINAL `w`. Native signature verification under the original `vk_x` then accepts the intended challenge. No cross-UTXO replay or malicious setup. By encryption, evaluation, functional-release, and signature correctness, success is at least `1-eps_enc-eps_eval-eps_func-eps_sig`. Entire public pk/vk/context and arbitrary auxiliary inputs can be exposed; this is a deterministic classical PPT attack, therefore available to QPT adversaries.

This is **not** ordinary MAC forging: a public Eval calculates a valid *encrypted* MAC under encrypted `alpha`. Substituting any efficiently computed authenticated flag with a key inside the arbitrarily writable ciphertext has the same semantic flaw, even with a PQ signing algorithm. The attack requires arbitrary-circuit homomorphic Eval, not just restricted approved state transitions. A protected guard independently recomputing the complete ORIGINAL `R(x,u)` blocks it on false instances, but may defeat minimality. No narrowly justified alternative transition-authentication primitive is constructed here.

**Run-259 composition:** An authenticated Boolean flag is NOT an accepted complete residual/source representation. The theorem `accepted complete z -> ORIGINAL witness` cannot be applied to this accepted native signature. Missing: `native authorization -> accepted complete z OR independent QPT break`.
