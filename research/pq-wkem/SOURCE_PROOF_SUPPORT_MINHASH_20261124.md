## 1. Concrete selection algorithm and its required equation

Let R_x(w) be the fixed canonical ORIGINAL verifier, including all three independent grounds, actual source authentication, maturity and relevance. Let S be the exact safe preauthorized signature and ctx the fully bound statement, native VK/message, capsule ID and claim context. Setup samples a lambda-bit t and publishes h=H_trap(t), for the internal proof relation Q(w,t')=R_x(w) OR [H_trap(t')=h]. The second branch is a setup device only, never a qualifying ORIGINAL challenge.

Use the concrete three-party XOR-share MPC execution of the previous fixed-view note (AND output share c_i=a_i b_i XOR a_i b_(i+1) XOR a_(i+1) b_i XOR r_i XOR r_(i+1), indices modulo 3). For a satisfying input u, generate all views, commit to each with an independent lambda-bit salt, and use a domain-separated Fiat-Shamir hash of the commitments and claimed output to select an adjacent pair to reveal. Serialize the commitments, output shares, revealed views and salts canonically. Denote this deterministic proof generator with L-bit uniform random tape by P(u;r). Nothing here assumes a QPT proof-of-knowledge theorem for this generator. Let A_u={P(u;r): r in {0,1}^L}; duplicate transcript bytes count only once. The support has at least 2^lambda distinct transcripts: for each salt value a, the tape with all three salts equal to a is allowed; whichever adjacent pair is opened, both revealed salts equal a. Hold the other tape bits fixed. Distinct a give distinct serialized transcripts.

Choose a fresh public seed e. Define priority J_e(p)=H_priority(ctx,e,p) with 2L+lambda output bits, using a separate hash domain. Let Min_e(A) be the member minimizing (J_e(p),p) in lexicographic order. Exact candidate:

The internal trapdoor is erased. These equations specify actual operations, not an assumed efficient Min oracle: enumeration of all L-bit tapes is an exact classical algorithm but is not a PPT Build/Open. If the two supports are EXACTLY identical, every witness gives identical p and hence identical S. Ordinary computational witness indistinguishability does not imply support equality. Even statistical closeness of weighted distributions does not imply equality of supports, and a minimum over support can select a transcript with negligible probability under the original sampler. For the next step grant exact support equality for free; this is deliberately stronger than anything proved for this MPC proof generator. ## 2. Attempt to make exact selection polynomial: global random-priority search

Try a trie of proof tapes and a tournament of subtree minima, using the public priority seed to compute the first winning branch without enumerating leaves. In the ideal domain-separated classical ROM, condition on the actual proof oracle, statement, setup witness, and proof support A of N distinct transcript strings. Give the entire support and arbitrary indexing into it to the selector for free. These data are independent of the fresh priority domain (the proof generator never queries it). The N priority values are independent uniform strings of length 2L+lambda. Since N<=2^L, the probability of any tie is at most N(N-1)/(2*2^(2L+lambda))<=2^(-lambda-1).

Condition on no ties. Even an adaptive q-query classical selector cannot identify the global minimum with probability greater than (q+1)/N (cap at 1). Proof: revealing distinct previously unqueried support members reveals an exchangeable sequence of distinct random priority ranks. Any adaptive choice of the next unqueried member is symmetric among the remaining members, so the probability the minimum lies in the q revealed members is q/N. If it is not among them, each unqueried member is equally likely to be the minimum, even given the revealed numerical priorities and the event that the minimum is unqueried. Outputting one unqueried member adds at most (1-q/N)/(N-q)=1/N. Off-support queries supply independent values and cannot improve the bound. This proof allows the algorithm to know N and the entire support, not just a prover tape. With ties restored, the bound is (q+1)/N+2^(-lambda-1). A trie/tournament only moves this unstructured minimization into its child subproblems; it cannot derive unknown subtree priorities from their indices.

For direct recovery of the exact K without identifying p, add the independent H_key domain to the same experiment. Give the algorithm the priority of every support member it queries in either domain, for free. The probability it queries the actual minimizing member is at most q/N (q is the combined query bound); otherwise its unseen H_key output is independently uniform, so exact K recovery is at most q/N+2^-lambda+2^(-lambda-1), for a lambda-bit K. This isolated bound concerns the honest selector before the mask is produced, not an adversary receiving a native VK and S-masked capsule. It does not claim concrete SHA behaves as a programmable random oracle or give a QROM theorem. It is a classical correctness failure: even the setup participant with its full trapdoor cannot perform the specified exact selection in polynomial oracle queries. For the concrete proof generator N>=2^lambda. No source hardness assumption is needed for this failure.

## 3. Polynomial truncation and the missing correlation

First repair: choose a polynomial public list of tape strings from e and minimize only the resulting P(u;r) outputs. This is a real PPT algorithm but the two resulting subsets need not coincide. Even an exactly witness-independent output distribution gives no guarantee about coupled samples using the same tape: a prover can permute its uniform tape depending on its witness without changing any marginal distribution. In the simple control where two generators are bijections of the same N-element tape space onto the same N transcript strings and the relative tape permutation is uniformly random, for a fixed list of T distinct tapes the two images are a fixed T-set and a uniform T-set. Their expected intersection size is T^2/N; the probability of any shared member is at most T^2/N. A common minimum requires a shared member. This control is not claimed to instantiate the actual MPC proof, but rules out inferring coupling correctness from identical marginals alone. The exact global minimum was invariant under tape permutations precisely because it used the whole support; the truncated algorithm loses that property. No proof of a witness-independent same-tape coupling for the actual ORIGINAL proof generator is supplied.

Second repair: draw a polynomial list p_1,...,p_T of candidate transcript bytes directly from a public proposal generator using e; each witness privately tests support membership and selects the first qualifying one. This avoids needing a shared tape-to-transcript map, even if support membership is hard without a witness. But the full public capsule leaks the release through enumeration. An adversary computes every candidate K_i=H_key(ctx,e,p_i) and unmasks S_i. If honest correctness is p, choosing a uniform list index gives exact S with probability at least p/T, with no ability to test membership or find an original witness. The native verifier can also identify an accepted cancellation capability, even if multiple same-message signatures validate. This is an actual classical full-capsule attack on that repair, not a claim of exact-signature uniqueness from native verification. It applies regardless of whether the candidate list was filtered by a source-validity proof in honest Open. A hidden selector index alone cannot protect a polynomial public list.

A possible different equation would be a compressed, private-membership sampler over exponentially many transcripts with efficient witness-dependent **jump-to-canonical-member** algorithms at both setup and opening, without public enumerable candidates. It would need a specific non-random-priority structure whose conditional search is efficiently computable with any actual ORIGINAL witness and the setup witness, yet hard without one. Equal distributions, independent samplers, public proof checking and ordinary hash commitments do not supply this structure. A public program that ranks a small affine support would instead need to survive the prior affine-closure regressions; no such program is assumed. Do not continue with more tape samples, longer priorities, another hash ordering, another proof salt, or further trie fixtures. In particular this work does not establish that all possible common-randomness samplers are impossible.
