# Run 579: two-capsule hidden shift without a public reference

2026-10-17. Research only on draft `syscoin/PVUGC#1`, branch `research/pq-wkem-validation-20260918`, live starting SHA `11c4e541f2197b788a54a1d142b4b51c5e4ae2f3`. Not a practical PQ witness-KEM.

**Interface.** Honest classical PPT setup chooses shifts `d1,d2 in F_2^n` and any classical PPT injective reference permutation `B`, and supplies independently coherently evaluable public functions `G_i(s)=B(s XOR d_i)`. There is **no separately exposed B**. Publishing explicit circuits containing shifts is trivially insecure; granting protected/opaque public evaluation only strengthens the attacker model. No concrete opaque classical-PPT packaging is claimed. If public views are `(A_i,F_i=A_i XOR G_i)`, coherent XOR cancellation supplies `G_i`. QPT adversaries receive every public program, native checking key, auxiliary input and other capsule; the attack uses only `G1,G2`.

**Theorem (exact Simon promise).** Set `h=d1 XOR d2`; define `J(s,0)=G1(s)`, `J(s,1)=G2(s)`. Then `J(s,b)=J(s XOR h,b XOR 1)` for every input. Injectivity of B proves there are *exactly two* preimages per output, so the unique nonzero period is `p=(h,1)`, including when h=0. With `n+lambda` Simon samples the QPT adversary recovers h except with probability <=`2^-lambda`, using `O(n+lambda)` coherent public calls and polynomial GF(2) linear algebra. No quantum rewinding, QROM extraction or LWE/SIS assumption is used. The algorithm recovers **relative** shift, not necessarily the absolute shifts.

**One authorized anchor compromises a false capsule.** If a legitimate ORIGINAL witness for `x1` releases *raw* d1 while an ORIGINAL-false `x2` protects `K2=KDF(context2,d2)` (or d2 itself), the attacker combines h with d1 to calculate d2 and K2 with no `x2` witness. This is neither signing-seed reuse (Run 573) nor linear-projection reuse (Run 576). If release discloses only a one-way image of d1, the corollary does not follow. Independent per-capsule references remove this precise common-reference promise but prove no security by themselves. Downstream KDF context labels alone do not stop the anchored attack.

**Exact gauge boundary.** If B is a uniform ideal random permutation and d1,d2 are uniform, the transformation `B'(u)=B(u XOR a)`, `di'=di XOR a` preserves both entire oracle truth tables and their distribution. Consequently d1 is uniform conditioned on `(G1,G2)` alone, even to an unbounded adversary, while h is determined. This *excludes* correlated public native verification keys, retained setup coins, authorized disclosed shifts and other auxiliary leakage; it is NOT full-public QPT hiding. Uniform random-permutation table sampling is an ideal-model statement, not an honest-PPT implementation.

**Narrow output.** For a random b-bit B, public offset vectors `V_i(s)=(G_i(s XOR t))_{t in T}` remain two shifted views of the same vector function, without raw B access. Run 570's exact XOR-Sidon injectivization bound applies. Its n=128, b=1 example k=385, lambda=128 gives injectivization failure <2^-129 and Simon sample rank failure <2^-128 with 256 samples, conditional on coherent oracles. These are *query* bounds, not physical quantum cost or a concrete 128-bit implementation.

**Attack taxonomy.** (1) optional A/F cancellation; (2) relative-frame synchronization but absolute gauge survives without anchor; (3) uniform individual marginals yet correlated pair; (4) reused reference across claims; (5) coherent chosen-input evaluations; (6) honest setup is enough, erasure cannot fix correlated public views; (7) KDF labels do not repair raw-shift reuse; (8) public checking-key correlations not needed for the attack and invalidate the positive gauge lemma; (9) genuine Simon quantum period recovery. No generic CCMR or CLZ attack is claimed: neither was shown to expose this exact interface.
