Candidate: Source-Synchronized Hash Template (SSHT). Let the full parent Bitcoin SHA256d hash for qualifying AuxPoW evidence be Y=H2(header), and let u be its first d non-PoW-constrained bits after the target's forced prefix. Build chooses frozen K, tries a table E_u=K XOR H_pad(context,u). Open parses candidate source evidence, obtains u and returns E_u XOR H_pad(context,u). Selective release is intended to depend on authenticated work and source relevance. This is a hypothesis, not a solution. Must test raw key extraction without a verifier, and whether table corrections computed before future B can cover every valid SOURCE-qualified work certificate.
