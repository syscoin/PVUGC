NEW THEOREM (restricted public interface, not a break of CLZ): Honest classical PPT setup makes public P=(x,claim/UTXO/branch context,C0,H,O,pk_native,aux), where H is a deterministic publicly executable fixed unary transition and O a publicly executable *witness-independent* opening routine. Suppose that for every valid ORIGINAL witness w, a classical PPT witness-holder can select a number t(w) <= T of H iterations, for one uniform polynomial horizon T, and recover the identical protected signing credential K by applying O to H^t(C0), with probability >= 1-epsilon. The holder cannot input w, a witness-dependent token, a new ciphertext, special random seeds, or controlled updates into H or O. Public native verification checks whether a candidate credential signs the intended fixed admissible branch.

A classical PPT outsider simply enumerates C0,H(C0),...,H^T(C0), publicly calls O on each and checks candidates against the *correlated* public native verification key. Whenever the honest witness-holder succeeds on a given setup, this outsider must also succeed. The outsider's success probability is >= 1-epsilon, without recovering any ORIGINAL witness; its cost is O(T) public evaluations. This is an unconditional information-theoretic interface implication and therefore also defeats arbitrary-QPT recovery resistance. If y=f(w) is a QPT-hard one-way-permutation instance with witness-free setup, an extraction theorem deriving w from every such unauthorized credential recovery would contradict the specified hardness assumption, absent an independent QPT break.

MINIMAL PUBLIC-CONTROL CONTRAST: A single unary H provides at most T+1 reachable clock positions within T steps. Two publicly selectable transitions H0,H1 can encode arbitrary n-bit witness choices in n rounds and attain 2^n distinct paths. This is an expressivity distinction, NOT a release construction: adversaries also choose those bits. Public binary control must still be cryptographically bound to ORIGINAL verification and common K. The general public-cover search obstruction was already documented in Run 672; the exact fixed-unary late-input interface is the focus here.

SCOPE: Public-evaluation seam, native checking-key correlation, one-capsule replay and honest setup are explicitly tested. No global-frame synchronizing attack or local fingerprint is needed. Fixed unary with *witness-dependent protected output*, witness-selected exceptional randomness, late witness ciphertext insertion, secret functional-key inputs, or genuinely controlled multi-transition programs are outside the theorem. The actual CLZ construction uses key-dependent obfuscated decrypt/apply programs under iO/PPRP/SCP-style conditions; this theorem does not refute CLZ or establish QPT security for it. Ordinary FHE public opening was addressed separately in Run 680.
