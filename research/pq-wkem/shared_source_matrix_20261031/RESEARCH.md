# SSMA — Shared-Source Matrix Amortization (2026-10-31, offline)

**Status:** Concrete efficiency and full-joint simulation extension of restricted C12, **not** a generic post-quantum witness-KEM. Current predecessor: C12 at 1c943352dda27878798e7e657f29d76fba7f2c8d, syscoin/PVUGC PR #1. No external research was used.

## Exact new construction

For polynomially many independent claim scopes i=1..m, sample a **single** public A uniformly from F_q^(d×n), then each t_i independently uniformly from F_q^d. For each scope, generate a completely independent native signing pair (vk_i,sk_i) with claim/UTXO/path/branch/anchor/window metadata; XOR-share sk_i into h lanes and generate r related capsules. For every lane/capsule/symbol, independently sample s uniformly from F_q^d, e from chi^n and eStar from chi, chi uniform integer [-B,B]. Certify e with 2(B+max(sum positive e,sum negative magnitudes e))<g, g=floor(q/2^b), resampling on failure and capping resampling in polynomial time. Publish beta=A^T s+e mod q and tau=t_i^T s+eStar+g*symbol mod q. Include real native checking key, permitted genuine adaptive P-domain preauthorization signatures, complete scoped context and all related capsules. Never pre-sign a challenge-domain message.

Each valid ORIGINAL **binary-ISIS** witness w in {0,1}^n with Aw=t_i reconstructs every symbol from tau-w^T beta and yields the **same precommitted native sk_i** in all capsules. Distinct w need not have common internal states. Source setup samples no witness. Checking w inside a public release API does not enforce adversarial security; attackers can bypass it.

Compared with independent matrices A_i for separate claims, this changes ONLY the source-matrix correlations: one common A, independent t_i, sk_i and encryption s/e across claims. It is **not** a public-seed PRG expansion of A. Do not reuse native signing keys, share coins or LWE secrets across scopes. The random t_i are not a compiler binding arbitrary ORIGINAL SYS/BTC claims; those semantics remain unsolved.

## Full-public QPT argument with shared A

**Exact generator.** A uniform, t_i independently uniform conditional on A; independent native keypairs, XOR shares, certified q-ary LWE ciphertexts, vk_i, scoped messages and signatures, related capsules. A QPT adversary receives this entire classical joint public transcript, may process it coherently, adaptively select an unopened target scope, and disclose all native signing keys and all actual LWE coins of other scopes, as well as up to h-1 complete target share lanes and their coins. No arbitrary per-bit cross-lane opening, arbitrary target-secret-dependent auxiliary advice, adversarially fixed A/t, cross-scope secret KDF relation, quantum signing-query oracle or target challenge pre-signature is allowed. Native signature queries are classical. The proof is in the nonuniform-QPT model.

1. **Group TRUE conditioning:** for each uniform (A,t_i), the second-moment bound on binary-ISIS gives delta=(q^d-1)/(2^n+q^d-1) for the FALSE event. The scopes share A, so TRUE/FALSE events are NOT assumed independent. The union bound gives Pr[any FALSE]<=m delta. The **entire** public joint distribution conditioned on all scopes TRUE is within m delta of the unconditioned classical-PPT generator. No SOURCE witness sampler is assumed.
2. **Real error coins:** with mu=B(B+1)/(2(2B+1)), D=g/2-B-n*mu>0, the reject probability is at most epsilon=2 exp(-2D^2/(n B^2)). For T=m*h*r*ceil(ell/b) independent encryption vectors, the distribution with certified coins (including any permitted coin disclosures) couples to ordinary unconditioned chi-error LWE with total-variation distance at most T epsilon. Trace distance cannot increase under joint coherent QPT postprocessing. The simulator does NOT inspect unknown errors of an embedded LWE challenge.
3. **Ordinary LWE embedding for a selected target, even with shared A:** an ordinary decisional-LWE challenger supplies a uniformly random (n+1) by d matrix M and its vector y. Parse the first n rows as A^T and the final row as t_i^T. The simulator uses this SAME A to generate every sibling t_k uniformly and all sibling independent keys, encryption secrets, errors, actual checking keys, context, signatures and coin disclosures. It samples all other target ciphertexts genuinely and uses y+(0,...,0,g*symbol) for the selected target ciphertext. This exactly simulates all public **source-opening correlations** without a SOURCE-opening oracle or the challenge secret. Replace target ciphertext vectors sequentially by uniform using ordinary single-vector nonuniform-QPT DLWE.
4. **Adaptive target and complete-lane opening:** for each fixed target i and lane a, consider only a fresh native challenge forgery/recovered signing capability where a is never opened. The reduction aborts if a is requested, but can open any other eligible lane or sibling scope with its authentic coins. Every attack success with at least one unopened lane contributes to at least one such event. After replacing all protected-lane symbol ciphertexts in all r capsules, the remaining XOR shares are uniformly independent of the unknown target sk_i. The final simulator uses the native QPT-EUF-CMA challenger's genuine vk_i and classical adaptive preauthorization signing oracle; everything for sibling scopes is independently generated from A. A recovered usable sk_i also produces a fresh native signature. This is a straight-line proof, not classical rewinding or extractor-from-representation.

Thus under independently justified ordinary nonuniform-QPT decisional LWE for exact q,d,n,chi and a genuine native QPT-EUF-CMA signature scheme with classical signing queries, the restricted fresh target-native-forgery or usable-key-recovery probability conditioned on all random scopes TRUE is bounded by

m delta + T epsilon + SUM_(i,a,j) Adv_QPT_DLWE(i,a,j) + SUM_(i,a) Adv_QPT_native_EUF(i,a)

plus native correctness error. The sums account for adaptive target/lane choice and all encrypted symbol occurrences; no exponential guessing or unusual shared-matrix LWE assumption is needed. This is NOT a concrete 128-bit hardness statement; illustrative parameters are not calibrated.

## Exact resources and offline evidence

Reuse C12 illustrative q=1099511627689, d=512, n=21008, B=16384, b=12, h=3, r=2, ell=512, using five bytes per field element. Shared A costs **53,780,480 bytes once**; t_i costs **2,560 bytes/scope** and 258 ciphertext vectors cost **27,101,610 bytes/scope**. For eight scopes, independent A_i requires **647,077,200 bytes**, whereas one shared A requires **270,613,840 bytes**. Savings: **376,463,360 bytes (58.179049%)**, with the same restricted per-target ordinary-QPT-LWE assumption; extra checking keys and native signatures are excluded equally from both sides. Group random-FALSE bound log2 <= -525.0000; total certified-coin coupling log2 <= -1174.2262. Neither is a quantum computational hardness estimate. The remaining ~270 MB group and ~27 MB per scope are not practical production sizes.

Exact self-contained published checker.js is executed as-is; output.json is its captured result. It exhausts 729 matrices and 19,683 joint source tuples at q=3,d=1,n=6,m=3, verifies actual shared-A multi-scope certified q-ary ciphertexts, multiple valid witnesses producing identical mock signing capabilities, all sibling coin openings, adaptively selected target with a protected lane, the known nonbinary FALSE attack, and exact resource/tail arithmetic. A separate full offline Python checker passed 264,833 assertions **twice with byte-identical output**, including more densely sampled independent t and multiple unrelated witnesses; its source, outputs and provenance are preserved in a local offline archive. Toy keys are NOT native PQ signatures and arithmetic checks cannot test QPT hardness.

## Critical unsolved obligations

**Adversarial-FALSE break remains:** chosen A=[1], t=[3] has no binary ORIGINAL witness, but public z=3 recovers protected symbols when supported noise is zero, including the final key. Sharing A does not fix this. Same native sk reused in sibling scopes is directly unsafe. Source t collisions may permit witness reuse, so independently uniform t and claim-scoped native messages are required; adversarial t is excluded. The generic ORIGINAL relation is not authenticated by the binary-ISIS source relation, so this does not establish SYS/BTC burn/branch/window validity.

The next indispensable construction is witness-free classical-PPT Comp(R_original,x,claim/UTXO,branch,anchors,window,vk) and public Lift(Comp(...),W)=K_precommitted for EVERY valid ORIGINAL witness, plus a full-public arbitrary-QPT FALSE/hard-TRUE recovered-key or fresh-native-forgery reduction to ORIGINAL W or an independently justified PQ break. Malicious one-honest N-of-N setup, graph/funding/abort/DA, source fork/header/AuxPoW/tag qualification, and the hypothetical native PQ Bitcoin endpoint are not solved. No completion claim; leave the existing research program active.
