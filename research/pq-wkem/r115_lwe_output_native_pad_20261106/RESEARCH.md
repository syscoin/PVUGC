## Actual release algorithm and improvement

R115 instead encrypts only two independent *ordinary LWE generator secret/error vectors*, and publishes a masked native signature once. This is a concrete classical-PPT algorithm, not an uninstantiated witness PRG oracle, and does **not** add an independent PRG assumption: its pseudorandom masks are directly ordinary scalar decisional LWE samples under the SAME `(q,d,m,chi)` family as R110.

At the uncalibrated R110 parameters sample `A<-U(Z_q^(m×d))`, q=65521 prime, d=256, m=2000. Honest capsule-local source keys: each `S_ij<-U(Z_q^(256×64))`, `E_ij<-U([-3,3])^(2000×64)`, `B_ij=AS_ij+E_ij (mod q)`. Independent S/E for every capsule and honest identity; **one A** shared. The original source predicate is **restricted**, checking a supplied bounded-error (S',E') for selected CNF credentials; no generic ORIGINAL NP-to-source compiler is available.

Let `sigma_j=Sign(sk_native,M_j)` be the exact preauthorized native challenge-path signature; message M_j binds relation identity, claim/UTXO, branch, anchors/window, graph, capsule ID, path and intended native verification key. A distinct native message is required for every related capsule. Interpret sigma's fixed 7,856 bytes as a nonnegative integer and encode it canonically into `L=3929` base-q digits `mu_j` because `q^3929 >= 2^62848`. Draw TWO independent `s_h<-U(Z_q^256)`, `e_h<-U([-3,3])^2000`, h=1,2. Calculate `g_h=As_h+e_h mod q`; let `pad=(g_1||g_2)[0:3929]`. Publish `Dsig=mu_j+pad mod q`, length 3,929 q-elements = 7,858 bytes. **The generator secrets/errors are private**, unlike g_h, and are never exposed in an authorized unopened capsule.

Encode both s's canonically in 16-bit residues and both e's in 3-bit `e+3` codes. The seed is exactly `T=2*(256*16+2000*3)=20192` bits, with an EXPLICIT NONUNIFORM binary distribution; it is not claimed to be a uniform-bit PRG seed. For a monotone-CNF policy `P=C_1 AND ... Encrypt each clause share under EVERY credential occurrence in that clause, using the genuine R110 packed LWE PKE: 64 two-bit symbols (128 bits) per ciphertext group, `r<-Uniform({r in [-3,3]^2000: ||r||_1<=2729})`, `u=A^T r, v=B_ij^T r+16380*mu_group mod q`, 320 residues ×2 bytes =640 bytes/group.
