## Exact compact-output bypass (no exponential tensor expansion)

Each published Q_i is a conjugate of a rank-one local reset, tensored with identities on other registers. All Q_i commute and their product

    Q = product_i Q_i = T (tensor_i R_i) T^(-1)

is a nonzero rank-one operator with image span(V). This equality does not rely on an original witness, and holds on FALSE as well as TRUE instances. The public support of Q_i is a bounded-radius interval. Color the intervals into a constant number of classes of disjoint supports (e.g. by wire index modulo a constant larger than twice the radius). Commutation permits this ordering. Q is therefore a constant-depth circuit of bounded-support linear maps, not necessarily invertible. Across any line cut only constantly many of these maps cross it. Build its exact MPO by layers, using constant local dimensions and bond-rank factorization. Equivalently expand each crossing map in its constant-size operator Schmidt decomposition; maps entirely on a side do not increase the cut rank. The resulting MPO is polynomial size even though Q is defined on d^n coordinates. This step does not need the secret T.

Find a nonzero matrix entry Q_(alpha,beta) without searching d^(2n) entries: treat paired row/column letters at each site as the constant alphabet of the MPO tensor train. Compute suffix contraction spans backwards. Starting from the left boundary choose a letter with a nonzero contraction against some vector in the next suffix span; the existence of such a letter follows from nonzeroness. Iterating yields a nonzero entry and its column index beta. Contract the MPO with the product basis ket |beta> to obtain the polynomial-size tensor train Q|beta>. It is nonzero and lies in span(V). Therefore Can(Q|beta>)=Can(V), so the adversary unmasks D and recovers EXACT S. No original gate rows, certificates, hidden T, representation from an external adversary, native forgery, hash collision or retained source coins are used. It is a specified classical PPT attack and hence also a QPT attack. The public hash is evaluated at the correct input, not inverted. This differs from the previous explicit-state search: the ambient state space is exponential and not enumerated. It also does not use a low-degree trace oracle or independent wire labels. The entire terminal line is exposed by the public composition of reset operators.

## Repair 1: fuse the resets into the last source occurrence

Try removing the separate public reset operations. Replace the last occurrence check on wire i with a map L_i,b satisfying L_i,b e_b=v_i and L_i,b e_(1-b)=0. If a wire occurs only once use a first-and-last write sending u to v_i. Conjugate the whole gate row as before; now no separate reset matrix Q_i is published. Honest consistency and same-S correctness are unchanged. This does change the disclosed objects, so the standalone-reset attack does not automatically apply to every fixed source circuit.

There is nonetheless an exact counterexample for this generic compiler under the ordinary semantics-preserving normalization that appends a unary tautology check for each wire. Both local rows are allowed at such a check; it enforces no new constraint and does not change the original accepted witness set. Each is now a last-occurrence row. Choose the published row for bit 0 at each unary check. The product of these n conjugated maps is again a nonzero rank-one operator with image span(V), because each raw L_i,0 maps e_0 to v_i, and the raw maps act on disjoint wires. The MPO attack above applies unchanged to this NEW serialization even though there are no standalone resets and each published last map is labelled as an allowed source row. On a FALSE original statement the capsule still returns S to this attacker. No claim that the deployed verifier has these tautology checks; this is a failure of the proposed generic compiler on a legitimate verifier normal form. Nor does it establish the same attack on an arbitrary fused-row representation where all last occurrences are coupled to other wires with no independently accessible terminal maps. Such a representation would need an actual joint-public analysis.

## Repair 2: global operators without accessible single-register reset rows

There is a second structural check on the zero-invalid variant, even if no reset product is publicly isolated. Suppose the ambient vector representation and public matrix application are fully polynomial (not just the honest product-state subclass). Let M_l,a be every allowed row operator at layer l. For independent random field weights z_l,a form

    Y = (sum_a z_L,a M_L,a) ... (sum_a z_1,a M_1,a) U.

The expansion contains one monomial per complete row sequence. Under the exact annihilating-verifier invariant the contribution is zero for every inconsistent sequence, and V times its monomial for every accepting sequence. Hence Y=V P(z) for the formal polynomial P that sums the distinct accepting monomials. On TRUE, P is nonzero over every prime field: different sequences choose different indexed variables, and each monomial has coefficient 1. For p>L, independent uniform z give nonzero Y with probability at least 1-L/p by the elementary root bound applied inductively in the variables. Use a polynomial-size field with p>2L, or repeat independent trials. Projective normalization then recovers S without finding an accepting sequence. This is a classical randomized full-public attack on an efficiently evaluable arbitrary-vector variant, including hard-TRUE distributions. It requires neither computing P itself nor a representation supplied by an attacker.

Important limitation: in the actual exponential tensor variant, weighted sums of row operators can generate exponentially large intermediate bond ranks; the above polynomial-time attack is NOT established for an arbitrary fused-row tensor train with only an honest-path width bound. A compact circuit expression for the weighted sum is not a polynomial algorithm to canonicalize its resulting tensor. The direct rank-one reset extraction above, by contrast, has a demonstrated constant-depth MPO bound and does not make this unjustified contraction assumption. Do not report the weighted-sum calculation as a general attack on tensor-network WE or as a new impossibility theorem.

One possible materially different repair would make invalid paths produce unknown nonzero terminal decoys rather than zero, and remove separately accessible terminal maps. Then Y need not lie in span(V); the weighted-sum shortcut no longer follows algebraically. The actual requirement is to construct public row maps whose correct original paths all give the SAME hidden terminal projective vector, while inconsistent paths produce decoys, and where the whole representation does not reveal local image factors, a shared accepting subspace projector, or a public canonicalization shortcut. Simply adjoining a publicly separated reject block to the zero-invalid construction does not suffice: an attacker can project it away and reinstate the zero-invalid algebra. Using independently visible per-wire success/decoy factors reinstates the earlier splice. A secret global mixing that genuinely hides the accept component would require a new explicit representation and a joint simulator; no such construction is supplied here. Do not run bond-dimension, field-size, random-basis, entangling-depth or toy-gate sweeps before that operation is built. Dropping projective normalization and using an unknown exact amplitude also requires a new analysis: the image-line attack alone does not recover that amplitude, and no exact-amplitude security or original-source reduction is claimed.
