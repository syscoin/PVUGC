## Constructive delta and limitations

R95's private-receipt N-of-N audit repaired malicious *signature packagers* but still assumed every *source LWE key* honestly generated. That assumption is stronger than one honest party in N-of-N funding. R96 replaces it for one restricted class: a 3-of-3 (more generally n-of-n) ORIGINAL LWE-short-error-key relation with ONE mandatory honest, independently generated, uncompromised source leaf. Other n-1 LWE source keys can be arbitrarily malicious and even publicly decryptable; their shares may be disclosed completely. The honest source leaf is indispensable for every valid ORIGINAL opening.

This is not arbitrary NP, not a compiler binding PoW into LWE, not a deployable Bitcoin witness-KEM, and not a proof that a PoW witness includes such an LWE secret. If the sole secret for the mandatory honest leaf is erased or unavailable when an actual ORIGINAL witness must open, completeness fails; an offline honest participant cannot become an unannounced online release authority. The cryptographic source threshold is distinct from N-of-N transaction preauthorization, one-of-N watchers and ChainLock voting.

## Explicit classical-PPT honest setup, witness predicate and release

Let q be an odd prime >6, public key dimension d, m sampled LWE rows and ell packed columns. Exact honest-key distribution: A_h <- U(Z_q^(m x d)), S_h <- U(Z_q^(d x ell)), E_h <- chi^(m x ell), with bounded ||E_h||_infinity<=beta; B_h=A_h S_h+E_h mod q. An arbitrary QPT adversary, seeing PK_h and independent quantum advice, chooses n-1 other correctly shaped PK_i=(A_i,B_i) using any classical output function, with keys and randomness of its choice. All keys are bound to the fixed ORIGINAL restricted statement x=(relation id, actual claim/UTXO, challenge branch, anchors/window, graph, full list of PK, exact native VK, message, context). PK_i choices are committed before the honest T and ciphertexts. A malformed shape aborts before funding.

The actual ORIGINAL relation R_LWE_AND(x,w)=1 iff w supplies n pairs (S_i,E_i), each obeying B_i=A_i S_i+E_i mod q with bounded centered error and the exact x scope. Any valid pair is accepted, not necessarily the setup's secret; different witness representations remain distinct. Malicious leaves may have A_i=B_i=0, E_i=0, yielding publicly decipherable ciphertexts with many valid S_i.

Build, without knowing any ORIGINAL witness, uniformly samples T in {0,1}^kappa. For each T byte, sample n-1 independent uniform coefficients a_1,...,a_(n-1) in GF(256), form f(z)=T_byte+sum a_j z^j, and assign one share f(alpha_i) to each leaf for distinct nonzero alpha_i. Encrypt each share under its leaf's actual PK_i using fresh packed Regev randomness r in {-3,...,3}^m per group: (u=A_i^T r, v=B_i^T r+Delta*bit) mod q, Delta=floor(q/2), with required concrete decoding margin 3*m*beta < q/4-1. Arbitrary malformed keys for which Enc is undefined are excluded before funding. Signed native challenge M is frozen by the honest N-of-N preauthorization controller. For honestly pre-signed sigma, set P||Bcheck=QPTsecurePRG(T), Dsig=sigma XOR P, J=Digest(frozen graph, all PK, all ciphertexts, masked native capabilities, related capsule context), CK=F(Bcheck,J,C,x,nativeVK) and Aux=G(Bcheck,CK,J,C,x,related capsules). F and G are public acyclic PPT functions. An audit attestation covers J, CK, Aux and graph. Honest root/seed, native signing secret and encryption coins are protected; the audit receipt is private, not part of the public output.

Off-chain Open(x,C,w) first checks the actual ORIGINAL LWE-key predicate, decrypts all n shares, reconstructs T via Lagrange at 0, derives P||Bcheck, recomputes J, CK, Aux, unmasks sigma, and requires native Verify(VK,M,sigma)=1 on the unique intended challenge path. Valid source keys all decrypt the same share if their bounded errors satisfy the margin, therefore ALL valid ORIGINAL witness representations reconstruct the identical precommitted T/sigma. No canonical witness, common short preimage, common intermediate state or SourceOpen oracle is used. Ordinary native signature verification is conditional on a proposed SLH-like native endpoint and hypothetical no-EC-key-path P2MR-like Bitcoin output; neither is claimed deployed.

## Exact arbitrary-QPT full-public simulation in the restricted game

The attacker sees x, all PK, C, CK, Aux, frozen graph and native VK, public audit attestation, any independently seeded related capsule(s) inside the same authorized claim/path scope, and even all n-1 malicious-source *witness keys, plaintext Shamir shares, encryption randomness and auxiliary data*. It may perform coherent joint QPT postprocessing with independent nonuniform quantum advice. It never receives mandatory PK_h's secret/error, an honest target native signing key, honest T/sigma/private audit receipt, an opening oracle for PK_h, or quantum-superposition source openings. Related capsules can reuse PK_h but have independent roots and messages; unrelated UTXO/owner authorization must NOT reuse credentials. All public auxiliary correlations are efficiently computable from challenge ciphertext bytes, simulator-known data and adversary-provided independent data; none depends on secret challenge coins or unknown honest source SK. A malicious setup can choose other keys depending on PK_h, but not after learning the honest root.

Hybrid H0 is real public output. For each packed target share ciphertext group under PK_h, the simulator gets a GENUINE ordinary QPT INDCPA encryption challenger for the standard honest LWE PK, uses the actual share vs zero as its two messages, encrypts all other source and related-capsule shares normally, and rebuilds ALL J,CK,Aux and public audit-attestation bytes over the genuine ciphertext supplied by the challenger. It needs no challenge encryption randomness because private receipt is never given to the adversary. The standard multi-message bound is g times the QPT INDCPA advantage for the honest PK. No INDCPA assumption is used for the n-1 malicious PKs.

After target honest encryption is replaced by encryption of zero, ALL other n-1 shares are jointly uniform and independent of T: the matrix mapping the n-1 random coefficients to the n-1 nonzero evaluation points is a non-singular Vandermonde matrix (after factoring alpha_i). Even publicly revealed malicious plaintext shares, exact source-key coins, related capsule outputs and arbitrary deterministic PPT functions of these shares do not leak T. Therefore the simulator can replace PRG(T) with a genuine independent QPT PRG challenger while reproducing Dsig, J, CK, Aux and related data without knowing the PRG seed. The replacement is a straight-line QPT hybrid with no quantum rewinding or assumed extractor.

With a uniform L-bit PRG replacement, masked honest sigma is independent of target native signature, allowing a straight-line QPT EUF-CMA reduction that never asks its signing challenger for the target native message. For accepted unauthorized *native target-message forgery*:

 Pr[forge] <= g*Adv_QPT_INDCPA(PK_h) + Adv_QPT_PRG + Adv_QPT_EUF-CMA(native) + eps_binding/audit,

where any selective target/related-capsule guessing loss and graph or audit failure are explicit if included. The exact root-recovery terminal instead inherits R93's generator-image membership bound 2^(kappa-L), not an unproved 2^-kappa. All reductions assume classical honest Build/Setup, nonuniform QPT adversaries with independent advice, honest audited no-bypass graph, no target signing-secret leakage, and actual independent QPT premises. A keyless Build and arbitrary quantum-correlated setup secrets are NOT established.

This is a restricted hard-TRUE independent-PQ-break route, NOT extraction of an arbitrary SYS/BTC ORIGINAL witness. The R89 generic 3CNF compiler remains publicly breakable. For adversarial fixed FALSE instances, malicious PK generation and full-public source soundness are separately UNPROVEN; no arbitrary-FALSE security is asserted. Availability, malicious full source generation, adaptive target honest-key disclosure, pre-funding DA/censorship, abort security beyond R95 conditions, practical 128-bit quantum parameters and hypothetical Bitcoin native PQ endpoint remain open.
