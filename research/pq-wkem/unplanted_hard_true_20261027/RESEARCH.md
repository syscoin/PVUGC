## Classical PPT algorithms and joint public view

Rker(B,w) = [w in {0,1}^n AND w[0]=1 AND sum(w)=h AND B*w=0 mod q].

Auxiliary data, other capsules and native pre-signatures must be generated jointly as described below, not silently omitted.

Open publicly verifies Rker(B,w), computes r_j=w^T*p_j and decodes the unique cyclic center g*t with centered distance at most E, reconstructs Z and the SAME precommitted K=V XOR D XOR Z, checks the true native pk, and signs the correctly scoped challenge OFF CHAIN. ## Lemma 1: no planting, yet overwhelmingly true
For S in the (h-1)-subsets of {1,...,n-1}, set z_S=e0+sum_{i in S}e_i. Let N=C(n-1,h-1), X(B)=sum_S 1[B z_S=0], mu=N/q^d. For each S the event has probability q^-d. For S != T, z_S and z_T are linearly independent: their anchored coordinate is 1, so scalar dependence would force equality. Uniform rows of B therefore make their kernel events pairwise independent. Thus
E[X]=mu; Var[X]=mu*(1-q^-d);
delta:=Pr_B[X=0] <= (1-q^-d)/mu < q^d/N.
This proof requires neither a witness oracle nor source-truth testing.

Asymptotic PPT family: d=lambda, public prime q in [lambda^3,2lambda^3], n=ceil(d*log2(q)+4lambda)+1, h=1+floor((n-1)/2). The central binomial bound N>=2^(n-1)/n gives log2(mu)>=4lambda-log2(n)>=3lambda for sufficiently large lambda, so delta<=2^(-3lambda). Also q>2g eventually, n=O(lambda log lambda), ell=O(lambda/log lambda) for kappa=2lambda, matrix and capsule polynomial size. The precise parameter decisional-LWE QPT hardness remains an INDEPENDENT assumption; no automatic worst-case hardness or Grover estimate is inferred.

## Lemma 2: complete-public true-target QPT security by exact coupling
Let T={B:X(B)>0}. The distribution U of UNCONDITIONED uniform B and all honestly generated public data differs in total variation from the SAME generation conditioned on T by exactly delta when B itself is present. The quantum-channel/data-processing inequality preserves an outcome-distance bound delta even under arbitrary coherent-QPT postprocessing and permitted classical adaptive oracle interactions, provided all auxiliary/advice samplers obey the declared independence rules. The reduction does not test T or sample via rejection.

For unconditioned B, an ordinary QPT decisional-LWE challenger supplies (B,y) with y=B^T s+eps or uniform y. In a STRAIGHT-LINE target-only column hybrid the simulator knows K,U,Z, inserts p_j=y+g*t_j*e0, and generates all non-target capsules and permitted openings/signatures honestly. Never uniformize an opened sibling: its revealed witness would distinguish. There are ell challenge switches. After all target columns become uniform, for each FIXED real native K, (U,Z)->(D=U XOR Z,V=K XOR U) is a bijection, hence D,V are jointly independent uniform even conditioned on the ACTUAL pk(K), public B, allowed related capsules and permitted signatures. The final simulator, given a REAL native EUF-CMA challenge pk and classical signing oracle, publishes uniform D,V,p, answers allowed signing queries, and converts any fresh intended-path signature or usable signing seed into a native QPT EUF-CMA forgery. No adversary representation, SourceOpen oracle, oracle programming, rewinding or common-preimage assumption is involved.

Consequently, for an unopened restricted target conditioned true:
Pr[unauthorized usable native seed OR fresh native challenge forgery | T] <= ell*Adv_QPT-DecLWE(d,n,q,chi) + Adv_QPT-EUF-CMA(native) + delta.
The arbitrary adversary is QPT, with a classical public transcript and classical adaptive opening/signing interfaces; efficiently generated quantum advice must not encode hidden target setup coins. Related capsules must be independently keyed and independent of the target SOURCE matrix; no opened sibling may reuse a kernel that opens the target. Target openings are excluded from an unauthorized win. A polynomial number of targets incurs the corresponding target-only hybrid sum and statistical-conditioning error. ## Lemma 3: direct hard-true witness-search reduction
Let arbitrary QPT A, given only uniformly sampled classical B and independent advice (NOT the challenge sample y), output any valid w with probability epsilon. Given (B,y) from ordinary decisional-LWE, run A(B), check Rker, then test whether centered w^T y is in [-h,h]. For real y=B^T*s+eps this is always true when w valid. For uniform y, since w is a fixed nonzero vector independent of y, w^T y is uniform in F_q and accepts with probability g/q. Thus D has EXACT distinguishing advantage epsilon*(1-g/q), and epsilon <= Adv_QPT-DecLWE/(1-g/q). For B conditioned T, the corresponding success is at most Adv_QPT-DecLWE/[(1-delta)*(1-g/q)]. Full-public key attackers who can see the LWE-derived p are instead handled by Lemma 2. This is a direct QPT black-box transformation, not extraction by classical rewinding.
