# Run 535 — public low-treewidth chip compositions remain symbolically searchable

Research-only draft PR syscoin/PVUGC#1. Starting head `c418f591c99391f1b60d585974222722a77e3c41`. This is a scoped factor-graph attack, NOT practical WKEM or an EOC/RIO break.

## Exact theorem A: known-failure baseline
Honest classical-PPT setup/evaluation publishes a total public deterministic terminal F_x(s), with public random coins included in s if necessary. A complete, sound public Boolean factorization Phi_x(s,z,o) has a valid completion for every freely selectable s and *every* such completion returns o=F_x(s). Its primal factor graph has an explicitly supplied/efficiently computed tree decomposition of width t, with polynomially many local truth tables. A nonempty success set G_x returns the SAME h-bit signing capability K_x; outside G_x every output equals the public fixed B_x.

For each i, solve Phi_x AND [o_i != B_{x,i}] by standard CSP variable elimination, in O(N 2^(t+1) poly(t)) operations per bit for a given good decomposition. This is satisfiable iff K_{x,i} != B_{x,i}. Thus the entire K_x is recovered in O(h N 2^(t+1) poly(t)) time; backtracking gives an actual successful input if K_x != B_x. For t=O(log lambda) and polynomial N,h this is a **classical PPT** unauthorized recovery, hence also an arbitrary-QPT attack. No ORIGINAL witness or Run-259 representation is needed. This applies to a *total clear sound composition*, not to unexposed encoded-state constraints or just small individual chips.

## Theorem B: variable junk and an augmented native checker
If failures output arbitrary junk, include a public, sound-and-complete constraint realization Psi_x(o,v) of the *actual branch-bound* usable-native-credential predicate. If the joint graph Phi_x AND Psi_x (INCLUDING all source, internal, key derivation and checker variables) has a supplied/efficient tree decomposition of width t', honest successful release ensures satisfiability. Standard variable elimination and backtracking recover one usable credential in O((N+|Psi|)2^(t'+1) poly(t')). This does not claim that native SLH-DSA has such a decomposition. Checking-key correlations are explicitly in the augmented graph, not handwaved away.

## Precise separation from Run 534
Use m independent pairs (x_j,y_j), e_j=[x_j=y_j], a_0=1, a_{j+1}=a_j AND e_j, and o_i=B_i XOR (a_m AND (K_i XOR B_i)). Each public local factor has scope at most 3. Elimination in order x_j,y_j,e_j,a_j (then a_m,o_i) has maximum join scope 3 regardless of m, so symbolic evaluation is linear in m per output bit. In contrast, under the SPECIFIED fixed complete-OBDD order x_0..x_(m-1),y_0..y_(m-1), equality has 2^m distinct residual functions at the middle cut, hence exponential ordered-OBDD width when K_i != B_i. The absence of a small final OBDD does not by itself imply joint symbolic hardness.

The toy fixtures use public XOR shares that trivially disclose their toy key; their recovered-key counts illustrate structural solver correctness only and are **not evidence of independent cryptographic key hiding or a practical attack**.

## Executed check / attack scope
Independent Python standard-library factor elimination/backtracking: 43/43 deterministic toy-key matches, 128 pair columns, 64-bit toy keys, join scope 3. Compact Node checker: 22/22 cases, 96 pairs, 32-bit toy keys, join scope 3; repeated outputs byte-identical. These are not quantum computations or SLH tests. Fixed-baseline A requires freely selectable s and an exposed sound/total joint factor graph; native-check B additionally requires small treewidth **after adding the native checking constraint**. Hidden correlated RIO chips and hard ORIGINAL-source authentication can make the full joint graph high-width or inaccessible. No generic claim against them.

Attack taxonomy: no seam, gauge reconstruction, statistical fingerprint or multi-capsule opening required; public chosen-input/symbolic access is essential. Honest setup suffices; malicious setup and replay are not solved. Theorem B includes public checking-key correlations. Attack is classical, hence valid for QPT; quantum advice, rewinding and superposition queries play no role. Binding x must include relation, UTXO, branch, anchors and window. Run 259 extraction applies only if the returned accepted representation satisfies its actual residual/SIS theorem, not to direct key recovery.

Literature: EOC by Chamon, Jakes-Schauer, Mucciolo and Ruckenstein (arXiv:2203.08876) uses polynomial-size individual-chip OBDDs and an additional correlated-obfuscation assumption, not an openly low-treewidth complete semantic factor graph. Standard CSP treewidth dynamic programming is prior art (Bodlaender 1987; Zhang–Mackworth 1992). No QPT-security or paper-wide proof audit is claimed.
