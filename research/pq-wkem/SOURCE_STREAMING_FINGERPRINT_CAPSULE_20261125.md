## Explicit Build/Open candidate

Let x bind the unchanged bounded three-ground ORIGINAL relation R_x(w), all claim/source/endpoint context and native VK/message. Convert its deterministic Boolean verifier to bounded-arity gate constraints, including canonical input/length checks, constants and output=1. Include each occurrence of a wire as a separate position in a stream of local rows (one allowed row per gate or check). An authentic w supplies one uniquely consistent stream by evaluating the verifier. A globally consistent stream of locally allowed rows gives a genuine original w by projecting its input assignments. No source scope is weakened here.

For wire i with occurrence bits b_i,0,...,b_i,k, choose public independent coefficients r_i,j uniformly in F_p^* for j>=1, with p a prime polynomial in the security parameter and circuit size. Define the rolling fingerprint

    A = sum_(i,j>=1) r_i,j (b_i,j - b_i,0) mod p.

Assign the resulting linear coefficient to each occurrence. Each local row a at stream layer l contributes a publicly computable increment delta_l(a). No equality between independently chosen occurrences is tested except through the final A. For a fixed inconsistent stream chosen independently of the coefficients, condition on all but one nonzero-difference coefficient: the acceptance probability is at most 1/(p-1). This is not an adaptive soundness guarantee.

For L layers, instantiate a keyed layered graph on (l,A) with A in F_p. Choose independent lambda-bit random labels K_l,A. The public start label is K_0,0. For every locally allowed row a and state A, publish an entry with locator H("lookup",x,l,a,K_l,A) and ciphertext

    Enc_l,A,a = K_(l+1,A+delta_l(a)) xor H_expand("edge",x,l,a,K_l,A).

Use distinct domains, capsule IDs and injective encodings. A concrete table can include an authentication tag on ciphertext and locator, with a separate domain; reject absent entries. The label width/locator collisions can be treated as negligible in the ideal hash calculation for a polynomial graph; none of the attacks depends on a collision. All row sets have constant bounded cardinality. Hide state indices from the public table if desired. Publish D=enc(S) xor H_expand("native",x,K_L,0). Build uses only x,S and sampled randomness. It erases labels except the serialized entries and start label. Its graph/table size is O(L p 2^c) for local arity c, and classical time is polynomial. Open evaluates the actual original verifier on w, uses its true local rows to follow the encrypted state path, and unmasks D using the final label. For every qualifying w the fingerprint is identically zero, so this computes the SAME S, not an independent source pad or proof hash. It does not require knowing future witnesses at Build.

This is a complete candidate serialization for functional correctness, not a secure capsule. In particular its public table exposes every outgoing row from a reached key, and its acceptance relies on compressed consistency rather than on exact original source authentication.

## Adaptive full-public attack and exact correction budget

A party does not need to guess any secret graph state label. Starting at K_0,0, enumerate the constant number of allowed local rows, look up and decrypt successors, and deduplicate by reached label at each layer. This explores at most p labels per layer (ignoring negligible accidental collisions) and uses O(L p 2^c) public computations. It can try unmasking D from every reached last-layer key and test the public native VK/message. The correct K_L,0 yields the exact S whenever state zero is reachable, even if the graph labels do not explicitly reveal the accumulated residue. An honest-code precheck of the source or path is not part of this key recovery. Unlike extracting a representation from a general adversary, this is a specified classical attacker, also a QPT attacker.

To establish a deterministic FALSE counterexample for this verifier compiler rather than merely presume that the actual source circuit has convenient collisions, use an ordinary semantics-preserving circuit extension: add p-1 unused input wires, each copied by two separate identity gates with unused outputs. Their input-occurrence equality remains among the global wire consistency constraints. The dummy input values can be canonically zero in a globally valid trace by choosing a separate fixed-zero representative occurrence and treating the two identity occurrences as copies; alternatively leave them free as auxiliary circuit variables and project them away. Use the free-auxiliary variant in the following proof, so each dummy wire has exactly two occurrences. This extension does not create any original accepting witness when R_x is FALSE. There are p-1 extra independently weighted repeated-wire differences, each can be chosen as 0 or 1 by assigning its representative bit 0 and its second occurrence either 0 or 1, and assigning each identity output to match its own input. No other constraints use these outputs. Every dummy row is locally valid.

Pick any locally allowed row for every original gate/check independently. Each ordinary gate relation is nonempty and the fixed-output/constant checks are separate local rows; thus this is possible even on a FALSE instance. Let their accumulated fingerprint be A0. Write the extra nonzero weights as r_1,...,r_(p-1). The reachable dummy sums contain ALL of F_p. Indeed let B_0={0} and B_j=B_(j-1) union (B_(j-1)+r_j). If B_(j-1) is nonempty and proper, translation by nonzero r_j cannot leave it invariant, since r_j generates the additive group of prime order. Therefore its size increases by at least one at each step until p. Inductively B_(p-1)=F_p. An ordinary subset-sum DP of O(p^2) operations finds a subset summing to -A0. Use that subset's dummy row choices. The resulting stream is locally valid, has A=0, and on FALSE x cannot correspond to any qualifying ORIGINAL certificate. Following the actual serialized edge table yields the exact native S. No source witness, hash break, label collision, interpolation, cross-capsule input or retained source coins is required. The extension adds O(p) gates, polynomial in the same parameters. Choose p as a polynomial of lambda alone before this extension, or specify a fixed polynomial bound on the already compiled base circuit, to avoid a circular padding definition.

This is a counterexample to the proposed generic trace compiler even on a circuit implementing the full original verifier with semantics-preserving dummy wires. It is not a claim that the currently deployed source verifier contains this padding or that every fixed circuit has a readily constructed neutral correction. The graph search attack above does apply to any such explicit serialization whenever a spurious accepting path exists. Even on hard-TRUE distributions, a guaranteed accessible zero state gives a polynomial attacker recovering S. The graph can output a path; if it were guaranteed to decode to an authentic witness, this same search would be a source-finding algorithm. Therefore on a genuinely hard-TRUE ensemble it cannot both be an efficient complete explicit graph and guarantee that all accessible accepting paths decode to original evidence.

## Repairs screened

1. Stronger public fingerprint: use a field of exponential size so fixed-stream collisions become negligible, or enforce enough independent fingerprints jointly. This is a genuine change to adaptive collision resistance, but the explicit state-label table now has superpolynomial size. A separate table per fingerprint with one secret share at each accepting endpoint is not a joint verifier: one can search each table independently, selecting a different local stream. Reject that unchanged cross-stream access structure without implementing. A cryptographic hash accumulator of the entire trace likewise has exponentially many possible states; its exact state labels would need a different generator. No claim that the hash has weak collision resistance.

2. Trace-dependent Fiat-Shamir coefficient seed: deriving coefficients from a commitment to the whole stream can help an ordinary proof system, but Build must still publish a graph that can open all future qualifying streams. If it exposes one independently traversable graph per public seed in a polynomial domain, the attacker selects a seed and traverses the corresponding graph without binding that selection to the eventual trace. A software check of the seed after the key is reached changes no edge. A seed commitment used in key generation could prevent that shortcut only if the actual terminal correction is bound to a valid seed/trace pair, without requiring a preknown trace. That is a different serialized gate, not supplied by the random-coefficient table. Increasing the hash width without constructing it is not a repair.

3. Compact high-width state labels: try an independent hash-based PRF seed for each layer, with K_l,A=F_{k_l}(A), and public transition corrections for each fixed row increment delta. Correctness requires, for every relevant A,

    Advance(T_l,a, A, F_{k_l}(A)) = F_{k_(l+1)}(A+delta_l(a)).

This is now an input-dependent evaluation-key problem rather than storage. Publishing the next-layer root gives the final zero-state key without a source path. Giving explicit corrections for all A recreates the exponential table. Merely changing GGM coordinate order cannot relate the two independently seeded leaf functions by addition. A shared label function with identity corrections for two different increments delta,delta' forces F(A+delta)=F(A+delta') at all A under the all-state equation; on prime field indices a nonzero difference then forces the function to be constant by iteration. This exact collapse is a rejection of the identity-correction repair, not a theorem about arbitrary transition encodings or restrictions to reachable states. Publishing an invertible frame as an alternative requires rechecking the already recorded reversible-frame regression; no such variant pursued here. A genuinely one-way transition evaluator with compact correlated labels and the correct globally consistent convergence might be different, but neither its public algorithm nor its simulator follows from ordinary hash/PRF pseudorandomness. It must be exhibited before any state-width optimization.
