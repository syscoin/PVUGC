# Run 347: shared-projector public-mask kernel leak

This is a new bounded **negative** result on multiple simultaneous release capsules, not another proposed generic projective compiler. It attacks the tempting optimization of reusing one hidden linear projector across different statement-bound proof branches/UTXOs. No WE, local-mixing, LWE, or quantum security assumption is added.

Let q be prime, T=[t_1|...|t_m] in F_q^(n x m), and let a single setup secret s in F_q^n be reused. A capsule protecting encoded key c_i publishes d_i=c_i-<s,t_i>. The complete public LWE view would additionally contain A, hp=A^T s+e, all contexts and checking keys; the attack below requires only d and T.

**Theorem 1 (same key, exact mask-only dichotomy).** If c_i=c for every i and s is uniform, d=c*1-T^T s. Put W=im(T^T). If 1 is in W, the distributions of d for different c are identical in the *mask-only view*: for a vector lambda with T^T lambda=1, d_c(s)=d_0(s-c lambda). This positive statement does NOT imply hiding with hp or any other auxiliary output. If 1 is not in W, a public vector a satisfying T a=0 and <a,1>=1 exists, and the outsider recovers c=<a,d> exactly, without any original witness. The leaking condition is rank([T;1])>rank(T).

For random uniform T with m>n, conditional on row-space rank r, the chance a fixed nonzero 1 lies in that space is (q^r-1)/(q^m-1). Hence the probability of a public same-key leak is at least 1-(q^n-1)/(q^m-1), greater than 1-1/q when m=n+1. This distributional statement applies to random matrices, not automatically to concrete context-derived targets.

**Concrete three-prefix attack.** With t1=(1,0), t2=(0,1), t3=(1,1), all distinct/nonzero, d1=c-s1, d2=c-s2, d3=c-s1-s2 and therefore c=d1+d2-d3. Perfect per-prefix witness correctness cannot repair this cross-prefix exposure.

**Theorem 2 (distinct keys).** For arbitrary c=(c1,...,cm), every a in ker(T) exposes <a,c>=<a,d>. If all c_i were independent uniform full-field symbols and rank(T)=r, the public masks reveal exactly (m-r)log2(q) bits of key information. Restricted bit-codeword leakage can be stronger. In particular, choose t2=2t1, reuse s, and let c_b be 0 for b=0 and (q-1)/2 for b=1, q odd >=5. The public value d2-2d1=c_(b2)-2c_(b1) uniquely distinguishes all four (b1,b2) pairs. This reveals **both** separately keyed bits without a witness or public signing-key oracle. For kappa independent bit rows with the same per-row cross-capsule reuse, it reveals both complete kappa-bit keys.

These failures are conditional on shared s and the indicated linear target relations. Fresh independent projectors per capsule stop this specific elimination but do not instantiate witness release or prove QPT hiding. The original honest-erasure N-of-N baseline is not the same as the malicious-retained-builder keyless game: retaining s trivially reveals all c_i. Context binding is mandatory but does not change the algebra once target relations exist.

**Attacks tested:** local mask cancellation; global gauge/annihilator synchronization; exact full-view-independent leakage (no fingerprint needed); multi-prefix/multi-UTXO reuse; chosen proportional targets; retained setup s; context/branch replay requirements; auxiliary PK(K) not needed for the attack. The attack is information-theoretic and therefore valid against arbitrary QPT adversaries; no coherent quantum security theorem for a surviving construction is claimed.
