Assume an independent publicly evaluable quantum-one-way permutation family f_i on lambda bits, and a native scheme with classical PPT KeyGen/Sign and QPT EUF-CMA for a fresh context-bound message. This is a conditional assumption, NOT an LWE construction or concrete 128-bit claim. The ORIGINAL relation is R_i((b,y,ctx),(u,t)) iff b=1 and f_i(u)=y, with arbitrary t of d bits. All b=1 statements are true with 2^d distinct ORIGINAL witnesses but finding u for random y=f_i(U) is QPT-hard; all b=0 statements are false. The public verifier can preserve distinct intermediate states (u,t).

Setup(i,x) samples fresh independent native (vk,K), without access to f_i^{-1}(y). The public capsule is P_x=(vk,C_x), where C_x=K when b=1, and C_x=empty when b=0. Public Recover checks R_i(x,w) and returns C_x on valid witnesses. Every valid ORIGINAL witness gets the SAME K. On false statements the capsule is exactly constant beyond vk: no additional key- or signing-capability leakage over the native vk-only game, under the native QPT security hypothesis. Do not misstate this as K statistically pseudorandom given vk.

On a TRUE statement, adversary A reads K from public C_x, signs m_x, and returns only the accepted native signature, without knowledge of any ORIGINAL witness or accepted Run-259 representation. If a QPT extractor Ext, even given setup coins/K, the adversary's code and quantum access to it, public f_i, and independent auxiliary advice, could extract u with f_i(u)=y with nonnegligible probability over y=f_i(U), we could invert the assumed quantum OWP: on challenge (i,y), sample native (vk,K), build the exact capsule and signing adversary, run Ext, output its u. This is a straight-line reduction with no rewinding or QROM programming. The reduction also handles white-box inspection of A's native signing coins, which are independent of u. Arbitrary auxiliary input containing the hidden preimage is NOT covered; extraction would then trivially succeed. The empty-auxiliary counterexample alone refutes the implication from the weaker games.

Precise scoped conclusion: all-witness common-key correctness plus even perfect absence of extra false-capsule leakage do not imply unauthorized TRUE-instance native authorization -> an ORIGINAL witness.
