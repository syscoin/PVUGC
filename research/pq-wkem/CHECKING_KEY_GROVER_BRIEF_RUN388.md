If `M` **distinct** states derived from valid ORIGINAL witnesses all authorize `m`, then `|A|>=M`. Thus ideal search requires **at most** `O(2^(b/2)/sqrt(M))` queries. A necessary benchmark for >=`2^lambda` generic Grover queries is `b >= 2lambda + log2(M)`, ignoring constants. For lambda=128: `M=1` needs b>=256, `M=2^32` needs b>=288, and `M=2^64` needs b>=320 for this *metric*. This is NOT a realized 128-bit construction or proof of security. If `b=O(log lambda)` and M>=1, the search is asymptotically QPT; if `b=Theta(lambda)` it is generally exponential, so do not mislabel a concrete-work estimate as a QPT break.
