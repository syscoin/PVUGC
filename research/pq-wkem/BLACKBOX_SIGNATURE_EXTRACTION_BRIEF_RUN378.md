## Conditional theorem and straight-line QPT reduction

Let f be a QPT one-way function on uniform n-bit preimages and define the NP source relation R(y,(w,t)) = [f(w)=y and t in {0,1}]. For arbitrary y, classical PPT witness-INDEPENDENT Setup(y) produces public capsule P, native checking key vk, and a private signing credential K. Every ORIGINAL witness (w,t) satisfying R recovers SAME exact K with probability at least 1-delta, despite potentially distinct source states. The public P includes all context, auxiliary outputs, presignatures, branch/UTXO binding and checking-key correlations that Setup produces.

Consider a witness-holder A_(w,t) that first recovers K with its private witness, caches K, then exposes ONLY an ordinary signature oracle on context-bound messages. Suppose a uniform QPT black-box extractor E, given (y,P,vk) and arbitrary adaptive/coherent oracle access to A, outputs any w' satisfying f(w')=y with probability epsilon. An inverter I for f receives y=f(w) without w, runs Setup(y) itself, and simulates the entire black-box signature oracle using its internally known K. On the honest correctness event, the oracle seen by E is identical to A_(w,t), so I outputs E's recovered w' and succeeds with probability at least epsilon-delta. This is straight-line; no rewinding, QROM programming, or quantum-advice cloning. If the oracle is deterministic and clean reversible, both worlds expose the identical unitary U|m,z> = |m,z XOR Sig(K,m)>, hence even entangled/coherent chosen-message queries distinguish nothing.

Conclusion: assuming QPT one-wayness, an extractor that sees ONLY accepted native signatures and public data cannot universally recover the ORIGINAL source witness, even when an actual witness holder generated the signatures. This is a black-box **interface lower bound**, not a claim that the signature forger can break a real WKEM. The witness holder is AUTHORIZED, so this theorem does not refute extraction guarantees restricted to genuinely unauthorized adversaries, or reductions that obtain witness-dependent execution evidence, adversary code, or an independent QPT break. It does show that treating bare signature verification as proof of ORIGINAL knowledge is invalid.

## Connection to local-mixing and Run 259

The output-only seam erases the witness-dependent state. The extractor's public checking key and all chosen signature messages are held fixed in both worlds, so correlated public checks do not repair the loss. Multiple valid ORIGINAL witnesses (the duplicate t bit) produce one semantic capability and the same signature transcript. No canonical witness, common preimage, affine collapse or raw-gate inverse is required. Global gauge alignment and gate fingerprints are outside this black-box model; no concrete local mixer is refuted. Malicious setup, retained seeds, cross-claim replay and general related-capsule security remain untested. The coherent equality is a real quantum-oracle equality, not a classical attack sped up by Grover.

Run 259 applies only AFTER a complete representation passes the exact residual/source checks; a native signature is not such a representation. A future security proof should either reduce unauthorized **signature-only** success directly to an independently justified QPT-hard problem, or show a concrete non-bypassable release interface that supplies authenticated source evidence to a valid quantum extractor. It may not insert an unjustified black-box signature-to-witness arrow. Bitcoin must continue verifying only an ordinary native signature and fixed graph conditions.

## Model, limits, and reproduction

Honest setup/evaluation is classical PPT. The conditional adversary/extractor is arbitrary uniform QPT with reproducible PUBLIC auxiliary advice and polynomially many clean coherent signature-oracle queries. One-copy private quantum advice entangled with an unknown witness, non-black-box adversary-code access, and source-recovery trace access are excluded. The statement is conditional on QPT OWF hardness, with loss delta; no OWF is instantiated.

The published compact checker uses an intentionally INVERTIBLE toy affine function (not an OWF), an IDEAL unimplemented release, and toy hashed signatures. It confirms two valid ORIGINAL witnesses, same exact K, chosen-message transcript equality and coherent-oracle basis equality for 1080 finite contexts. Captured output reports 37800 assertions; two executions were byte-identical and Python syntax passed. An extended local-only checker independently passed 166576 assertions including sparse complex-amplitude oracle comparisons. Neither check implies QPT security, native SLH-DSA correctness, a protected release compiler or concrete 128-bit parameters.
