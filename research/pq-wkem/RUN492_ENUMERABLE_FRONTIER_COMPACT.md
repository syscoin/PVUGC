# Run 492 — enumerable-input late-witness frontier barrier

2026-10-13. Starting verified `syscoin/PVUGC#1` head `2456c6c662f80b667a087f2d9b5128b7f67b7893`, branch `research/pq-wkem-validation-20260918`, open/draft/unmerged.

**Conditional theorem.** Let `L={x:exists w R(x,w)=1}` be an NP language. A uniform classical-PPT honest `Build(x)` gives public capsule P, native branch checking key vk, and a fixed fresh branch message m. Suppose the *entire* late-witness control at the protected release region is a public selector u in a uniformly polynomial-time enumerable set U(x,P) with `|U|<=poly(lambda,|x|)`. `Open(P,u)` is a publicly runnable classical-PPT algorithm and returns a native signing credential or signature; verifier `Verify(vk,m,sigma)` is public. There is no other input from w: no large authenticated state, witness-bearing ciphertext, proof, or private setup oracle. A classical copy of P permits independent tries of all u.

Assume for every valid ORIGINAL witness w there is an allowed `u_w` such that `Open(P,u_w)` produces an accepted signature with probability at least `1-eps_c`, while for every ORIGINAL-false x the full-public-view experiment forbids *any* PPT/QPT adversary from producing that fresh native authorization with probability above `eps_s`. The intended branch message must not already have been presigned. These are proposed **security obligations**, not assumed independent hardness or a constructed mixer.

**Proof:** On input x, sample honest Build, enumerate all public selectors u, run Open and native Verify, and accept if any succeeds. This algorithm is uniform classical PPT. For x in L, fix any existing valid w *for analysis only*. Enumeration includes u_w, hence succeeds with probability `>=1-eps_c` without knowing w. For x not in L, the enumerator itself is a permitted PPT attacker, so it accepts with probability `<=eps_s`. Therefore `L in BPP`. A compiler of this interface for generic NP implies `NP subseteq BPP`; absent that complexity collapse it cannot solve generic NP release. The argument uses no QROM programming or rewinding and already works classically, so QPT adversaries include it.

**Fixed-unary implication:** If protected state only evolves by a publicly callable fixed unary F, and w changes solely the chosen number `t<=poly` of sequential public iterations `F^t(C)`, let U be all t; the theorem applies. It does NOT rule out witness-dependent encrypted-state insertion, an unenumerable interface, arbitrary efficient jump-ahead indexing, publicly selected functional keys that admit larger inputs, or the full Canetti–Luo–Zhang construction. This proves a narrow **late-witness admission interface** limitation, not a break of controlled homomorphism, RIO/iO or any implemented WKEM. Distinct valid witnesses may keep different s_w; the no-go applies only when none of s_w enters Open except through the enumerable selector.
