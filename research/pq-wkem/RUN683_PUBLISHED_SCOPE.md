**Concrete restricted HPS candidate.** Let `G=<g>` have odd prime order `q`, `h=g^a` with `a!=0`. Honest classical setup chooses `(alpha,beta)` uniformly and publishes `p=g^alpha h^beta`. The secret hash of `W=(u,v)` is `T=u^alpha v^beta`. A valid restricted witness `(W,r)` satisfies `W=(g^r,h^r)` and computes `T=p^r`. Different true clauses with independently generated secret hashing keys can output distinct hashes `T_i` while recovering the identical protected group element `M` via `C_i=M*T_i`. A deterministic `KDF(context,M)` can represent the intended native branch seed, but this note does not implement native signature verification or ORIGINAL-source compilation.

**Exact one-word smoothness.** For false `W=(g^r,h^t)` with `t!=r`, condition on the public projection exponent `theta=alpha+a beta` (stronger than merely observing `p`). Then `log_g T = r theta + a(t-r) beta` and the still-uniform `beta` makes `T` exactly uniform in `G`. Thus one multiplicative capsule `C=M*T` is uniform conditional on its projection key and **adds zero information about M** beyond any correlated native verification key, provided such auxiliary public data are independently generated from M/context and do not leak the secret HPS-key fiber. This is conditional ciphertext independence, not a claim that `M` is hidden by the native key itself. Chosen false words fixed after viewing `p` are covered, but not words chosen after viewing their own ciphertext.

**NEW exact two-view counterexample (shared HPS key).** Let `W^-1=(u^-1,v^-1)`, which remains false if `W` is false. If both clauses reuse the same `(alpha,beta)` and the same protected `M`, then `T(W^-1)=T(W)^-1`. The two public ciphertexts satisfy `C(W)*C(W^-1)=M^2`. As `q` is odd, an outsider recovers `M=(C(W)*C(W^-1))^((q+1)/2)` by classical polynomial-time group operations, then derives the branch seed. **Both individual false-word capsules remain perfectly smooth.** This defeats *that* attempted shared-key optimization under honest erasure and full public native-key correlations; no witness, setup coins, or quantum algorithm is required. It does NOT break Run 682's independently keyed per-clause construction or automatically transfer to `K xor Ext_s(T)`.

**Positive JOINT composition lemma.** For any fixed finite family of false words `W_i`, sample independent secret pairs `(alpha_i,beta_i)` per published slot. Condition on all public projections, `M`, and auxiliary data independent of each fresh secret-key fiber. The `T_i` are independent uniform elements of `G`; hence `(C_1,...,C_m)` is exactly uniform on `G^m`, independent of `M`. It remains so for sequential adaptively chosen false words, provided each word is selected before its own ciphertext appears and uses a **fresh independent** key pair. This is an information-theoretic full-classical-public-view statement and remains true under arbitrary QPT postprocessing, including coherent evaluation of public deterministic algorithms. It does not supply a secret-key superposition oracle, protect retained setup coins, or prove arbitrary accepted native forgery extraction. It gives a minimal joint-law invariant for restricted OR release without imposing a common witness state.
