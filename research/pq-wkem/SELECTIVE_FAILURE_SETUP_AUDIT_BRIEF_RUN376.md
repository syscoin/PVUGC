**Result (SCOPED FALSIFIER, not WKEM):** A one-honest-party setup cannot certify all-ORIGINAL-witness SAME-credential correctness of an *arbitrary opaque release program* merely with polynomially many black-box tests. All-witness correctness of unrestricted readable Boolean circuits is coNP-complete. Coherent quantum oracle testing of one uniformly concealed defective witness still has the standard unstructured-search lower bound. Neither result rules out a reproducible, structurally constrained and efficiently verifiable release compiler.

**Theorem 1 (transparent circuit descriptions).** Given deterministic circuits R(w), C(w), and a known output bit k, define UniformCorrect(R,C,k) iff for every w with R(w)=1, C(w)=k. The complement is in NP: supply a w with R(w)=1 and C(w)!=k. For coNP hardness map any Boolean formula phi to R(w)=1, C(w)=phi(w), k=1. UniformCorrect holds iff phi is a tautology. The arbitrary-circuit decision problem is thus coNP-complete. No claim that honest parties cannot validate a specific syntactically restricted compiler.

**Theorem 2 (opaque black-box release oracle).** Set W={0,1}^n and R(w)=1 for all w. This is a deliberately easy toy ORIGINAL relation for *correctness auditing only*, NOT a hidden-key WKEM. Fix a native-like signing credential K and public checking key vk=PK(K). An honest object Good(w)=K for all w. A malicious setup party retains uniformly sampled a in W and supplies Bad_a(w)=bottom if w=a, otherwise K. The public vk and other auditor side information must be independent of a. Witness-dependent intermediate states remain distinct: s_w=w. Any adaptive classical auditor making at most q queries detects the single bad valid witness with probability at most min(1,q/2^n), with equality for q distinct queries. Until the marked point is queried, the two transcript distributions are identical.

**Structured selective denial.** If the malicious failure condition instead matches a hidden t-bit prefix a of w, it denies 2^(n-t) valid witnesses at once. Uniform random witness samples hit it with probability 2^(-t); q tests hitting distinct prefixes have success at most min(1,q/2^t). A future evidence class can therefore be excluded even if it occupies a tiny fraction of possible witness encodings. Whether a particular Syscoin evidence class admits such an encoding and whether the setup can maliciously embed it are NOT established.

**Quantum oracle scope.** Grant the auditor coherent, reversible query access to the defect predicate and even the value K. The empty-vs-single-unknown-marked-item promise is the established BBBV/Zalka unstructured-search problem. Constant-success detection requires Omega(2^(n/2)) *oracle queries*. Grover search attains this order; its exact single-mark search success after T iterations is sin^2((2T+1)*asin(2^(-n/2))). The executed checker simulates full statevectors, but the lower bound is the existing BBBV/Zalka theorem, not a numerical test result. Arbitrary a-correlated quantum advice or a readable circuit containing a invalidates the black-box concealment condition. This DOES NOT show that a concrete locally mixed gate hides a in its full public description, or imply concrete PQ security.

**Threat-model consequence.** This is a selective *completeness denial*, not a key-theft or false-instance attack. A legitimate qualified counterwitness can be denied its branch credential, potentially leaving an unsafe timeout path unchallenged. Honest-erasure N-of-N setup and a native verification key are not substitutes for certification that EVERY valid ORIGINAL counterwitness works. This proof does not construct a maliciously hidden puncture against an actual setup ceremony.

**Run 259 interface.** Run 259 conditionally proves accepted COMPLETE representation -> ORIGINAL witness or the specified SIS break. Bad_a merely refuses some valid representations: source soundness remains true while completeness fails. Moreover a signature-only attacker need not output a Run-259 representation. The missing recovery-or-signature -> accepted representation implication remains independent of this audit.

**Attack taxonomy.** The local seam is a hidden witness-conditioned denial; random-output/gate-class fingerprints and public chosen-input evaluation are explicitly bounded only in the *oracle* model. Global gauge attacks are irrelevant. Reused or related capsules and arbitrary auxiliary keys may leak the marker and are NOT covered. The builder chooses and retains a; honest auditor auxiliary data are a-independent in Theorem 2. Cross-UTXO replay and branch binding do not fix selective failure within one bound x. Public vk is identical in the two games and independent of a. Fully coherent quantum queries are considered using standard unstructured-search bounds, not merely a classical speedup. No post-unlock owner restriction is imposed.

**Reproducibility.** Python 3 standard-library checker selective_failure_run376_check.py was compiled and executed twice with identical output. It checks 278 Boolean truth-table functions on at most three input bits, exact classical hidden-mark probabilities, 126 hidden-prefix family counts, and full-state coherent Grover evolution through 8 input qubits against its closed-form success law. These finite checks establish no WKEM, iO/RIO/WE, real SLH signing, QPT cryptographic hardness, or native Bitcoin script semantics. The exact result is in selective-failure-run376-validation.json.

**Repair obligation, not assumed solution.** Before irreversible funding, one honest setup participant must verify an efficiently checkable *structural* universal-correctness invariant of the actual protected release compiler or a genuinely sound and applicable correctness proof, including branch/UTXO/vk/graph binding. These checks are setup-time/off-chain, not Bitcoin NP verification. The full security of the concrete protected representation remains unproved. A verifier only spot-checking an opaque adversarial object is insufficient.

**Ledger.** Honest setup/evaluation classical PPT; malicious setup retains selected defect trigger; classical/QPT auditor with quantum coherent oracle as specified. Theorem 1 is unconditional worst-case coNP completeness. Theorem 2 is unconditional classical black-box probability; QPT oracle query bound is conditional on the *ideal oracle access model*, relying on the established unstructured-search theorem, not a cryptographic assumption. There are no concrete 128-bit parameters or established PQ hardness here. Full-public-view QPT hiding, arbitrary-QPT true-instance signature-to-ORIGINAL extraction, malicious N-of-N ceremony, related-capsule composition and conditional Bitcoin P2MR/SLH deployment all remain UNPROVED.
