# Run 458 — restartable-QPT Goldreich–Levin minimality lift

Date 2026-10-12 UTC. Starting verified syscoin/PVUGC#1 draft PR head `51b774b2754a61eab310866f39cdfc6eec7b92d5`, branch `research/pq-wkem-validation-20260918`. No production changes. Strengthens **only Run 457's public-Build result**, not a proposed practical WKEM.

**Exact premise.** Classical PPT *publicly executable* `Build(x)` outputs an n-bit common capability K and a complete classical public view Y (capsule, intended native vk, context/UTXO/branch, auxiliary data and related capsules). For every valid ORIGINAL w, `Decap(Y,w)=K` with high probability. For a false x, uniform **restartable QPT** cannot recover exact K from Y with nonnegligible probability, even given all stated classical correlations. Here restartable means D can be run repeatedly from fresh workspaces; any necessary quantum aux is efficiently re-preparable from public inputs. No assertion about instance-correlated *single-copy* quantum aux. This is **stronger setup functionality than honest-erasure N-of-N**; do not transplant the conclusion to that baseline.

**Theorem.** `WE.Enc_b(x)` runs `Build(x)->(Y,K)` and publishes `(Y,r,c=b XOR <r,K>)`, uniform independent r in GF(2)^n. Valid ORIGINAL witnesses recover the same K, hence b. Under the premise this is bit WE with false-instance indistinguishability against restartable uniform QPT. The reduction uses independent **measured** runs of D, no coherent oracle queries to D, rewinding or cloning.

**Constructive proof.** Orient any distinguisher so it guesses b with unconditional advantage delta>0. For fixed Y,K define classical randomized `P_Y(r)` by uniform c, fresh `D(Y,r,c)`, output `c XOR D`. Then signed `gamma(Y,K)=Pr[P_Y(r)=<r,K>]-1/2` averages to delta. At least Omega(delta) of Build outcomes have gamma>=delta/2. For any fixed such outcome sample ell independent uniform `v_i` in GF(2)^n, define `v_a=XOR_{i:a_i=1}v_i`; distinct nonzero a give pairwise independent uniform vectors. For every bit coordinate j and nonzero a, independently query `P_Y(v_a XOR e_j)`; let `F_j(a)=(-1)^P`, `F_j(0)=0`; compute its Walsh transform `Z_j(t)=sum_a F_j(a)(-1)^<t,a>`. At hidden `t*=(<K,v_i>)`, `E[Z_j(t*)]=(-1)^K_j 2 gamma (M-1)`, `Var<=M-1`, M=2^ell. Chebyshev plus n-coordinate union bound puts K in the sign-bit candidate list of size at most 2M (include complements) with probability >=`1-n/(4 gamma^2(M-1))`. Choose M=O(n/delta^2). A uniformly selected list member is K with inverse-polynomial probability, contradicting the false-instance QPT one-way game. Walsh processing is O(n M log M); D queries are n(M-1). Exact K checking is **not** assumed; public vk correlations are included in Y.
