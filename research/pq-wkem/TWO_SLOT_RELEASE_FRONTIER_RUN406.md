## Theorem A — ordinary FE message privacy does not conceal a secret embedded in its function key

Take any ordinary single-key functional-encryption scheme secure for encrypted messages and a PUBLICLY SELECTED function f. Extend its issued functional key to (SK_f, canonical_description(f)), and have its decryptor ignore the description. Since f is selected/known to the adversary in the ordinary FE message-privacy experiment, the extension preserves that plaintext-security guarantee. But if f=f_{K,x}(w) is 'return literal K if R(x,w)', publishing the description immediately publishes K. Hence the seemingly simpler public Encrypt(w) + FE key for f_{K,x} cannot be justified by standard FE security. This is a direct function-key leakage counterexample, NOT a break of FE, iO, CLZ, or local mixing.

The encrypted-K first slot removes this *specific* literal-function-key leak. It does NOT establish security of multi-input composition.

## Theorem C — a universal publicly accessible two-slot release compiler is WE-hard

Suppose classical-PPT Setup(x,K)->P and public EncWitness(P,w), Eval(P,EncWitness(P,w)) have the preceding all-witness SAME-K correctness and complete-public-view false-instance QPT hiding for **every** polynomial-time NP verifier R. Then WE.Enc(x,K)=Setup((R,x),K) and WE.Dec(P,w)=Eval(P,EncWitness(P,w)) constitute WE for arbitrary NP relations. ## Attacks / boundaries

(1) **Seam:** the bound C0 must not be replaceable by unrelated or malformed ciphertexts that produce the original K. (2) **Global gauge:** publishing secret-bearing function descriptions defeats cosmetic local masks. (3) **Fingerprint:** function-key distributions may reveal literal K even when FE hides plaintexts. (4) **Multi-capsule:** multiple contexts, reused keys and correlated views must be covered jointly. (5) **Chosen input:** arbitrary public watcher encryption and coherent evaluator access are mandatory, not exceptions. (6) **Malicious setup:** corrupt retained master secrets and biased keys are unproved under the N-of-N honest-erasure model. (7) **Replay:** bind relation identity, claim, UTXO, branch, anchors and output-bound sighash. (8) **Checking key:** vk remains correlated with K in both hybrid games; other K-derived public fields require simulation. (9) **Quantum:** no actual scheme's coherent/joint QPT game was proven; these reductions only inherit an explicitly QPT two-slot FE security hypothesis.
