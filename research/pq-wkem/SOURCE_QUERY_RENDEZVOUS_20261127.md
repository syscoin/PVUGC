## 1. Explicit conditional algorithms

Fix injective, length-delimited query-address encodings, including the hash function identifier, canonical source input and relevant context. With the public hash functions/oracle fixed, let T_x(w) be the set of distinct encoded original source hash addresses computed in a deterministic full verification of w. Include at most L addresses; L is a polynomial in the bounded verification input/parameters. A witness can derive its own T without Build. No assumption that such addresses actually contain an independent high-entropy secret or individually prove full source validity.

Let Select(x;r) be a classical PPT sender sampler of a list of at most m distinct addresses Q, with private fresh randomness r. m polynomial. At first separate the sampler from S, allowing it to depend on the FULL public x (including native context) and any public hash/oracle. This is the natural sender-set selection if actual source addresses are to be predicted without assuming possession of a native-secret-derived input by the original verifier.

Build: sample Q; for each q in Q publish
    tag_q = H("rendezvous-tag",ctx,q),
    body_q = S XOR ExpandH("rendezvous-pad",ctx,q,|S|).
Publish all rows (possibly shuffled), x, ctx, and the stipulated native verification context. Use independently separated tag and pad domains and unambiguous encoding; no SHA random-oracle claim follows from separation alone.

Open: verify R_x(w), enumerate T_x(w), compute each address's tag and check for a row. On an exact q match, recover S by the corresponding pad. Check the native capability as appropriate. A relevant tag collision is a separate correctness event; the attack below uses exact q equality and no collision. For every w, the exact-match completeness premise is
    Pr_r[Q(x;r) intersects T_x(w)] >= 1-epsilon.
This condition must hold pointwise for all qualifying original certificates, not just an average over easy sampled witnesses. The construction does not rely on all witnesses sharing one q. It is polynomial and exact on an intersection. The issue is whether there exists a useful Select with that property and secrecy. Merely running the original verifier before decrypting a matched row is not cryptographic enforcement.

If Select only produces a list of publicly enumerable source-anchor inputs, there is an immediate attack: enumerate that public list and match tags. That is the familiar public-input/optional-check failure; do not implement that variant. If Select samples independent random addresses from a huge domain, coverage is not established; do not run another independent-source-pad experiment. The proposed repair is to bias private sampling toward actual source addresses using x, without publishing the sampling outcomes.

## 2. Independent-setup resampling screen for the proposed repair

The following attack applies to ANY such public S-independent randomized Select, even a highly nonuniform sampler tailored to the original source statement. Fix x, ctx, native public verification data, and the hash functions/oracle realization. Consider a hard-TRUE instance with at least one qualifying ORIGINAL w, not known to the attacker. Fix that w and its deterministic T=T_x(w), |T| <= L. Probability below is over fresh Select coins, not a distribution of witnesses. Define p_q=Pr_r[q in Q(x;r)] for q in T.

If the candidate gives the claimed exact-match completeness for w then
    sum_{q in T} p_q >= Pr[Q intersects T] >= 1-epsilon.
Consequently there is some q* in T with p_{q*} >= (1-epsilon)/L. Its identity is not needed by the attacker.

The actual unauthorized algorithm given the capsule runs the PUBLIC Select(x;r') with independent fresh coins r'. For every q' in Q', it computes the public tag and tries corresponding row recovery. It never runs R_x, receives no original witness and needs no private setup state, query log or representation from a victim. It can use the public native checking key/message to identify an accepted recovered signature, as required by the accepted-forgery goal; exact recovery candidates can also be selected randomly with polynomial loss if the exact fixed S is not separately recognizable. In a collision-free matching execution each exact address match returns precisely the frozen S by the published body equation.

Since Q and Q' are independent conditional on the fixed x and oracle, both include q* with probability p_{q*}^2 >= (1-epsilon)^2/L^2. Thus the unauthorized algorithm recovers at least one exact S candidate with nonnegligible probability whenever the every-witness premise holds with nonnegligible probability. If at most polynomially many matches/candidates are tried, guessing among them still has nonnegligible exact-S probability. For accepted native forgery, a direct matching candidate suffices, without relying on same-message uniqueness or EUF. A sharper bound uses Cauchy-Schwarz:
    E[|Q intersect Q' intersect T|] = sum_{q in T} p_q^2
                                   >= (1-epsilon)^2/L.
Since the intersection size is at most min(m,L), the event probability is at least (1-epsilon)^2/(L min(m,L)).
The weaker q* bound is enough and also permits a variable list size with polynomial bound.

This proof does NOT assume public knowledge of w or of T, that there is one address shared by all certificates, that source hashes are uniform, or that the attacker can simulate a valid source verifier trace. It uses no quantum operation, no salt search and no label splice. It is a straight-line attack on a proposed actual polynomial construction, including the secret-biased sampling repair. If correctness is stated only over an ideal random oracle and coins, one must average conditional probabilities correctly; for a fixed w valid relative to the oracle, write c(O)=Pr_r[intersection|O] and the same bound c(O)^2/L^2 holds pointwise. Jensen gives the corresponding average lower bound when the stated completeness average is over the qualifying oracle/instance experiment. No claim about sampling hard TRUE source instances, adaptive oracle-dependent x distributions, or general QROM impossibility is inferred. Hardness of obtaining an ORIGINAL certificate is not used by the algorithm; if its arbitrary recovery were to imply one, that requires a separate justified reduction for this exact attack, not a requirement that the attacker output its sampled q as a witness. The construction itself exposes no such extraction. An independent local query may be part of many nonqualifying traces.

This resampling argument is the reason to reject the privately biased selection repair before coding: it defeats the secrecy even if a perfect actual source coverage sampler is granted. Increasing sender/receiver polynomial lists, changing hash domains, using additional independently sampled private sets, or replacing exact addresses by publicly computable token projections with polynomial lists leaves the argument unchanged. Do not use it to claim impossibility of arbitrary witness encryption or of arbitrary capsule-correlated receiver computation.

## 3. Try to change the dependency of Select

The explicit attack needs public independent resampling under the same public x and oracle. A possible escape is Select(x,S;r) with dependence on the frozen native contribution that is unavailable to the attacker. This is a substantive change to the attack premise; it cannot be declared broken by the preceding independent-Q equation without more analysis.

Try two concrete choices. First choose q=H("rendezvous-address",ctx,S,r) and replace source addresses by q-like projected tokens. If Open's projection contains S or r, original w alone cannot compute it. If instead Open enumerates public projections of its genuine source trace independently of S and r, the independently chosen address has no stipulated correlation to that list. No every-witness guarantee follows. This is the already-recorded independent-opening obstruction, so reject that repair without implementation.

Second let Select use S to choose a secret subset of a public finite catalog of source addresses (e.g. known baseline path addresses, fixed public verifier inputs). If the catalog is polynomial and computable from x, enumerating the WHOLE catalog reveals every row matching a catalog member, regardless of the secret selection rule. For actual independently sufficient original branches, matching one known anchor alone also does not establish a relevant authenticated alternative history or burn refutation. If the catalog is exponentially large, Build needs an actual S-dependent efficient sampler with coverage for every original trace; the source verifier's address format supplies no such property. Do not promote a declaration of such a sampler to an algorithm.

More generally there is a second restricted resampling result if one can independently sample the secret/candidate selection distribution at the same public x (for example synthetic independent payloads): take p_q over both secret and sender coins; independent joint resampling yields the same lower bound for average correctness. This does NOT apply automatically to a real native signature conditioned on its fixed VK/message or correlated auxiliary state; conditional sampling of the native secret may itself be infeasible. A real proposed secret-dependent selector must specify its distribution and show why honest original witnesses intersect while arbitrary public attack/resampling fails. No such construction found here.

Another escape is making the receiver's candidate list depend on the actual capsule, T(C,w), so that it cannot be fixed before Select. That also invalidates the independence proof as stated. But any such repair must provide an actual classical PPT public receiver algorithm that computes the capsule-dependent query addresses from the full original w, not a secret label, ideal evaluator, or witness-only optional check. The present trial supplies no such correlated receiver computation. In particular, generating capsule-dependent public tags of source paths does not by itself construct secret addresses or guarantee exact common-output recovery.

## 4. Handoff

No candidate meeting (a) was produced, much less (b). Do not rerun larger sets, more sampled source traces, alternate hash projections or an independent-label QROM experiment. This is a construction screen, not the desired missing advance.
