## 1. Full-public proposal diagnostic

A proposed capsule C includes public parameters, statement, exact native verification key and cancel message, context and ciphertext. Let G(C,t) be its proposed deterministic terminal decoding algorithm using a complete random tape/trajectory t. G is publicly evaluable without w; it may reject malformed tapes. A public PPT proposal algorithm B(C) samples a tape from P_C. The intended honest Open with an actual original w samples a tape from Q_(C,w) using source-dependent guidance, evaluates G, and returns the exact frozen native capability with probability at least 1-epsilon (deterministic or perfectly correct algorithms are the epsilon=0 case). The distributions include all internal randomness needed to evaluate the decoder.

Define S_C as the set of tapes for which G returns a native accepted cancel capability under the exact bound message/VK, rather than just a candidate with the right format. Where the endpoint requires several contributions, test the complete accepted transaction/signature vector. This predicate must be publicly computable for the diagnostic. Exact recovery implies membership in S_C, but the converse is NOT assumed (same-message alternative valid signatures may exist). An adversary that finds any accepted output already violates the accepted-forgery obligation when it has no qualifying evidence or independent native break. No signature forgery assumption is used to bound a public decoder's output.

Conditional on C and w, write p=P_C(S_C), q=Q_(C,w)(S_C)>=1-epsilon. Suppose a proposed guide has pointwise likelihood ratio at most M (Q(t)<=M P(t) on its support). Then p>=q/M by summation. Even the weaker chi-squared condition E_P[(Q/P)^2]<=M2 implies p>=q^2/M2 by Cauchy-Schwarz. These inequalities do not require independence between source commitments, capsule and native VK. They are conditional statements for the actual distributions, not a simulator for the entire bridge.

For finite KL divergence D=KL(Q||P), applying the log-sum inequality separately on S and its complement gives

    D >= q log(q/p) + (1-q) log((1-q)/(1-p))
      >= q log(1/p) - h(q).

Therefore p >= exp(-(D+h(q))/q). In particular, for honest q bounded below by a constant, D=O(log(lambda)) is insufficient for hiding: a public proposal has inverse-polynomial accepted-output probability. The chi-squared and likelihood-ratio bounds give analogous inverse-polynomial thresholds. If these bounds hold on a nonnegligible set of hard-TRUE capsule instances with at least one qualifying w (not necessarily known to the attacker), a single public sampler plus native verification already gives nonnegligible accepted-output probability on that set. Repetition with independent sampler coins conditional on C amplifies p to 1-(1-p)^N; the attacker never needs the w used to prove the lower bound. This does NOT assert that a genuine release violates the bound or that its source witnesses are easy to find. For a FALSE-instance attack one must separately establish a lower bound there; the existence of q on TRUE alone does not establish that.

The test remains valid if the proposed guide has many valid trajectories, uses nonuniformly distributed actual source certificates, or has no common successful tape. It neither extracts the attacker's query logs nor assumes a rank representation. It directly uses the public native endpoint, not an extra equality oracle for the frozen exact signature.

## 2. Attempted source-conditioned trajectory repair

Let P be generated by public classical stochastic transitions p_j(t_j|t_<j,C). Try Q generated by rejection-conditioning each transition on a source-specific admissible set A_j(w,t_<j,C). For any prefix reachable under Q let alpha_j=P[t_j in A_j | prefix,C]. For exact rejection sampling with alpha_j>0,

    q_j(t_j|prefix,C) = p_j(t_j|prefix,C) 1_(t_j in A_j) / alpha_j.

Multiplying the transition probabilities gives exact likelihood ratio product_j alpha_j^(-1) on guided tapes, and KL(Q||P)=E_Q sum_j log(1/alpha_j). Thus merely adding a few local checks of high acceptance probability, or any sequence with cumulative entropy deficit O(log lambda), cannot be the release barrier if honest completeness holds. This is not a claim that polynomially many constant-density checks have small total deficit: their product can be exponentially small even when honest rejection sampling is efficient.

The prospective repair is to exploit that latter regime: many individually efficient witness-guided restrictions with exponentially small JOINT public success. The source verifier can in fact check or replay its entire authentic certificate, so A_j can reference the exact same w rather than independent occurrences. If the restrictions A_j are publicly computable from the current tape, the adversary runs the same rejection sampler. If they depend on genuine source witness data, they can induce a nonpublic proposal distribution with large cumulative deficit. But this does not establish that G decodes sigma_cancel on the guided tapes. The key missing Build operation is to sample an actual public terminal decoder descriptor such that EVERY original w induces a guided tape distribution supported on its accepted native outputs, while on FALSE and hard-TRUE arbitrary unauthorized algorithms cannot compute an accepted output except by actual evidence or independent justified break.

One explicit attempt would let the terminal decoder take the complete guided tape as a KDF input, with E=sigma_cancel XOR KDF(ctx,K) for a sampled K. Build then requires each guided tape to yield the same KDF pad (or a publicly encoded corresponding wrap) despite the unknown future w. Independent K makes this exactly the rejected independent-plant correlation; public K exposes the mask. No different hash placement or larger fixture is warranted. An explicit polynomial list of complete public candidate outputs is also rejected: regardless of the density of successful indices or difficulty of knowing which index a valid witness selects, compute and verify every candidate. Replacing that list with a secret-seed generator and calling the generator only on honest source tapes is not a serialized public decoder; publishing the seed changes the joint distribution and may expose the release. If the decoder is instead a finite polynomial-size explicit directed state graph with all legal transitions and terminal accepted candidates accessible, graph reachability bypasses rare path probability (already-recorded complete-state graph limitation, no new fixture).

A more ambitious stochastic variant would use a public base process and a source-dependent harmonic guide h_w on its succinct state space. A conditional process with h(s)>0 and transition law p(s'|s)h(s')/h(s) is implementable if h is computable and harmonic for the desired terminal event. For the natural choice h(s)=Pr_P[accepted terminal | s], it conditions on precisely the desired event; the likelihood ratio telescopes to 1/h(start) on accepting paths. This is an identity, not an algorithm for computing h. If a public PPT algorithm can evaluate the guide and sample the conditioned transitions, the adversary runs it; if only w can do so, an actual source-dependent relation between h_w and the hidden decoder must be constructed. Ordinary source authentication provides no such conditional native success probabilities. Different h_w selecting different subsets of accepted terminals avoid the requirement of a common trajectory but not the Build obligation above. No viable source-guided harmonic evaluator or correlated decoder was found. Do not assume either one as a primitive or count a numerical sampler as a solution.
