## Constructive continuation

R21's fixed-degree Boolean-quotient SOURCE has matrix B over F_q, square-free monomial rows indexed by |U|<=D=min(n,d+3), and column vectors for the clause-failure polynomials g_j multiplied by monomials of degree <=d. There are M=sum_{k=0}^D binom(n,k) rows. Classical Build samples r uniformly in F_q^L, independent centered row errors e_U in [-eta,eta] (instantiated sampler uniform in {-1,0,1}), and publishes C=B*r+Delta*mu*e_empty+e modulo q for each bit mu of one precommitted native signing capability K. Build needs no ORIGINAL witness; a keyless builder is not claimed.

For **each distinct valid ORIGINAL witness** w, the witness-preserving 3CNF extension a defines lambda_a[U]=product_{i in U}a_i. Hence lambda_a^T B=0, lambda_a^T e_empty=1 and, without shared witness states,

    lambda_a^T C = Delta*mu + E_a (mod q),
    E_a = sum_{U subset support(a), |U|<=D} e_U.

The prior sufficient *deterministic* correctness condition was M*eta<T, where T=min(Delta,q-Delta)/2 is the circular nearest-center decoding radius. The NEW theorem permits greater degree at the *same* modulus and unchanged SOURCE distribution, accepting negligible honest-Build failure. Since the E_a summands are independent, mean zero and bounded by eta, classical Hoeffding gives for each a and bit:

    Pr[|E_a|>=T] <= 2 exp(-T^2/(2 M eta^2)).

There are <=2^n Boolean assignments, ell capability bits and S independent authenticated bases. Therefore the probability that **any** valid ORIGINAL witness fails on **any** base/bit is bounded by

    2^(n+1) * ell * S * exp(-T^2/(2 M eta^2)).              (R23.1)

This quantifies over *all* Boolean assignments before any adversary chooses a witness: arbitrary QPT adaptive selection, public-transcript-dependent selection and coherent processing cannot increase the probability of the bad honest-sampling event. On the good event, the deterministic Lift circuit returns the same precommitted capability for every valid ORIGINAL witness. This is reliability, not secrecy, witness extraction, or a QPT hardness reduction. Quantum-coherent secret-opening oracles and maliciously sampled noise are excluded; polynomial restarts/fresh base scopes count in S.

R22's same-scope public offsets C_j=C_0+B*u_j satisfy lambda_a^T C_j=lambda_a^T C_0 **exactly**. Thus any number of adaptive public-only derivatives shares the *same* error and introduces **no extra derivative-count factor** into (R23.1). Derivation and checking keys must remain public functions of the authenticated immutable base scope (relation identity, claim/UTXO, branch, anchors/window, native vk, intended challenge path). Publishing the source coins or private opening remains unsafe.

On R21's publicly degree-certified FALSE subclass with B*t=e_empty, R20/R22's exact full-public public-G/native-verification-key simulator is unaffected: the bijective shift r'=r+Delta*mu*t absorbs the protected bit while preserving the independent noise distribution. This restricted perfect-hiding theorem continues to hold with arbitrarily correlated public checking-key/context metadata generated by the **specified public G** and permitted native-signing-oracle auxiliary interface, not arbitrary secret-correlated checking keys. No false-instance beyond that certified class is made secure.

## Checked scope, assumptions and blockers

Honest noise samples are independent across SOURCE rows, with per-row mean zero and bounded magnitude. All checking-key, native-verification-key, context, public auxiliary and related-capsule correlations are inherited from R20–R22, rather than independently simulated here. Multiple BASE scopes pay the factor S, while related public derivatives do not. The claimed all-witness event is an ordinary classical union bound that holds regardless of an adversary's quantum postprocessing; it is **not** a classical-to-QPT hardness lift.

R19/R21's uncertified FALSE short-pseudoevaluation disclosure remains a classical attack; the source B is structured, not an ordinary random QPT-LWE challenge. Arbitrary hard-TRUE recovered-key/native-forgery success still has no reduction to an ACTUAL ORIGINAL witness or an independently justified quantum break. Unknown-one-honest N-of-N malicious setup/abort, secret-dependent checking keys, selective target openings, graph composition, the conditional native SLH-like signature/no-EC-path endpoint, pre-funding DA and concrete native security are unresolved. No deployment or funding claim follows.

const cases=[];
for(const [n,d] of [[20,2],[30,1],[40,2],[50,1]]){
 const M=rowsCount(n,d),bits=(T*T/(2*M*eta*eta)-n*Math.log(2)-Math.log(2*ell))/Math.log(2);

}
const clauses=[
 [[0,true],[1,false],[2,true]],[[0,false],[3,true],[4,true]],
 [[1,true],[3,false],[5,true]],[[2,false],[4,false],[6,true]],
 [[1,false],[5,false],[6,false]],[[0,true],[4,true],[5,false]]
];
function multiply(A,B){
 const C=new Map();
 for(const [i,x] of A)for(const [j,y] of B)C.set(i|j,(C.get(i|j)||0)+x*y);
 return C;
}
function buildMatrix(n,clauses,d){
 const rows=mons(n,d+3),shifts=mons(n,d),ix=new Map(rows.map((m,i)=>[m,i])),cols=[];
 for(const clause of clauses){
  let g=new Map([[0,1]]);

   const c=Array(rows.length).fill(0);

 B.cols.forEach((c,j)=>c.forEach((v,i)=>out[i]=mod(out[i]+v*r[j])));
 return out;
