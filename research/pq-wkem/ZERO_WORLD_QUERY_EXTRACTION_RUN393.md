# Run 393 — Zero-world quantum-query extraction, ideal local-release support only

Exact source note: GLOBAL_FINGERPRINT_SOURCE_BINDING_RUN259.md (blob c7f3b77f0273ca1cbe6f0b31c1a086b8eb3acbf2); newest Run 390 brief (blob a1efd75071fb530aa09ffd4ac1b8145778467139). This is a specialization of the **known** quantum one-way-to-hiding / oracle-difference hybrid, not a new cryptographic construction or an iO/RIO/QPT-security theorem.

Let Acc_x(z) accept a COMPLETE source representation to which Run 259 actually applies. Honest classical setup samples native (vk,K), and only the *ideal* reversible oracle O_K: |z,b> -> |z,b XOR (Acc_x(z)*K)> is assumed. The zero oracle O_0 acts as identity. Both experiments expose exactly the same vk, public source relation, all auxiliary classical/quantum information and other capsules, and differ only in target-oracle answers. An arbitrary QPT A makes at most q>=1 coherent target-oracle queries. Let pReal and pZero be its respective accepted fresh native-challenge-signature probabilities, and epsilon=max(0,pReal-pZero). Other correlated capsules are allowed in the view but may make pZero high.

**Theorem (straight-line zero-world query extractor).** Run A in the **zero-oracle world**, select a uniformly random target query, and measure its classical z input immediately before the query. The probability of Acc_x(z)=1 is at least epsilon^2/(4q^2). In particular, no protected key K is required to run this extractor.

**Proof.** Purify A and its arbitrary quantum advice. Let phi_j be the zero-world pre-jth-query state, a_j=||Pi_acc phi_j||^2. Since O_K and O_0 agree outside accepted z, ||(O_K-O_0)phi_j||<=2 sqrt(a_j). The final real/zero state Euclidean distance is at most 2 sum_j sqrt(a_j), by hybrid triangle inequalities using the ZERO state at each step. The probability difference epsilon is no greater than that distance. Cauchy–Schwarz gives epsilon<=2 sqrt(q sum a_j). Measuring a uniformly random zero-world query returns an accepted z with probability (sum a_j)/q >=epsilon^2/(4q^2). No rewinding, QROM programming, witness canonicalization, common intermediate states or classical-query assumption is used.

**Run-259 composition — exact scope:** after recovering an Acc-accepted COMPLETE representation z, if rho_x(z)=0 then SrcExt(x,z) returns an ORIGINAL witness. If rho_x(z)!=0 but the published SIS residual digest accepts, Enc(rho_x(z))-Enc(0) is the specified nonzero short SIS kernel vector (subject to its exact assumption/distribution); alternatively enough random global folds bound existence of any invalid accepted z information-theoretically. A signature by itself is NOT an accepted representation.

**Why not a practical WKEM:** We have not made a publishable locally mixed oracle. If public program source contains K, an adversary can sign without target-oracle calls: its zero-world baseline is also high, so the lemma says nothing. If invalid-input outputs differ between real and zero (seam signals, rejects, candidate signing seeds, frame correlations, two jointly observed individually uniform masks), the difference set is not Acc and measured queries need not be ORIGINAL representations. Native checking keys, graph pre-signatures, other capsule correlations and malicious retained setup coins may inflate pZero. No black-box-to-white-box simulation is proved; assuming one with the desired hidden release would risk simply restating WE/iO.

Attack taxonomy: (1) joint seams fail marginal-secrecy reasoning; (2) frame/gauge not addressed; (3) fingerprints not tested; (4) other capsules affect pZero; (5) adaptive chosen-inputs covered at the oracle level; (6) malicious setup excluded; (7) x tightly binds claim/UTXO/branch but replay unproved; (8) checking vk stays in both games; (9) coherent quantum queries and zero-world measurement explicitly covered.

The executable compact JS checker simulates coherent Grover phase-oracle queries (an XOR output oracle with |-> answer), the real and zero worlds, and verifies the bound for 108 finite fixtures, plus white-box/joint-seam controls. These finite tests do NOT prove the general theorem or an actual scheme.
