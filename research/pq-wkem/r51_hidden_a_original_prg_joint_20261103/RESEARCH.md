## Repair to R49's single-claim public-matrix cost

R49 encrypts a narrow LWE seed (s,e) by actual ORIGINAL-NP quotient capsules, expands it to a native-signature-length pad Y=A s+e mod 2^t, and publishes a full independently uniform m-by-n matrix A. At its illustrative parameters A costs 2,097,152 bytes. **Publishing a 256-bit seed r of A=G(r) does NOT solve this under standard PRG security**: any observer seeing (r,A) tests equality with G(r), trivially distinguishing from (r,U). This would need a new QPT *seeded/structured LWE* assumption, not ordinary QPT-PRG plus uniform-matrix LWE.

R51 instead ENCRYPTS the expansion seed rA with the *same ORIGINAL-witness source*, so it is **not public**. Honest Build knows rA and A=G(rA), but publishes only a collision-resistant commitment alpha to A. A valid ORIGINAL witness opens rA off chain, regenerates A and recovers the SAME precommitted capability. Crucially, for certified FALSE source statements the source capsules are exactly independent of rA; that independence permits a standard *hidden-seed* PRG hybrid from G(rA) to uniform A in the **full correlated public view**, after which R49's ordinary QPT-DLWE and native EUF hybrids go through. This is not a new SOURCE security assumption and uses no SourceOpen oracle.
