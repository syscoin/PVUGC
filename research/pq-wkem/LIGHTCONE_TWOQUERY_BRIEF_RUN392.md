# Run 392 — two-query causal-cone distinguisher for isolated shallow local mixing

2026-10-09. Exact starting live PR: syscoin/PVUGC#1, branch research/pq-wkem-validation-20260918 at 48037d3a11556f5dd2a702973622094dd3badb47 (open/draft). Run391 is an unreferenced commit 539089b2deeb047d7090f0314b37edfc927a86a8, not live head; Run390 is attached. Read exact original notes.

THEOREM. Consider any distribution over n-bit reversible permutations formed from L sequential layers of disjoint <=k-input local gates, allowing arbitrary wiring permutations between layers. Honest setup/evaluation classical PPT, attacker arbitrary QPT, given public outputs and auxiliary checking data and chosen-input access to the *isolated forward permutation*. Every output coordinate depends on at most k^L original input bits by a backward causal-cone induction. For uniformly independent x and input/output coordinate pair i,j, a two-query attacker obtains P(x),P(x XOR e_i), and announces IDEAL if output bit j changes. Every such local circuit has Pr[IDEAL] <= min(k^L,n)/n.

For a uniformly random EVEN permutation on N=2^n points, the alternating group is two-transitive for N>=4, so images of distinct inputs are uniform distinct and Pr[IDEAL] = N/[2(N-1)] (half the output points have bit j set). The exact distinguishing advantage is therefore at least max(0,N/[2(N-1)]-min(k^L,n)/n). This avoids comparing local even permutations to the full symmetric group. With k=3, n=512, L=4 the lower bound is 0.341796875; for L=5 it is 0.025390625; for n=1024 L=5 it is 0.2626953125. Full input dependence requires L>=ceil(log_k n), necessary but far from sufficient for cryptographic security.

Compared to Run391's higher derivative attack needing 2^(2^L+1) queries, this attack uses TWO for shallow circuits whose cones are sparse. It is classical and hence within QPT, but not a coherent quantum attack. Attack taxonomy: gate-local seam (1), influence fingerprint (3), chosen-input evaluator (5). Other attacks (2),(4),(6)-(9) are not proved against a surviving source-bound release.

LIMITS: this falsifies ONLY isolated shallow mixer PRP behavior under unrestricted chosen-input forward evaluation. It does NOT recover native keys, falsify source verification, supply an accepted Run259 complete representation/ORIGINAL witness, break RIO, CLZ, iO or WE/WKEM, or apply when an inseparable source computation diffuses inputs first. No new security assumption or 128-bit implementation. Literature: Canetti–Chamon–Mucciolo–Ruckenstein ePrint 2024/006 is a conditional RIO/iO route, not shallow PRP security; Gay–He–Kocurek–O'Donnell arXiv:2502.07159 proves approximate k-wise independence for much deeper random reversible circuits, consistent with this lower bound. Prior arXiv:2404.14648 proposed computational PRP theorem withdrawn.
