**Graph-gauge theorem.** For an oriented graph 'Gamma=(V,E)', group of public invertible finite permutations 'G', independent uniform private vertex masks 'g_v', and bare transitions 'T_e', publish 'A_e=g_head*T_e*g_tail^-1'. Choose a spanning forest and define bare tree products 'P_v(T)' from the component root. Every non-tree edge 'e:u->v' defines a fundamental-cycle word 'H_e(T)=P_v(T)^-1*T_e*P_u(T)'. The public analogue is exactly 'H_e(A)=g_root*H_e(T)*g_root^-1'. Public tree-edge tables are independent uniform group elements, independent of the uniformly simultaneous-conjugated fundamental-cycle tuple. Thus two bare families generate identical full table distributions **iff** their fundamental-cycle tuples lie in the same simultaneous-conjugacy orbit; otherwise their public distributions have disjoint supports. Orbit distinguishing need not be efficient for arbitrary groups. If the graph is a forest, its public tables are perfectly uniform independent of the bare transitions, but **only in the table-only view**, not when endpoint labels, checking keys or other correlated outputs are added.

**Minimum opaque-seam criterion (exact scope).** An underlying graph with 'c' components has cycle rank 'beta=|E|-|V|+c'. If every secret-dependent fundamental-cycle word is to be removed from *public invertible edge algebra*, at least 'beta' edges must be made non-public-invertible/composable, and choosing complement edges of a spanning forest suffices. This is NOT a general cryptographic lower bound, not proof that hiding 'beta' edges suffices for WE, and not necessary when the cycle orbit is capability-independent. Forward-only protected permutations and coherent attacks remain separate questions.

**Concrete reconverging diamond.** Let vertices be 'r,u,v,t', edges 'r->u->t' and 'r->v->t', group 'S3', 'S=(0 1)', 'Q=(1 2)' (fixing state 0). Secret 'b=0': all bare edges identity. Secret 'b=1': both first edges identity, 'u->t=S', 'v->t=S Q'. Both paths take reachable input state '0' to the SAME output 'b'; intermediate masked states generally differ. Nevertheless publicly computable path maps 'B_u=A_ut A_ru', 'B_v=A_vt A_rv' reveal 'B_v B_u^-1': identity for 'b=0', a conjugate of transposition 'Q' for 'b=1'. The hidden bit is recovered classically with probability 1 for every honest setup coin, without an ORIGINAL witness or a native checking key. Every one-edge-deleted three-edge view has identical distribution across the bits. This is a new *graph reconvergence/unused-state* leakage condition beyond Run 546's two-frame parallel-table example; it does not claim to defeat obfuscated-forward CLZ.

The analytic theorem is separate from finite tests.

It covers seam cancellation, global gauge synchronization, joint statistical fingerprints, and multi-view; chosen queries, malicious setup and coherent-only quantum techniques are unnecessary.
