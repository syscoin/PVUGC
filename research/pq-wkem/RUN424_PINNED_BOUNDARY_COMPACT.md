# Run 424 — boundary pins defeat full-table forest hiding

Starting PR head: 200c954b5e032f8f8cbea65a88c2b150b80e11aa; draft branch: research/pq-wkem-validation-20260918. Scoped extension of Run 423; not a CCMR/RIO attack or complete WKEM.

MODEL. Fix a finite group H and graph (V,E). Honest classical PPT setup samples independent uniform M_v in H and publishes every complete edge-table value G_(u,v)=M_v F_(u,v) M_u^-1. Additionally, public boundary pins expose masks M_a for vertices a in A. The adversary gets all public tables, pins, inverse tables, verification keys and related capsules, with adaptive public evaluation and coherent evaluation allowed.

EXACT GAUGE-ORBIT THEOREM. For fixed edge assignments F,F', the full public transcript distributions are either identical or disjoint. They are identical iff there are Q_v in H with F'_(u,v)=Q_v F_(u,v) Q_u^-1 on every edge and Q_a=1 for all pinned vertices. Proof: this gauge gives the uniform-mask bijection M'_v=M_v Q_v^-1 and leaves public tables/pins unchanged. Conversely overlapping support yields masks M,M' with identical transcript; Q_v=(M'_v)^-1 M_v satisfies the equations. No computational hardness assumption. This does not assert efficient gauge-orbit testing in all groups.

FOREST WITH BOUNDARIES. The published edge-table distribution conditioned on pins is independent of EVERY F assignment iff the undirected graph is a forest with <=1 PUBLIC pin per connected component. On a connected tree with n vertices and <=1 pin, each edge-table tuple has probability |H|^-(n-1), regardless of F. With k>=2 pins, conditioned on their values, only |H|^(n-k) edge-table tuples occur, each with probability |H|^-(n-k). A path between pins exposes the RAW underlying transport F_path=M_end^-1 G_path M_start. A cycle with no pins already leaks source holonomy (Run 423). This precise iff is about complete public group tables and pins, not local mixing generally.

CROSS-CAPSULE SEAM. Capsule A publishes (M_0,G_01), and capsule B publishes (G_12,M_2). They reuse hidden intermediate frame M_1, while B has known underlying F_12=identity. Each isolated one-pin capsule has perfectly uniform edge tables, but their union reveals F_01=M_2^-1 G_12 G_01 M_0 in polynomial time. No explicit relative-mask value is published. Encoding 256 seed bits in identity/transposition F_01 values gives witness-free native signing even on a false source instance. Extended independent Python checker shows 24 toy non-PQ Ed25519 signatures after reconstructing 6144 seed bits. This is a negative-control scheme; no authorization or WE security is claimed.

EXECUTED EXACT CHECKS. The published dependency-free JS checker exhausts S3, 36 edge assignments, 216 mask triples per assignment, four boundary-pin configurations, 5184 pairwise public-law comparisons and 1296 cross-capsule seam cases. It passed 15768 assertions; independently executed local Python checker passed 37488 assertions. Tests verify finite algebra, not assumptions or practical quantum hardness.

QPT/ATTACK LEDGER. The path leak is classical PPT, hence works for QPT, and uses honest independent uniform masks per vertex. It tests public seam cancellation, global gauge synchronization, statistical/source fingerprints, multi-view and related-capsule reuse, chosen public evaluation and full native-checking-key toy correlation. Malicious setups and aborts are unproved; context-bound keys do not cure shared-frame leakage. The forest positive statement excludes arbitrary public checking-key correlations, which require their own security proof. No quantum-only attack on other mixers, QROM programming or rewinding is involved. Run 259 applies only after an accepted complete source representation and does not cover this bypass.
