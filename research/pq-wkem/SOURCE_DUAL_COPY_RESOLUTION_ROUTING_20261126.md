Preserve all original contextual admission and native bindings; write R_x(w) for the complete bounded verifier, not a newly implemented source compiler. ## 1. Construct the routing object without a witness

Fix a fan-in-two Boolean circuit for R_x, with public context fixed and all variable original evidence bits as input. Encode every gate using its full truth-table CNF. Make copies A and B with SHARED witness-input variables, distinct internal wires, identical constants, and output variables a,b. Put in the formula F all gate-consistency clauses for both copies plus the two unit clauses (a) and (not b). F is unsatisfiable for ANY x, because the circuit is deterministic. This is true even if the original relation is hard-TRUE or FALSE.

There is a classical polynomial-size resolution DAG for this contradiction: derive the two clauses for equality of each pair of corresponding wires in topological order. Shared input equality is immediate; fixed constants are identical. At a fan-in-two gate the local gate CNFs and already derived input-equality clauses imply output equality. Explicitly, to derive each direction, restrict the two output bits to the forbidden unequal setting, enumerate the at most 16 assignments to the four input bits, and eliminate them by resolution on the local variables. The local number of clauses and proof length are bounded constants because the gate arity is fixed. Equivalently use a constant-sized resolution derivation for each Boolean gate type; repeated inputs reduce the number of distinct variables. Weakening, if used for tautologies/local derivations, is harmless for falsified-clause routing (a falsified weakening implies its parent false). Finally resolve (a) with (not a OR b) to obtain (b), and resolve with the target input unit T=(not b) to obtain the empty clause. The final step explicitly uses T even on FALSE x. This is a syntactic proof compiler from the circuit, not a source-witness finder, and need not construct any proof of unsatisfiability of R itself. The polynomial-size DAG can reuse each gate equality derivation. No claim of polynomial *tree* or regular resolution size is necessary.

Given a genuine w, evaluate both copies and form the complete assignment t. All gate clauses and (a) hold, and the ONLY falsified input clause is T. Start at the empty clause (always false). At a resolution node for C=D OR E derived from D OR p and E OR not p, the current C is false under t. Follow the first parent if p=0 and the second if p=1. The chosen parent remains false. (The usual removal of duplicate literals or weakening does not change the rule.) Following this path terminates at a falsified input clause, necessarily T. Distinct genuine original witnesses can have completely different routes. This gives every-witness correctness at the level of a globally defined routing invariant, without finding a common witness/preimage, without labels per circuit-wire occurrence, and without knowing any future certificate during Build.

## 2. Actual serialized hash capsule trial

Assign independent lambda-bit node keys k_v to proof nodes. Publish the DAG, root key k_root, and for each directed edge v->u with its pivot/branch marker b, publish

    E_v,u,b = k_u XOR H("resolution-edge",ctx,v,u,b,k_v).

Use a domain-separated hash stream if necessary. Publish P_T=S XOR StreamH("resolution-target",ctx,k_T,|S|), and no payload at other leaves. A node key is shared across incoming paths; there are no independent local correction tokens. Context includes the fixed original statement, capsule and exact safe native message/checking key. All encodings injective. Honest Build and Open are classical PPT in circuit and proof size; Open follows the invariant with t and obtains k_T then S exactly for EVERY R_x(w)=1. No online helper or hidden evaluator is needed for this syntactic candidate.

Full-public security fails directly: the target leaf and its incident edges are public. The final resolution step has T as one parent. Anyone can compute k_T from k_root and its edge ciphertext, irrespective of the pivot value that a true source trace would use. Even if redundant intermediate nodes are introduced, search the public graph for a path root->T and decrypt edges in order. The attacker is not supplying any local source labels, querying an invalid-trace oracle, or claiming a false proof is accepted by R; it is executing the published hash arithmetic on reachable node keys. It works for FALSE instances as well because the dual-copy proof contains T independently of satisfiability. In particular for two distinct equal-length chosen payloads the public adversary can recover the payload and distinguish perfectly, without a source certificate or independent hash break. Including a native VK/message or sibling capsules cannot repair that full-view distinction. This is a classical straight-line counterexample, hence applies in the arbitrary QPT model too. No QROM assumption or extractor is used.

This is not a defect in resolution soundness: the proof is sound and the honest routing invariant holds. The invariant is a property of a computation on a fixed complete assignment, NOT a cryptographic restriction on the publicly accessible edges. Moving the native payload to a target reached by a longer path, or obscuring which leaf contains it, does not remove public traversal. With a public native check, the attacker can recover the keys of all reachable nodes in topological order and check candidate terminal payloads. For the exact published P_T trial the target is already known.

## 3. Repair screens before implementation

(a) Regular proof. Suppose a polynomial regular resolution derivation were available (no repeated pivot along any root-to-leaf path). Then any path's pivot choices extend to a single partial Boolean assignment. But this structural consistency alone does not imply satisfaction of the original source circuit: only the clauses encountered on that path are constrained to be false, and reaching T does not show all other input clauses true. The direct edge computation above applies unchanged, including on FALSE x. Even a path-consistency guarantee does not enforce validity of the entire original trace. Do not implement a regularizer or larger proof fixtures to address this failure.

(b) Independent proof orderings. Build m differently ordered/refactored proofs of the same dual-copy contradiction and secret-share S into m XOR shares, each protected by its own target key. Genuine w opens all shares via its full trace. A public adversary independently traverses each proof to its target and XORs the shares. The capsule contains each required public graph/key/ciphertext; no shared honest trace is enforced. Thus even an arbitrary polynomial number of correlated or independently generated proof orderings in this explicit construction cannot supply a consistency check. An honest wrapper checking that all routes came from one w is bypassable.

(c) Replace the accessible edge pad by H(ctx,v,u,b,k_v,h_w), where h_w commits to the entire actual original trace. This would at least prevent direct reuse of an old edge ciphertext with a new trace digest *if* the ciphertext were prepared for that digest. But Build cannot fix future h_w for all witnesses. In the exact one-ciphertext-per-edge scheme, if it encrypts using an independently selected h_0, opening with a distinct h_w yields the intended node key only when the two domain-separated hash outputs agree. For fixed distinct inputs independent of the relevant ideal hash domain this is probability 2^-lambda; this is an illustrative correctness calculation, not a concrete SHA/QROM security claim. Publishing h_0 allows the old arbitrary path traversal. A per-trace correction/evaluator making every valid h_w yield the same intended key is the unimplemented source-conditioned operation; a table of all possible traces violates the PPT target. No simulator for this repair is obtained.

(d) A different repair would build an explicit public polynomial graph in which EVERY reachable target path has an efficient decoder to a genuine original certificate, rather than merely a partial assignment. Then public graph reachability followed by that decoder is itself a classical PPT original-witness finder whenever a genuine witness exists and Build guarantees completeness. This is not by itself a cryptographic attack in the allowed extraction game (the finder has a certificate); it would be an extraordinary independent solution to the original hard witness search problem and is not provided by the dual-copy proof. In particular standard resolution gives no such decoder, as FALSE instances in the exact trial demonstrate. A graph with implicit, hidden or source-dependent edges needs an actual public traversal algorithm and security argument; do not substitute an ideal private edge evaluator.

## Handoff

The dual-copy construction obtains a proof of contradiction in polynomial size BEFORE future evidence, and every genuine witness reaches the same leaf. But proof-path correctness does not cryptographically gate access to that leaf. The direct public traversal defeats the actual serialized trial and its independent-ordering and structural-regularity repairs. Do not implement or scale those variants. The missing equation is a public edge/terminal transport that is not reachable by graph search on arbitrary pivot choices, while the full original witness can evaluate it without a setup-secret trace digest, and a joint full-view simulator/extractor for that transport. No source-independent puzzle, weaker predicate, graph-size optimization, or claimed impossibility of arbitrary hash-only WKEM.
