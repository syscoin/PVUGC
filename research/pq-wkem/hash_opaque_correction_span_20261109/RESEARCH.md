## Candidate and missing public evaluator (explicitly not instantiated)

Fix an arbitrary 3CNF verifier over witness bits z_1,...,z_n. Let c_j index three witness-bit occurrences in clause j and f_j the unique three-bit assignment violating it. Honest Build samples private k-bit words S_j and R[j,k,b] and independent hash-derived local words U[j,a] for all clause tuples a. The same frozen capability key is K = XOR_j S_j. Publish only valid local rows
    A[j,a] = S_j XOR U[j,a] XOR (XOR_{k=1}^3 R[j,k,a_k]), a != f_j,
and occurrence cancellation rows
    B[i,b] = XOR_{j,k:variable(j,k)=i} R[j,k,b].
The attempted global correction is
    D(z) = XOR_j U[j, z restricted to c_j].

With public access to D, every ORIGINAL-valid assignment w would open exactly the same K:
    Open(w)=XOR_j A[j,w|c_j] XOR_i B[i,w_i] XOR D(w)=K.
There is no requirement that distinct valid witnesses share a preimage. **D is a hypothetical public oracle**: the checker simulates it from private SHA256-derived mask words, but the actual public-only Build/Open interface DOES NOT IMPLEMENT D. Publishing secret seeds leaks them; a callable hidden-seed public evaluator must not be assumed as a primitive. Even granting such an oracle, the following exact extraction refutes security.

## Structural theorem for known-incidence XOR-affine public correlations

Let Y be a vector of public lambda-bit words and suppose, over GF(2), Y=A(x)t+b(x)K, where all hidden setup words t can be arbitrary SHA outputs (not necessarily statistically independent), and the coefficient matrix A and key incidence vector b are PUBLIC computable in time poly(|x|,lambda). Every valid witness w supplies a reconstruction vector c(w) satisfying c(w)^T Y=K as a formal identity for all t,K. Therefore
    A^T c(w)=0,  b^T c(w)=1.
A standard public Gaussian elimination solves these linear equations in polynomial time whenever any such c(w) exists, then obtains K=c^T Y. It does not require w, raw source certificates, K, t, private hash seeds, a query trace, or a quantum attack. The proof is pure linear algebra on publicly indexed formal mask slots. Correlations among actual SHA outputs do not prevent a valid symbolic identity from evaluating to K.

Consequently **for every TRUE x in this particular class**, all-witness correctness implies that a classical polynomial-time adversary recovers K from the full public view. On FALSE x, the rowspace may or may not contain the key row; full false-instance hiding does not follow from local clause rejection. This theorem concerns XOR-affine *public-incidence* schemes. It does not refute hash-based witness encryption in general, hidden non-affine correlations, or private coefficient representations which themselves must still have a concrete public evaluator and security proof.

For the proposed opaque local correction, the public matrix treats U[j,a] as an independent formal variable, even when U[j,a] is generated by SHA256(secret_j,a). The oracle values D(z) expose known coefficient rows, because each is explicitly the XOR of the three-local U coordinates selected by z. On the Boolean cube, D has algebraic normal form of degree <=3, even if SHA is nonlinear in its hidden seed. Therefore D(z) for ANY z can be computed as an XOR of its values at the 1+n+binom(n,2)+binom(n,3) low-Hamming-weight inputs, by Boolean Moebius inversion. This makes the complete target rowspace accessible in polynomially many public D calls, independent of a witness.

This is a more general failure than the prior specific degree-three two-point correction: it includes completely arbitrary SHA-derived nonlinear local masks, provided the publicly callable aggregate D and the public incidence have the specified form. No uninstantiated secrecy oracle is promoted to a construction.
