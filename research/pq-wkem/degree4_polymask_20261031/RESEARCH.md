## Classical Comp and all-ORIGINAL-witness Lift

For any three-distinct-variable 3CNF F, work in Boolean polynomial quotient z_i^2=z_i over prime F_q. For clause c with forbidden assignment b on variables i_1,i_2,i_3 define violation indicator C_c(z)= product_j (z_{i_j} if b_j=1, else 1-z_{i_j}). Fix degree d >= 3. Let M_d be the squarefree monomials of degree <=d, T=sum_{k<=d} binom(n,k), e the constant-monomial coordinate, v_d(W) the vector of monomial values on Boolean assignment W. Let D be the public matrix of coefficients of all C_c(z)*z_S with |S|<=d-3 (Boolean reduced). For each satisfying ORIGINAL W, D v_d(W)=0 and e^T v_d(W)=1, with distinct valid W allowed distinct v.

Comp(F,context) is classical PPT for fixed d: sample protected 512-bit K=(32-byte native signing seed,32-byte native PRF seed) in honest-erasure baseline, fresh native public seed and actual native pk derived from K (not executed by toy checker), random u in F_q^ell, random R in F_q^(ell x rows(D)); publish structured B=u e^T+R D. For each K bit b, independently sample S_b uniform F_q^rows(D), s_b uniform F_q^ell, and bounded centered noises eta_b in [-E,E]^T and eta_*b in [-E,E]. Set P_b=K_b e^T+S_b D; publish c_b=B^T s_b+eta_b+g P_b^T mod q and t_b=u^T s_b+eta_*b mod q. Publish F, x, D, B, u, all (c,t), genuine pk, relation/claim/UTXO/branch/anchors/window/challenge-path/verification-key/context binding, auxiliary data and related capsules. The toy checker has only mock bits and no actual native signature or Bitcoin functionality.

Public OFF-CHAIN Lift(F,W,capsule): check the actual ORIGINAL 3CNF assignment W, compute v=v_d(W), round centered v^Tc_b-t_b modulo q to 0 or g to recover each K_b, then validate real pk and sign the intended native challenge path. **All-witness SAME-K correctness:** v^Tc_b-t_b=gK_b+v^T eta_b-eta_*b mod q, since Bv=u and Dv=0. Error <=E(T+1); require q>4g and 2E(T+1)<g. This is a concrete witness-free 3CNF source-bound release, *not* generic WE security.

## Restricted complete-public FALSE theorem, independently instantiated

If e is in rowspan(D) over F_q, compute explicit h satisfying e=hD. For uniform S_b, the plaintext coefficient mask P_b=(S_b+K_b h)D has an **identical distribution for K_b=0 and K_b=1**, including all public B,u,c,t correlations, since S_b+K_b h is uniform and independent of protected K. This equality is exact even against unbounded processing or coherent QPT attacks on the classical view with independent quantum advice. The genuine native pk and permitted native-signature oracle remain correlated with K: usable K or a fresh scoped native forgery then implies a native QPT EUF-CMA break, provided all non-native auxiliary outputs are sampled independently of secret K from the full public view. Fresh masks and keys are mandatory per related scope; revealing another protected scope's master is excluded. This theorem needs NO LWE assumption for such certified FALSE F, but does require genuine QPT native EUF and authenticated context for the final native claim. No quantum signing-oracle superposition, hidden-K-correlated advice, malicious N-1 setup or shared-mask related-capsule security is claimed.

The checker supplies an explicit unsatisfiable ten-clause F10 on five variables. At d=3: T=26, 10 constraint rows, rank(D)=10, e NOT in rowspan(D). At d=4: T=31, 60 rows, rank(D)=28 and an explicitly computed finite-field h satisfies hD=e. Direct mask translations P(0,S)=P(1,S-h) passed 16 deterministic samples. Therefore d=4 fully closes FALSE **capsule-versus-K distributional hiding for this one F10**, conditional only on the separate genuine-pk/signature assumptions for key/forgery security.

## Explicit failure and exact boundary

For the *same* FALSE F10 at d=3, publicly computable v has v_empty=1 and v_{1,2,3}=1, all other coordinates zero, with Dv=0, e^Tv=1, ||v||_1=2, yet NO ORIGINAL W exists. Consequently v^Tc_b-t_b=gK_b+eta_empty+eta_{1,2,3}-eta_* recovers the entire master. The executed JS checker independently recovered 512/512 secret bits from the complete public c/t with no witness, using a single shared B. An independent Python checker in the local research archive also recovered twelve complete 512-bit FALSE masters. This disproves arbitrary FALSE-instance security for degree three.

A separate unsatisfiable 16-clause four-equation 3XOR formula over six variables has e outside degree-four row span (rank 53 of T=57), and inside degree-five row span (rank 63 of T=63). At degree four there is an exact non-Boolean rational pseudomoment of denominator 8, integer scaling L1=83, with D(8v)=0 and (8v)_empty=8. At illustrative q=65537,g=8192, 8g=-1 modulo q, so this **does not itself demonstrate a successful plaintext decoder** at d=4. It proves only that the exact span-hiding theorem does NOT cover this FALSE source. Degree five repairs this specific source's span condition, not arbitrary NP. No fixed constant degree for arbitrary false inputs was proved; full degree n has exponential source size.

## QPT proof obligations, no handwaving

The joint-public real distribution is precisely (F,x,D,B,u,all c,t,genuine pk,context,aux,related capsules), with B=u e^T+R D, P=K e+S D, independent classical coins as above. Honest setup/evaluation are classical PPT for fixed d; QPT adversaries may carry nonuniform independent quantum advice, process all classical fields coherently, use classical permitted-message signature queries and independently generated related scopes. The perfect-hiding FALSE theorem is distributional and survives those operations, but not malicious source-correlated aux or cross-scope secret sharing.

**Ordinary QPT-LWE does NOT yet justify this candidate.** The publicly structured B lies in a readily testable affine subspace and is not a uniformly random LWE matrix. There is no valid standard-QPT-LWE challenge simulator for the complete ORIGINAL-conditioned public view. A separate new "structured LWE is hard" assumption would be an uninstantiated relabel, not a solution. Nor is there an arbitrary hard-TRUE unauthorized native-key recovery/forgery -> actual ORIGINAL witness or independent QPT break; public non-witness pseudomoments and nonlinear key recovery are not constrained to yield representations. Full generic FALSE security also fails at d=3 and is unproved at d=4 or 5. The previous source-independent true-to-false transfer, low-degree closure, and rank boundaries remain adversarial tests.
