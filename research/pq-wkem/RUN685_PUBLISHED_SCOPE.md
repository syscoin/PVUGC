# Run 685 — bounded-wise-independent HPS rekeying fails lawful selective opening

**Research only.** Starting live syscoin/PVUGC#1 draft head 7bc816093968b78ca108952b959a6d287ecd564e; no production changes. Extension of Run 684's **identical-key** attack: here every slot has a distinct-looking, degree-d polynomially derived hashing key, and every d+1 slot keys are jointly independent before public projection.

Work in a cyclic odd-prime-order group G=<g>, let h=g^a for nonzero a. Sample independent uniform degree-d polynomials alpha(X), beta(X) over F_q. For public slot lambda, define hk_lambda=(alpha(lambda),beta(lambda)), projection p_lambda=g^{alpha(lambda)}h^{beta(lambda)}, and hidden mask T_lambda(u,v)=u^{alpha(lambda)}v^{beta(lambda)}. A valid DH witness rho for (g^rho,h^rho) computes exactly p_lambda^rho. Each claim's capability M_lambda is independently generated; a clause publishes C_lambda=M_lambda*T_lambda(W).

**Exact conditional rank theorem.** Fix any false word W=(g^r,h^t), r!=t. Condition on the complete public projection polynomial theta=alpha+a beta; then beta remains a uniform degree-d polynomial and log_g T_lambda(W)=r theta(lambda)+a(t-r)beta(lambda). For k distinct labels the mask vector is uniform over an affine evaluation code of rank min(k,d+1). Thus any d+1 masks are **independent uniform**, even conditional on all projections, but d+2 masks have public interpolation relations. Likewise any d+1 raw slot keys are independent *before* public projection.

**Lawful selective-opening break.** Suppose d+1 other claims have independently chosen credentials M_j, a valid *alternate* true clause that releases each M_j, and false clauses on this same W. Their public false ciphertexts reveal T_j=C_j/M_j after legitimate opening. For any distinct target label lambda_* whose claim has only the false W, interpolate T_* = product_j T_j^{L_j(lambda_*)} using public Lagrange coefficients, and recover M_*=C_*/T_*. This is **classical polynomial-time, probability-one unauthorized recovery**, with no target witness, retained setup randomness, or native signing oracle. Pairwise-independent keys (d=1) therefore fail after two lawful openings. Public domain-hashed labels do not block interpolation. A true-clause ciphertext M_j*p_j^rho and known rho explicitly supplies lawful opening without disclosing secret HPS fibers.
