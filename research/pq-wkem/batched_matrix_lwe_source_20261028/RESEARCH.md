## 1. Explicit construction: no reused scalar-key message coins

For q an odd prime, m>n, d>=1, h>=1 with 2h<q, set g=2h+1, radix T=floor(q/g)>=2, kappa native seed bits, ell=ceil(log_T(2^kappa)), L=ceil(ell/d) ciphertext batches per share, and t polynomially bounded XOR shares. Let sphere S(m,h)={r in Z^m: sum |r_i|=h} of cardinality N(m,h)=sum_{k=1}^{min(m,h)} 2^k C(m,k) C(h-1,k-1). A classical PPT exact sampler chooses support cardinality k with the displayed weight, then uniform support, positive composition of h, and independent signs.

The public SOURCE is now a matrix pair A in F_q^{m x n}, B in F_q^{m x d}. Its restricted ORIGINAL witness is a matrix pair (S,E) in F_q^{n x d} x {-1,0,1}^{m x d} satisfying B=AS+E mod q. This is an ACTUAL relation, not an internal adversary-volunteered representation. The TRUE source distribution is uniform A, uniform independent columns S, independent uniform ternary columns E, and B=AS+E. The UNIFORM branch is uniform independent A,B. Honest Build receives ONLY public A,B and typed context, not S,E. Whether a real generic NP statement can produce such a source witness-free is NOT established; choosing a source secret oneself and then appending an unrelated NP statement is invalid.

Build creates an independently sampled genuine native signing seed K and actual pk(K), and uniform independent kappa-bit U,Z_1,...,Z_t. Publish D=U xor (xor_i Z_i), V=K xor U, pk(K), relation/source/statement, typed context/claim/UTXO/branch/anchors/window, all ciphertexts, and permitted auxiliary/related capsules. Encode each Z_i as ell base-T digits; zero-pad the last batch. For each share i and batch j sample fresh r_ij uniformly from S(m,h), and publish one vector ciphertext

    c_ij = A^T r_ij mod q
    v_ij = B^T r_ij + g*a_ij mod q,

where a_ij is a vector of d radix digits, including zero padding in the final batch. Each ciphertext uses n+d field elements, NOT d*(n+1). Different batches and shares have independent sphere coins. Reusing the SAME r with the former single public b would reveal differences g*(a_j-a_k); public affine transforms of that b also permit cancellation. The new B columns have independent LWE secrets/errors, not public reparametrizations of one b.

Public OFF-CHAIN Release checks the ACTUAL bounded-matrix-LWE ORIGINAL relation (S,E), then forms y=v-S^T c=g*a+E^T r mod q. Every coordinate's centered noise is bounded by h, because each column of E is ternary and ||r||_1=h. Digit centers are separated by g>2h, including the cyclic last-to-first gap since g*T<=q. Nearest cyclic decoding uniquely recovers every digit and then K=V xor D xor (xor_i Z_i). Thus EVERY valid ORIGINAL (S,E), without a canonical source witness or common intermediate state, recovers the SAME precommitted K. This does NOT authenticate a real SYS/BTC burn or run an NP verifier/trace on Bitcoin. The checking key must be from a real native PQ signing scheme in an eventual implementation; the checker uses a conspicuously insecure mock for algebra tests.

## 2. Exact QPT source and complete-public simulator

Adversaries are arbitrary QPT with efficiently preparable, challenge-independent quantum advice, and classical public capsules, checking keys, typed context, auxiliary data, signing queries and full-coin Open(i) responses. Sign/Open interfaces take classical queries, not quantum superpositions. Auxiliary data may depend on public A,B, independently samplable other capsules, challenge-independent advice and revealed allowed shares/coins; it must not expose K, hidden share, a source witness, unopened encryption coins, or otherwise correlate with the hidden witness in a way the reduction cannot simulate. All honest algorithms and QPT reductions are polynomial-time and straight-line. No quantum rewinding, random-oracle extraction, SOURCE-open oracle, or supplied SOURCE representation is invoked.

(a) Matrix LWE from ordinary QPT scalar decisional LWE. Replace each of the d B columns, one at a time, between As_j+e_j with uniform secret s_j and ternary error e_j, and independent uniform. In the j-th hybrid the QPT scalar DecLWE challenger supplies (A,b_j); the simulator generates all other true or uniform B columns, genuine target K and pk(K), correlated U/Z/D/V, all source sphere coins and all independently generated related capsules. All permitted full-coin openings are answered from sampled coins WITHOUT any LWE secret. Therefore the TRUE-to-UNIFORM complete-public distinguishing gap is at most d*Adv_QPT-DecLWE for exactly these source distributions and quantum advice model. One must account for the d=14 computational loss when calibrating concrete security.

(b) Uniform H=[A B] in F_q^{m x(n+d)} gives an exact whole-vector collision bound. For two distinct signed sphere vectors r,r', their difference is NONZERO in F_q^m because 2h<q; hence Pr_H[H^T(r-r')=0]=q^{-(n+d)}. Consequently

    E_H Coll(H^T r | H) = 1/N + (1-1/N)/q^(n+d)
    E_H TV(H^T r | H, Uniform(F_q^(n+d)))
        <= delta_d = (1/2)*sqrt((q^(n+d)-1)/N).

Shifting the last d output components by g*a does not change their distance to uniform. CONDITIONING on sampled H and all OTHER independently sampled capsules/shares/coins, the selected hidden share still uses independent r in L batches. An L-step product hybrid and E_H[TV] bound replace only its ciphertexts with independent uniform n+d vectors at joint statistical cost <=L*delta_d. The argument is made over the joint H-dependent public distribution BEFORE adversarial opening selection; it does not assume a per-instance conditional bound after an adversary selects a rare H. Quantum data processing cannot amplify the variation/trace distance of these classical transcript mixtures.

(c) Full-coin adaptive survivor, including genuinely correlated pk(K), D, V. For a designated target, at most t-1 whole distinct shares are opened adaptively. Open(i) discloses Z_i and ALL its encryption coins r_ij and therefore reproduces every public ciphertext. Choose a uniform J in [t] independently; define E_J=(target usable K recovery OR fresh intended-path native forgery) AND (J never opened). Then Pr[E_J]>=Pr[E]/t exactly. Apply (a), then randomize ONLY unopened J's L ciphertexts via (b); if Open(J) is attempted abort and score failure. All other opened capsules remain exactly genuine and coin-consistent.

In the final native EUF-CMA game, a simulator is given genuine target pk(K) but not K. It chooses independent uniform D,V, the genuine other share plaintexts/coins/ciphertexts, and uniform J ciphertexts. For fixed native K and other Z_i, the mapping (U,Z_J)->(V,D) is a bijection, hence the final view is exactly the hybrid's distribution even conditioned on real pk(K) and all permitted other share openings. Classical native signing queries are forwarded. A usable target signing seed gives a fresh signature, or the adversary directly outputs a fresh signature. Thus

    Pr_TRUE[unauthorized TARGET K or fresh native signature]
       <= t * (d*Adv_QPT-DecLWE + L*delta_d + Adv_QPT-native-EUF-CMA).

The proof also admits polynomially many other independently generated capsules under the SAME exact SOURCE release predicate and H, with target chosen in advance, even if non-target capsule shares/coins are fully disclosed: other K values are known to the simulator, all coins are independent and no ORIGINAL source witness is revealed. For adaptive choice of one target among several native keys, a further multi-target guessing/union-bound loss is needed. A witness for the common source can open ALL these capsules; this is appropriate ONLY if they are intentionally governed by the SAME authorization condition. Typed context labels alone do not stop a source-witness holder from bypassing another, different claim. Arbitrary malicious related capsules and additional K-correlated leakage are excluded.

False-instance security holds on the uniform random SOURCE distribution under the statistical hybrid, not on every fixed false NP statement. Hard-TRUE security holds on the exact planted matrix-LWE distribution, with the claimed independent QPT DecLWE/native assumptions, not a generic original-NP recovery-to-witness theorem. Source witness disclosure, malicious Build retaining native K, all t target share openings, arbitrary partial opens across every target share, superposition oracle queries, malicious N-of-N setup, unbounded related capsules and unavailable Bitcoin PQ endpoints are outside the result.
