## Concrete honest classical Build and Lift

Fix odd prime q, Delta=(q-1)/2, eta>=1, and constant degree d=6. Branch i of the ORIGINAL relation has a faithful classical verifier-to-3CNF compilation on n_i Boolean variables and authentic clause-failure polynomials f_{ia}. The actual outer x binds relation identity, claim/UTXO, branch, anchors/window, context, intended native signature verification key vk, and challenge path. Preauthorization commits ONE common signing capability K under vk; the native no-EC-key-path PQ endpoint is conditional, not deployed. Let M_i=sum_{j=0}^{min(6,n_i)} binom(n_i,j).

Per branch i, independent base scope s, and capability bit b with mu_b in {0,1}: for each j=1..t_i draw independent uniform field masks r_{ibsj},s_{ibsj} in F_q^{m_i}, put U_j=sum_a r_{ja}f_{ia}, V_j=sum_a s_{ja}f_{ia}. **Explicit new noise law:** independently for every squarefree monomial z^T of degree <=6, draw xi_{ibsT} uniformly from {-1,+1} and set e_{ibsT}=eta*xi_{ibsT}. These coins are independent of K, x, vk, auxiliary data and all other source coins conditional on (x,vk,K). Publish

 C_{ibs} = sum_{j=1}^{t_i} U_j V_j + Delta*mu_b*1 + sum_{|T|<=6} e_{ibsT} z^T  (mod q)

in the Boolean quotient F_q[z]/(z_u^2-z_u), with x,vk,context, checking key CK and related capsules. CK and public related capsules must be generated by **publicly reproducible deterministic functions** of the declared base transcript; different base scopes use fresh independent source coins. Honest Build and Lift are classical PPT for fixed degree, although enormous in practice. The setup may know K under honest-erasure baseline. This does not implement the stronger optional keyless Build, source-coin verification, or malicious-setup soundness.

For EVERY genuine ORIGINAL witness w of branch i, its own faithful Boolean assignment z_w makes all f_{ia}(z_w)=0. Consequently U_j(z_w)V_j(z_w)=0 and

 C_{ibs}(z_w)=Delta*mu_b+E_{ibs}(z_w) mod q,
 E(z)=sum_{T subseteq supp(z), |T|<=6} e_T     (integer).

Nearest-center circular decoding (0 versus Delta) returns mu_b whenever |E(z)|<(q-1)/4. Different valid ORIGINAL witnesses may yield completely different internal states but decode the SAME precommitted K on one simultaneous global good-noise event; no canonical witness, common preimage, SourceOpen oracle, or attacker-supplied representation is required for honest Lift.

## New mathematical lemma: simultaneous all-witness correctness

For a *fixed* Boolean assignment z with h set bits, E(z) is the sum of M(h)=sum_{j=0}^{min(6,h)} binom(h,j) independent mean-zero Rademacher variables bounded in [-eta,eta]. Each satisfies E[exp(theta*e_T)]=cosh(theta*eta)<=exp(theta^2*eta^2/2). Multiplying moment bounds and using Chernoff yields

 Pr[|E(z)|>=T] <= 2 exp(-T^2/(2 eta^2 M(h))).

Taking T=(q-1)/4 and a union bound over **ALL 2^{n_i} Boolean assignments in each branch**, all ell bits and S independent base scopes, proves

 Pr[exists ANY valid ORIGINAL w with ANY incorrect bit]
 <= 2 ell S SUM_i 2^{n_i} exp(-(q-1)^2/(32 eta^2 M_i)).

The bound is stronger than per-fixed-witness correctness: it remains valid if a quantum adversary adaptively selects a genuine witness AFTER reading the entire classical transcript, because on the good-noise event **every assignment already decodes correctly**. This is a classical probability theorem requiring no quantum lifting, rewinding, oracle extraction or LWE assumption. It is uniform for every precommitted K and real vk, conditioned on data independent of the fresh noise.

For B branches all satisfying n_i<=n and M_i<=M, choose a prime q such that

 log2(Pbad) <= 1 + log2(ell*S*B) + n - (q-1)^2/(32 eta^2 M ln(2)) <= -lambda.

The old sufficient *deterministic* condition was M*eta < (q-1)/4. The new requirement is **over honest Build randomness** and permits exponentially rare bad capsules. It is not a malicious-builder guarantee; a dishonest builder might deliberately select bad coins unless independently checked. The full key's same-capability correctness is simultaneous, not one randomly sampled witness at a time.

## Restricted-FALSE public-output security unchanged under its exact premises

For R32's already qualified FALSE branch with 1 in W=span{f_a*f_c}, the previous proof establishes for D=sum U_jV_j the Fourier bound TV(D,D+Delta*1) <= q^(M/2-t). The new independent symmetric coefficient noise law cannot increase the distinguishing advantage:

 TV(D+e,D+Delta*1+e) <= TV(D,D+Delta*1)

because convolution is stochastic postprocessing. Thus choose t for the actual q and target bound, and retain R32/R33's restricted-FALSE full-permitted-public-view statistical hybrid: condition on x,K,real vk and auxiliary systems independent of fresh source coins; generate CK and related capsules only by deterministic public functions; use independent base coins, a triangle bound across bits/branches, and quantum data processing for arbitrary coherent QPT processing. This does NOT prove security for arbitrary FALSE, any TRUE source, adversarial coin-dependent CK, secret target openings, reused randomness, or malicious setup. The source-dependent setup and LWE simulator are NOT jointly instantiated by this lemma.
