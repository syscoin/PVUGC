## Scoped theorem (actual capability recovery)
Let classical PPT Setup(x,K) run without the later ORIGINAL witness. A public PPT front-end maps every valid w to a freely synthesizable token s of ell bits. An independently callable public PPT terminal T(P_x,s) returns K (or failure), and a public native checking key VK_x tests any recovered authorization. Different valid witnesses may map to different s, but all must recover the SAME K. For fixed setup and a fixed valid witness, let q_s be the distribution of honest frontier tokens, and p_s the probability that a fresh independent call to T on token s produces usable authority. If honest correctness is C=sum_s q_s p_s, then max_s p_s >= C. Exhaustively calling T once on every one of N=2^ell possible tokens and testing each result succeeds with probability 1-product_s(1-p_s) >= C. Complexity N public calls. When ell=O(log lambda), this is classical PPT; it does not require recovering or even possessing the ORIGINAL witness.

If the original relation has a QPT-hard witness-search generator (e.g. the inversion relation of an independently postulated QPT one-way function), a claimed general unauthorized credential -> ORIGINAL witness PPT/QPT extractor applied to this enumerator would violate that search hardness, unless another independently identified assumption fails. This is a TRUE-instance premature-recovery barrier, not a false-instance hiding attack. Run 259 binds only an accepted complete source representation; the enumerator never supplies one.

For deterministic public T and native Check, the classical evaluator can be made reversible and queried coherently. If M>=1 tokens authorize, generic quantum search finds one in expected O(sqrt(2^ell/M)) public predicate evaluations, with unknown M handled by standard randomized quantum search. Against this upper bound alone, the 128-bit quantum query target requires ell-log2(M)>=256; this is necessary only for that attack model, not sufficient for security.

## Critical scope
This applies only when ALL short terminal tokens are independently publicly synthesizable/invocable. It does NOT apply if access to T requires an authenticated, source-bound witness-dependent state that cannot be reconstructed from an arbitrary short token. It is independent of hidden-frame synchronization, nonlinear gate degree, reference capsule openings, sector switches, or transparent gate seams; honest setup and one target suffice. It includes native public key checking, and may be run by arbitrary QPT attackers. No malicious-setup or multi-capsule security theorem is claimed.

The exact executed checker is a deliberately toy public-token oracle with a SHA-256 native-check analogue: 21 deterministic enumeration cases with 21 successful recoveries and three distinct valid tokens agreeing on one capability. Its amplitude calculation is not quantum hardware or a PQ proof. A separate independently executed Python checker and full proof are retained in the local research checkpoint. CCMR local mixing and CLZ controlled homomorphism are architectural background only; no complete new full-paper QPT proof audit occurred this pass.
