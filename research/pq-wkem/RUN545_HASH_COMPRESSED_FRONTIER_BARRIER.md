# Run 545 — Hash-compressed local release: witness multiplicity and padding collapse

New result concerns public compressed witness-admission state, not Run 544's hidden-hash mate search.

**Architecture explicitly attacked.** The honest classical PPT compiler takes statement x and fresh protected seed K but does not know a valid ORIGINAL witness. A deterministic publicly executable classical PPT terminal E(P_x,s) accepts b-bit frontier input s WITHOUT an additional authenticated ORIGINAL witness, and returns a candidate secret. The public hashlock/checking key Check_x recognizes K; complete published P_x, native VK, claim/branch/context and all other public correlations are available. Every valid ORIGINAL w must make s=g_x(w) accepted and yield the same K. The theorem does not claim this compiler exists; it rules out a security requirement for this particular class if its inputs can be freely chosen.

**Frontier search theorem (true instances).** Let A={s in {0,1}^b: Check_x(E(P_x,s))=1}, t=|A|>=1, N=2^b. A uniform QPT attacker can produce accepted s and z=E(P_x,s) using O(sqrt(N/t)) coherent evaluations of the publicly reversible E and Check circuits, with standard unknown-t search if necessary. Known t gives success sin^2((2q+1)arcsin(sqrt(t/N))) after q Grover iterations. If z is not the intended K, a hash-based Check yields another accepted hash opening (not automatically a native signature). This establishes a query-security upper bound (b-log2 t)/2, before full reversible gate costs. For b=O(log lambda) classical enumeration is PPT. There is no false-statement hiding theorem or new cryptographic assumption in this argument. Full source proofs/cryptographic admission tokens must be included in the effective enumerable input; a source-authenticated terminal is outside the attacked class.

**Hash-compressed all-witness law.** If independent domain-separated random hash g_x maps m fixed distinct valid ORIGINAL witnesses to b-bit states, the number d of distinct images has E[d]=N(1-(1-1/N)^m), Pr[d<m]<=m(m-1)/(2N). Every image must be accepted, so t>=d. With overwhelmingly likely no collisions for m much smaller than sqrt(N), query exponent is <=(b-log2 m)/2. Examples b=256,m=2^20: <2^-217 compression collision probability, <=118-bit query exponent; m=2^64: <2^-129, <=96-bit query exponent. Thus 128-bit query-security would require b>=256+log2 m FOR THIS INPUT-ONLY ARCHITECTURE, not universally. Witnesses depending on g or correlated label distributions invalidate this independent occupancy calculation.

**Stronger padding attack (CLASSICAL).** Take any QPT one-way function f, a true x=f(w*), and the ORIGINAL relation R'(x,(w,p))=[f(w)=x] with r unconstrained padding bits p. Finding ANY ORIGINAL witness still inverts f. Yet a hash-frontier terminal that accepts g_x(w*,p) for EVERY valid padded encoding, with independent uniform b-bit g outputs and no source token, must accept a random s with probability >=1-(1-2^-b)^(2^r). When r=b this approaches 1-e^-1 ~=0.632; when r=b+4 it exceeds 1-e^-16 ~=0.999999887. One CLASSICAL random input releases K with constant probability despite the underlying source witness remaining hard. Any uniform QPT extractor recovering w from this attack transcript plus public capsule, for a compiler Setup(x,K) that does not know w*, would straight-line invert f: sample K, run Setup, run random-s attacker, invoke extractor, output w. No quantum rewinding. Therefore source-hash compression alone does not meet original-source binding in this model. This is a model-specific impossibility, NOT a generic hash-based WKEM impossibility or a claim that Syscoin evidence literally contains these free padding bits.

**Attacks and limits.** Local seam: freely callable terminal bypasses ORIGINAL admission. No gauge synchronization or gate fingerprint extraction is needed; the public checking key supplies the success predicate. Multiple different valid witnesses enlarge successful-state density. Chosen-input and coherent access are available from any public deterministic evaluator. Honest setup already suffices; retained randomness, malicious seeds, cross-UTXO replay and multi-capsule correlations remain separate concerns. Context binding does not prevent a same-claim attack. Grover is coherent but no new joint/coherent Simon attack is claimed. If complete accepted states admit ORIGINAL extraction under the EXACT Run 259 hypotheses, searching them may find a genuine witness; a short witness hash alone does not supply that extractor. Canonicalization of genuinely distinct ORIGINAL witnesses is not required, but normalizing irrelevant padding or enforcing authenticated source admission is necessary to avoid this particular collapse.

Neither executes quantum hardware nor instantiates E/P/SLH-DSA. No new primary-literature full-proof audit this iteration; uses standard Grover search and balls-in-bins probability.
