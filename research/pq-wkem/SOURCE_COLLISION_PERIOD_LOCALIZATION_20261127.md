## 1. Global collision-invariant candidate

Let V_x be the complete original verifier with all three independent OR grounds and exact claim/source/native bindings. Let n be the key bit length. Choose K uniformly in {0,1}^n. A conceptual way to make every collision have the same secret is to choose an injective publicly evaluable permutation P on n bits and define

    F(0,v) = P(v)
    F(1,v) = P(v XOR K).

For instance P can be a public even-width Feistel permutation with domain-separated hash rounds; no hardness of P or group assumption is used. For odd n pad to an even width. The capsule would contain an expansion mask E = sigma_cancel XOR H_final(ctx,K;length). Every cross-branch collision supplies K by XOR of the two n-bit inputs. In particular, if a source-dependent lifting algorithm could turn any original w into such a pair, different w could yield different pairs with identical key. The intended lifting algorithm is NOT implemented; writing F literally exposes K. Even if a new serialization hid its constant, the following attack precludes this entire global design at the functional level. No effort is spent encoding its circuit.

Set z=(b,v) in the (n+1)-dimensional binary vector space. For all z, F(z)=F(z XOR p) for p=(1,K). Injectivity of P proves the converse: equal outputs imply either identical inputs or difference p. This holds also at K=0. A classical PPT public evaluator can be made coherent by reversible simulation and uncomputation, so arbitrary QPT access includes this oracle. Start in uniform superposition over z; evaluate F, and measure the output register. The input register is the equally weighted superposition of z and z XOR p. A Hadamard on all n+1 input bits gives a uniform sample from the n-dimensional subspace p-perp. After n+t independent samples, failure to span p-perp is bounded by (2^n-1)2^(-(n+t)) < 2^-t: union-bound over all nonzero linear functionals on that subspace. Binary Gaussian elimination returns the unique nonzero period p with the complementary probability. Recover K and the exact mask plaintext. This is a polynomial-time quantum algorithm with n+t oracle calls and no original certificate, hash inversion, mixed labels, adversarial representation or query-log extraction. It works on false and unauthorized hard-true statements. A simulator purporting to hide the same payload behind those functional interfaces fails: the observer can compute K and unmask. Granting perfect black-box hiding of the code does not help.

A public source check in the advertised Open that precedes collision extraction cannot fix this. Conversely, gating the actual F evaluations so the second branch is only available on a globally qualifying w would remove the Simon promise, but the missing source-conditioned evaluation then is exactly what must be serialized. Do not assume that gate. Replacing XOR with a different public additive basis does not repair this candidate and is rejected without implementation.

## 2. Mathematical repair: local rather than global paired fiber

The period argument uses a single offset across ALL inputs, not merely the existence of one pair. Change the mathematical structure to a distinguished target fiber only, with two independently sampled n-bit values a,b. Set K=a XOR b. Build can publish salted domain-separated hash commitments

    A = H_a(ctx,a), B = H_b(ctx,b)
    E = sigma_cancel XOR H_final(ctx,K;length).

Use hash outputs of at least 2n bits for the point tests (or explicitly model separate ideal random oracles with that output width); this does not assert a concrete SHA theorem or perfect uniqueness. The following concrete public function G uses tagged outputs of distinct syntactic types. It is serialized by the two commitments, the complete original verifier V_x, and literal instructions:

    G(tag,u):
      if tag = 0 and H_a(ctx,u) = A: return (target,ctx)
      if tag = 1 and H_b(ctx,u) = B: return (target,ctx)
      if tag = 2 and V_x(u) = 1: return (target,ctx)
      return (singleton,tag,u)

Use fixed length/canonical encoding in each tagged domain, and disjoint tagged output prefixes. A valid original witness now genuinely yields an input to the payload-bearing target fiber, and the two builder points also belong to that same fiber. There is no promised global period even if the tag-2 domain is omitted: generic tag-0 and tag-1 points have distinct singleton outputs. This is a concrete source-conditioned public collision structure with no hidden evaluator. It is NOT a complete release construction.

Attempted Open: accept ANY qualifying w, evaluate G(2,w), then use the target fiber to obtain the two special builder points and recover K. This second operation is absent. The source input does not give either preimage of A,B; reaching the common output is not inversion of the other branches. For a source certificate fixed independently of the setup coins, the entire tag-2 evaluation depends only on public x, ctx, w and not a,b. Its output is a known constant; it contains no further information about the independently sampled pair. Hence every candidate algorithm using that evaluation can replace the evaluation with the constant (given w); the point-test part still needs its own independent recovery algorithm. More source collisions (including a second distinct legitimate w) merely give more tag-2 inputs, not a tag-0 or tag-1 preimage. This is exact, including malicious retention of source coins. Accidental hash collisions in the point tests do not supply an algorithm returning the exact chosen K; no claim of computational uniqueness is needed to identify this missing step.

The failure is not that an honest Open has neglected to verify w: the verifier is in the actual public function defining the fiber. The failure is that membership of the common fiber does not implement a transfer between its different representations. An arbitrary collision extractor that treats every two inputs as a key-bearing pair would be incorrect, since two distinct tag-2 inputs can be independent of a,b. Requiring one input from each of tags 0 and 1 restores the XOR equation but leaves completeness unresolved. The repair thus eliminates the global quantum period without achieving an original-source release.

A useful diagnostic simulator experiment omits E and fixes an independently generated true (x,w,ctx). Given only the two independent point-test commitments, the remainder of G and the target output can be simulated exactly without a,b. Any claimed inversion of the chosen pair from G plus w in this experiment would invert the independent point-test challenge with the same probability: the reduction samples or hardwires the independent (x,w,ctx), constructs G, and checks the output pair against the challenge. For exact K alone the relevant independent problem is recovery of XOR of the hidden preimages, not ordinary single-preimage inversion. Neither a QPT hardness reduction for this XOR problem nor a hybrid including the correlated native mask E is claimed here. The experiment diagnoses the proposed source-to-pair transfer, not full-public WKEM security. In particular it must not be cited as a proof that arbitrary source-dependent collision families are impossible.

## 3. Next construction selection

A new collision-based approach must implement a *local fiber transfer* in which the full original witness provides a way to compute a key-bearing representation, not just another member of a publicly identifiable fiber. One possible abstract interface is Build(x,r) generating a target and two encodings, with Lift(x,w,target,encodings) producing a pair whose invariant is the same r for every qualifying original w. This interface alone is circular and is not a primitive assumption to invoke. The mathematical requirement is a source-conditioned relation among the chosen builder points and original witness representations, generated without knowing future w, with no global hidden period and with a joint full-public simulator. Merely adding the original NP predicate as another branch of a public collision map, salting the fixed point tests, using a public equivalence-class identifier, or increasing the key width does not implement that transfer. Do not spend another run on these variants.
