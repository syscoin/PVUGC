2026-10-19, `syscoin/PVUGC#1`, starting draft head `452392c6626e9a8852a64272ac4d17d85695d0c4`. This quantitatively strengthens Run 631 for randomized witness preprocessing; it is NOT a secure WKEM, a new post-quantum assumption, or a claim about CCMR/RIO implementations.

**Exact model.** Classical PPT setup publishes the entire claim/UTXO, relation, branch, context, native checking key and digest, all capsules and auxiliary public correlations `P`. For any fixed ORIGINAL-valid `w` and fixed good `P`, public randomized preprocessing outputs a *complete* `b`-bit state `S`; no private witness service remains. Public polynomial-size classical `F(P,s;r)` performs release and native signing using independent coins `r`; public native verification gives `q(s)=Pr_r[Verify(pk,d,F(P,s;r))=1]`. Adversaries are arbitrary QPT with unrestricted public-byte processing, arbitrary auxiliary advice, and coherent evaluation of the actual published circuits, but NOT a fictitious hidden source-gated oracle.

Assume `E_S q(S)>=1-eps` and **conditional** `max_s Pr[S=s|P,w]<=2^(-h)`. Then

`Pr_{s uniform,r}[Verify(pk,d,F(P,s;r))=1] >= 2^(h-b)(1-eps)`.

**Proof:** `1-eps <= sum_s Pr[S=s]q(s) <= 2^(-h) sum_s q(s)`; divide by `2^b`. BBHT/amplitude amplification finds an accepted native signature in `O(2^((b-h)/2)/sqrt(1-eps))` coherent public evaluations. It does not need `w`, a sampler for legitimate states, the erased seed `K`, or SOURCE computation. This is tight: uniform `S` on any hidden set of size `2^h`, accepting exactly that set, attains equality. For a smooth distribution within total variation `nu` of a min-entropy-`h` distribution, replace `1-eps` by `max(0,1-eps-nu)`. Per-package bounds do NOT follow merely from average conditional entropy across bad packages.

**New local-gauge application.** If public rerandomization of any good release state has a distinct orbit of size `T` and every orbit element successfully signs with probability `>=1-eps`, the same attack takes `O(sqrt(2^b/[T(1-eps)]))` public evaluations, even without knowing the initial state. Appending `t` independently accepted gauge bits raises both `b` and `log2 T` by `t` and buys no search security; enlarging the accepted orbit *within the same width* makes this attack faster. Randomized state mixing cannot be credited as hidden-key entropy unless the effective **residual** gap `b-h` is accounted for. Diagnostic: `b=384,h=256` gives an attack bound near `2^64` public evaluations at high correctness; `b=512,h=256` gives near `2^128`. These are NOT practical parameter approvals.

Honest setup suffices; malicious setup and key correlations remain separate obligations. The checker uses simple XOR gauge orbits only as finite diagnostics. This attack yields an accepted **native signature**, not necessarily the precise Run-259 complete representation or ORIGINAL evidence.
