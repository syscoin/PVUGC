## A concrete source improvement, not a source security repair

R26's Build publishes sigma=H(Delta*mu*e0+e), with H a full-rank left-kernel basis of public Boolean-quotient clause matrix B in F_q^(m x L). Its Lift has to solve omega*H=lambda_w for each valid ORIGINAL witness w, where lambda_w is its witness-specific square-free Boolean evaluation vector. This run replaces H by a **canonical systematic basis** so there is no per-witness Gaussian solve or need to construct the m x m row-operation matrix used by the old checker.

Choose q an odd prime, deterministic square-free compiler and row ordering with e0 the empty-monomial row. From B=B(R,x), deterministically select ordered independent pivot rows P=(p1,...,pr), r=rank B, and nonpivots N in original order, k=m-r. Select r independent columns Q of B_P; G=B[P,Q] is invertible. Define A_j=B[j,Q] G^-1 for each j in N. Verify all row identities B[j,:]=A_j B[P,:]. Define S in F_q^(k x m) by S_N=I_k and S_P=-A (in row order P,N). It follows directly that SB=0, rank S=k, ker S=Im B. All choices and checks are classical polynomial time, public and deterministic.

**Build_sys(R,x,K)**. Bind the ORIGINAL NP relation identifier, claim/UTXO, source branch/path, anchors/window/context, native intended verification key and precommitted signing capability to one authenticated descriptor. The honest ceremony already supplies K (an optional keyless Build is not proved). For every capability bit mu, independently sample centered bounded coefficient noise e from public D_e. Publish the k-symbol syndrome

tau_mu = (e_N - A e_P) + Delta*mu*((e0)_N - A(e0)_P) mod q,

with canonical checking-key/context generated by publicly specified reproducible algorithms and genuine native vk. Neither the original witness, uniform affine mask r nor a SourceOpen oracle is used by Build.

**Lift_sys(R,x,tau,w)**. Verify the ORIGINAL relation and compile w to its own Boolean extension a OFF CHAIN. Compute only lambda_a[j]=product_{i in row mask j} a_i for j in N. Let z_a=sum_{j in N} lambda_a[j]*tau[j] mod q; decode each bit and check the assembled native signing key against its precommitted native vk before signing the intended challenge path. No common witness, canonical preimage or common intermediate state is required. Every valid ORIGINAL witness has lambda_a B=0 and lambda_a e0=1. From B_N=A B_P follows lambda_P=-lambda_N A. Thus lambda=lambda_N S, so for every v:

lambda*v = lambda_N*(S*v).

In particular z_a = Delta*mu + lambda_a*e. Therefore all valid ORIGINAL witnesses recover the SAME precommitted capability on R23's simultaneous correct-decoding event; the statistical tail bound still uses m independent original noise coordinates, **not k**. Different witnesses can have different raw noise terms but decode identical bits. R22 same-base public derivatives obey S(C+B*u)=SC exactly. Independent bases use independent e and authenticated context.

## Quantified useful efficiency

R26 per-witness Lift solves a length-m by k linear system for omega; here its unique omega is literally lambda_N. Per witness: k monomial evaluations and a length-k dot product, no Gaussian elimination. R26 tracked an m x m row-operation matrix to construct H; here A is built once by ordinary pivot selection and a single r x r inverse, and may be kept implicitly. Explicit stored H material shrinks from k*m to k*r field elements plus pivot indices (saving fraction k/m), while the k-symbol capsule itself does not get smaller. This improves a surviving restricted component without changing its security game, INCLUDING its attacks.
