# Run 691 — Generic NP same-capability WKEM implies bit witness encryption

**2026-10-21; mathematical dependency theorem, NOT a practical construction.** Live start: `syscoin/PVUGC#1`, draft/unmerged, branch `research/pq-wkem-validation-20260918`, SHA `84ef43846b143dde75eba52f0aced0c5e1f63c5d`. Builds on exact live Run 259 source binding (blob `c7f3b77f0273ca1cbe6f0b31c1a086b8eb3acbf2`) and Run 690 total-reversible projection scope. Latest substantive ordinary PR comment is `6241612333`.

**Statement.** Suppose classical PPT `Setup_R(x)->(V,K)` and `Recover_R(V,x,w)` work for arbitrary NP relations R. `K` is an exact polynomial-length binary credential; V contains the complete public view, including native `PK(K)`, the chosen statement and UTXO/branch/context, all capsules, auxiliary values and public evaluation programs. Assume every valid ORIGINAL witness (including adaptively selected witnesses) recovers this SAME K with the stated high probability. Assume that for each false x, **exact K recovery from the complete V** is negligible for arbitrary uniform QPT adversaries with reproducible classical/public auxiliary data. This is an explicit premise; signature EUF by itself does not imply it.

**Black-box conversion.** Define one-bit witness encryption by `Enc(x,m)`: sample `(V,K) <- Setup_R(x)`, uniform `a <- {0,1}^{|K|}`, and output `(V,a,c=m XOR <K,a>_2)`. Decrypt with a valid witness w by recovering K and removing the parity mask. This preserves all-witness correctness and allows distinct witness-dependent intermediate states.

For false x, a QPT distinguisher between ciphertexts for m=0 and m=1 yields, through a uniform-bit hybrid, a QPT predictor of `<K,a>` with nonnegligible advantage. Repeated classical-input/classical-output invocations of that predictor on the SAME V, varying a, feed the ordinary Goldreich–Levin Hadamard list decoder. The decoder yields a polynomial-size list containing K with nonnegligible probability. Return one random list member to recover exact K with nonnegligible probability, contradicting the premise. No quantum rewinding or programmable QROM is needed: predictor executions use fresh quantum workspaces. A one-use setup-correlated quantum advice state that cannot be reproduced is **outside this scoped proof**. QPT coherent access to public programs is allowed. The classical GL list-decoding lift, not a new cryptographic assumption, is the reduction target.

**Consequence.** A generic-NP release compiler meeting the original exact-capability and false-instance hiding obligations already gives one-bit WE. Thus shrinking protection to a local frontier may improve implementation size, but it does NOT make the *generic-NP functionality* cryptographically strictly weaker than WE. This is a conditional consequence, not a proof that WE is impossible or that full iO is required. A genuinely restricted, non-NP-complete Syscoin evidence relation may still permit a narrower primitive; allowing arbitrary embedded verifiers may destroy that restriction. Multi-bit/multi-capsule composition does NOT automatically follow: Runs 683–685 show selective-opening hazards.

**Attack/security scope.** The full native public checking-key correlation and chosen-input/coherent public-evaluation access are in V. Setup uses honest-erasure/N-of-N baseline, not malicious keyless builder security. Cross-UTXO replay and branch scope require exact x binding. This reduction does not authenticate a SOURCE representation, does not extract ORIGINAL evidence from native signatures, and does not protect a new mixer against seam, gauge, statistical fingerprint, malicious setup or correlated-capsule attacks. Run 259 only applies once an accepted complete SOURCE representation exists. All practical 128-bit/QPT release, full-public false hiding, true-instance extraction, N-of-N/abort and P2MR/SLH implementation obligations remain **UNPROVED**.

**Executed check.** `run691_published_check.py` is a deterministic standard-library finite calculation of exact public-key-leakage/posterior parity distance: for secret K with h unknown bits, the distance between `(V,a,<K,a>)` and `(V,a,U_1)` is `2^(-h-1)`. The three small exhaustive fixtures passed; the captured JSON records 5,376 cells. Extended local proof/checker validates five grids and a toy Walsh decoder. These are algebra checks, not quantum-security experiments or an implementation of WKEM.
