# SSTO: same-scope threshold-open SOURCE-LWE and native preauthorization

**Actual advance, strictly restricted:** the prior ISOC theorem could disclose full keys and LWE encryption coins of *independent* scopes, not same-key copies, because an opened ordinary LWE ciphertext reveals its bit. SSTO explicitly changes the classical release compiler: XOR-share the one canonical precommitted native signing key into h independent share lanes, LWE-encrypt every lane bit in every related capsule, and permit an adaptive QPT adversary to open any h-1 **entire same-key lanes** (plaintext shares and all encryption coins) and still attack the unopened native challenge. All valid ORIGINAL binary-ISIS witnesses recover the SAME native signing key. The narrow security theorem is instantiated under ordinary nonuniform-QPT decisional LWE and native QPT EUF-CMA, but only for uniformly generated FALSE binary-ISIS sources. This does not solve chosen-FALSE, hard-TRUE, generic NP, arbitrary key recovery -> ORIGINAL witness, or malicious setup.

## Distribution and release

For security parameter lambda choose prime q, d,n, bounded independent errors chi in [-B,B] and bit gap g with g>2B(n+1), 2(g+B(n+1))<q. Uniformly sample A in F_q^(d x n), t in F_q^d independently of signing keys. SOURCE relation R((A,t),w) checks w in {0,1}^n and A w=t mod q. For independent scopes i, native classical-PPT KeyGen gives true (sk_i,vk_i), with canonical sk bit encoding k_i of length ell_i. For h>=2, sample h-1 independent uniform bitstrings u_i,1..h-1 and set u_i,h = k_i XOR u_i,1 XOR ... XOR u_i,h-1. No two lanes are independent native keys: they are XOR shares of the SAME target native secret.

For every scope i, share lane a, bit j, and each polynomially many related capsule r, independently sample s_iajr uniform F_q^d, e_iajr <- chi^n, e*_iajr <- chi. Publish actual SOURCE-dependent beta_iajr=A^T s_iajr+e_iajr, tau_iajr=t^T s_iajr+e*_iajr+g u_i,a[j] mod q. The whole view includes relation/statement, every ciphertext and sibling capsule, true vk_i, canonical context binding claim/UTXO, branch, source anchors and observation window, credential policy and intended challenge path; genuine native P-domain preauthorization signatures are generated under sk_i. Classical-PPT signing policy may adapt messages to actual public ciphertexts, contexts, earlier signatures and sanctioned disclosures, not unopened native keys/coins/witnesses except via native Sign callback. C-domain challenge signature must not have been preauthorized under the exact native signing-message semantics. No Bitcoin NP verification or proof/VM steps are assumed, and native no-EC path/PQ signatures remain hypothetical.

An allowed *whole-lane opening* reveals all plaintext bits u_i,a and all (s,e,e*) coins for that lane's every bit and related capsule. Adaptive attacker may open <=h-1 complete lanes of its eventual target scope and all permissible independent sibling scopes. It may never open the last lane, learn target sk from any external channel, or request native Sign for the challenge message. No per-bit cross-lane opening policy (which can reveal all key bits), correlated keys/secret-dependent auxiliary leakage, malicious issuer or quantum superposition Sign/Open queries are in this theorem. Attacker itself is arbitrary nonuniform QPT with independent advice and coherent quantum memory; opening and signing queries are classical.

For any valid ORIGINAL binary w, tau_iajr-w^T beta_iajr=g u_i,a[j]+e*_iajr-w^T e_iajr mod q. Error magnitude <=B(n+1), so both distinct ORIGINAL witnesses and all related capsules round correctly to the same lane bits. XOR all h lanes yields the precommitted canonical native sk_i. Public release requires no common witness representation; the different witnesses can retain different states.

## Full joint QPT hybrid theorem (random-FALSE only)

Set p=Pr_uniform A,t[exists binary w:Aw=t] <= delta=2^n/q^d. Uniform source conditioned FALSE has statistical distance exactly p from unconditioned uniform source, and any joint source-capsule-native-signing/opening/QPT transcript is a channel, so source conditioning costs p ONCE.

For target scope i and lane a define E_i,a: attacker chooses never-fully-opened scope i, produces fresh accepted C-domain native signature (or actual canonical key that signs), and a is the **least indexed never-opened lane**. E_i,a partition success. Fix (i,a). A straight-line reduction samples real A,t, all native keys, true XOR shares, actual sibling ciphertexts and authentic adaptive native setup signatures. For every target lane a ciphertext vector, one at a time, replace ordinary source LWE vector y=[A^T;t^T]s+[e;e*] shifted by g u_i,a[j] in its final coordinate with uniform y shifted by that bit. The LWE challenger supplies uniform M=[A^T;t^T] and challenge y; the reduction knows target sk at every LWE hop and can simulate **all** other source-dependent ciphertexts, true checking keys, adaptive P-signatures and all coins/openings for other lanes/scopes. Abort/score 0 if attacker opens lane a: E_i,a was then impossible. Thus each entire joint adaptive transcript hop reduces to ordinary nonuniform-QPT single-vector decisional LWE, without an oracle for SOURCE opening or arbitrary-quantum rewinding.

In the final game all ciphertext vectors of protected lane a are uniform independent of their plaintext. Crucial exact XOR-share identity: **for every fixed canonical sk**, even nonuniform and correlated with vk, the OTHER h-1 shares are mutually uniform and independent of sk. A native EUF challenger supplying only real vk_i and a classical Sign oracle therefore permits the reduction to sample every other lane/share/coin with the exact distribution, output uniform target lane ciphertexts, generate real sibling scopes and relay adaptive target P-message signatures through the genuine native oracle. Any fresh accepted C-signature forwards as EUF forgery; any recovered canonical native sk is used to sign a fresh unsent C-message and forwarded. Arbitrary QPT processing of the joint classical output is straight-line simulated.

For fixed source shared by scopes:
Pr_{uniform | FALSE}[winning] <= p + SUM_i SUM_a (SUM_{j=1}^{T_ia} Adv_QPT_DLWE(B_iaj) + Adv_QPT_native_EUF(C_ia))
<= delta + (SUM_i SUM_a T_ia) epsilon_LWE + (SUM_i h_i) epsilon_native.
T_ia counts every ciphertext bit and related capsule in protected lane a. If sources differ across scopes, source-conditioning losses need appropriate union treatment, not this one p. Nonuniform advice is independent of hidden native secrets except through the specified view; the native signer accepts only classical queries. No QROM extraction, SIS assumption, structured SOURCE hardness, or volunteer representation assumption is used. The bound is asymptotic and **not a concrete 128-bit estimate**. Ciphertext field-element volume increases by factor h; for h=3, 512 key bits and 2 capsules, 3072 vectors instead of 1024 (n+1 elements per vector).

## Fatal chosen-FALSE and ORIGINAL gap (not repaired)

For publicly chosen FALSE A=[1], t=[3] in F_257 no binary w satisfies Aw=t. Yet public nonbinary z=3 solves Az=t and tau-z beta =g u+e*-3e on EVERY share lane, with |e*-3e|<=4 at B=1,g=64. It recovers all 512 bits of all three shares and thus the complete native master, with zero openings, then signs an accepted challenge. The executable checker tests this explicit failure. Ordinary QPT-LWE cannot imply chosen-FALSE security for this source. Planted hard TRUE sources are statistically unlike the uniform-FALSE source, so no hard-TRUE extractor is established.
