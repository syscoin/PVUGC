# Run 575 — public unary-orbit enumeration barrier for late-witness release

Date: 2026-10-16. Repo: syscoin/PVUGC PR #1, branch research/pq-wkem-validation-20260918. Starting verified head a7e52011789254acdbdd1cc3f7279ea241ce8dd3. One new bounded research result; no production changes.

## Targeted interface, not a claimed CLZ break

Honest setup is classical PPT and publishes a fully specified claim/UTXO/branch context x, an initial protected capability-bearing object c0, a **single fixed publicly evaluable unary transition** Phi, a finalizer Out, and the intended native signing verification key. The ONLY late-witness influence on the capability-bearing computation is choosing the number t(P,w) of Phi iterations, with 0 <= t <= T(lambda,|x|), where T is a public polynomial. Out receives the resulting object and P, but no extra witness-dependent encrypted input, sidecar or secretly issued key. Public Test(P,k) checks that a candidate capability yields a valid native signature on the intended branch/message; several different candidates may pass. Every ORIGINAL-valid w produces an accepted credential with probability >= 1-delta. Intermediate states may vary with w.

**Theorem (unconditional):** For every true x, a classical PPT attacker without any ORIGINAL witness succeeds with probability >= 1-delta. Enumerate c0, Phi(c0), ..., Phi^T(c0) incrementally; at each state run Out and Test. A valid witness's chosen t occurs somewhere in this list, and the attacker can run the same finalizer there with independent coins. Costs: <=T applications of Phi, T+1 finalizations and T+1 public checks. Neither malformed ciphertexts nor homomorphic combination nor secret setup randomness is needed. This conclusion applies with arbitrary QPT attackers because the successful adversary is classical. Unique checking is NOT required; any valid native signing credential is sufficient. A publicly enumerable polynomial-size complete family of release states has the same weakness even without a unary transition.

**Hard-YES corollary:** For an assumed QPT one-way injective function f, take the ORIGINAL relation R((b,y),w)=[b=1 and f(w)=y]. True random instances x=(1,f(u)) require inversion of f to find ORIGINAL w, but the orbit enumerator obtains an accepted signing credential without w. Any claimed uniform QPT transformation from every accepted credential/signature to a valid ORIGINAL witness (using public/setup coins and no hidden witness trapdoor) would invert f. This is a conditional impossibility only for this interface, not a proof that suitable one-way functions exist. False b=0 instances remain logically false; the theorem alone does not prove hiding or its failure.

**Generic-NP corollary:** Suppose the above uniform compiler works for arbitrary NP R and its false-instance game forbids **every** accepted native signature with negligible probability for **each** false x. Generating P, enumerating the polynomial orbit, and applying Test is a randomized polynomial decider for the NP language: true instances are accepted with high probability and false instances rejected with high probability. Thus the combined claims imply NP subset BPP. This is a conditional complexity obstruction, not a proof that NP differs from BPP; if false security is only distributional, only a distributional conclusion follows. A restricted Syscoin relation does not automatically imply the generic collapse.

**Minimum admission capacity:** For q selectable public transforms of length <=T, the number of syntactic trajectories is <=sum_{j=0}^T q^j. With q=1 this is T+1. Two choices with long input sequences can avoid polynomial enumeration, but **do not establish security**: source authentication and attacks on local seams, gauge alignment, overlapping views, adaptive evaluation, malicious setup, cross-claim reuse, public-key correlations and coherent quantum access still require proofs. Efficient random-access jumping to exponential indices also lies outside this sequential-iteration theorem.

**Scope:** Does not apply when the valid watcher inserts a new witness-dependent protected state, supplies an authenticated sidecar to the finalizer, uses nonenumerably many transformations, or consumes a witness in the protected release region. Those are unresolved possible escape routes, not completed constructions. A permissionless watcher cannot require an online secret-release authority. The publicly output capability must be bound to the intended challenge branch; Bitcoin still verifies only an ordinary conditionally assumed native signature and preauthorized graph conditions.

**Relation to actual CLZ:** The abstract of Canetti–Luo–Zhang, CRYPTO 2026, describes controlled public repeated application of a fixed length-preserving function alongside functional decryption and other capabilities. This checkpoint only eliminates a narrow WKEM adaptation where **iteration count is the sole late-witness channel**. It does NOT cryptanalyze CLZ's encryption/security proof, nor CCMR's local mixing, nor establish their QPT applicability.
