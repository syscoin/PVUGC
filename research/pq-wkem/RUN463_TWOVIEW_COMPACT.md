# Run 463 — paired injective forward views create a Simon period

Live draft `syscoin/PVUGC#1` read first: branch `research/pq-wkem-validation-20260918`, head `1c500b2b59dc4deb9d5a9625ed21dae76c1f389e`; latest ordinary comment `6067040320`. Exact Run 259, Run 459, Run 461 and CLZ applicability notes checked. Research only; production unchanged.

**Narrow new attack relative to Run 462.** Let `P` be any `n`-bit bijection and secret `Delta`. Individually injective public forward functions `F0(z)=P(z)` and `F1(z)=P(z XOR Delta)` have no internal XOR periods, yet the combined public coherent evaluator `G(b,z)=F_b(z)` has the *exact* Simon period `(1,Delta)`. Equality of outputs forces either identical `(b,z)` or the pair `(b XOR 1,z XOR Delta)`. A uniform-QPT adversary reversibly evaluates the two classical public programs in superposition. Fourier sampling returns `(a,v)` with `a=<v,Delta>`; `q=n+kappa` samples recover Delta by GF(2) elimination except with probability `<2^(-kappa)`. No quantum oracle service or rewinding is needed. This is an application of Simon (SIAM J. Comput. 1997), not an attack on actual CCMR/CLZ or a new hardness assumption.

**Output-label synchronization lemma.** For *any* deterministic `G:{0,1}^N->Y`, the same Fourier procedure satisfies `E_y[(-1)^<y,p>] = Pr_z[G(z)=G(z XOR p)] = C_p`, hence `Pr[<y,p>=0]=(1+C_p)/2`. Proof: expand Fourier amplitudes `2^(-N) sum_{z:G(z)=u} (-1)^<y,z>` and apply character orthogonality to input pairs. If the second view is relabeled by permutation `L`, then `C_(1,Delta)=|Fix(L)|/2^n`. A derangement removes this *particular* linear bias, not all quantum attacks. If `L` is publicly invertible, normalizing the second output immediately restores the exact Simon period.

**Scope.** If a vulnerable scheme derives its branch signing credential as public `KDF(Delta, bound_context)`, extracted Delta gives witness-free accepted native authorization on the same branch (for true or false source statements). If Delta is harmless and does not determine authority, signature compromise does *not* follow. Literal public reversible gate lists also expose `P^{-1}`, allowing a simpler classical attack; the QPT statement is relevant to forward-only, potentially obfuscated public maps whose inverse is not provided. No classical white-box lower bound claimed.

**Executed evidence.** `run463_compact_check.py`, Python standard library, passed 504 deterministic assertions, twice byte-identical, on eight toy pairs (`n=3..6`). It exactly enumerates joint Fourier probability amplitudes, period hyperplanes and the public output-derangement/normalization case. Extended local-only checker additionally solves Delta from sampled quantum outcomes and performs a non-PQ Ed25519 conditional-signature diagnostic (1,031 assertions). Toy permutations are trivial to invert and tests establish no security.

**Attack ledger.** Global frame synchronization + related views + coherent chosen-input Simon sampling are decisive. No seam, gate-class fingerprint or malicious setup is required. Context binding stops replay, not disclosure of same-context `K`. Public verification keys cannot conceal a leaked credential. Arbitrary auxiliary quantum advice is allowed but unused.
