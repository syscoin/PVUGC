## The conditional construction attacked

Classical PPT setup generates an independent hidden native signing capability K and secret authentication key alpha. It publishes a capsule encrypting `(K,alpha,context,a=0,u=0,tag=0,workspace=0)`, a fixed public release rule, and the correct native verification key. Release outputs **unchanged K** iff `a=1` and `tag=Auth_alpha(context,a,u)`.

Suppose public callers may choose polynomial-length sequences drawn ONLY from three local reversible operations on encrypted bits: NOT(target), CNOT(control,target), and TOFFOLI(control1,control2,target). The public evaluator can use secret alpha bits as **controls**, but K, alpha, and context are **read-only** registers: operations may target only the acceptance bit, late witness input, tag and zero scratch bits. No cryptographic enforcement of the source-specific instruction *sequence* or transition provenance is supplied.

**Theorem (classical PPT bypass):** For any efficiently computable Boolean Auth with circuit size s, a public algorithm with no knowledge of alpha or K synthesizes O(s+|u|+|tag|) permitted gates that change a from known zero to one, install arbitrary u*, compute Auth_alpha(context,1,u*) on encrypted controls, XOR the result into the tag, and reverse the computation to clean every scratch bit. All protected registers remain unchanged. Release then yields K on any ORIGINAL-false instance, without an ORIGINAL witness. The arbitrary native branch signature under the correct published verification key follows. If gate/release/signature errors are eps_eval,eps_rel,eps_sig, success is at least 1-eps_eval-eps_rel-eps_sig.

**Proof:** Each XOR and NOT gate of the known Boolean Auth circuit embeds into a reversible CNOT/NOT operation; each AND embeds into Toffoli with a fresh zero target. The full circuit retains its inputs and accumulates scratch bits. Copy the output into the tag using CNOT, then run the reversible circuit backward. The copy survives and all ancillas reset. Alpha is never exposed as plaintext and never modified. The attack does NOT forge the MAC in its usual game; it invokes its computation homomorphically on an encrypted secret. This is reversible-circuit universality, not a new cryptographic assumption.

## Scope, source binding, and threat model

This attack specifically requires chosen **gate schedules and wire addressing**, including alpha as a control and the acceptance/tag as writable targets, plus state-predicate-based release without source-transition provenance. A fixed, cryptographically enforced verifier transition schedule may avoid it. Neither CLZ's obfuscated-forward fixed-unary construction nor Canetti–Chamon–Mucciolo–Ruckenstein RIO automatically offers the attacked API; no claim of breaking those works is made. This is stronger than merely observing an arbitrary-circuit Eval bypass (Run 475): it shows a constant-size local gate whitelist and read-only protected secret registers do not suffice.

The entire adversary is classical PPT, hence also an allowed arbitrary-QPT adversary. Honest setup fails even with independent contexts/capsules; no auxiliary hints, malicious seeds, replays, gauge alignment, fingerprint leakage, or quantum oracle assumptions are required. The fixed verification key is used for the same intended context, not cross-UTXO replay. The recovered signature has no accepted COMPLETE source representation; Run 259's information-theoretic fold or conditional SIS arrow is inapplicable. Missing: unauthorized native authorization -> accepted COMPLETE z or independent QPT break.

Taxonomy: (1) acceptance/tag seam; (2) no gauge; (3) no statistics; (4) independent capsules are individually attackable; (5) adversarial gate scheduling is decisive; (6) honest setup already fails; (7) same-context attack; (8) native key/checking key match; (9) classical attack within QPT, not a genuinely coherent quantum attack.

## Executed evidence and limits

`run478_compact_check.js` was run in a deterministic V8 JavaScript execution. The captured `run478_compact_validation.json` records 27,970 passing checks, 429 allowed gates, 169 wires, 64 false-instance unauthorized releases, read-only protected registers, and zeroed workspace. Its 8-bit keyed nonlinear tag is deliberately NOT a secure MAC; the theorem applies to any public polynomial-size Auth circuit. Separately, a local-only extended Python checker passed 530 assertions, including 36 Ed25519 native-signature verifications and 36 cross-context rejections; an independent local Node.js checker passed 21,666 assertions. Those use ideal gate semantics, not actual encrypted FHE/FE, and Ed25519 is NOT post-quantum. Reproducibility is an algebra/circuit-semantics check, not 128-bit security evidence.
