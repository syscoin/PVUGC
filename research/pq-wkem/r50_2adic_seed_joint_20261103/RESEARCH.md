## Lemma A: strong joint-coupling simulation of TRUE seed capsules would solve search-LWE on EASY-TRUE ORIGINAL instances

Let (x0,w0) be an efficiently generated genuinely TRUE ORIGINAL statement with *known* valid w0, in the generic NP class. Every valid witness deterministically opens R49's honestly prepared seed capsules to (s,e), up to correctness error eps. Suppose a QPT simulator Sim(A,Y,x0) reproduces the **joint distribution (A,Y,Z)** (or a stronger full view containing this correlated projection), to any QPT distinguisher including one supplied w0, without knowing the challenge seed.

Define T(A,Y,Z): use the real ORIGINAL opening algorithm with w0 to get (s',e'); accept iff e' is in S_b^m and As'+e'=Y mod q. T accepts the honest joint distribution with probability >=1-eps. Its acceptance on Sim's output therefore remains >=1-eps-negl under the stipulated QPT indistinguishability. A straight-line QPT search-LWE solver, given (A,Y), runs Sim once, opens with known w0, checks T, outputs any consistent (s',e'). No rewinding, quantum lifting of a classical extractor, SourceOpen oracle or adversary-supplied internal representation is assumed. Under independently justified QPT search-LWE security for this exact distribution, **such a universal strong joint-coupling simulator is impossible**.

CRITICAL SCOPE: Y is not an independent public field in R49. This does **not** prove every public-marginal-view simulator impossible; one could ignore the supplied Y and generate independent capsules, but that does not establish the needed challenge-secret-dependent hybrid. The argument is only for a strong embedding that genuinely correlates supplied challenge Y with opened capsules. It also does not exclude a different simulation restricted to hard-TRUE x where the reduction does not know a witness, or imply generic WE impossibility. An adversarial opening or arbitrary QPT native forgery does not thereby yield ORIGINAL w.

## Lemma B: honest R49 matrix gives an almost surely unique narrow-error seed, with a CORRECT 2-adic bound

Naively borrowing R47's prime-field uniform-row collision bound is invalid for q=2^t: for nonzero delta s with 2-adic valuation r=min_i(v2(delta s_i)), each row A_i*delta s is uniform only on subgroup 2^r Z_q of size 2^(t-r). With errors in consecutive alphabet of size h, its difference set is [-(h-1),h-1]; this intersects the subgroup at d_r=2*floor((h-1)/2^r)+1 residues. There are N_r=2^((t-r)*n)-2^((t-r-1)*n) nonzero delta s with exact valuation r. All m rows independent. Thus for a uniformly drawn A, *even allowing competing seeds chosen after A*,

Pr[exists distinct (s,e),(s',e') in Z_q^n x S_b^m with As+e=As'+e' mod q]
<= min(1, SUM_{r=0}^{t-1} N_r*(d_r/2^(t-r))^m).

For delta s=0, injective e modulo q precludes distinct pairs. No hardness assumption is used in this bound. In R49's **illustrative, not security-validated** t=16,n=256,m=4096,b=4, r=15 contributes <2^-3840, r=4..14 each <=2^-7680, r=0..3 each <2^-40960, so the bound is **<2^-3839**. This is not evidence that the underlying LWE parameters resist quantum algorithms. It only closes a seed-representation collision calculation.

The exact published executable checks toy t=3,n=1,m=3,b=1: among 512 possible A matrices 116 are noninjective, actual probability 29/128, while the bound's three terms are (27+4+16)/128=47/128.
