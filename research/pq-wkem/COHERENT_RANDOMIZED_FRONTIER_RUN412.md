**Candidate and exact game.** A classical PPT setup publishes a public locally mixed package P_x and native checking key vk_x for x=(relation identity, UTXO/claim, branch, BTC/SYS anchors/window/context). An independently callable *public* classical randomized release algorithm M(P_x,u;r) has selectable d-bit input u and c-bit public random tape r, outputs a candidate capability K or bottom. Define G_x(u,r)=1 when the candidate lets anyone construct a fresh branch-bound native signature accepted under vk_x. The entire public evaluator and checking-key correlation are visible; an arbitrary QPT adversary can reversibly simulate both and select coins coherently. This is the standard-model public-code model, not a privately stateful API; QROM access requires separately specifying its quantum oracle model. Other capsules, public auxiliary data and known keys from other claims may be present; the one-capsule attack needs none.

**Theorem (density-aware quantum public-evaluator search).** Let a_x be the number of accepting (u,r) pairs among 2^(d+c), and mu_x=a_x/2^(d+c)>0. Public amplitude amplification finds a pair yielding a usable capability in O(1/sqrt(mu_x)) coherent evaluator/check calls (constant success probability), with polynomial gate overhead per call. Proof: coherently compute G_x into a phase, uncompute the workspace, and reflect the uniform input superposition about itself; its initial accepted squared amplitude is mu_x, so Grover's 2-dimensional rotation yields the stated bound. For mu_x>1/2, classical random sampling is already O(1). This query bound is generally exponential, not automatically QPT.

If h distinct witness-dependent **frontier states** u each yield a working common branch capability with public-coin success at least p, then mu_x >= h*p/2^d and quantum query cost is O(sqrt(2^d/(h*p))). Unlike Run403's one-state/deterministic enumeration, the random-tape dimension cancels and the number of distinct accepted states matters. For an illustrative 128-bit *quantum-query* margin against this attack alone, one requires roughly d-log2(h*p)>=256. This is neither a recommendation of parameters nor a concrete gate-cost estimate.

**Critical source-binding fork (Run259).** An accepting u is not automatically an unauthorized bypass. If (u,r) supplies an **accepted complete source representation** and Run259's exact residual/extraction conditions hold, a quantum searcher may merely have discovered an ORIGINAL witness, which is allowed. A false ORIGINAL statement has no such witness: every G-accepting pair is an unsound ghost, so any nonnegligible mu is a QPT false-instance key-recovery failure. A true statement with both source-bound and ghost pairs requires analyzing the fraction of ghosts; finding a valid accepted pair alone is NOT an extraction failure. Arbitrary recovered K/signature does not intrinsically supply a Run259 representation. No generic sound mixer is refuted.
