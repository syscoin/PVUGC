## A bounded conditional theorem — not a cryptographic construction

Let R(x,w) be an NP relation. Assume classical PPT honest setup can be centrally simulated as Gen(x)->(P,K), K a poly-length native signing capability known to that simulator, while the real N-of-N honest parties erase/share their secrets. P includes the entire classical public view: verification key, programs, claim/UTXO/branch/context, related already-generated capsules and auxiliary public inputs. Every valid ORIGINAL w recovers exactly the same K, although its source state may depend on w. For a false x, arbitrary QPT cannot recover the complete K given P and all public evaluation interfaces. Public native-signature unforgeability implies this key-recovery property when recovered K suffices to sign. The converse need not hold.

Construct one-bit witness encryption: encrypt bit m by running Gen, then draw independent fresh uniform r in {0,1}^|K| and output (P,r,c=m XOR <r,K>). A valid w obtains K and decrypts. Suppose a QPT distinguisher D distinguishes bit 0 from bit 1 with nonnegligible difference eps. For classically chosen r, choose c uniformly and output c XOR D(P,r,c). With suitable output orientation this predicts <r,K> with advantage eps/2, because averaging over uniform c exactly simulates both possible bits. Classical-query Goldreich–Levin heavy-Hadamard decoding, using fresh QPT invocations, returns a polynomial-size list containing K with nonnegligible probability. Picking a random list member recovers exact K with nonnegligible probability. This contradicts false-instance key hiding. No quantum rewinding, QROM programming, or input-superposition access to D is needed.

Scope: arbitrary classical, copyable, K-correlated auxiliary data in P fixed before r; independent nonuniform quantum advice can be supplied in polynomially many copies. A single uncloneable K-correlated quantum auxiliary state, a malicious post-r oracle generating secret-dependent auxiliary information, and keyless Build that never computes K even in centralized simulation are NOT covered. This proves no QPT hardness for an actual release circuit and no true-instance extraction. A generic all-NP native-credential release API with this security would already imply one-bit WE, so claiming it is independently substantially weaker than WE merely because K need not be pseudorandom is not justified. A restricted Syscoin relation need not imply all-NP WE.

## Same-key multi-bit mask failure

A naive optimization sends t public GL rows r_i with c_i=m_i XOR <r_i,K> under one fixed K. For messages 0^t and 1^t, conditional ciphertext supports are im(R) and 1_t+im(R), where R is the t-by-n row matrix. Those cosets are identical if 1_t lies in im(R) and otherwise disjoint. Hence exact statistical distance over public (R,c) is Pr_R[1_t not in im(R)]. At t=n+kappa this is at least 1-2^-kappa by a union bound, independently of any checking-key leakage. Do not stretch one secret into many linear pads without a separate proof; independent capsules per bit can give a standard hybrid if their security game supports it.
