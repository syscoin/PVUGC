## 1. Actual witness-adaptive proof completion

Let G=G_x be the directed graph on n>=3 vertices, represented by a Boolean adjacency matrix. Let S be the directed cyclic graph on Z/n, with edges i->i+1 mod n. Build chooses a uniform permutation tau of n vertices and plants D=tau(S). It commits to a partial adjacency matrix of D with a fixed 1 on every planted edge, and a wildcard at every other entry. Concretely choose independent lambda-bit salts r_ij and publish

    c_ij = H_commit(ctx,i,j,type_ij,r_ij),

where type_ij=1 on the planted edges and type_ij=* elsewhere. The hash domains, lengths, context and encoding are injectively separated; ctx binds the complete existing claim/native endpoint/capsule context. The wildcard is explicitly a commitment to a wildcard, NOT a binding bit commitment that somehow opens to two different bits. Its specified verification permits either graph bit. Serialize the fixed challenge-1 opening (D, salts on planted edges), and the wildcard salts and types. All this is polynomial and can be sampled without a source witness. Salts are public here deliberately: test the source-adaptive completion first, not a hypothetical secret opening service.

For each qualifying original w, the assumed witness-translating compiler yields a directed Hamiltonian cycle W in G. Choose a bijection phi mapping W to D by walking the directed cycles in corresponding order. Challenge-0 response is phi and the matrix of G relabeled by phi, with the appropriate fixed/wildcard openings. It passes: every planted edge is a 1 in phi(G), and every other cell is unrestricted. This uses the same fixed commitment and challenge-1 opening for every W, even when W differs substantially. Conversely, a valid complementary response with a bijection phi, exactly relabeled G, and fixed ones on D implies phi^{-1}(D) is a directed Hamiltonian cycle in G. Thus it yields an original certificate under the compiler. Verification of the actual serialized partial-commitment records is straightforward; no fake collision or equivocation of a binding bit commitment is required. This is not a new ZK proof claim: the public challenge-1 opening is given in advance, the wildcard changes the ordinary protocol, and the complementary response directly supplies a witness.

Contrast ordinary binding commitments to the entire simulated adjacency matrix: those would force a particular complete graph before knowing w. Here allowing wildcards really enables the specified adaptive completion, without the occurrence mixing of independent local proof labels. It does NOT yet produce a secret. The following attempts to put the payload into the permutation itself.

## 2. Concrete transporter Build/Open

Build has tau and D. Let

    k = H_key(ctx,enc(tau)),
    y = H_check(ctx,enc(tau)),
    E = sigma_cancel XOR H_final(ctx,k; length).

Use independent hash domains and deterministic length expansion. Publish the partial commitment capsule from section 1, D, y, E. To remove exact-recovery ambiguity rather than rely on native verification or ordinary EUF, Build enumerates the n cycle transporters from S to D and checks that y identifies its tau uniquely. It can fail/retry before irrevocable funding (bounded retries and explicit failure; for an ideal lambda-bit H_check the chance of a competing match is at most (n-1)/2^lambda). No deployment or concrete SHA bound asserted.

Open on w constructs the complementary opening phi as above. Let psi_W:S->W be the directed cycle ordering of W. Then

    t = phi composed with psi_W

is an isomorphism S->D. The set of all such isomorphisms is exactly t Aut(S)=tau Aut(S). Aut(S) consists of the n rotations of the directed cycle: an automorphism is determined by the image of vertex zero, and adjacency determines all subsequent images. Open enumerates t composed with each rotation, checks y, selects the unique tau, computes k and recovers the exact precommitted sigma. This is a genuine classical-PPT algorithm and correct on every original witness when Build succeeds. No witness-specific fixed hash output is assumed and no cross-witness cancellation identity is used. The extractor of complementary proof openings yields original evidence, not the setup permutation; the explicit transporter enumeration is the new payload recovery step.

## 3. Full-public attack on the carrier

The directed planted cycle D is public as part of the fixed opening. Independently of G, w, phi, all challenge-0 responses and their existence, compute a transporter t_public:S->D by selecting any public D vertex as the image of zero and following the unique D successor n-1 times. This enumerates exactly the same n candidates as honest Open. Evaluate the same y check, obtain tau, then unmask E. The attack works for every successfully built capsule, including FALSE and hard-TRUE original statements. It recovers the EXACT sigma, not merely a same-message alternative signature, and it does not need a native verification oracle. It is classical PPT, so the required arbitrary QPT security already fails.

In particular the original-witness translation is real, but source authentication is not cryptographically necessary for the payload. A final honest-code check that a complementary proof was presented cannot repair this attack. No query logging, rewinding, or representation extracted from a malicious adversary is used. No hash is inverted beyond evaluating the polynomial candidate set. The whole public view can be sampled given tau and the native payload; the source proof transcript/partial commitment sampling can in fact be simulated exactly from D and public ctx using independent salts, without tau or w. That component simulation does not hide the correlated E,y: the public candidate enumeration tests the real key correlation. A simulator that replaces E by an independent random string fails this test (for a known candidate payload, except for the chance of a matching random string). No QPT simulator for the required capsule is established.

## 4. Specific repair: decorated skeletons, hidden stabilizers, and a different needed operation

One proposed repair is to use an arbitrarily complex publicly decorated skeleton S' containing the distinguished directed spanning cycle S, and D'=tau(S'), with a distinguished D cycle revealed in the fixed proof opening. Decorations could be intended to make graph isomorphism hard or uniquely determine tau. But any isomorphism required to preserve these distinguished cycles must lie in the SAME n-element transporter list. Enumerate by following D and test each candidate against every public decoration/adjacency entry. This is polynomial even if the full unmarked graph isomorphism problem were hard; unique decorations can only reduce the list. Thus no parameter sweep or added public graph gadgets repairs this particular carrier.

Another repair is to hide the marked cycle, or plant a skeleton with an exponentially large automorphism group, so public enumeration is no longer easy. Hiding D in the current design also removes the fixed challenge-1 opening used for the every-witness complementary proof. Restoring that opening by revealing D on demand from the actual source evidence is a new source-dependent key operation, not provided by the present commitments.

For a general planted S', if the proof view is generated from D'=tau(S') and independent randomness, then conditional on D' the uniform setup permutation is uniform on one right coset of Aut(S'). For any tau_0 mapping S' to D', composition tau_0 a with a in Aut(S') enumerates exactly all transporters bijectively. Fix any original w independently of setup (w need not be canonical). This conditional distribution is unchanged by w and by its deterministic/adaptively randomized complementary proof computed solely from D', public salts and w. Consequently a large stabilizer does not itself provide source-dependent selection of the particular tau: the source computation contains no additional information about which stabilizer element was sampled. This is an exact conditional-distribution observation about those components, BEFORE the public check y and payload E; those may reveal information about tau. It is not a claim that computational recovery from a full-public correlated capsule is impossible, nor a claim about adversarially correlated original witnesses in arbitrary future schemes. A source witness might provide computational help in a genuinely different construction. No such coupling is implemented here.

A separate tempting repair is to compose this challenge-response mechanism with an OR proof of original evidence OR knowledge of k. For independent sigma branches with total challenge e=e_source XOR e_key, keep the public key branch transcript fixed and let w change the source branch challenge. Special soundness from the two transcripts extracts only the witness in the CHANGED source branch; the key branch has the identical commitment, challenge and response. Forcing the key branch challenge to change would require a new response for that same commitment, which the above source completion does not produce. Publishing both key-branch responses allows anyone to apply its special-soundness extractor. This is a preflight of the straightforward OR-proof composition, not a QPT extraction theorem or a general impossibility for coupled proofs. Encrypting the missing response under an independent hash of each complete source transcript repeats the full-address correction failure/unconstructed common-output requirement, and was rejected before implementation.

The exact missing operation for this direction is a **witness-mediated hidden transporter or binding proof-opening correlation**: the *actual* original witness must enable a private component of the committed graph/opening to be recovered, for ALL valid witnesses, with a witnessless polynomial sampler and a joint simulator. The fixed directed-cycle construction instead makes all possible transporters publicly enumerable; the large-stabilizer variant lacks a coupling to the original witness. Do not treat a solver for graph isomorphism or an assumed proof-completion key as a hash-only foundation. No standalone graph-hardness assumption added.
