## Exact theorem and attack

Suppose the release frontier publicly accepts **any** `b`-bit input state `s`, with a hidden capability `K` returned iff `T^{-1}(s)` lies in a guard/acceptance set `A`, where `T` is *any* bijection (for example a reversible local mixer). Write `delta=|A|/2^b`. Even if implementation is ideally sealed and the attacker never learns `T`, the accepting set `T(A)` has **exactly the same cardinality**. Uniformly sampling a public input and evaluating the public release program yields `K` with probability `delta` per independent query, or `1-(1-delta)^q` in `q` independent trials. This is a classical PPT attack whenever `delta` is inverse polynomial.

If the public deterministic classical evaluator has polynomial circuit size, a QPT adversary can compute the `!=bottom` bit coherently, phase-flip it and uncompute. Grover success after `r` iterations is `sin^2((2r+1)asin(sqrt(delta)))`, giving `Theta(1/sqrt(delta))` evaluation queries at small `delta`. It does not need a rewinding extractor, superposition-access service, duplicated unknown advice, or a checking-key attack. **One freely writable acceptance bit gives delta=1/2 independent of state width and mixing quality.** With a 128-bit freely writable guard, generic quantum search costs `Theta(2^64)` queries, below a *concrete* 128-bit target. The `2^-256` density benchmark is necessary only for this ideal generic-search metric, not a security proof. Asymptotic QPT and concrete bit-work claims differ.

Toy ORIGINAL relation: true `x=1` has valid witnesses `w=0,1`, mapped to distinct guard-zero states, which release the SAME `K`; false `x=0` has no ORIGINAL witness, but a release frontier that trusts a **writable guard** still has a nonempty release set. A random outsider obtains `K` without producing any accepted Run-259 representation. Context-specific `T_x` does not remove the attack. This rejects only the accept-bit-only/free-input interface, **not** a source-enforcing frontier with empty release set on false instances or a hard-to-find witness-dependent acceptable set.

## Assumptions, taxonomy and boundary

Honest setup/evaluation: classical PPT for a *hypothetical* efficient public reversible circuit, arbitrary QPT adversary with all public outputs/verification keys/related capsules/auxiliary public data. The proof holds for every permutation. Local seam injection (1), public evaluation (5) and quantum coherent search (9) succeed; global gauge (2), fingerprints (3), multiview (4), malicious seed bias (6), cross-UTXO replay (7), or checking-key recovery (8) are unnecessary. The checker enumerates *finite permutation tables*, not scalable obfuscation; full-state coherent Grover probabilities and all-witness toy correctness are exact finite checks only.

The conditional quantum local-mixing treatment, Gheorghiu–Gupte–Havlíček–Liu arXiv:2609.40289v2 §6, explicitly requires joint-seam quantum RIO and split-circuit pseudorandomness; neither is instantiated here. Earlier Canetti–Chamon–Mucciolo–Ruckenstein local mixing is likewise not refuted by this free-input toy. Sources: https://arxiv.org/html/2609.40289v2 and https://eprint.iacr.org/2024/006 .
