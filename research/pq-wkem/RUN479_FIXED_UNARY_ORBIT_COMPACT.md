## Narrow interface and exact theorem

Classical PPT Setup(x) publishes an encrypted hidden capability K, its correctly bound native verification key, initial ciphertext C0 and a fixed public functional-release key. Public Step on ciphertext plaintext implements one deterministic unary F_x; public Refresh preserves plaintext. Functional release depends only on the current plaintext, returns the unchanged K (or its equivalent native authorization), and does not interpret ciphertext random coins as an alternate witness channel. Witness-aware honest Rec(P,w) can only choose when to stop and when to refresh. At most T=poly(lambda,|x|) **sequential** public Steps are allowed; there is no witness-dependent plaintext write, proof input, per-witness functional key, fast-forward oracle or online signer. Assume honest correctness failure epsilon and refresh/Step/release semantic errors totaling at most O(T delta).

**Orbit exposure theorem.** Every honest reachable plaintext is in the public orbit {m0,F_x(m0),...,F_x^T(m0)}. If any valid ORIGINAL witness recovers K and signs with probability 1-epsilon, then a classical polynomial-time attacker with no witness enumerates the T+1 public orbit points, tries the same Open and checks results under the public native key. It obtains K (or authorization) with probability at least 1-epsilon-O(T delta).

**Proof.** Induct on Step count: only Step changes plaintext, and Refresh preserves it. Thus any accepting honest depth j is one of 0,...,T. The attacker can reach and test each such depth without w. Correctness/semantic-invariance transfers the honest successful depth, and a union bound handles errors. No rewinding, quantum advice, or QROM programming is used. A classical attack is also an admissible arbitrary-QPT attack.

**ORIGINAL-extraction separation.** Let f be a QPT one-way function and R(x,(s,b))=[f(s)=x and b in {0,1}], with x=f(s) on a random s. Setup depends on x only; each true x has two valid ORIGINAL witnesses and may release at distinct orbit depths, both to the same K. The enumerator yields native authorization from x without s. Any efficient arbitrary-QPT signature-to-ORIGINAL extractor working on that public transcript and the witnessless attack algorithm would invert f: given inversion challenge x, perform public Setup(x), run the attacker and extractor and output s'. This is straight-line and covers complete independently generated public data including vk. Challenge-dependent quantum advice already containing s is excluded from the one-wayness assumption. Hence the required extraction implication is incompatible with such a no-input fixed-unary release API unless the QPT one-wayness assumption fails.

**Scope.** This is NOT a theorem about real Canetti–Luo–Zhang encryption, controlled homomorphism, RIO, obfuscated forward circuits, or any design admitting later witness data through a separate cryptographically restricted transition. The CLZ author-linked abstract describes arbitrary iterations of a fixed length-preserving g and prevents other homomorphisms; this result says only that **iteration count plus rerandomization alone cannot provide the missing late-input interface**. Source: https://simons.berkeley.edu/talks/ji-luo-mit-csail-2026-07-13 . Full paper/QPT assumption proof not audited.

**Relation to Runs 475/478.** Those falsify arbitrary writable encrypted transitions. This falsifies the opposite endpoint—no writable plaintext at all. It does not prove an intermediate restricted source-aligned admission primitive exists. Run 259 proves accepted complete representation -> ORIGINAL under its folding/SIS premises, but an orbit-derived signature need not supply a representation: the missing arrow remains native authorization -> accepted COMPLETE representation or QPT break.
