**Correction to Run 463's suggested defense.** Let P,L be arbitrary n-bit permutations with PUBLIC efficient forward evaluators, and Delta a hidden n-bit shift. A local mixer exposes F0(z)=P(z) and F1(z)=L(P(z XOR Delta)). Even when L is a derangement, so the raw combined pair has zero Fourier parity bias at (1,Delta), the adversary can compute H0(z)=L(F0(z)) using FORWARD L ALONE. Set H1=F1. Then H1(z)=H0(z XOR Delta), and G(b,z)=H_b(z) has exactly the Simon period (1,Delta). No inverse of L or P is needed. Uniform QPT coherent public evaluation, n+kappa Simon samples, and GF(2) elimination recover Delta with failure less than 2^-kappa. If the branch capability is K_x=KDF(context_x,Delta), this gives witness-free native signing authority. Otherwise, recovering a harmless Delta does not prove key compromise. This does not attack actual CCMR/CLZ/RIO interfaces absent such publicly available correlated maps.

**Sharp ideal-oracle separator.** If P and L are independently uniform HIDDEN permutations and only the forward-oracle pair (P, L o P o T_Delta) is exposed, its distribution is exactly two independent uniform permutations FOR EVERY Delta: for fixed oracle tables p,q, exactly one L=q o T_Delta o p^-1 exists. Therefore even arbitrary coherent quantum oracle access has ZERO information about Delta from this pair alone. This is NOT a public algorithm/obfuscator or practical hiding result: uniform permutations of 2^n elements are exponentially large, their descriptions are withheld, and correlated auxiliary input (notably public verification keys or a public forward L) is excluded. Exposing forward L restores Simon. No new local-mixing assumption is introduced.
