# Run 426 — full-table nonbijective gates leak exact fiber spectra

**Narrow mathematical result, not CCMR/RIO/iO security and not a PQ witness-KEM.** Actual PR starting head `784f005cdfc6925505e58ecddd1e76e2fa13cda1` on `research/pq-wkem-validation-20260918`, draft/unmerged. Exact previous checkpoints read: Run 425 `511cfd34cee890a7ac338c6fcf871b6b735ca73d` and Run 424 `7c8bbbd205dadc3431044588daebdf13ed20b811`. This new attack requires **no exposed boundary pin** but assumes that the complete table of a **nonbijective small gate** is public and polynomially enumerable.

Let f:[n]->[m] be a fixed local function. Honest classical setup samples *independent uniform* U in S_n and V in S_m, and publishes the complete table g=V f U^{-1}. Define the fiber profile phi(f) as the sorted list of cardinalities of f^{-1}(y), including empty fibers. If a_r is the count of outputs with r preimages, sum_r a_r=m and sum_r r a_r=n.

**Exact orbit theorem.** Distribution of g is uniform on the orbit of f under two-sided relabeling. Two source functions have identical full-table transcript laws iff their fiber profiles agree; otherwise their supports are **disjoint**. The orbit contains exactly

N_orbit = n! m! / product_{r=0}^n ( (r!)^{a_r} * a_r! )

different tables, each with probability 1/N_orbit. The adversary obtains phi(f)=phi(g) by scanning the public table, in O(n+m) work. Proof: reassigning input labels preserves fiber cardinalities and reassigning output labels merely permutes fibers. Matching equal-cardinality fibers and bijecting their inputs proves the converse. The stabilizer permits a_r! permutations of equal-sized output fibers and (r!)^{a_r} permutations of their inputs. Orbit-stabilizer gives the formula and uniform law.

**Security relevance.** Independently randomized complete tables cannot hide whether a local irreversible gate is constant, balanced or has another fiber spectrum. For a two-input Boolean gate, AND has 3/1 preimages, XOR 2/2, and a constant gate 4/0. If secret signing-key bits select between these gate classes, the table exposes those bits regardless of hidden U,V. This is a deliberately broken release encoding, **not** a general release attack: the fingerprint alone does not imply knowledge of arbitrary secret K. The attack is efficient only when the gate domain is polynomial-sized and enumerable; it says nothing about black-box exponentially large functions or the actual CCMR randomized reversible circuits.

**Reversible embedding as structural repair, not release:** Given f(x) encoded on b bits, F(x,z)=(x,z XOR f(x)) is a permutation on (x,z), eliminating this particular nonbijective-gate fingerprint. However public clean-ancilla conditions and exposed input/output labels still require the separate seam tests from Runs 423–425. Reversibility does not authenticate late ORIGINAL witnesses, hide a native signing capability, or establish true-instance recovery extraction.

Ed25519 is **not PQ**; neither checker establishes cryptographic security.

**Attack ledger.** (1) no neighboring seam needed; (2) no hidden frame recovered; (3) exact statistical function-class fingerprint; (4) works within one capsule and persists under composition; (5) full public truth-table evaluation; (6) works with honestly independent masks, malicious setups untested; (7) context-specific per-UTXO frames do not fix same-gate leakage; (8) a correlated public native verification key cannot recover already-lost secret entropy; (9) classical deterministic polynomial-in-table attack, hence QPT-applicable, with no new quantum algorithm. Honest setup/evaluation are classical PPT for polynomial-size local gates; attacker can be arbitrary QPT with all public checking keys, auxiliary inputs, multiple capsules, and coherent evaluator access. This negative result uses no LWE/SIS assumption, random oracle, extraction, or rewinding.
