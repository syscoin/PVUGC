# Run 690 — Total reversible release projection preserves the quantum-search density

Research-only; **not** a practical PQ witness-KEM or a break of RIO/CLZ. Live starting PR: 'syscoin/PVUGC#1', draft/unmerged, branch 'research/pq-wkem-validation-20260918', SHA 'e2475ac272b493857e7969b93575047cc1e5776c'. **Exact model.** Classical PPT setup publishes a publicly and coherently evaluable *total bijection* 'F:{0,1}^n -> {0,1}^n'. Anyone may supply any complete input 's'. The release credential is 'prefix_k(F(s))'. Under a fixed native public checking key, let 'S' be the nonempty set of k-bit candidates whose canonical Sign+Verify accepts the intended previously unsigned branch message. All auxiliary public values, including 'pk', are available to the QPT adversary. This model has NO authenticated-input restriction or protected reject flag.

**Theorem.** Each k-bit prefix has exactly '2^(n-k)' preimages under F. Hence the public signature-check predicate is true on exactly '|S|*2^(n-k)' input states: success density '|S|/2^k'. Local reversible mixing, gate depth, random relabeling and an inaccessible inverse do not alter this density. Quantum amplitude amplification over the public forward evaluator and native checker finds a signing-capable candidate in 'O(sqrt(2^k/|S|))' coherent calls; no source witness or hidden inverse is needed. This is a *concrete query bound*, not an asymptotic QPT break for k linear in the security parameter, and not a quantum gate-cost estimate.

**Witness-state capacity.** If 'M' distinct states from valid ORIGINAL witnesses produce the *same* exact credential, their different reversible outputs need different 'n-k'-bit garbage suffixes: 'M<=2^(n-k)'. This does NOT canonicalize witnesses. Crucially, 'M' need not equal the number of all signing-capable states. With 'n=512,k=128,M=1', the total projection has '2^384' accepting inputs and admits '2^64' Grover-query search, much cheaper than the generic Run 688 bound obtained from M alone. Enlarging n without changing k does not improve this candidate's query bound.

**Attack coverage.** The chosen-input/public-evaluation oracle, native checking-key correlation and genuine coherent quantum search are essential; seam cancellation, global frame synchronization, statistical gate fingerprints, malicious setup and related-capsule combinations are *not* required. Cross-UTXO replay and setup-retained secrets remain separate obligations. The theorem says nothing about a protected authenticity gate, restricted reachable state domain, source-dependent rejection, non-total mapping, or actual RIO/iO assumptions. A public prefix that is bypassable does not authenticate an ORIGINAL witness.

**Executed checker.** The exact Python checker tests NOT/CNOT/Toffoli/SWAP permutations at 3 wire widths, 5 depths and 4 deterministic seeds (60 complete fiber-count cases) plus 30 state-vector Grover probabilities and capacity checks. Python compilation and two byte-identical runs pass. This is finite algebra, **not** cryptographic testing.

**Handoff.** Run 259 only extracts an ORIGINAL witness from an accepted *complete SOURCE representation*. Finding a candidate native signing key does not supply that representation. No new hardness assumption was introduced. Next test a specific compact *protected rejection/source-authentication* gadget; reversible input mixing alone cannot enforce the needed WE-like release. Complete all-witness correctness, false-instance QPT hiding, true-instance recovery/forgery-to-ORIGINAL, malicious N-of-N/abort, related capsules, concrete 128-bit parameters and conditional native SLH/P2MR Bitcoin enforcement remain UNPROVED.
