## Explicit attempted compiler

Let A_{i,0},A_{i,1} be known GL_d(F_p) branching-program matrices for a relation. An honest globally consistent input w yields product_i A_{i,w_i}=g!=I if accepted, otherwise I. Repeated occurrences of one wire must carry identical values. Setup selects secret invertible boundaries P_0,...,P_L and publishes

    B_{i,b}=P_{i-1}^{-1} A_{i,b} P_i
    C_target=P_0^{-1} g P_L          [secret: not published]
    D=S XOR SHA256(domain || serialize(C_target))
    Capsule=(A,B,D,domain)

Public prescribed opening on complete w computes E(w)=product_i B_{i,w_i} and D XOR SHA256(domain||serialize(E(w))). Every ACCEPTING globally consistent w gives the SAME frozen S without knowing a canonical satisfying witness. This is serialized and classical polynomial-time at fixed matrix width, but full-public security is unproved until the next analysis.

## Exact full-public recovery lemma

An attacker can choose arbitrary LOCAL occurrence bit strings z even when repeated occurrences disagree, without providing an ORIGINAL witness. Compute public A(z)=product_i A_{i,z_i}, B(z)=product_i B_{i,z_i}. Both satisfy B(z)=P_0^{-1} A(z) P_L. Form a HOMOGENEOUS LINEAR system in 2*d*d unknown entries X,Y:

    X B(z) - A(z) Y = 0   for chosen mixed words z.

The honest pair (P_0,P_L) solves every equation. If the system has a one-dimensional nullspace generated by an invertible endpoint pair, Gaussian elimination returns (X,Y)=(cP_0,cP_L). The common scalar c cancels, so

    C_rec = X^{-1} g Y = P_0^{-1} g P_L = C_target
    S_rec = D XOR SHA256(domain || serialize(C_rec)) = S.

Therefore for any instance meeting that exact rank condition the public capsule reveals S in polynomial time WITHOUT an accepting globally consistent witness. This is a conditional lemma about a concrete known-clear-program matrix-gauge construction, NOT a hash-only FE impossibility theorem. A classical break also breaks its intended QPT security.

If no accepting witness exists, two fixed distinct secrets S0,S1 are perfectly distinguishable in the FULL published distribution by recovering C_rec and XOR-decrypting D, so even FALSE security fails. No setup correctness ZK changes this.

One obvious repair, secretly applying local changes of basis, fails algebraically: for arbitrary secret invertible Q_i, set A'_{i,b}=Q_{i-1}^{-1} A_{i,b} Q_i, P'_i=Q_i^{-1} P_i, g'=Q_0^{-1} g Q_L. This leaves all public B_{i,b} and the target matrix C unchanged; an attacker still uses the known canonical A and solves its endpoint linear system. A genuinely non-gauge-equivalent private randomized program would need a NEW compiler, proof of exact relation equivalence, and independent full-public security. We did not construct that repair.
