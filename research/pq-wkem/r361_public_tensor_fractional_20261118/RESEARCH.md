## Restricted candidate
Let F=GF(2^m). For a bounded-occurrence 3CNF, place a variable COPY tensor `E_i(a_1,...,a_d) = 1[all a_j equal]` at each variable and clause tensor `T_j(b_1,b_2,b_3)=1[clause j satisfied]` at every clause. Multiply the satisfying entries at one designated clause j0 by a frozen nonzero secret field element S. Independently pick each incidence matrix `B_(i,j) in GL_2(F)`, transform every COPY leg by B and every incident clause leg by B inverse, and publish *all* transformed tensors. For constant variable degree, the published tensors have polynomial size. Under consistent hidden-bit channel labels, any satisfying global assignment yields exactly S; gauge contributions cancel. This is conditional correctness, not an actual source-dependent Build/Open: the future ORIGINAL evidence-to-bit-channel interface has not been built.

The architectural change was to share one COPY tensor across *all* occurrences of a variable, hoping a public tensor would cryptographically enforce global witness consistency instead of allowing independent local garbled labels. We test the complete public tensor distribution, not an ideal oracle.

## Executable FALSE counterexample and algebra
Three Boolean variables x,y,z, and eight clauses j=0..7, each forbidding precisely the corresponding 3-bit tuple j, form an UNSAT 3CNF. Each variable has degree 8 and its COPY tensor contains 256 entries. For every variable, the published transformed COPY tensor has tensor rank two:
`E'_i = sum_(b=0,1) tensor_(j=0)^7 B_(i,j)[:,b]`.
The attacking code sees *only* E'_i and the published transformed clause tensors, never the private B.

Each COPY tensor can be decomposed in public polynomial time at this fixed degree: contract its final five legs against the standard covector e0, giving a 2x2x2 tensor with first two slices M0,M1. Generically `M0` is invertible and `M1 M0^-1` has two distinct eigenvalues; its eigenvectors recover the first-leg column modes up to permutation/scaling. Dual-mode contraction of the full 8-mode tensor isolates two rank-one 7-mode tensors, factorizable by coordinate ratios. This recovers factors L_(i,j,b) such that `E'_i=sum_b tensor_j L_(i,j,b)` EXACTLY. The checker verifies the reconstruction on all 256 public entries for every variable.

For each clause j and local assignment a=(a_x,a_y,a_z), contract its PUBLIC transformed tensor against `L_(x,j,a_x),L_(y,j,a_y),L_(z,j,a_z)`, yielding a public value `q_(j,a)`. Exactly one of eight is zero and seven nonzero. The recovered 0/1 mode order may be globally permuted per variable; the forbidden triples still enumerate all eight possibilities, so neither the source labels nor a secret permutation is required.

For each clause j choose P_j, the four three-bit local assignments with parity *opposite* the parity of that clause's unique forbidden tuple. They are ALL locally satisfying, and each variable's two values appear exactly twice in P_j. But their choices across the eight clauses are incompatible; there is NO global satisfying witness.

Let gamma_(i,j,b) denote the unobserved proportionality of recovered L_(i,j,b) to the corresponding original B column. Exact coefficient-one COPY decomposition implies `product_j gamma_(i,j,b)=1` for each i,b. Then the PUBLIC product
`Q=product_(j=0)^7 product_(a in P_j) q_(j,a)`
is `S^4 * product_(i,b)(product_j gamma_(i,j,b))^2 = S^4`: four copies of S from clause j0, all random gauge scalings canceled by balanced *fractional local assignments*. In GF(2^m), fourth powering is invertible, so `S=Q^(2^(m-2))`. This is an exact **classical public FALSE recovery**, hence a QPT-valid attack, on a genuinely nonlinear local SAT gadget. It needs no accepted witness, query log, private gauge, or oracle access.
